Example 3.3.20 A transformation defined in steps.

Let \(T\colon\R^3\to\R^3\) be the linear transformation that reflects over the \(xy\)-plane and then projects onto the \(yz\)-plane. What is the standard matrix for \(T\text{?}\)
🔗

Solution.

This transformation is described geometrically, in two steps. To find the columns of \(A\text{,}\) we need to follow the standard coordinate vectors through each of these steps. \def\drawarrow#1{ \begin{tikzpicture}[myxyz, y={(1cm,-.28cm)}, scale=0.8, thin border nodes, baseline] \path[clip, resetxy] (-2,-2) rectangle (2,2); \begin{scope}[transformxy] \fill[blue, opacity=.05] (-1.5,-1.5) rectangle (1.5,1.5); \draw[step=1cm, help lines, blue!40!black] (-1.5, -1.5) grid (1.5, 1.5); \end{scope} \node[blue!40!black,right] at (-.5,.8,-.5) {$xy$}; \begin{scope}[transformyz] \fill[green, opacity=.05] (-1.5,-1.5) rectangle (1.5,1.5); \draw[step=1cm, help lines, green!40!black] (-1.5, -1.5) grid (1.5, 1.5); \end{scope} \node[green!40!black] at (.75,-1,1) {$yz$}; #1 \end{tikzpicture} } \drawarrow{\draw[vector] (0,0,0) -- (1,0,0) node[below right, pos=.5] {$e_1$};} $\xrightarrow{\text{reflect $xy$}}$ \drawarrow{\draw[vector] (0,0,0) -- (1,0,0);} $\xrightarrow{\text{project $yz$}}$ \drawarrow{\point at (0,0,0);} Since \(e_1\) lies on the \(xy\)-plane, reflecting over the \(xy\)-plane does not move \(e_1\text{.}\) Since \(e_1\) is perpendicular to the \(yz\)-plane, projecting \(e_1\) onto the \(yz\)-plane sends it to zero. Therefore,
\begin{gather*} T(e_1) = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
\drawarrow{\draw[vector] (0,0,0) -- (0,1,0) node[below left, pos=.6] {$e_2$};} $\xrightarrow{\text{reflect $xy$}}$ \drawarrow{\draw[vector] (0,0,0) -- (0,1,0);} $\xrightarrow{\text{project $yz$}}$ \drawarrow{\draw[vector] (0,0,0) -- (0,1,0);} Since \(e_2\) lies on the \(xy\)-plane, reflecting over the \(xy\)-plane does not move \(e_2\text{.}\) Since \(e_2\) lies on the \(yz\)-plane, projecting onto the \(yz\)-plane does not move \(e_2\) either. Therefore,
\begin{gather*} T(e_2) = e_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}\text{.} \end{gather*}
\drawarrow{\draw[vector] (0,0,0) -- (0,0,1) node[left, pos=.4] {$e_3$};} $\xrightarrow{\text{reflect $xy$}}$ \drawarrow{\draw[vector] (0,0,0) -- (0,0,-1);} $\xrightarrow{\text{project $yz$}}$ \drawarrow{\draw[vector] (0,0,0) -- (0,0,-1);} Since \(e_3\) is perpendicular to the \(xy\)-plane, reflecting over the \(xy\)-plane takes \(e_3\) to its negative. Since \(-e_3\) lies on the \(yz\)-plane, projecting onto the \(yz\)-plane does not move it. Therefore,
\begin{gather*} T(e_3) = -e_3 = \begin{pmatrix} 0 \\ 0 \\ -1 \end{pmatrix}\text{.} \end{gather*}
Now we have computed all three columns of \(A\text{:}\)
\begin{align*} \left.\begin{aligned} T(e_1) \amp= \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix} \\ T(e_2) \amp= \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} \\ T(e_1) \amp= \begin{pmatrix} 0 \\ 0 \\ -1 \end{pmatrix} \\ \end{aligned}\right\} \implies A = \begin{pmatrix} 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp -1 \end{pmatrix}\text{.} \end{align*}
