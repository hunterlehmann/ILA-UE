Example 2.4.7 The solution set is a line.

Compute the parametric vector form of the solution set of \(Ax=0\text{,}\) where
\begin{align*} A = \begin{pmatrix} 1 \amp -3 \\ 2 \amp -6 \end{pmatrix}\text{.} \end{align*}
🔗

Solution.

We row reduce (without augmenting, as suggested in the above Example 4):
\begin{align*} \begin{pmatrix} 1 \amp -3 \\ 2 \amp -6 \end{pmatrix} \quad\xrightarrow{\text{RREF}}\quad \begin{pmatrix} 1 \amp -3 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
This corresponds to the single equation \(x_1 - 3x_2=0\text{.}\) We write the parametric form including the redundant equation \(x_2=x_2\text{:}\)
\begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp 3x_2 \amp {} \\ x_2 \amp {}={} \amp x_2 \amp . \end{alignedat}\right. \end{align*}
We turn these into a single vector equation:
\begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = x_2\begin{pmatrix} 3 \\ 1 \end{pmatrix}\text{.} \end{gather*}
This is the parametric vector form of the solution set. Since \(x_2\) is allowed to be anything, this says that the solution set is the set of all scalar multiples of \({3\choose 1}\text{,}\) otherwise known as
\begin{gather*} \Span\left\{\begin{pmatrix} 3 \\ 1 \end{pmatrix}\right\}\text{.} \end{gather*}
