Example 3.2.34 Matrix transformations that are both one-to-one and onto.

In Subsection 3.1.1, we discussed the transformations defined by several \(2\times 2\) matrices, namely:
\begin{align*} \text{Reflection:} \amp\qquad A=\begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Dilation:} \amp\qquad A=\begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}\\ \text{Identity:} \amp\qquad A=\begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Rotation:} \amp\qquad A=\begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}\\ \text{Shear:} \amp\qquad A=\begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
In each case, the associated matrix transformation \(T(x)=Ax\) is both one-to-one and onto. A \(2\times 2\) matrix \(A\) has a pivot in every row if and only if it has a pivot in every column (if and only if it has two pivots), so in this case, the transformation \(T\) is one-to-one if and only if it is onto. One can see geometrically that they are onto (what is the input for a given output?), or that they are one-to-one using the fact that the columns of \(A\) are not collinear.
