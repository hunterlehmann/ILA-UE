Note A.0.5.

If \(f\) is a polynomial with real coefficients, and if \(\lambda\) is a complex root of \(f\text{,}\) then so is \(\bar\lambda\text{:}\)
\begin{align*} 0 = \bar{f(\lambda)} \amp= \bar{\lambda^n + a_{n-1}\lambda^{n-1}+\cdots+a_1\lambda+a_0}\\ \amp= \bar\lambda{}^n + a_{n-1}\bar\lambda{}^{n-1}+\cdots+a_1\bar\lambda+a_0 = f\bigl(\bar\lambda\bigr)\text{.} \end{align*}
Therefore, complex roots of real polynomials come in conjugate pairs.
