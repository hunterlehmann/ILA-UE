Example 3.2.12 A matrix transformation that is not one-to-one.

Let
\begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\text{,} \end{align*}
and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) Is \(T\) one-to-one? If not, find two different vectors \(u,v\) such that \(T(u)=T(v)\text{.}\)
🔗

Solution.

The reduced row echelon form of \(A\) is
\begin{align*} \begin{pmatrix} 1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
There is not a pivot in every column, so \(T\) is not one-to-one. Therefore, we know from the Theorem 5 that \(Ax=0\) has nontrivial solutions. If \(v\) is a nontrivial (i.e., nonzero) solution of \(Av = 0\text{,}\) then \(T(v) = Av = 0 = A0 = T(0)\text{,}\) so \(0\) and \(v\) are different vectors with the same output. In order to find a nontrivial solution, we find the parametric form of the solutions of \(Ax=0\) using the reduced matrix above:
\begin{gather*} x - y + 2z = 0 \quad\implies\quad x = y - 2z\text{.} \end{gather*}
The free variables are \(y\) and \(z\text{.}\) Taking \(y=1\) and \(z=0\) gives the nontrivial solution
\begin{align*} T\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = 0 = T\begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{align*}
