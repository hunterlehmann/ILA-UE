Example 2.4.3 No nontrivial solutions.

What is the solution set of \(Ax=0\text{,}\) where
\begin{align*} A = \begin{pmatrix} 1 \amp 3 \amp 4 \\ 2 \amp -1 \amp 2 \\ 1 \amp 0 \amp 1 \end{pmatrix}? \end{align*}
🔗

Solution.

We form an augmented matrix and row reduce:
\begin{align*} \left(\begin{array}{rrr|r} 1 \amp 3 \amp 4 \amp 0 \\ 2 \amp -1 \amp 2 \amp 0 \\ 1 \amp 0 \amp 1 \amp 0 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \left(\begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \end{array}\right)\text{.} \end{align*}
The only solution is the trivial solution \(x=0\text{.}\)
