Example 5.3.18 A diagonalizable \(3\times 3\) matrix.

Diagonalize the matrix
\begin{align*} A = \begin{pmatrix} 4 \amp -3 \amp 0 \\ 2 \amp -1 \amp 0 \\ 1 \amp -1 \amp 1 \end{pmatrix}\text{.} \end{align*}
🔗

Solution.

We need to find the eigenvalues and eigenvectors of \(A\text{.}\) First we compute the characteristic polynomial by expanding cofactors along the third column:
\begin{align*} f(\lambda) \amp= \det(A-\lambda I_3) = (1-\lambda)\det\left(\begin{pmatrix} 4 \amp -3 \\ 2 \amp -1 \end{pmatrix} - \lambda I_2\right)\\ \amp= (1-\lambda)(\lambda^2 - 3\lambda + 2) = -(\lambda-1)^2(\lambda-2)\text{.} \end{align*}
Therefore, the eigenvalues are \(1\) and \(2\text{.}\) We need to compute eigenvectors for each eigenvalue. We start with \(\lambda_1 = 1\text{:}\)
\begin{align*} (A-I_3)v = 0 \iff \begin{pmatrix} 3 \amp -3 \amp 0 \\ 2 \amp -2 \amp 0 \\ 1 \amp -1 \amp 0 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
The parametric vector form is
\begin{align*} \left\{\begin{alignedat}{2} x \amp {}={} \amp y \amp {} \\ y \amp {}={} \amp y \amp {} \\ z \amp {}={} \amp z \amp {} \end{alignedat}\right. \implies \begin{pmatrix} x \\ y \\ z \end{pmatrix} = y\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + z\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{align*}
Hence a basis for the \(1\)-eigenspace is
\begin{gather*} \cB_1 = \bigl\{ v_1,v_2 \bigr\} \sptxt{where} v_1 = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}, \quad v_2 = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
Now we compute the eigenspace for \(\lambda_2 = 2\text{:}\)
\begin{align*} (A-2I_3)v = 0 \iff \begin{pmatrix} 2 \amp -3 \amp 0 \\ 2 \amp -3 \amp 0 \\ 1 \amp -1 \amp -1 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 0 \amp -3 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 0 \end{pmatrix}v = 0 \end{align*}
The parametric form is \(x = 3z, y = 2z\text{,}\) so an eigenvector with eigenvalue \(2\) is
\begin{gather*} v_3 = \begin{pmatrix} 3 \\ 2 \\ 1 \end{pmatrix}\text{.} \end{gather*}
🔗
The eigenvectors \(v_1,v_2,v_3\) are linearly independent: \(v_1,v_2\) form a basis for the \(1\)-eigenspace, and \(v_3\) is not contained in the \(1\)-eigenspace because its eigenvalue is \(2\text{.}\) Therefore, the Theorem 11 says that
\begin{align*} A = CDC\inv \sptxt{for} C = \begin{pmatrix} 1 \amp 0 \amp 3 \\ 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
