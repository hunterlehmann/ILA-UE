Theorem 2.5.12.

A set of vectors \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent if and only if one of the vectors is in the span of the other ones.
🔗
Any such vector may be removed without affecting the span.
🔗
🔗

Proof.
Suppose, for instance, that \(v_3\) is in \(\Span\{v_1,v_2,v_4\}\text{,}\) so we have an equation like
\begin{gather*} v_3 = 2v_1 - \frac 12v_2 + 6v_4\text{.} \end{gather*}
We can subract \(v_3\) from both sides of the equation to get
\begin{gather*} 0 = 2v_1 - \frac 12v_2 - v_3 + 6v_4\text{.} \end{gather*}
This is a linear dependence relation.
🔗
In this case, any linear combination of \(v_1,v_2,v_3,v_4\) is already a linear combination of \(v_1,v_2,v_4\text{:}\)
\begin{align*} x_1v_1 + x_2v_2 + x_3v_3 + x_4v_4 \amp= x_1v_1 + x_2v_2 + x_3\left(2v_1-\frac 12v_2 + 6v_4\right) + x_4v_4\\ \amp= (x_1+2x_3)v_1 + \left(x_2-\frac 12x_3\right)v_2 + (x_4+6)v_4\text{.} \end{align*}
Therefore, \(\Span\{v_1,v_2,v_3,v_4\}\) is contained in \(\Span\{v_1,v_2,v_4\}\text{.}\) Any linear combination of \(v_1,v_2,v_4\) is also a linear combination of \(v_1,v_2,v_3,v_4\) (with the \(v_3\)-coefficient equal to zero), so \(\Span\{v_1,v_2,v_4\}\) is also contained in \(\Span\{v_1,v_2,v_3,v_4\}\text{,}\) and thus they are equal.
🔗
In the other direction, if we have a linear dependence relation like
\begin{gather*} 0 = 2v_1 - \frac 12v_2 + v_3 - 6v_4\text{,} \end{gather*}
then we can move any nonzero term to the left side of the equation and divide by its coefficient:
\begin{gather*} v_1 = \frac 12\left(\frac 12v_2 - v_3 + 6v_4\right)\text{.} \end{gather*}
This shows that \(v_1\) is in \(\Span\{v_2,v_3,v_4\}\text{.}\)
🔗
We leave it to the reader to generalize this proof for any set of vectors.
