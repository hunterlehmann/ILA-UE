Proposition 6.2.10 The orthogonal complement of a column space.

Let \(A\) be a matrix and let \(W=\Col(A)\text{.}\) Then
\begin{gather*} W^\perp = \Nul(A^T)\text{.} \end{gather*}
🔗
🔗

Proof.
To justify the first equality, we need to show that a vector \(x\) is perpendicular to the all of the vectors in \(W\) if and only if it is perpendicular only to \(v_1,v_2,\ldots,v_m\text{.}\) Since the \(v_i\) are contained in \(W\text{,}\) we really only have to show that if \(x\cdot v_1 = x\cdot v_2 = \cdots = x\cdot v_m = 0\text{,}\) then \(x\) is perpendicular to every vector \(v\) in \(W\text{.}\) Indeed, any vector in \(W\) has the form \(v = c_1v_1 + c_2v_2 + \cdots + c_mv_m\) for suitable scalars \(c_1,c_2,\ldots,c_m\text{,}\) so
\begin{align*} x\cdot v \amp= x\cdot(c_1v_1 + c_2v_2 + \cdots + c_mv_m)\\ \amp= c_1(x\cdot v_1) + c_2(x\cdot v_2) + \cdots + c_m(x\cdot v_m)\\ \amp= c_1(0) + c_2(0) + \cdots + c_m(0) = 0\text{.} \end{align*}
Therefore, \(x\) is in \(W^\perp.\)
🔗
To prove the second equality, we let
\begin{gather*} A = \begin{pmatrix} \matrow{v_1^T} \\ \matrow{v_2^T} \\ \vdots \\ \matrow{v_m^T} \end{pmatrix}\text{.} \end{gather*}
By the Definition 9 of Section 2.3, for any vector \(x\) in \(\R^n\) we have
\begin{gather*} Ax = \begin{pmatrix} v_1^Tx \\ v_2^Tx \\ \vdots \\ v_m^Tx \end{pmatrix} = \begin{pmatrix} v_1\cdot x \\ v_2\cdot x \\ \vdots \\ v_m\cdot x \end{pmatrix}\text{.} \end{gather*}
Therefore, \(x\) is in \(\Nul(A)\) if and only if \(x\) is perpendicular to each vector \(v_1,v_2,\ldots,v_m\text{.}\)
