Theorem 5.3.11.

An \(n\times n\) matrix \(A\) is diagonalizable if and only if \(A\) has \(n\) linearly independent eigenvectors.
🔗
In this case, \(A = CDC\inv\) for
\begin{align*} C = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_n \\ | \amp | \amp | \end{pmatrix} \qquad D = \begin{pmatrix} \lambda_1 \amp 0 \amp \cdots \amp 0 \\ 0 \amp \lambda_2 \amp \cdots \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp \lambda_n \end{pmatrix}\text{,} \end{align*}
where \(v_1,v_2,\ldots,v_n\) are linearly independent eigenvectors, and \(\lambda_1,\lambda_2,\ldots,\lambda_n\) are the corresponding eigenvalues, in the same order.
🔗
🔗

Proof.
First suppose that \(A\) has \(n\) linearly independent eigenvectors \(v_1,v_2,\ldots,v_n\text{,}\) with eigenvalues \(\lambda_1,\lambda_2,\ldots,\lambda_n\text{.}\) Define \(C\) as above, so \(C\) is invertible by the Theorem 31 of Section 5.1. Let \(D = C\inv A C\text{,}\) so \(A = CDC\inv\text{.}\) Multiplying by standard coordinate vectors picks out the columns of \(C\text{:}\) we have \(Ce_i = v_i\text{,}\) so \(e_i = C\inv v_i\text{.}\) We multiply by the standard coordinate vectors to find the columns of \(D\text{:}\)
\begin{gather*} De_i = C\inv A Ce_i = C\inv Av_i = C\inv\lambda_i v_i = \lambda_iC\inv v_i = \lambda_ie_i\text{.} \end{gather*}
Therefore, the columns of \(D\) are multiples of the standard coordinate vectors:
\begin{align*} D = \begin{pmatrix} \lambda_1 \amp 0 \amp \cdots \amp 0 \amp 0 \\ 0 \amp \lambda_2 \amp \cdots \amp 0 \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp \lambda_{n-1} \amp 0 \\ 0 \amp 0 \amp \cdots \amp 0 \amp \lambda_n \end{pmatrix}\text{.} \end{align*}
🔗
Now suppose that \(A = CDC\inv\text{,}\) where \(C\) has columns \(v_1,v_2,\ldots,v_n\text{,}\) and \(D\) is diagonal with diagonal entries \(\lambda_1,\lambda_2,\ldots,\lambda_n\text{.}\) Since \(C\) is invertible, its columns are linearly independent. We have to show that \(v_i\) is an eigenvector of \(A\) with eigenvalue \(\lambda_i\text{.}\) We know that the standard coordinate vector \(e_i\) is an eigenvector of \(D\) with eigenvalue \(\lambda_i\text{,}\) so:
\begin{gather*} Av_i = CDC\inv v_i = CDe_i = C\lambda_ie_i = \lambda_iCe_i = \lambda_i v_i\text{.} \end{gather*}
