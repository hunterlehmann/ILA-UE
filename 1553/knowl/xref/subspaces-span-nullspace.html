Recipe 2.6.18 Compute a spanning set for a null space.

To find a spanning set for \(\Nul(A)\text{,}\) compute the parametric vector form of the solutions to the homogeneous equation \(Ax=0\text{.}\) The vectors attached to the free variables form a spanning set for \(\Nul(A)\text{.}\)
