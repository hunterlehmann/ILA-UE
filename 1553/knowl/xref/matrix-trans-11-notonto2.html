Example 3.2.22 A matrix transformation that is not onto.

Let \(A\) be the matrix
\begin{align*} A = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
and define \(T\colon\R^2\to\R^3\) by \(T(x) = Ax\text{.}\) Is \(T\) onto? If not, find a vector \(b\) in \(\R^3\) such that \(T(x)=b\) has no solution.
🔗

Solution.

The reduced row echelon form of \(A\) is
\begin{align*} \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
Hence \(A\) does not have a pivot in every row, so \(T\) is not onto. In fact, since
\begin{align*} T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x \\ y \\ x \end{pmatrix}\text{,} \end{align*}
we see that for every output vector of \(T\text{,}\) the third entry is equal to the first. Therefore,
\begin{gather*} b=(1,2,3) \end{gather*}
is not in the range of \(T\text{.}\)
