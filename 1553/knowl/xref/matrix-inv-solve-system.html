Theorem 3.5.11.

Let \(A\) be an invertible \(n\times n\) matrix, and let \(b\) be a vector in \(\R^n.\) Then the matrix equation \(Ax=b\) has exactly one solution:
\begin{gather*} x = A\inv b\text{.} \end{gather*}
🔗
🔗

Proof.
We calculate:
\begin{align*} Ax = b \quad\implies\amp\quad A\inv(Ax) = A\inv b\\ \quad\implies\amp\quad (A\inv A)x = A\inv b\\ \quad\implies\amp\quad I_n x = A\inv b\\ \quad\implies\amp\quad x = A\inv b\text{.} \end{align*}
Here we used associativity of matrix multiplication, and the fact that \(I_n x = x\) for any vector \(b\text{.}\)
