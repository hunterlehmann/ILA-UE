Corollary 3.6.4 A Left or Right Inverse Suffices.

Let \(A\) be an \(n\times n\) matrix, and suppose that there exists an \(n\times n\) matrix \(B\) such that \(AB=I_n\) or \(BA=I_n\text{.}\) Then \(A\) is invertible and \(B = A\inv\text{.}\)
🔗
🔗

Proof.
Suppose that \(AB = I_n\text{.}\) We claim that \(T(x)=Ax\) is onto. Indeed, for any \(b\) in \(\R^n\text{,}\) we have
\begin{gather*} b = I_nb = (AB)b = A(Bb)\text{,} \end{gather*}
so \(T(Bb) = b\text{,}\) and hence \(b\) is in the range of \(T\text{.}\) Therefore, \(A\) is invertible by the Theorem 1. Since \(A\) is invertible, we have
\begin{gather*} A\inv = A\inv I_n = A\inv (AB) = (A\inv A)B = I_n B = B\text{,} \end{gather*}
so \(B = A\inv.\)
🔗
Now suppose that \(BA = I_n\text{.}\) We claim that \(T(x) = Ax\) is one-to-one. Indeed, suppose that \(T(x) = T(y)\text{.}\) Then \(Ax = Ay\text{,}\) so \(BAx = BAy\text{.}\) But \(BA = I_n\text{,}\) so \(I_nx = I_ny\text{,}\) and hence \(x=y\text{.}\) Therefore, \(A\) is invertible by the Theorem 1. One shows that \(B = A\inv\) as above.
