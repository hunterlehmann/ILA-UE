Example 5.3.8.

If a matrix \(A\) is diagonalizable, and if \(B\) is similar to \(A\text{,}\) then \(B\) is diagonalizable as well. Indeed, if \(A = CDC\inv\) for \(D\) diagonal, and \(B = EAE\inv\text{,}\) then
\begin{gather*} B = EAE\inv = E(CDC\inv)E\inv = (EC)D(EC)\inv\text{,} \end{gather*}
so \(B\) is similar to \(D\text{.}\)
