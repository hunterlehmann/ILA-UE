Remark 5.3.30 Non-diagonalizable \(2\times 2\) matrices with an eigenvalue.

As in the above Example 21, one can check that the matrix
\begin{align*} A_\lambda = \begin{pmatrix} \lambda \amp 1 \\ 0 \amp \lambda \end{pmatrix} \end{align*}
is not diagonalizable for any number \(\lambda\text{.}\) We claim that any non-diagonalizable \(2\times 2\) matrix \(B\) with a real eigenvalue \(\lambda\) is similar to \(A_\lambda\text{.}\) Therefore, up to similarity, these are the only such examples.
🔗
To prove this, let \(B\) be such a matrix. Let \(v_1\) be an eigenvector with eigenvalue \(\lambda\text{,}\) and let \(v_2\) be any vector in \(\R^2\) that is not collinear with \(v_1\text{,}\) so that \(\{v_1,v_2\}\) forms a basis for \(\R^2\text{.}\) Let \(C\) be the matrix with columns \(v_1,v_2\text{,}\) and consider \(A = C\inv BC\text{.}\) We have \(Ce_1=v_1\) and \(Ce_2=v_2\text{,}\) so \(C\inv v_1=e_1\) and \(C\inv v_2=e_2\text{.}\) We can compute the first column of \(A\) as follows:
\begin{gather*} Ae_1 = C\inv BC e_1 = C\inv Bv_1 = C\inv\lambda v_1 = \lambda C\inv v_1 = \lambda e_1\text{.} \end{gather*}
Therefore, \(A\) has the form
\begin{align*} A = \begin{pmatrix} \lambda \amp b \\ 0 \amp d \end{pmatrix}\text{.} \end{align*}
Since \(A\) is similar to \(B\text{,}\) it also has only one eigenvalue \(\lambda\text{;}\) since \(A\) is upper-triangular, this implies \(d=\lambda\text{,}\) so
\begin{align*} A = \begin{pmatrix} \lambda \amp b \\ 0 \amp \lambda \end{pmatrix}\text{.} \end{align*}
As \(B\) is not diagonalizable, we know \(A\) is not diagonal (\(B\) is similar to \(A\)), so \(b\neq 0\text{.}\) Now we observe that
\begin{align*} \begin{pmatrix} 1/b \amp 0 \\ 0 \amp 1 \end{pmatrix}\begin{pmatrix} \lambda \amp b \\ 0 \amp \lambda \end{pmatrix}\begin{pmatrix} 1/b \amp 0 \\ 0 \amp 1 \end{pmatrix}\inv = \begin{pmatrix} \lambda/b \amp 1 \\ 0 \amp \lambda \end{pmatrix}\begin{pmatrix} b \amp 0 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} \lambda \amp 1 \\ 0 \amp \lambda \end{pmatrix} = A_\lambda\text{.} \end{align*}
We have shown that \(B\) is similar to \(A\text{,}\) which is similar to \(A_\lambda\text{,}\) so \(B\) is similar to \(A_\lambda\) by Example 8.
