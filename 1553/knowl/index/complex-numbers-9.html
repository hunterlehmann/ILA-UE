Note A.0.2 Arithmetic of Complex Numbers.

We can perform all of the usual arithmetic operations on complex numbers: add, subtract, multiply, divide, absolute value. There is also an important new operation called complex conjugation.
  • Addition is performed componentwise:
    \begin{gather*} (a + bi) + (c + di) = (a + c) + (b + d)i\text{.} \end{gather*}
    🔗
    🔗
  • Multiplication is performed using distributivity and \(i^2=-1\text{:}\)
    \begin{gather*} (a+bi)(c+di) = ac + adi + bci + bdi^2 = (ac-bd) + (ad+bc)i\text{.} \end{gather*}
    🔗
    🔗
  • Complex conjugation replaces \(i\) with \(-i\text{,}\) and is denoted with a bar:
    \begin{gather*} \bar{a+bi} = a - bi\text{.} \end{gather*}
    The number \(\bar{a+bi}\) is called the complex conjugate of \(a+bi\text{.}\) One checks that for any two complex numbers \(z,w\text{,}\) we have
    \begin{gather*} \bar{z+w} = \bar z + \bar w \sptxt{and} \bar{zw} = \bar z\cdot\bar w\text{.} \end{gather*}
    Also, \((a+bi)(a-bi) = a^2 + b^2\text{,}\) so \(z\bar z\) is a nonnegative real number for any complex number \(z\text{.}\)
    🔗
    🔗
  • The absolute value of a complex number \(z\) is the real number \(|z| = \sqrt{z\bar z}\text{:}\)
    \begin{gather*} |a+bi| = \sqrt{a^2 + b^2}\text{.} \end{gather*}
    One chacks that \(|zw| = |z|\cdot|w|.\)
    🔗
    🔗
  • Division by a nonzero real number proceeds componentwise:
    \begin{gather*} \frac{a+bi}c = \frac ac + \frac bci\text{.} \end{gather*}
    🔗
    🔗
  • Division by a nonzero complex number requires multiplying the numerator and denominator by the complex conjugate of the denominator:
    \begin{gather*} \frac zw = \frac{z\bar w}{w\bar w} = \frac{z\bar w}{|w|^2}\text{.} \end{gather*}
    For example,
    \begin{gather*} \frac{1+i}{1-i} = \frac{(1+i)^2}{1^2+(-1)^2} = \frac{1+2i+i^2}2 = i\text{.} \end{gather*}
    🔗
    🔗
  • The real and imaginary parts of a complex number are
    \begin{gather*} \Re(a+bi) = a \qquad \Im(a+bi) = b\text{.} \end{gather*}
