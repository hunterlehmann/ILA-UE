Example 3.5.19 Rotation.

Let \(T\colon\R^2\to\R^2\) be counterclockwise rotation by \(45^\circ\text{.}\) Is \(T\) invertible? If so, what is \(T\inv\text{?}\)
🔗

Solution.

Let \(U\colon\R^2\to\R^2\) be clockwise rotation by \(45^\circ\text{.}\) Then \(T\circ U\) first rotates clockwise by \(45^\circ\text{,}\) then counterclockwise by \(45^\circ\text{,}\) so the composition rotates by zero degrees: it is the identity transformation. Likewise, \(U\circ T\) first rotates counterclockwise, then clockwise by the same amount, so it is the identity transformation.
