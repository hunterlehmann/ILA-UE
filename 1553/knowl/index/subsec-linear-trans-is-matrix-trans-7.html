Example 3.3.17 The matrix of a dilation.

Define \(T\colon\R^2\to\R^2\) by \(T(x)=1.5x\text{.}\) Find the standard matrix \(A\) for \(T\text{.}\)
🔗

Solution.

The columns of \(A\) are obtained by evaluating \(T\) on the standard coordinate vectors \(e_1,e_2\text{.}\)
\begin{align*} \left.\begin{aligned} T(e_1) \amp= 1.5e_1 = \begin{pmatrix} 1.5 \\ 0 \end{pmatrix} \\ T(e_2) \amp= 1.5e_2 = \begin{pmatrix} 0 \\ 1.5 \end{pmatrix} \end{aligned}\right\} \implies A = \begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}\text{.} \end{align*}
This is the matrix we started with in Example 9 of Section 3.1.
