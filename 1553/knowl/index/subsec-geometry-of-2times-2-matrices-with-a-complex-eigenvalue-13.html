Note 5.4.13 Dynamics of a \(2\times 2\) Matrix with a Complex Eigenvalue.

Let \(A\) be a \(2\times 2\) matrix with a complex (non-real) eigenvalue \(\lambda\text{.}\) By the Theorem 7, the matrix \(A\) is similar to a matrix that rotates by some amount and scales by \(|\lambda|\text{.}\) Hence, \(A\) rotates around an ellipse and scales by \(|\lambda|\text{.}\) There are three different cases.
🔗
\(\mh{|\lambda|} > 1\text{:}\) when the scaling factor is greater than \(1\text{,}\) then vectors tend to get longer, i.e., farther from the origin. In this case, repeatedly multiplying a vector by \(A\) makes the vector “spiral out”. For example,
\begin{align*} A = \frac 1{\sqrt 2}\begin{pmatrix} \sqrt3+1 \amp -2 \\ 1 \amp \sqrt3-1 \end{pmatrix} \qquad \lambda = \frac{\sqrt3-i}{\sqrt 2} \qquad |\lambda| = \sqrt 2 > 1 \end{align*}
gives rise to the following picture: \pgfmathsetmacro{\sqrtii}{sqrt(2)} \begin{tikzpicture}[scale=1, samples at={0,.25,...,4.25}, smooth, tension=.5, thin border nodes=2pt] \draw[dashed, cm={1,1,-1,0,(0,0)}] (0,0) ellipse[radius=10/4]; \draw[->, very thin] (-4,0) -- (4,0); \draw[->, very thin] (0,-4) -- (0,4); \begin{scope}[cm={1,1,-1,0,(0,0)}, <->/.tip={Stealth}] \foreach \rot in {0,60,...,359} { \draw[seq-blue,rotate=\rot] plot ({\sqrtii^\x*cos(\x*30)},{\sqrtii^\x*sin(\x*30)}); % Can’t use decorations.markings for this; it exceeds TeX’s limited % capacity for numerical calculations. \foreach \x in {0,3,4.25} { \draw[seq-blue,->,rotate=\rot] ({\sqrtii^\x*cos(\x*30)},{\sqrtii^\x*sin(\x*30)}) -- ({\sqrtii^(\x+.1)*cos((\x+.1)*30)},{\sqrtii^(\x+.1)*sin((\x+.1)*30)}); } } \foreach \x in {0,1,2,3} { \pgfmathsetmacro{\y}{\x+1.1} \coordinate (v\x) at ({\sqrtii^\y*cos(\y*30+180)},{\sqrtii^\y*sin(\y*30+180)}); \draw[vector,seq-green] (0,0) -- (v\x) node[point,seq-green,scale=.5] {}; } \end{scope} \foreach \x in {0,1,2,3} { \pgfmathanglebetweenpoints{\pgfpoint{0cm}{0cm}}{\pgfpointanchor{v\x}{center}} \node[anchor={\pgfmathresult+180},seq-green] at (v\x) {$\ifnum\x>0\ifnum\x>1A^\x\else A\fi\fi v$}; } \point at (0,0); \end{tikzpicture}
🔗
\(\mh{|\lambda|} = 1\text{:}\) when the scaling factor is equal to \(1\text{,}\) then vectors do not tend to get longer or shorter. In this case, repeatedly multiplying a vector by \(A\) simply “rotates around an ellipse”. For example,
\begin{align*} A = \frac 12\begin{pmatrix} \sqrt3+1 \amp -2 \\ 1 \amp \sqrt3-1 \end{pmatrix} \qquad \lambda = \frac{\sqrt3-i}2 \qquad |\lambda| = 1 \end{align*}
gives rise to the following picture: \pgfmathsetmacro{\sqrtii}{sqrt(2)} \begin{tikzpicture}[scale=.25, thin border nodes=2pt, decoration={markings, mark=between positions 0 and .75 step .25 with {\arrow{Stealth}}}] \draw[->, very thin] (-16,0) -- (16,0); \draw[->, very thin] (0,-16) -- (0,16); \draw[postaction=decorate, seq-blue, cm={1,1,-1,0,(0,0)}] (0,0) ellipse[radius=10]; \foreach \x in {0,...,3} { \pgfmathsetmacro{\y}{\x-.4} \begin{scope}[cm={1,1,-1,0,(0,0)}] \coordinate (v\x) at ({10*cos(\y*30)},{10*sin(\y*30)}); \draw[vector,seq-green] (0,0) -- (v\x) node[point,seq-green,scale=.5] {}; \end{scope} \pgfmathanglebetweenpoints{\pgfpoint{0cm}{0cm}}{\pgfpointanchor{v\x}{center}} \node[anchor={\pgfmathresult+180},seq-green] at (v\x) {$\ifnum\x>0\ifnum\x>1A^\x\else A\fi\fi v$}; } \point at (0,0); \end{tikzpicture}
🔗
\(\mh{|\lambda|} \lt 1\text{:}\) when the scaling factor is less than \(1\text{,}\) then vectors tend to get shorter, i.e., closer to the origin. In this case, repeatedly multiplying a vector by \(A\) makes the vector “spiral in”. For example,
\begin{align*} A = \frac 1{2\sqrt 2}\begin{pmatrix} \sqrt3+1 \amp -2 \\ 1 \amp \sqrt3-1 \end{pmatrix} \qquad \lambda = \frac{\sqrt3-i}{2\sqrt 2} \qquad |\lambda| = \frac 1{\sqrt 2} \lt 1 \end{align*}
gives rise to the following picture: \pgfmathsetmacro{\sqrtii}{sqrt(2)} \begin{tikzpicture}[scale=1, samples at={0,.25,...,4.25}, smooth, tension=.5, thin border nodes=2pt] \draw[dashed, cm={1,1,-1,0,(0,0)}] (0,0) ellipse[radius=10/4]; \draw[->, very thin] (-4,0) -- (4,0); \draw[->, very thin] (0,-4) -- (0,4); \begin{scope}[cm={1,1,-1,0,(0,0)}, <->/.tip={Stealth}] \foreach \rot in {0,60,...,359} { \draw[seq-blue,rotate=\rot] plot ({-\sqrtii^\x*cos(\x*30)},{\sqrtii^\x*sin(\x*30)}); % Can’t use decorations.markings for this; it exceeds TeX’s limited % capacity for numerical calculations. \foreach \x in {0,3,4.25} { \draw[seq-blue,<-,rotate=\rot] ({-\sqrtii^\x*cos(\x*30)},{\sqrtii^\x*sin(\x*30)}) -- ({-\sqrtii^(\x+.1)*cos((\x+.1)*30)},{\sqrtii^(\x+.1)*sin((\x+.1)*30)}); } } \foreach \x in {3,2,1,0} { \pgfmathsetmacro{\y}{(3-\x)+1.1} \coordinate (v\x) at (-{\sqrtii^\y*cos(\y*30-120)},{\sqrtii^\y*sin(\y*30-120)}); \draw[vector,seq-green] (0,0) -- (v\x) node[point,seq-green,scale=.5] {}; } \end{scope} \foreach \x in {3,2,1,0} { \pgfmathanglebetweenpoints{\pgfpoint{0cm}{0cm}}{\pgfpointanchor{v\x}{center}} \node[anchor={\pgfmathresult+180},seq-green] at (v\x) {$\ifnum\x>0\ifnum\x>1A^\x\else A\fi\fi v$}; } \point at (0,0); \end{tikzpicture}
