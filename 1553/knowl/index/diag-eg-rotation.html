Example 5.3.27 A rotation matrix.

Let
\begin{align*} A = \begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
so \(T(x) = Ax\) is the linear transformation that rotates counterclockwise by \(90^\circ\text{.}\) We saw in Example 17 of Section 5.1 that \(A\) does not have any eigenvectors at all. It follows that \(A\) is not diagonalizable.
🔗
The characteristic polynomial of \(A\) is \(f(\lambda) = \lambda^2+1\text{,}\) which of course does not have any real roots. If we allow complex numbers, however, then \(f\) has two roots, namely, \(\pm i\text{,}\) where \(i = \sqrt{-1}\text{.}\) Hence the matrix is diagonalizable if we allow ourselves to use complex numbers. We will treat this topic in Section 5.4.
