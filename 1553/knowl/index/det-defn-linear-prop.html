Proposition 4.1.28 Multilinearity Property.

Let \(i\) be a whole number between \(1\) and \(n\text{,}\) and fix \(n-1\) vectors \(v_1,v_2,\ldots,v_{i-1},v_{i+1},\ldots,v_n\) in \(\R^n\text{.}\) Then the transformation \(T\colon\R^n\to\R\) defined by
\begin{gather*} T(x) = \det(v_1,v_2,\ldots,v_{i-1},x,v_{i+1},\ldots,v_n) \end{gather*}
is linear.
🔗
🔗

Proof.
First assume that \(i=1\text{,}\) so
\begin{gather*} T(x) = \det(x,v_2,\ldots,v_n)\text{.} \end{gather*}
We have to show that \(T\) satisfies the Definition 1 of Section 3.3.
  • By the first Definition 1, scaling any row of a matrix by a number \(c\) scales the determinant by a factor of \(c\text{.}\) This implies that \(T\) satisfies the second property, i.e., that
    \begin{gather*} T(cx) = \det(cx,v_2,\ldots,v_n) = c\det(x,v_2,\ldots,v_n) = cT(x)\text{.} \end{gather*}
    🔗
    🔗
  • We claim that \(T(v+w) = T(v) + T(w)\text{.}\) If \(w\) is in \(\Span\{v,v_2,\ldots,v_n\}\text{,}\) then
    \begin{gather*} w = cv + c_2v_2 + \cdots + c_nv_n \end{gather*}
    for some scalars \(c,c_2,\ldots,c_n\text{.}\) Let \(A\) be the matrix with rows \(v+w,v_2,\ldots,v_n\text{,}\) so \(T(v+w) = \det(A).\) By performing the row operations
    \begin{gather*} R_1 = R_1 - c_2R_2;\quad R_1 = R_1 - c_3R_3;\quad\ldots\quad R_1 = R_1 - c_nR_n\text{,} \end{gather*}
    the first row of the matrix \(A\) becomes
    \begin{gather*} v+w-(c_2v_2+\cdots+c_nv_n) = v + cv = (1+c)v\text{.} \end{gather*}
    Therefore,
    \begin{align*} T(v+w) = \det(A) \amp= \det((1+c)v,v_2,\ldots,v_n)\\ \amp= (1+c)\det(v,v_2,\ldots,v_n)\\ \amp= T(v) + cT(v) = T(v) + T(cv)\text{.} \end{align*}
    Doing the opposite row operations
    \begin{gather*} R_1 = R_1 + c_2R_2;\quad R_1 = R_1 + c_3R_3;\quad\ldots\quad R_1 = R_1 + c_nR_n \end{gather*}
    to the matrix with rows \(cv,v_2,\ldots,v_n\) shows that
    \begin{align*} T(cv) \amp= \det(cv,v_2,\ldots,v_n)\\ \amp= \det(cv+c_2v_2+\cdots+c_nv_n,v_2,\ldots,v_n)\\ \amp= \det(w,v_2,\ldots,v_n) = T(w)\text{,} \end{align*}
    which finishes the proof of the first property in this case.
    🔗
    Now suppose that \(w\) is not in \(\Span\{v,v_2,\ldots,v_n\}\text{.}\) This implies that \(\{v,v_2,\ldots,v_n\}\) is linearly dependent (otherwise it would form a basis for \(\R^n\)), so \(T(v)\) = 0. If \(v\) is not in \(\Span\{v_2,\ldots,v_n\}\text{,}\) then \(\{v_2,\ldots,v_n\}\) is linearly dependent by the Theorem 14 of Section 2.5, so \(T(x) = 0\) for all \(x\text{,}\) as the matrix with rows \(x,v_2,\ldots,v_n\) is not invertible. Hence we may assume \(v\) is in \(\Span\{v_2,\ldots,v_n\}\text{.}\) By the above argument with the roles of \(v\) and \(w\) reversed, we have \(T(v+w) = T(v)+T(w).\)
    🔗
    🔗
🔗
For \(i\neq 1\text{,}\) we note that
\begin{align*} T(x) \amp= \det(v_1,v_2,\ldots,v_{i-1},x,v_{i+1},\ldots,v_n)\\ \amp= -\det(x,v_2,\ldots,v_{i-1},v_1,v_{i+1},\ldots,v_n)\text{.} \end{align*}
By the previously handled case, we know that \(-T\) is linear:
\begin{gather*} -T(cx) = -cT(x) \qquad -T(v+w) = -T(v) - T(w)\text{.} \end{gather*}
Multiplying both sides by \(-1\text{,}\) we see that \(T\) is linear.
