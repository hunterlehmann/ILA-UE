Example 5.3.13 Easy Example.

Apply the Theorem 11 to the matrix
\begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\text{.} \end{align*}
🔗

Solution.

This diagonal matrix is in particular upper-triangular, so its eigenvalues are the diagonal entries \(1,2,3\text{.}\) The standard coordinate vectors are eigenvalues of a diagonal matrix:
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} = 1\cdot\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \qquad \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} = 2\cdot\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} \end{align*}
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = 3\cdot\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{align*}
Therefore, the diagonalization theorem says that \(A=CDC\inv\text{,}\) where the columns of \(C\) are the standard coordinate vectors, and the \(D\) is the diagonal matrix with entries \(1,2,3\text{:}\)
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\inv\text{.} \end{align*}
This just tells us that \(A\) is similar to itself.
🔗
Actually, the diagonalization theorem is not completely trivial even for diagonal matrices. If we put our eigenvalues in the order \(3,2,1\text{,}\) then the corresponding eigenvectors are \(e_3,e_2,e_1\text{,}\) so we also have that \(A = C'D'(C')\inv\text{,}\) where \(C'\) is the matrix with columns \(e_3,e_2,e_1\text{,}\) and \(D'\) is the diagonal matrix with entries \(3,2,1\text{:}\)
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} = \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix} \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix}\inv\text{.} \end{align*}
In particular, the matrices
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} \sptxt{and} \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
are similar to each other.
