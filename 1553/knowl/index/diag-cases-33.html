Example 5.3.55 Diagonalizability of \(3\times 3\) Matrices.

Let \(A\) be a \(3\times 3\) matrix. We can analyze the diagonalizability of \(A\) on a case-by-case basis, as in Example 54.
  1. \(A\) has three different eigenvalues. In this case, each eigenvalue has algebraic and geometric multiplicity equal to one. This implies \(A\) is diagonalizable. For example:
    \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 4 \\ 0 \amp 2 \amp 3 \\ 0 \amp 0 \amp -1 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
  2. \(A\) has two distinct eigenvalues \(\lambda_1,\lambda_2\text{.}\) In this case, one has algebraic multiplicity one and the other has algebraic multiplicity two; after reordering, we can assume \(\lambda_1\) has multiplicity \(1\) and \(\lambda_2\) has multiplicity \(2\text{.}\) This implies that \(\lambda_1\) has geometric multiplicity \(1\text{,}\) so \(A\) is diagonalizable if and only if the \(\lambda_2\)-eigenspace is a plane. For example:
    \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 4 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    On the other hand, if the geometric multiplicity of \(\lambda_2\) is \(1\text{,}\) then \(A\) is not diagonalizable. For example:
    \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 4 \\ 0 \amp 2 \amp 1 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
  3. \(A\) has only one eigenvalue \(\lambda\text{.}\) If the algebraic multiplicity of \(\lambda\) is \(1\text{,}\) then \(A\) is not diagonalizable. This happens when the characteristic polynomial has two complex (non-real) roots. For example:
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 0 \\ 1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    Otherwise, the algebraic multiplicity of \(\lambda\) is equal to \(3\text{.}\) In this case, if the geometric multiplicity is \(1\text{:}\)
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    or \(2\text{:}\)
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    then \(A\) is not diagonalizable. If the geometric multiplicity is \(3\text{,}\) then \(\Nul(A-\lambda I_3) = \R^3\text{,}\) so that \(A-\lambda I_3\) is the zero matrix, and hence \(A = \lambda I_3\text{.}\) Therefore, in this case \(A\) is necessarily diagonal, as in:
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
