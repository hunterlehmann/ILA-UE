Recipe 5.3.20 Diagonalization.

Let \(A\) be an \(n\times n\) matrix. To diagonalize \(A\text{:}\)
  1. Find the eigenvalues of \(A\) using the characteristic polynomial.
    🔗
    🔗
  2. For each eigenvalue \(\lambda\) of \(A\text{,}\) compute a basis \(\cB_\lambda\) for the \(\lambda\)-eigenspace.
    🔗
    🔗
  3. If there are fewer than \(n\) total vectors in all of the eigenspace bases \(B_\lambda\text{,}\) then the matrix is not diagonalizable.
    🔗
    🔗
  4. Otherwise, the \(n\) vectors \(v_1,v_2,\ldots,v_n\) in the eigenspace bases are linearly independent, and \(A = CDC\inv\) for
    \begin{align*} C = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_n \\ | \amp | \amp | \end{pmatrix} \sptxt{and} D = \begin{pmatrix} \lambda_1 \amp 0 \amp \cdots \amp 0 \\ 0 \amp \lambda_2 \amp \cdots \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp \lambda_n \end{pmatrix}\text{,} \end{align*}
    where \(\lambda_i\) is the eigenvalue for \(v_i\text{.}\)
    🔗
    🔗
