Example 3.5.30 Dilation.

Let \(T\colon\R^2\to\R^2\) be dilation by a factor of \(3/2\text{:}\) that is, \(T(x) = 3/2x\text{.}\) Is \(T\) invertible? If so, what is \(T\inv\text{?}\)
🔗

Solution.

In Example 9 of Section 3.1 we showed that the matrix for \(T\) is
\begin{align*} A = \begin{pmatrix} 3/2 \amp 0 \\ 0 \amp 3/2 \end{pmatrix}\text{.} \end{align*}
The determinant of \(A\) is \(9/4\neq 0\text{,}\) so \(A\) is invertible with inverse
\begin{align*} A\inv = \frac 1{9/4}\begin{pmatrix} 3/2 \amp 0 \\ 0 \amp 3/2 \end{pmatrix} = \begin{pmatrix} 2/3 \amp 0 \\ 0 \amp 2/3 \end{pmatrix}\text{.} \end{align*}
By the Theorem 29, \(T\) is invertible, and its inverse is the matrix transformation for \(A\inv\text{:}\)
\begin{align*} T\inv(x) = \begin{pmatrix} 2/3 \amp 0 \\ 0 \amp 2/3 \end{pmatrix}x\text{.} \end{align*}
We recognize this as a dilation by a factor of \(2/3\text{.}\)
