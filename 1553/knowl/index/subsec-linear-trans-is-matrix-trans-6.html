Note 3.3.16 Dictionary.

Linear transformations are the same as matrix transformations, which come from matrices. The correspondence can be summarized in the following dictionary. \parbox{.3\linewidth}{\centering% $T\colon\R^n\to\R^m$\\ Linear transformation}% \;$\xrightarrow{\phantom{MMM}}$\; \hbox to .5\linewidth{$m\times n$ matrix \small$A = \begin{pmatrix} | \amp | \amp | \\ T(e_1) \amp T(e_2) \amp \cdots \amp T(e_n) \\ | \amp | \amp | \end{pmatrix}$\hss}\\[3mm] \leavevmode \hbox to .3\linewidth{\hfil $\begin{aligned}&T\colon\R^n\to\R^m\\&T(x) = Ax\end{aligned}$\hfil}% \;$\xleftarrow{\phantom{MMM}}$\; \hbox to .5\linewidth{$m\times n$ matrix $A$\hfil}
