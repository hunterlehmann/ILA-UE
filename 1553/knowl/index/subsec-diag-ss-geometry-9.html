Example 5.3.39 Eigenvalues \(|\lambda_1| = 1,\,|\lambda_2|\lt1\).

Describe how the matrix
\begin{align*} A = \frac 16\begin{pmatrix} 5 \amp -1 \\ -2 \amp 4 \end{pmatrix} \end{align*}
acts on the plane.
🔗

Solution.

First we diagonalize \(A\text{.}\) The characteristic polynomial is
\begin{gather*} f(\lambda) = \lambda^2 - \Tr(A)\lambda + \det(A) = \lambda^2 - \frac 32\lambda + \frac 12 = (\lambda - 1)\left(\lambda - \frac 12\right)\text{.} \end{gather*}
Next we compute the \(1\)-eigenspace:
\begin{align*} (A-I_3)v = 0 \iff \frac 16\begin{pmatrix} -1 \amp -1 \\ -2 \amp -2 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
The parametric form of this equation is \(x = -y\text{,}\) so one eigenvector is \(v_1 = {-1\choose 1}\text{.}\) For the \(1/2\)-eigenspace, we have:
\begin{align*} \left(A-\frac 12I_3\right)v = 0 \iff \frac 16\begin{pmatrix} 2 \amp -1 \\ -2 \amp 1 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -1/2 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
The parametric form of this equation is \(x = 1/2y\text{,}\) so an eigenvector is \(v_2 = {1/2\choose 1}\text{.}\) It follows that \(A = CDC\inv\text{,}\) where
\begin{align*} C = \begin{pmatrix} -1 \amp 1/2 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1/2 \end{pmatrix}\text{.} \end{align*}
🔗
The diagonal matrix \(D\) scales the \(y\)-coordinate by \(1/2\) and does not move the \(x\)-coordinate. Therefore, it simply moves vectors closer to the \(x\)-axis along vertical lines. The matrix \(A\) does the same thing, in the \(v_1,v_2\)-coordinate system: multiplying a vector by \(A\) scales the \(v_2\)-coordinate by \(1/2\) and does not change the \(v_1\)-coordinate. Therefore, \(A\) “sucks vectors into the \(1\)-eigenspace” along lines parallel to \(v_2\text{.}\)
