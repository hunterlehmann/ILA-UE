Definition 3.5.1.

Let \(A\) be an \(n\times n\) (square) matrix. We say that \(A\) is invertible if there is an \(n\times n\) matrix \(B\) such that
\begin{gather*} AB = I_n \sptxt{and} BA = I_n\text{.} \end{gather*}
In this case, the matrix \(B\) is called the inverse of \(A\text{,}\) and we write \(B = A\inv\text{.}\)
