    Section 2.6 Subspaces

    Objectives

    1. Learn the definition of a subspace.
      🔗
      🔗
    2. Learn to determine whether or not a subset is a subspace.
      🔗
      🔗
    3. Learn the most important examples of subspaces.
      🔗
      🔗
    4. Learn to write a given subspace as a column space or null space.
      🔗
      🔗
    5. Recipe: compute a spanning set for a null space.
      🔗
      🔗
    6. Picture: whether a subset of \(\R^2\) or \(\R^3\) is a subspace or not.
      🔗
      🔗
    7. Vocabulary words: subspace, column space, null space.
      🔗
      🔗
    🔗
    In this section we discuss subspaces of \(\R^n\text{.}\) A subspace turns out to be exactly the same thing as a span, except we don’t have a particular set of spanning vectors in mind. This change in perspective is quite useful, as it is easy to produce subspaces that are not obviously spans. For example, the solution set of the equation \(x + 3y + z = 0\) is a span because the equation is homogeneous, but we would have to compute the parametric vector form in order to write it as a span.
    🔗
    
    🔗
    (A subspace also turns out to be the same thing as the solution set of a homogeneous system of equations.)
    🔗

    Subsection 2.6.1 Subspaces: Definition and Examples

    Definition 2.6.1.

    A subset of \(\R^n\) is any collection of points of \(\R^n\text{.}\)
    🔗
    🔗
    For instance, the unit circle
    \begin{gather*} C = \bigl\{ (x,y)\text{ in }\R^2 \bigm| x^2 + y^2 = 1 \bigr\} \end{gather*}
    is a subset of \(\R^2\text{.}\)
    🔗
    Above we expressed \(C\) in set builder notation: in English, it reads “\(C\) is the set of all ordered pairs \((x,y)\) in \(\R^2\) such that \(x^2+y^2=1\text{.}\)”
    🔗

    Definition 2.6.2.

    A subspace of \(\R^n\) is a subset \(V\) of \(\R^n\) satisfying:
    1. Non-emptiness: The zero vector is in \(V\text{.}\)
      🔗
      🔗
    2. Closure under addition: If \(u\) and \(v\) are in \(V\text{,}\) then \(u+v\) is also in \(V\text{.}\)
      🔗
      🔗
    3. Closure under scalar multiplication: If \(v\) is in \(V\) and \(c\) is in \(\R\text{,}\) then \(cv\) is also in \(V\text{.}\)
      🔗
      🔗
    🔗
    🔗
    As a consequence of these properties, we see:
    • If \(v\) is a vector in \(V\text{,}\) then all scalar multiples of \(v\) are in \(V\) by the third property. In other words the line through any nonzero vector in \(V\) is also contained in \(V\text{.}\)
      🔗
      🔗
    • If \(u,v\) are vectors in \(V\) and \(c,d\) are scalars, then \(cu,dv\) are also in \(V\) by the third property, so \(cu+dv\) is in \(V\) by the second property. Therefore, all of \(\Span\{u,v\}\) is contained in \(V\)
      🔗
      🔗
    • Similarly, if \(v_1,v_2,\ldots,v_n\) are all in \(V\text{,}\) then \(\Span\{v_1,v_2,\ldots,v_n\}\) is contained in \(V\text{.}\) In other words, a subspace contains the span of any vectors in it.
      🔗
      🔗
    If you choose enough vectors, then eventually their span will fill up \(V\text{,}\) so we already see that a subspace is a span. See Theorem 14 below for a precise statement.
    🔗

    Remark 2.6.3.

    Suppose that \(V\) is a non-empty subset of \(\R^n\) that satisfies properties 2 and 3. Let \(v\) be any vector in \(V\text{.}\) Then \(0v = 0\) is in \(V\) by the third property, so \(V\) automatically satisfies property 1. It follows that the only subset of \(\R^n\) that satisfies properties 2 and 3 but not property 1 is the empty subset \(\{\}\text{.}\) This is why we call the first property “non-emptiness”.
    🔗
    🔗

    Example 2.6.4.

    The set \(\R^n\) is a subspace of itself: indeed, it contains zero, and is closed under addition and scalar multiplication.
    🔗
    🔗

    Example 2.6.5.

    The set \(\{0\}\) containing only the zero vector is a subspace of \(\R^n\text{:}\) it contains zero, and if you add zero to itself or multiply it by a scalar, you always get zero.
    🔗
    🔗

    Example 2.6.6 A line through the origin.

    A line \(L\) through the origin is a subspace.
    🔗
    
    🔗
    Indeed, \(L\) contains zero, and is easily seen to be closed under addition and scalar multiplication.
    🔗
    🔗

    Example 2.6.7 A plane through the origin.

    A plane \(P\) through the origin is a subspace.
    🔗
    
    🔗
    Indeed, \(P\) contains zero; the sum of two vectors in \(P\) is also in \(P\text{;}\) and any scalar multiple of a vector in \(P\) is also in \(P\text{.}\)
    🔗
    🔗

    Example 2.6.8 Non-example (A line not containing the origin).

    A line \(L\) (or any other subset) that does not contain the origin is not a subspace. It fails the first defining property: every subspace contains the origin by definition.
    🔗
    
    🔗
    🔗

    Example 2.6.9 Non-example (A circle).

    The unit circle \(C\) is not a subspace. It fails all three defining properties: it does not contain the origin, it is not closed under addition, and it is not closed under scalar multiplication. In the picture, one red vector is the sum of the two black vectors (which are contained in \(C\)), and the other is a scalar multiple of a black vector.
    🔗
    
    🔗
    🔗

    Example 2.6.10 Non-example (The first quadrant).

    The first quadrant in \(\R^2\) is not a subspace. It contains the origin and is closed under addition, but it is not closed under scalar multiplication (by negative numbers).
    🔗
    
    🔗
    🔗

    Example 2.6.11 Non-example (A line union a plane).

    The union of a line and a plane in \(\R^3\) is not a subspace. It contains the origin and is closed under scalar multiplication, but it is not closed under addition: the sum of a vector on the line and a vector on the plane is not contained in the line or in the plane.
    🔗
    
    🔗
    🔗

    Subsets versus Subspaces.

    A subset of \(\R^n\) is any collection of vectors whatsoever. For instance, the unit circle
    \begin{gather*} C = \bigl\{ (x,y)\text{ in }\R^2 \bigm| x^2 + y^2 = 1 \bigr\} \end{gather*}
    is a subset of \(\R^2\text{,}\) but it is not a subspace. In fact, all of the non-examples above are still subsets of \(\R^n\text{.}\) A subspace is a subset that happens to satisfy the three additional defining properties.
    🔗
    🔗
    In order to verify that a subset of \(\R^n\) is in fact a subspace, one has to check the three defining properties. That is, unless the subset has already been verified to be a subspace: see Note  below.
    🔗

    Example 2.6.12 Verifying that a subset is a subspace.

    Let
    \begin{gather*} V = \left\{ \begin{pmatrix} a \\ b \end{pmatrix} \text{ in } \R^2 \bigm| 2a = 3b\right\}\text{.} \end{gather*}
    Verify that \(V\) is a subspace.
    🔗

    Solution.

    First we point out that the condition “\(2a = 3b\)” defines whether or not a vector is in \(V\text{:}\) that is, to say \({a\choose b}\) is in \(V\) means that \(2a = 3b\text{.}\) In other words, a vector is in \(V\) if twice its first coordinate equals three times its second coordinate. So for instance, \({3\choose 2}\) and \({1/2\choose 1/3}\) are in \(V\text{,}\) but \({2\choose 3}\) is not because \(2\cdot 2\neq 3\cdot 3\text{.}\)
    🔗
    Let us check the first property. The subset \(V\) does contain the zero vector \({0\choose 0}\text{,}\) because \(2\cdot 0 = 3\cdot 0\text{.}\)
    🔗
    Next we check the second property. To show that \(V\) is closed under addition, we have to check that for any vectors \(u = {a\choose b}\) and \(v = {c\choose d}\) in \(V\text{,}\) the sum \(u+v\) is in \(V\text{.}\) Since we cannot assume anything else about \(u\) and \(v\text{,}\) we must treat them as unknowns.
    🔗
    We have
    \begin{gather*} \begin{pmatrix} a \\ b \end{pmatrix} + \begin{pmatrix} c \\ d \end{pmatrix} = \begin{pmatrix} a+c \\ b+d \end{pmatrix}\text{.} \end{gather*}
    To say that \(a+c\choose b+d\) is contained in \(V\) means that \(2(a+c) = 3(b+d)\text{,}\) or \(2a + 2c = 3b + 3d\text{.}\) The one thing we are allowed to assume about \(u\) and \(v\) is that \(2a = 3b\) and \(2c = 3d\text{,}\) so we see that \(u+v\) is indeed contained in \(V\text{.}\)
    🔗
    Next we check the third property. To show that \(V\) is closed under scalar multiplication, we have to check that for any vector \(v = {a\choose b}\) in \(V\) and any scalar \(c\) in \(\R\text{,}\) the product \(cv\) is in \(V\text{.}\) Again, we must treat \(v\) and \(c\) as unknowns. We have
    \begin{gather*} c\begin{pmatrix} a \\ b \end{pmatrix} = \begin{pmatrix} ca \\ cb \end{pmatrix}\text{.} \end{gather*}
    To say that \(ca\choose cb\) is contained in \(V\) means that \(2(ca) = 3(cb)\text{,}\) i.e., that \(c\cdot 2a = c\cdot 3b\text{.}\) The one thing we are allowed to assume about \(v\) is that \(2a = 3b\text{,}\) so \(cv\) is indeed contained in \(V\text{.}\)
    🔗
    Since \(V\) satisfies all three defining properties, it is a subspace. In fact, it is the line through the origin with slope \(2/3\text{.}\)
    🔗
    
    🔗
    🔗
    🔗

    Example 2.6.13 Showing that a subset is not a subspace.

    Let
    \begin{gather*} V = \left\{ \begin{pmatrix} a \\ b \end{pmatrix} \text{ in } \R^2\bigm| ab=0 \right\}\text{.} \end{gather*}
    Is \(V\) a subspace?
    🔗

    Solution.

    First we point out that the condition “\(ab=0\)” defines whether or not a vector is in \(V\text{:}\) that is, to say \({a\choose b}\) is in \(V\) means that \(ab=0\text{.}\) In other words, a vector is in \(V\) if the product of its coordinates is zero, i.e., if one (or both) of its coordinates are zero. So for instance, \({1\choose 0}\) and \({0\choose 2}\) are in \(V\text{,}\) but \({1\choose 1}\) is not because \(1\cdot 1\neq 0\text{.}\)
    🔗
    Let us check the first property. The subset \(V\) does contain the zero vector \({0\choose 0}\text{,}\) because \(0\cdot 0=0\text{.}\)
    🔗
    Next we check the third property. To show that \(V\) is closed under scalar multiplication, we have to check that for any vector \(v = {a\choose b}\) in \(V\) and any scalar \(c\) in \(\R\text{,}\) the product \(cv\) is in \(V\text{.}\) Since we cannot assume anything else about \(v\) and \(c\text{,}\) we must treat them as unknowns.
    🔗
    We have
    \begin{gather*} c\begin{pmatrix} a \\ b \end{pmatrix} = \begin{pmatrix} ca \\ cb \end{pmatrix}\text{.} \end{gather*}
    To say that \(ca\choose cb\) is contained in \(V\) means that \((ca)(cb)=0\text{.}\) Rewriting, this means \(c^2(ab)=0\text{.}\) The one thing we are allowed to assume about \(v\) is that \(ab=0\text{,}\) so we see that \(cv\) is indeed contained in \(V\text{.}\)
    🔗
    Next we check the second property. It turns out that \(V\) is not closed under addition; to verify this, we must show that there exists some vectors \(u,v\) in \(V\) such that \(u+v\) is not contained in \(V\text{.}\) The easiest way to do so is to produce examples of such vectors. We can take \(u={1\choose 0}\) and \(v={0\choose 1}\text{;}\) these are contained in \(V\) because the products of their coordinates are zero, but
    \begin{gather*} \begin{pmatrix} 1 \\ 0 \end{pmatrix} + \begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 \\ 1 \end{pmatrix} \end{gather*}
    is not contained in \(V\) because \(1\cdot 1\neq 0\text{.}\)
    🔗
    Since \(V\) does not satisfy the second property (it is not closed under addition), we conclude that \(V\) is not a subspace. Indeed, it is the union of the two coordinate axes, which is not a span.
    🔗
    
    🔗
    🔗
    🔗
    🔗

    Subsection 2.6.2 Common Types of Subspaces

    Theorem 2.6.14 Spans are Subspaces and Subspaces are Spans.

    If \(v_1,v_2,\ldots,v_p\) are any vectors in \(\R^n\text{,}\) then \(\Span\{v_1,v_2,\ldots,v_p\}\) is a subspace of \(\R^n\text{.}\) Moreover, any subspace of \(\R^n\) can be written as a span of a set of \(p\) linearly independent vectors in \(\R^n\) for \(p\leq n\text{.}\)
    🔗
    🔗

    Proof.
    To show that \(\Span\{v_1,v_2,\ldots,v_p\}\) is a subspace, we have to verify the three defining properties.
    1. The zero vector \(0 = 0v_1 + 0v_2 + \cdots + 0v_p\) is in the span.
      🔗
      🔗
    2. If \(u = a_1v_1 + a_2v_2 + \cdots + a_pv_p\) and \(v = b_1v_1 + b_2v_2 + \cdots + b_pv_p\) are in \(\Span\{v_1,v_2,\ldots,v_p\}\text{,}\) then
      \begin{gather*} u + v = (a_1+b_1)v_1 + (a_2+b_2)v_2 + \cdots + (a_p+b_p)v_p \end{gather*}
      is also in \(\Span\{v_1,v_2,\ldots,v_p\}\text{.}\)
      🔗
      🔗
    3. If \(v = a_1v_1 + a_2v_2 + \cdots + a_pv_p\) is in \(\Span\{v_1,v_2,\ldots,v_p\}\) and \(c\) is a scalar, then
      \begin{gather*} cv = ca_1v_1 + ca_2v_2 + \cdots + ca_pv_p \end{gather*}
      is also in \(\Span\{v_1,v_2,\ldots,v_p\}\text{.}\)
      🔗
      🔗
    Since \(\Span\{v_1,v_2,\ldots,v_p\}\) satisfies the three defining properties of a subspace, it is a subspace.
    🔗
    Now let \(V\) be a subspace of \(\R^n\text{.}\) If \(V\) is the zero subspace, then it is the span of the empty set, so we may assume \(V\) is nonzero. Choose a nonzero vector \(v_1\) in \(V\text{.}\) If \(V = \Span\{v_1\}\text{,}\) then we are done. Otherwise, there exists a vector \(v_2\) that is in \(V\) but not in \(\Span\{v_1\}\text{.}\) Then \(\Span\{v_1,v_2\}\) is contained in \(V\text{,}\) and by the Theorem 14 of Section 2.5, the set \(\{v_1,v_2\}\) is linearly independent. If \(V = \Span\{v_1,v_2\}\) then we are done. Otherwise, we continue in this fashion until we have written \(V = \Span\{v_1,v_2,\ldots,v_p\}\) for some linearly independent set \(\{v_1,v_2,\ldots,v_p\}\text{.}\) This process terminates after at most \(n\) steps by Insight 10 of Section 2.5.
    🔗
    🔗
    If \(V = \Span\{v_1,v_2,\ldots,v_p\}\text{,}\) we say that \(V\) is the subspace spanned by or generated by the vectors \(v_1,v_2,\ldots,v_p\text{.}\) We call \(\{v_1,v_2,\ldots,v_p\}\) a spanning set for \(V\text{.}\)
    🔗
    Any matrix naturally gives rise to two subspaces.
    🔗

    Definition 2.6.15.

    Let \(A\) be an \(m\times n\) matrix.
    • The column space of \(A\) is the subspace of \(\R^m\) spanned by the columns of \(A\text{.}\) It is written \(\Col(A)\text{.}\)
      🔗
      🔗
    • The null space of \(A\) is the subspace of \(\R^n\) consisting of all solutions of the homogeneous equation \(Ax=0\text{:}\)
      \begin{gather*} \Nul(A) = \bigl\{ x \text{ in } \R^n\bigm| Ax=0 \bigr\}\text{.} \end{gather*}
      🔗
      🔗
    🔗
    🔗
    The column space is defined to be a span, so it is a subspace by the above Theorem 14. We need to verify that the null space is really a subspace. In Section 2.4 we already saw that the set of solutions of \(Ax=0\) is always a span, so the fact that the null spaces is a subspace should not come as a surprise.
    🔗

    Proof.
    We have to verify the three defining properties. To say that a vector \(v\) is in \(\Nul(A)\) means that \(Av = 0\text{.}\)
    1. The zero vector is in \(\Nul(A)\) because \(A0=0\text{.}\)
      🔗
      🔗
    2. Suppose that \(u,v\) are in \(\Nul(A)\text{.}\) This means that \(Au=0\) and \(Av=0\text{.}\) Hence
      \begin{gather*} A(u+v) = Au + Av = 0 + 0 = 0 \end{gather*}
      by the Proposition 4 of Section 2.3. Therefore, \(u+v\) is in \(\Nul(A)\text{.}\)
      🔗
      🔗
    3. Suppose that \(v\) is in \(\Nul(A)\) and \(c\) is a scalar. Then
      \begin{gather*} A(cv) = cAv = c\cdot 0 = 0 \end{gather*}
      by the Proposition 4 of Section 2.3, so \(cv\) is also in \(\Nul(A)\text{.}\)
      🔗
      🔗
    Since \(\Nul(A)\) satisfies the three defining properties of a subspace, it is a subspace.
    🔗
    🔗

    Example 2.6.16.

    Describe the column space and the null space of
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \\ 1 \amp 1 \\ 1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    The column space is the span of the columns of \(A\text{:}\)
    \begin{gather*} \Col(A) = \Span\left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\right\} = \Span\left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\right\}\text{.} \end{gather*}
    This is a line in \(\R^3\text{.}\)
    🔗
    
    🔗
    The null space is the solution set of the homogeneous system \(Ax=0\text{.}\) To compute this, we need to row reduce \(A\text{.}\) Its reduced row echelon form is
    \begin{align*} \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    This gives the equation \(x+y=0\text{,}\) or
    \begin{align*} \left\{\begin{alignedat}{2} x \amp {}={} \amp -y \amp {} \\ y \amp {}={} \amp y \amp {} \end{alignedat}\right. \quad\xrightarrow{\text{parametric vector form}}\quad \begin{pmatrix} x \\ y \end{pmatrix} = y\begin{pmatrix} -1 \\ 1 \end{pmatrix}\text{.} \end{align*}
    Hence the null space is \(\Span\bigl\{{-1\choose 1}\bigr\}\text{,}\) which is a line in \(\R^2\text{.}\)
    🔗
    
    🔗
    Notice that the column space is a subspace of \(\R^3\text{,}\) whereas the null space is a subspace of \(\R^2\text{.}\) This is because \(A\) has three rows and two columns.
    🔗
    🔗
    🔗
    The column space and the null space of a matrix are both subspaces, so they are both spans. The column space of a matrix \(A\) is defined to be the span of the columns of \(A\text{.}\) The null space is defined to be the solution set of \(Ax=0\text{,}\) so this is a good example of a kind of subspace that we can define without any spanning set in mind. In other words, it is easier to show that the null space is a subspace than to show it is a span—see the proof above. In order to do computations, however, it is usually necessary to find a spanning set.
    🔗

    Example 2.6.17 Null Spaces are Solution Sets.

    The null space of a matrix is the solution set of a homogeneous system of equations. For example, the null space of the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 2 \\ -2 \amp 1 \amp 3 \\ 4 \amp -2 \amp -3 \end{pmatrix} \end{align*}
    is the solution set of \(Ax=0\text{,}\) i.e., the solution set of the system of equations
    \begin{align*} \left\{\begin{alignedat}{4} x \amp {}+{} \amp 7y \amp {}+{} \amp 2z \amp {}={} \amp 0 \amp {} \\ -2x \amp {}+{} \amp y \amp {}+{} \amp 3z \amp {}={} \amp 0 \amp {} \\ 4x \amp {}-{} \amp 2y \amp {}-{} \amp 3z \amp {}={} \amp 0 \amp . \end{alignedat}\right. \end{align*}
    Conversely, the solution set of any homogeneous system of equations is precisely the null space of the corresponding coefficient matrix.
    🔗
    🔗
    To find a spanning set for the null space, one has to solve a system of homogeneous equations.
    🔗

    Recipe 2.6.18 Compute a spanning set for a null space.

    To find a spanning set for \(\Nul(A)\text{,}\) compute the parametric vector form of the solutions to the homogeneous equation \(Ax=0\text{.}\) The vectors attached to the free variables form a spanning set for \(\Nul(A)\text{.}\)
    🔗
    🔗

    Example 2.6.19 Two free variables.

    Find a spanning set for the null space of the matrix
    \begin{align*} A = \begin{pmatrix} 2 \amp 3 \amp -8 \amp -5 \\ -1 \amp 2 \amp -3 \amp -8 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We compute the parametric vector form of the solutions of \(Ax=0\text{.}\) The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp -1 \amp 2 \\ 0 \amp 1 \amp -2 \amp -3 \end{pmatrix}\text{.} \end{align*}
    The free variables are \(x_3\) and \(x_4\text{;}\) the parametric form of the solution set is
    \begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp x_3 - 2x_4 \amp {} \\ x_2 \amp {}={} \amp 2x_3 + 3x_4 \amp {} \\ x_3 \amp {}={} \amp x_3 \amp {} \\ x_4 \amp {}={} \amp x_4 \amp {} \end{alignedat}\right. \quad\xrightarrow[\text{vector form}]{\text{parametric}}\quad \begin{pmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{pmatrix} = x_3\begin{pmatrix} 1 \\ 2 \\ 1 \\ 0 \end{pmatrix} + x_4\begin{pmatrix} -2 \\ 3 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{align*}
    Therefore,
    \begin{gather*} \Nul(A) = \Span\left\{\begin{pmatrix} 1 \\ 2 \\ 1 \\ 0 \end{pmatrix},\;\begin{pmatrix} -2 \\ 3 \\ 0 \\ 1 \end{pmatrix}\right\}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    Example 2.6.20 No free variables.

    Find a spanning set for the null space of the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 3 \\ 2 \amp 4 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We compute the parametric vector form of the solutions of \(Ax=0\text{.}\) The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    There are no free variables; hence the only solution of \(Ax=0\) is the trivial solution. In other words,
    \begin{gather*} \Nul(A) = \{0\} = \Span\{0\}\text{.} \end{gather*}
    It is natural to define \(\Span\{\} = \{0\}\text{,}\) so that we can take our spanning set to be empty. This is consistent with the Definition 3 of Section 2.7.
    🔗
    🔗
    🔗

    Writing a subspace as a column space or a null space.

    A subspace can be given to you in many different forms. In practice, computations involving subspaces are much easier if your subspace is the column space or null space of a matrix. The simplest example of such a computation is finding a spanning set: a column space is by definition the span of the columns of a matrix, and we showed above how to compute a spanning set for a null space using parametric vector form. For this reason, it is useful to rewrite a subspace as a column space or a null space before trying to answer questions about it.
    🔗
    When asking questions about a subspace, it is usually best to rewrite the subspace as a column space or a null space.
    🔗
    🔗
    This also applies to the question “is my subset a subspace?” If your subset is a column space or null space of a matrix, then the answer is yes.
    🔗

    Example 2.6.21.

    Let
    \begin{gather*} V = \left\{ \begin{pmatrix} a \\ b \end{pmatrix} \text{ in } \R^2 \bigm| 2a = 3b\right\} \end{gather*}
    be the subset of a previous Example 12. The subset \(V\) is exactly the solution set of the homogeneous equation \(2x - 3y = 0\text{.}\) Therefore,
    \begin{align*} V = \Nul\begin{pmatrix} 2 \amp -3 \end{pmatrix}\text{.} \end{align*}
    In particular, it is a subspace. The reduced row echelon form of \(\begin{pmatrix} 2 \amp -3 \end{pmatrix}\) is \(\begin{pmatrix} 1 \amp -3/2 \end{pmatrix}\text{,}\) so the parametric form of \(V\) is \(x = 3/2y\text{,}\) so the parametric vector form is \({x\choose y} = y{3/2\choose 1},\) and hence \(\bigl\{{3/2\choose 1}\bigr\}\) spans \(V\text{.}\)
    🔗
    🔗

    Example 2.6.22.

    Let \(V\) be the plane in \(\R^3\) defined by
    \begin{gather*} V = \left\{\begin{pmatrix} 2x+y \\ x-y \\ 3x-2y \end{pmatrix}\bigm| x,y \text{ are in } \R \right\}\text{.} \end{gather*}
    Write \(V\) as the column space of a matrix.
    🔗
    Solution.
    Since
    \begin{gather*} \begin{pmatrix} 2x+y \\ x-y \\ 3x-2y \end{pmatrix} = x\begin{pmatrix} 2 \\ 1 \\ 3 \end{pmatrix} + y\begin{pmatrix} 1 \\ -1 \\ -2 \end{pmatrix}\text{,} \end{gather*}
    we notice that \(V\) is exactly the span of the vectors
    \begin{gather*} \begin{pmatrix} 2 \\ 1 \\ 3 \end{pmatrix} \sptxt{and} \begin{pmatrix} 1 \\ -1 \\ -2 \end{pmatrix}\text{.} \end{gather*}
    Hence
    \begin{align*} V = \Col\begin{pmatrix} 2 \amp 1 \\ 1 \amp -1 \\ 3 \amp -2 \end{pmatrix}\text{.} \end{align*}

    5.

    Consider the set \(S = \{(x, y) \textup{ in } {\bf R}^2 \ | \ xy \geq 0\}\text{.}\) Is \(S\) a subspace of \({\bf R}^2\text{?}\) If not, which properties does it fail?
    🔗
    Solution.
    (1) \(S\) contains the zero vector, since \(0\cdot 0 = 0 \geq 0\text{.}\)
    🔗
    (2) \(S\) is not closed under addition. For example, take \(u = \begin{pmatrix}1 \\ 2\end{pmatrix}\) and \(v = \begin{pmatrix}-2 \\ -1\end{pmatrix}\text{.}\) Both vectors are in \(S\) since \(1\cdot 2 > 0\) and \((-2)(-1) = 2 >0\text{.}\) However, their sum is \(u+v = \begin{pmatrix}-1 \\ 1\end{pmatrix}\text{,}\) which is not in \(S\) since \((-1)(1)\lt 0\text{.}\)
    🔗
    (3) \(S\) is closed under scalar multiplication. If \(u = \begin{pmatrix}x \\ y\end{pmatrix}\) is in \(S\) and \(c\) is any scalar, then for \(cu = \begin{pmatrix}cx \\ cy\end{pmatrix}\) we have
    \begin{gather*} (cx)(cy) = c^2 (xy) \geq 0 \quad \textup{ since } c^2 \geq 0 \textup{ and } xy \geq 0\text{.} \end{gather*}
    🔗
    Most students find it easier if we first draw a picture of \(S\) to gain intuition, rather than plugging in random vectors to test properties. In order for a vector to be in \(S\text{,}\) either both entries are positive, or both entries are negative, or at least one entry is zero. Putting this together, we see that \(S\) is the union of the first and third quadrants of the \(xy\)-plane (including the \(x\)-axis and \(y\)-axis).

    🔗

    11.

    If \(V\) and \(W\) are sets in \({\bf R}^n\text{,}\) then their \textit{union}, denoted \(V \cup W\text{,}\) is the set of all vectors that are in at least one of \(V\) and \(W\text{.}\) In other words, a vector \(x\) is in \(V \cup W\) if \(x\) is in \(V\) or \(x\) is in \(W\) (or \(x\) is in both \(V\) and \(W\)).
    🔗
    Suppose \(U\) and \(W\) are subspaces of \({\bf R}^n\text{.}\) When will \(U \cup W\) also a subspace of \({\bf R}^n\text{?}\)
    🔗
    Solution.
    The union will be a subspace of \({\bf R}^n\) if and only if one of one of \(U\) or \(V\) is contained in the other (or both are equal). In this case, the union \(U \cup V\) will just be one of \(U\) or \(V\text{,}\) which we already know to be subspaces.
    🔗
    On the other hand, suppose neither \(U\) nor \(V\) is contained in the other. Then there is a vector \(u\) that is in \(U\) but not in \(V\text{,}\) and there is a vector \(v\) that is in \(V\) but not in \(U\text{.}\) We show that:
    \begin{gather*} u+v \textup{ is not in } U \cup V\text{.} \end{gather*}
    After all, \(u+v\) cannot be in the subspace \(U\text{,}\) because if it were then \((u+v)-u = v\) would need to be in \(U\) since \(U\) is closed under addition. Similarly, \(u+v\) cannot be in \(V\) because then \((u+v)-v = u\) would need to be in \(V\) since \(V\) is closed under addition.
    🔗
    In summary: \(u\) and \(v\) are in \(U \cup V\text{,}\) but \(u+v\) is not in \(U \cup V\text{,}\) so \(U \cup V\) is not closed under addition and is therefore not a subspace of \({\bf R}^n\text{.}\)
    🔗
    🔗
    🔗

    (Challenge problem) Abstract spaces go beyond just \({\bf R}^n\text{.}\) For example, the set of all polynomials with real coefficients forms an abstract vector space.
    🔗
    Consider the set \(W\) consisting of all polynomials that have degree \(2\) or less. In other words, \(W\) is the set of all functions of the form
    \begin{gather*} f(x) = a_0 + a_1 x + a_2 x^2 \end{gather*}
    where \(a_0\text{,}\) \(a_1\text{,}\) and \(a_2\) are real numbers. Show that \(W\) satisfies the properties of a subspace:
    🔗

    (a)

    \(W\) contains the zero polynomial. In other words, \(W\) contains the polynomial given by \(p(x) = 0\) for all \(x\text{.}\)

    🔗

    (b)

    If polynomials \(f\) and \(g\) are in \(W\text{,}\) then so is the polynomial \(f+g\) given by
    \begin{gather*} (f+g)(x) = f(x) + g(x)\text{.} \end{gather*}
    🔗
    🔗

    (c)

    If \(f\) is in \(W\) and \(c\) is a scalar, then the polynomial \(cf\) given by \((cf)(x) = cf(x)\) is also in \(W\text{.}\)
