    Section 2.5 Linear Independence

    Objectives

    1. Understand the concept of linear independence.
      🔗
      🔗
    2. Learn two criteria for linear independence.
      🔗
      🔗
    3. Understand the relationship between linear independence and pivot columns / free variables.
      🔗
      🔗
    4. Recipe: test if a set of vectors is linearly independent / find an equation of linear dependence.
      🔗
      🔗
    5. Picture: whether a set of vectors in \(\R^2\) or \(\R^3\) is linearly independent or not.
      🔗
      🔗
    6. Vocabulary words: linear dependence relation / equation of linear dependence.
      🔗
      🔗
    7. Essential vocabulary words: linearly independent, linearly dependent.
      🔗
      🔗
    🔗
    Sometimes the span of a set of vectors is “smaller” than you expect from the number of vectors, as in the picture below. This means that (at least) one of the vectors is redundant: it can be removed without affecting the span. In the present section, we formalize this idea in the notion of linear independence.
    🔗

    Subsection 2.5.1 The Definition of Linear Independence

    Definition 2.5.2.

    A set of vectors \(\{v_1,v_2,\ldots,v_k\}\) is linearly independent if the vector equation
    \begin{gather*} x_1v_1 + x_2v_2 + \cdots + x_kv_k = 0 \end{gather*}
    has only the trivial solution \(x_1=x_2=\cdots=x_k=0\text{.}\) The set \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent otherwise.
    🔗
    🔗
    In other words, \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent if there exist numbers \(x_1,x_2,\ldots,x_k\text{,}\) not all equal to zero, such that
    \begin{gather*} x_1v_1 + x_2v_2 + \cdots + x_kv_k = 0\text{.} \end{gather*}
    This is called a linear dependence relation or equation of linear dependence.
    🔗

    Insight 2.5.3.

    Note that linear dependence and linear independence are notions that apply to a collection of vectors. It does not make sense to say things like “this vector is linearly dependent on these other vectors,” or “this matrix is linearly independent.”
    🔗
    🔗

    Example 2.5.4 Checking linear dependence.

    Is the set
    \begin{gather*} \left\{ \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\, \begin{pmatrix} 1 \\ -1 \\ 2 \end{pmatrix},\, \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} \right\} \end{gather*}
    linearly independent?
    🔗

    Solution.

    Equivalently, we are asking if the homogeneous vector equation
    \begin{gather*} x\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} + y\begin{pmatrix} 1 \\ -1 \\ 2 \end{pmatrix} + z\begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix} \end{gather*}
    has a nontrivial solution. We solve this by forming a matrix and row reducing (we do not augment because of Example 4 of Section 2.4):
    \begin{align*} \begin{pmatrix} 1 \amp 1 \amp 3 \\ 1 \amp -1 \amp 1 \\ 1 \amp 2 \amp 4 \end{pmatrix} \quad\xrightarrow{\text{row reduce}}\quad \begin{pmatrix} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{align*}
    This says \(x = -2z\) and \(y = -z\text{.}\) So there exist nontrivial solutions: for instance, taking \(z=1\) gives this equation of linear dependence:
    \begin{gather*} -2\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} - \begin{pmatrix} 1 \\ -1 \\ 2 \end{pmatrix} + \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    Example 2.5.6 Checking linear independence.

    Is the set
    \begin{gather*} \left\{ \begin{pmatrix} 1 \\ 1 \\ -2 \end{pmatrix},\, \begin{pmatrix} 1 \\ -1 \\ 2 \end{pmatrix},\, \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} \right\} \end{gather*}
    linearly independent?
    🔗

    Solution.

    Equivalently, we are asking if the homogeneous vector equation
    \begin{gather*} x\begin{pmatrix} 1 \\ 1 \\ -2 \end{pmatrix} + y\begin{pmatrix} 1 \\ -1 \\ 2 \end{pmatrix} + z\begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix} \end{gather*}
    has a nontrivial solution. We solve this by forming a matrix and row reducing (we do not augment because of Example 4 of Section 2.4):
    \begin{align*} \begin{pmatrix} 1 \amp 1 \amp 3 \\ 1 \amp -1 \amp 1 \\ -2 \amp 2 \amp 4 \end{pmatrix} \quad\xrightarrow{\text{row reduce}}\quad \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    This says \(x = y = z = 0\text{,}\) i.e., the only solution is the trivial solution. We conclude that the set is linearly independent.
    🔗
    🔗
    🔗

    Example 2.5.8 Vector parametric form.

    An important observation is that the vectors coming from the parametric vector form of the solution of a matrix equation \(Ax=0\) are linearly independent. In Example 9 of Section 2.4 we saw that the solution set of \(Ax=0\) for
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}? \end{align*}
    is
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = x_2\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + x_3\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    Let’s explain why the vectors \((1,1,0)\) and \((-2,0,1)\) are linearly independent. Suppose that
    \begin{gather*} \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix} = x_2\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + x_3\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} x_2-2x_3 \\ x_2 \\ x_3 \end{pmatrix}\text{.} \end{gather*}
    Comparing the second and third coordinates, we see that \(x_2=x_3=0\text{.}\) This reasoning will work in any example, since the entries corresponding to the free variables are all equal to 1 or 0, and are only equal to 1 in one of the vectors. This observation forms part of Theorem 17 of Section 2.7.
    🔗
    🔗
    The above examples lead to the following recipe.
    🔗

    Recipe 2.5.9 Checking linear independence.

    A set of vectors \(\{v_1,v_2,\ldots,v_k\}\) is linearly independent if and only if the vector equation
    \begin{gather*} x_1v_1 + x_2v_2 + \cdots + x_kv_k = 0 \end{gather*}
    has only the trivial solution, if and only if the matrix equation \(Ax=0\) has only the trivial solution, where \(A\) is the matrix with columns \(v_1,v_2,\ldots,v_k\text{:}\)
    \begin{align*} A = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_k \\ | \amp | \amp | \end{pmatrix}\text{.} \end{align*}
    This is true if and only if \(A\) has a pivot position in every column.
    🔗
    Solving the matrix equatiion \(Ax=0\) will either verify that the columns \(v_1,v_2,\ldots,v_k\) are linearly independent, or will produce a linear dependence relation by substituting any nonzero values for the free variables.
    🔗
    🔗
    (Recall that \(Ax=0\) has a nontrivial solution if and only if \(A\) has a column without a pivot: see Example 2 of Section 2.4.)
    🔗
    Suppose that \(A\) has more columns than rows. Then \(A\) cannot have a pivot in every column (it has at most one pivot per row), so its columns are automatically linearly dependent.
    🔗

    Insight 2.5.10.

    A wide matrix (a matrix with more columns than rows) has linearly dependent columns.
    🔗
    🔗
    For example, four vectors in \(\R^3\) are automatically linearly dependent. Note that a tall matrix may or may not have linearly independent columns.
    🔗

    Fact 2.5.11 Facts about linear independence.

    1. Two vectors are linearly dependent if and only if they are collinear, i.e., one is a scalar multiple of the other.
      🔗
      🔗
    2. Any set containing the zero vector is linearly dependent.
      🔗
      🔗
    3. If a subset of \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent, then \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent as well.
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. If \(v_1 = cv_2\) then \(v_1-cv_2=0\text{,}\) so \(\{v_1,v_2\}\) is linearly dependent. In the other direction, if \(x_1v_1+x_2v_2=0\) with \(x_1\neq0\) (say), then \(v_1 = -\frac{x_2}{x_1}v_2\text{.}\)
      🔗
      🔗
    2. It is easy to produce a linear dependence relation if one vector is the zero vector: for instance, if \(v_1=0\) then
      \begin{gather*} 1\cdot v_1 + 0\cdot v_2 + \cdots + 0\cdot v_k = 0\text{.} \end{gather*}
      🔗
      🔗
    3. After reordering, we may suppose that \(\{v_1,v_2,\ldots,v_r\}\) is linearly dependent, with \(r < p\text{.}\) This means that there is an equation of linear dependence
      \begin{gather*} x_1v_1 + x_2v_2 + \cdots + x_rv_r = 0\text{,} \end{gather*}
      with at least one of \(x_1,x_2,\ldots,x_r\) nonzero. This is also an equation of linear dependence among \(\{v_1,v_2,\ldots,v_k\}\text{,}\) since we can take the coefficients of \(v_{r+1},\ldots,v_k\) to all be zero.
      🔗
      🔗
    🔗
    🔗
    With regard to the first fact, note that the zero vector is a multiple of any vector, so it is collinear with any other vector. Hence facts 1 and 2 are consistent with each other.
    🔗
    🔗

    Subsection 2.5.2 Criteria for Linear Independence

    In this subsection we give two criteria for a set of vectors to be linearly independent. Keep in mind, however, that the actual Definition 2 is above.
    🔗

    Theorem 2.5.12.

    A set of vectors \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent if and only if one of the vectors is in the span of the other ones.
    🔗
    Any such vector may be removed without affecting the span.
    🔗
    🔗

    Proof.
    Suppose, for instance, that \(v_3\) is in \(\Span\{v_1,v_2,v_4\}\text{,}\) so we have an equation like
    \begin{gather*} v_3 = 2v_1 - \frac 12v_2 + 6v_4\text{.} \end{gather*}
    We can subract \(v_3\) from both sides of the equation to get
    \begin{gather*} 0 = 2v_1 - \frac 12v_2 - v_3 + 6v_4\text{.} \end{gather*}
    This is a linear dependence relation.
    🔗
    In this case, any linear combination of \(v_1,v_2,v_3,v_4\) is already a linear combination of \(v_1,v_2,v_4\text{:}\)
    \begin{align*} x_1v_1 + x_2v_2 + x_3v_3 + x_4v_4 \amp= x_1v_1 + x_2v_2 + x_3\left(2v_1-\frac 12v_2 + 6v_4\right) + x_4v_4\\ \amp= (x_1+2x_3)v_1 + \left(x_2-\frac 12x_3\right)v_2 + (x_4+6)v_4\text{.} \end{align*}
    Therefore, \(\Span\{v_1,v_2,v_3,v_4\}\) is contained in \(\Span\{v_1,v_2,v_4\}\text{.}\) Any linear combination of \(v_1,v_2,v_4\) is also a linear combination of \(v_1,v_2,v_3,v_4\) (with the \(v_3\)-coefficient equal to zero), so \(\Span\{v_1,v_2,v_4\}\) is also contained in \(\Span\{v_1,v_2,v_3,v_4\}\text{,}\) and thus they are equal.
    🔗
    In the other direction, if we have a linear dependence relation like
    \begin{gather*} 0 = 2v_1 - \frac 12v_2 + v_3 - 6v_4\text{,} \end{gather*}
    then we can move any nonzero term to the left side of the equation and divide by its coefficient:
    \begin{gather*} v_1 = \frac 12\left(\frac 12v_2 - v_3 + 6v_4\right)\text{.} \end{gather*}
    This shows that \(v_1\) is in \(\Span\{v_2,v_3,v_4\}\text{.}\)
    🔗
    We leave it to the reader to generalize this proof for any set of vectors.
    🔗
    🔗

    Insight 2.5.13.

    In a linearly dependent set \(\{v_1,v_2,\ldots,v_k\}\text{,}\) it is not generally true that any vector \(v_j\) is in the span of the others, only that at least one of them is.
    🔗
    🔗
    For example, the set \(\bigl\{{1\choose 0},\,{2\choose 0},\,{0\choose 1}\bigr\}\) is linearly dependent, but \({0\choose 1}\) is not in the span of the other two vectors. Also see Figure 20 below.
    🔗
    Theorem 12 makes precise in what sense a set of linearly dependent vectors is redundant.
    🔗

    Theorem 2.5.14 Increasing Span Criterion.

    A set of vectors \(\{v_1,v_2,\ldots,v_k\}\) is linearly independent if and only if, for every \(j\text{,}\) the vector \(v_j\) is not in \(\Span\{v_1,v_2,\ldots,v_{j-1}\}\text{.}\)
    🔗
    🔗

    Proof.
    It is equivalent to show that \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent if and only if \(v_j\) is in \(\Span\{v_1,v_2,\ldots,v_{j-1}\}\) for some \(j\text{.}\) The “if” implication is an immediate consequence of Theorem 12. Suppose then that \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent. This means that some \(v_j\) is in the span of the others. Choose the largest such \(j\text{.}\) We claim that this \(v_j\) is in \(\Span\{v_1,v_2,\ldots,v_{j-1}\}\text{.}\) If not, then
    \begin{gather*} v_j = x_1v_1 + x_2v_2 + \cdots + x_{j-1}v_{j-1} + x_{j+1}v_{j+1} + \cdots + x_kv_k \end{gather*}
    with not all of \(x_{j+1},\ldots,x_k\) equal to zero. Suppose for simplicity that \(x_k\neq 0\text{.}\) Then we can rearrange:
    \begin{gather*} v_k = -\frac 1{x_k}\bigl( x_1v_1 + x_2v_2 + \cdots + x_{j-1}v_{j-1} - v_j + x_{j+1}v_{j+1} + \cdots + x_{p-1}v_{p-1} \bigr)\text{.} \end{gather*}
    This says that \(v_k\) is in the span of \(\{v_1,v_2,\ldots,v_{p-1}\}\text{,}\) which contradicts our assumption that \(v_j\) is the last vector in the span of the others.
    🔗
    🔗

    🔗

    Insight 2.5.15.

    If you make a set of vectors by adding one vector at a time, and if the span got bigger every time you added a vector, then your set is linearly independent.
    🔗
    🔗
    🔗

    Subsection 2.5.3 Pictures of Linear Independence

    A set containg one vector \(\{v\}\) is linearly independent when \(v\neq 0\text{,}\) since \(xv = 0\) implies \(x=0\text{.}\)
    🔗
    
    🔗
    A set of two noncollinear vectors \(\{v,w\}\) is linearly independent:
    • Neither is in the span of the other, so we can apply the first Theorem 12.
      🔗
      🔗
    • The span got bigger when we added \(w\text{,}\) so we can apply the Theorem 14.
      🔗
      🔗
    🔗
    
    🔗
    The set of three vectors \(\{v,w,u\}\) below is linearly dependent:
    • \(u\) is in \(\Span\{v,w\}\text{,}\) so we can apply the first Theorem 12.
      🔗
      🔗
    • The span did not increase when we added \(u\text{,}\) so we can apply the Theorem 14.
      🔗
      🔗
    In the picture below, note that \(v\) is in \(\Span\{u,w\}\text{,}\) and \(w\) is in \(\Span\{u,v\}\text{,}\) so we can remove any of the three vectors without shrinking the span.
    🔗
    
    🔗
    Two collinear vectors are always linearly dependent:
    • \(w\) is in \(\Span\{v\}\text{,}\) so we can apply the first Theorem 12.
      🔗
      🔗
    • The span did not increase when we added \(w\text{,}\) so we can apply the Theorem 14.
      🔗
      🔗
    🔗
    
    🔗
    These three vectors \(\{v,w,u\}\) are linearly dependent: indeed, \(\{v,w\}\) is already linearly dependent, so we can use the third Fact 11.

    Subsection 2.5.4 Linear Dependence and Free Variables

    In light of Recipe 9 and Theorem 12, it is natural to ask which columns of a matrix are redundant, i.e., which we can remove without affecting the column span.
    🔗

    Theorem 2.5.25.

    Let \(v_1,v_2,\ldots,v_k\) be vectors in \(\R^n\text{,}\) and consider the matrix
    \begin{align*} A = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_k \\ | \amp | \amp | \end{pmatrix}\text{.} \end{align*}
    Then we can delete the columns of \(A\) without pivots (the columns corresponding to the free variables), without changing \(\Span\{v_1,v_2,\ldots,v_k\}\text{.}\)
    🔗
    The pivot columns are linearly independent, so we cannot delete any more columns without changing the span.
    🔗
    🔗

    Proof.
    If the matrix is in reduced row echelon form:
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 2 \amp 0 \\ 0 \amp 1 \amp 3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    then the column without a pivot is visibly in the span of the pivot columns:
    \begin{gather*} \begin{pmatrix} 2 \\ 3 \\ 0 \end{pmatrix} = 2\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} + 3\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} + 0\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{,} \end{gather*}
    and the pivot columns are linearly independent:
    \begin{gather*} \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix} = x_1\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} + x_2\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} + x_4\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} x_1 \\ x_2 \\ x_4 \end{pmatrix} \implies x_1 = x_2 = x_4 = 0\text{.} \end{gather*}
    🔗
    If the matrix is not in reduced row echelon form, then we row reduce:
    \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 23 \amp 3 \\ 2 \amp 4 \amp 16 \amp 0 \\ -1 \amp -2 \amp -8 \amp 4 \end{pmatrix} \quad\xrightarrow{\text{RREF}}\quad\begin{pmatrix} 1 \amp 0 \amp 2 \amp 0 \\ 0 \amp 1 \amp 3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    The following two vector equations have the same solution set, as they come from row-equivalent matrices:
    \begin{align*} \spalignsysdelims..\left\{\begin{alignedat}{8} x_1\begin{pmatrix} 1 \\ 2 \\ \amp {}-{} \amp 1 \end{pmatrix} \amp {}+{} \amp x_2\begin{pmatrix} 7 \\ 4 \\ \amp {}-{} \amp 2 \end{pmatrix} \amp {}+{} \amp x_3\begin{pmatrix} 23 \\ 16 \\ \amp {}-{} \amp 8 \end{pmatrix} \amp {}+{} \amp x_4\begin{pmatrix} 3 \\ 0 \\ 4 \end{pmatrix} \amp {}={} \amp 0 \amp {} \\ x_1\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \amp {}+{} \amp x_2\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} \amp {}+{} \amp x_3\begin{pmatrix} 2 \\ 3 \\ 0 \end{pmatrix} \amp {}+{} \amp x_4\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} \amp {} \amp {} \amp {} \amp {} \amp {} \amp {} \amp {}={} \amp 0 \amp . \end{alignedat}\right\text{.} \end{align*}
    We conclude that
    \begin{gather*} \begin{pmatrix} 23 \\ 16 \\ -8 \end{pmatrix} = 2\begin{pmatrix} 1 \\ 2 \\ -1 \end{pmatrix} + 3\begin{pmatrix} 7 \\ 4 \\ -2 \end{pmatrix} + 0\begin{pmatrix} 3 \\ 0 \\ 4 \end{pmatrix} \end{gather*}
    and that
    \begin{gather*} x_1\begin{pmatrix} 1 \\ 2 \\ -1 \end{pmatrix} + x_2\begin{pmatrix} 7 \\ 4 \\ -2 \end{pmatrix} + x_4\begin{pmatrix} 3 \\ 0 \\ 4 \end{pmatrix} = 0 \end{gather*}
    has only the trivial solution.
    🔗
    🔗
    Note that it is necessary to row reduce \(A\) to find which are its pivot columns. However, the span of the columns of the row reduced matrix is generally not equal to the span of the columns of \(A\text{:}\) one must use the pivot columns of the original matrix. See Theorem 10 of Section 2.7 for a restatement of the above theorem.
    🔗

    Example 2.5.26.

    The matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 2 \amp 0 \amp -1 \\ -2 \amp -3 \amp 4 \amp 5 \\ 2 \amp 4 \amp 0 \amp -2 \end{pmatrix} \end{align*}
    has reduced row echelon form
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp -8 \amp -7 \\ 0 \amp 1 \amp 4 \amp 3 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    Therefore, the first two columns of \(A\) are the pivot columns, so we can delete the others without changing the span:
    \begin{gather*} \Span\left\{\begin{pmatrix} 1 \\ -2 \\ 2 \end{pmatrix},\;\begin{pmatrix} 2 \\ -3 \\ 4 \end{pmatrix}\right\} = \Span\left\{\begin{pmatrix} 1 \\ -2 \\ 2 \end{pmatrix},\;\begin{pmatrix} 2 \\ -3 \\ 4 \end{pmatrix},\;\begin{pmatrix} 0 \\ 4 \\ 0 \end{pmatrix},\;\begin{pmatrix} -1 \\ 5 \\ -2 \end{pmatrix}\right\}\text{.} \end{gather*}
    Moreover, the first two columns are linearly independent.
    🔗
    🔗

    Insight 2.5.27 Pivot Columns and Dimension.

    Let \(d\) be the number of pivot columns in the matrix
    \begin{align*} A = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_k \\ | \amp | \amp | \end{pmatrix}\text{.} \end{align*}
    • If \(d=1\) then \(\Span\{v_1,v_2,\ldots,v_k\}\) is a line.
      🔗
      🔗
    • If \(d=2\) then \(\Span\{v_1,v_2,\ldots,v_k\}\) is a plane.
      🔗
      🔗
    • If \(d=3\) then \(\Span\{v_1,v_2,\ldots,v_k\}\) is a 3-space.
      🔗
      🔗
    • Et cetera.
      🔗
      🔗
    The number \(d\) is called the dimension. We discussed this notion in Dimension of the solution set and Dimension of the solution set. We will define this concept rigorously in Section 2.7.

    Exercises 2.5.5 Exercises

    1.

      Suppose \(v_1\) and \(v_2\) are vectors in \({\bf R}^2\) and neither vector is a scalar multiple of the other. Then \(\{v_1, v_2\}\) must be a linearly independent set.
      🔗

    • True.

    • False.

    Solution.
    True. The vectors \(v_1\) and \(v_2\) cannot be linearly dependent, since then \(x_1 v_1 + x_2 v_2 = 0\) would have a solution where \(x_1 \neq 0\) or \(x_2 \neq 0\text{.}\) This would mean \(v_1\) and \(v_2\) are scalar multiples of each other: if \(x_1 \neq 0\) then \(v_1 = - \frac{x_2}{x_1} v_2\text{,}\) and similarly if \(x_2 \neq 0\) then \(v_2 = -\frac{x_1}{x_2} v_1\text{.}\)
    🔗
    🔗
    🔗

    2.

      Suppose \(v_1\text{,}\) \(v_2\text{,}\) and \(v_3\) are vectors in \({\bf R}^3\) and that \(v_j\) and \(v_k\) are not collinear whenever \(j \neq k\text{.}\) \(\Span\{v_j, v_k\}\) is a plane whenever \(j \neq k\text{.}\) Then \(\{v_1, v_2, v_3\}\) is a linearly independent set.
      🔗

    • True.

    • False.

    Solution.
    False. Let \(v_1 = \begin{pmatrix}1 \\ 0 \\ 0\end{pmatrix}\text{,}\) \ \(v_2 = \begin{pmatrix}0 \\ 1 \\ 0\end{pmatrix}\text{,}\) \ \(v_3 = \begin{pmatrix}1 \\ 1 \\ 0\end{pmatrix}\text{.}\) No two among them are collinear, so any two vectors chosen among them will span a plane. However, they are linearly dependent since \(v_1 + v_2 = v_3\text{.}\)
    🔗
    🔗
    🔗

    3.

      If \(A\) is \(4 \times 2\) matrix and the solution set to \(Ax=\begin{pmatrix}1 \\ 2 \\ 2 \\ 1\end{pmatrix}\) is a line, then the columns of \(A\) are linearly dependent.
      🔗

    • True.

    • False.

    Solution.
    True. From section 2.4, we know that the solution set of any consistent system \(Ax=b\) is a translation of the homogeneous solution set. Here, the system \(Ax=\begin{pmatrix}1 \\ 2 \\ 2 \\ 1\end{pmatrix}\) has a line as its solution set, so the homogeneous system \(Ax=0\) has a line as its solution set and thus has infinitely many solutions. Therefore, the columns of \(A\) are linearly dependent.
    🔗
    🔗
    🔗

    4.

      If a set \(S\) of vectors contains fewer vectors than there are entries in the vectors, then the set is linearly independent.
      🔗

    • True.

    • False.

    Solution.
    False. For example, the set \(S=\left\{\begin{pmatrix}1 \\ 0 \\ 0\end{pmatrix}, \begin{pmatrix}0 \\ 0 \\ 0\end{pmatrix}\right\}\) in \({\bf R}^3\) is linearly dependent.
    🔗
    🔗
    🔗

    5.

      If \(u\) and \(v\) are vectors in \({\bf R}^5\text{,}\) then the set \(\{u, v, \sqrt{2}u - \pi v\}\) is linearly independent.
      🔗

    • True.

    • False.

    Solution.
    False. The third vector is a linear combination of the first two vectors, so the set is linearly dependent.
    🔗
    🔗
    🔗

    6.

      If a matrix \(A\) has a pivot in each column, then the columns of \(A\) are linearly independent.
      🔗

    • True.

    • False.

    Solution.
    True. Having a pivot in each column guarantees that \(Ax = 0\) has only the trivial solution, which is what it means for the columns of \(A\) to be linearly independent.
    🔗
    🔗
    🔗

    7.

    If you have a set of linearly independent set \(S\) of vectors, and the span of the vectors in \(S\) is a line, then how many vectors are in \(S\text{?}\)
    🔗
    Solution.
    There is exactly one vector in \(S\text{.}\) The span of any single nonzero vector is a line, whereas a linearly independent set with two (or more) vectors would span at least a plane.
    🔗
    🔗
    🔗

    8.

    In each case answer Always, Sometimes, or Never. Justify your answers.
    🔗

    (a)

    A collection of 99 vectors in \({\bf R}^{100}\) is linearly dependent.
    🔗
    Solution.
    False. We could get a set of 99 linearly independent vectors \(\{v_1, v_2, \ldots, v_{99}\}\) by putting \(1\) in the \(k^{th}\) entry of \(v_k\) for each \(k\) and making all other entries \(0\text{.}\)
    \begin{gather*} v_1 = \begin{pmatrix}1 \\ 0 \\ 0 \\ \vdots \\ \ \\ 0 \\ 0\end{pmatrix}, \quad v_2 = \begin{pmatrix}0 \\ 1 \\ 0 \\ \vdots \\ \ \\ 0 \\ 0\end{pmatrix}, \cdots, \quad v_{99} = \begin{pmatrix}0 \\ 0 \\ 0 \\ \vdots \\ \ \\ 1 \\ 0\end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    (b)

    A collection of 100 vectors in \({\bf R}^{99}\) is linearly dependent.
    🔗
    Solution.
    True. If we put the 100 vectors as columns of a matrix, we will get a \(99 \times 100\) matrix. This means the matrix has \(100\) columns but a max of \(99\) pivots, so it cannot have a pivot in each column, therefore the set of vectors is linearly dependent.
    🔗
    🔗
    🔗
    🔗

    Find all values of \(h\) so that the following set vectors is linearly independent.
    \begin{gather*} \left\{ \begin{pmatrix}5 \\ 7 \\ 1\end{pmatrix}, \begin{pmatrix}-5 \\ 7 \\ 0\end{pmatrix}, \begin{pmatrix}10 \\ 0 \\ h\end{pmatrix}\right\} \end{gather*}
    🔗

    10.

    In each case, determine whether the set of vectors is linearly dependent or linearly independent.
    🔗

    (a)

    \(\left\{\begin{pmatrix}1 \\ 0 \\ 0\end{pmatrix}, \ \begin{pmatrix}2 \\ -5 \\ 0\end{pmatrix}, \ \begin{pmatrix}3 \\ 1 \\ 7\end{pmatrix}\right\}\)
    🔗
    Solution.
    Forming a matrix \(A\) with the vectors as columns gives 3 pivot columns (no row-reduction required), so the vectors are linearly independent. Alternatively, use the Increasing Span Criterion.
    🔗
    🔗
    🔗

    (b)

    \(\left\{\begin{pmatrix}1 \\ 2 \\ 3\end{pmatrix}, \ \begin{pmatrix}0 \\ 0 \\ -1\end{pmatrix}, \ \begin{pmatrix}2 \\ 4 \\ 6\end{pmatrix}\right\}\)
    🔗
    Solution.
    The first and third vectors are multiples of each other, so the vectors are linearly dependent.
    🔗
    🔗
    🔗

    (c)

    \(\left\{\begin{pmatrix}1 \\ 0\end{pmatrix}, \ \begin{pmatrix}0 \\ 1\end{pmatrix}, \ \begin{pmatrix}-2 \\ 3\end{pmatrix}\right\}\)
    🔗
    Solution.
    Any three vectors in \({\bf R}^2\) are automatically linearly dependent.
    🔗
    🔗
    🔗

    11.

    Suppose that \(v_1, v_2, v_3, v_4, b\) are vectors in \({\bf R}^6\) and the equation
    \begin{gather*} x_1 v_1 + x_2 v_2 + x_3 v_3 + x_4 v_4 = b \end{gather*}
    has exactly one solution.
    🔗

    (a)

    Must \(\{v_1, v_2, v_3, v_4\}\) be linearly independent?
    🔗
    Solution.
    Yes. Since the first equation has exactly one solution, the matrix \(A\) whose columns are \(v_1\) through \(v_4\) has a pivot in every column, therefore \(\{v_1, v_2, v_3, v_4\}\) are linearly independent.
    🔗
    🔗
    🔗

    (b)

    Must the equation
    \begin{gather*} x_1 v_1 + x_2 v_2 + x_3 v_3 = 0 \end{gather*}
    have exactly one solution?
    🔗
    Solution.
    Yes. Since \(\{v_1, v_2, v_3, v_4\}\) is linearly independent, so is \(\{v_1, v_2, v_3\}\text{,}\) which is the same thing as saying \(x_1 v_1 + x_2 v_2 + x_3 v_3 = 0\) has only the trivial solution \(x_1 = x_2 = x_3 = 0\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Must there be a vector \(v\) so that \(\{b, v\}\) is linearly independent and the equation
    \begin{gather*} x_1 v_1 + x_2 v_2 + x_3 v_3 + x_4 v_4 = v \end{gather*}
    is consistent?
    🔗
    Solution.
    Yes. Since \(\{v_1, v_2, v_3, v_4\}\) is linearly independent, there is at least one vector \(v\) in \(\{v_1, v_2, v_3, v_4\}\) that is not a scalar multiple of \(b\) (otherwise they would all be scalar multiples of \(b\) and therefore linearly dependent). Since \(v\) is in the set \(\{v_1, v_2, v_3, v_4\}\) it is also in \(\textup{Span}\{v_1, v_2, v_3, v_4\}\text{,}\) therefore there is at least one solution to
    \begin{gather*} x_1 v_1 + x_2 v_2 + x_3 v_3 + x_4 v_4 = v\text{.} \end{gather*}
    It will become much easier to see why this part of the problem is true by the end of chapter 2.
