    Section 3.5 Matrix Inverses

    Objectives

    1. Understand what it means for a square matrix to be invertible.
      🔗
      🔗
    2. Learn about invertible transformations, and understand the relationship between invertible matrices and invertible transformations.
      🔗
      🔗
    3. Recipes: compute the inverse matrix, solve a linear system by taking inverses.
      🔗
      🔗
    4. Picture: the inverse of a transformation.
      🔗
      🔗
    5. Vocabulary words: inverse matrix, inverse transformation.
      🔗
      🔗
    🔗
    In Section 3.1 we learned to multiply matrices together. In this section, we learn to “divide” by a matrix. This allows us to solve the matrix equation \(Ax=b\) in an elegant way:
    \begin{gather*} Ax = b \quad\iff\quad x = A\inv b\text{.} \end{gather*}
    One has to take care when “dividing by matrices”, however, because not every matrix has an inverse, and the order of matrix multiplication is important.
    🔗

    Subsection 3.5.1 Invertible Matrices

    The reciprocal or inverse of a nonzero number \(a\) is the number \(b\) which is characterized by the property that \(ab = 1\text{.}\) For instance, the inverse of \(7\) is \(1/7\text{.}\) We use this formulation to define the inverse of a matrix.
    🔗

    Definition 3.5.1.

    Let \(A\) be an \(n\times n\) (square) matrix. We say that \(A\) is invertible if there is an \(n\times n\) matrix \(B\) such that
    \begin{gather*} AB = I_n \sptxt{and} BA = I_n\text{.} \end{gather*}
    In this case, the matrix \(B\) is called the inverse of \(A\text{,}\) and we write \(B = A\inv\text{.}\)
    🔗
    🔗
    We have to require \(AB = I_n\) and \(BA = I_n\) because in general matrix multiplication is not commutative. However, we will show in Corollary 4 of Section 3.6 that if \(A\) and \(B\) are \(n\times n\) matrices such that \(AB = I_n\text{,}\) then automatically \(BA = I_n\text{.}\)
    🔗

    Example 3.5.2.

    Verify that the matrices
    \begin{align*} A = \begin{pmatrix} 2 \amp 1 \\ 1 \amp 1 \end{pmatrix} \sptxt{and} B = \begin{pmatrix} 1 \amp -1 \\ -1 \amp 2 \end{pmatrix} \end{align*}
    are inverses.
    🔗

    Solution.

    We will check that \(AB = I_2\) and that \(BA = I_2\text{.}\)
    \begin{align*} AB \amp= \begin{pmatrix} 2 \amp 1 \\ 1 \amp 1 \end{pmatrix}\begin{pmatrix} 1 \amp -1 \\ -1 \amp 2 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ BA \amp= \begin{pmatrix} 1 \amp -1 \\ -1 \amp 2 \end{pmatrix}\begin{pmatrix} 2 \amp 1 \\ 1 \amp 1 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix} \end{align*}
    Therefore, \(A\) is invertible, with inverse \(B\text{.}\)
    🔗
    🔗
    🔗

    Remark 3.5.3.

    There exist non-square matrices whose product is the identity. Indeed, if
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \end{pmatrix} \sptxt{and} B = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{pmatrix} \end{align*}
    then \(AB = I_2.\) However, \(BA\neq I_3\text{,}\) so \(B\) does not deserve to be called the inverse of \(A\text{.}\)
    🔗
    One can show using the ideas later in this section that if \(A\) is an \(n\times m\) matrix for \(n\neq m\text{,}\) then there is no \(m\times n\) matrix \(B\) such that \(AB = I_m\) and \(BA = I_n\text{.}\) For this reason, we restrict ourselves to square matrices when we discuss matrix invertibility.
    🔗
    🔗

    Fact 3.5.4 Facts about invertible matrices.

    Let \(A\) and \(B\) be invertible \(n\times n\) matrices.
    1. \(A\inv\) is invertible, and its inverse is \((A\inv){}\inv = A.\)
      🔗
      🔗
    2. \(AB\) is invertible, and its inverse is \((AB)\inv = B\inv A\inv\) (note the order).
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. The equations \(AA^{-1}=I_n\) and \(A^{-1}A = I_n\) at the same time exhibit \(A^{-1}\) as the inverse of \(A\) and \(A\) as the inverse of \(A^{-1}.\)
      🔗
      🔗
    2. We compute
      \begin{gather*} (B\inv A\inv)AB = B\inv(A\inv A)B = B\inv I_n B = B\inv B = I_n\text{.} \end{gather*}
      Here we used the associativity of matrix multiplication and the fact that \(I_n B = B\text{.}\) This shows that \(B\inv A\inv\) is the inverse of \(AB\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Why is the inverse of \(AB\) not equal to \(A\inv B\inv\text{?}\) If it were, then we would have
    \begin{gather*} I_n = (AB)(A\inv B\inv) = ABA\inv B\inv\text{.} \end{gather*}
    But there is no reason for \(ABA\inv B\inv\) to equal the identity matrix: one cannot switch the order of \(A\inv\) and \(B\text{,}\) so there is nothing to cancel in this expression. In fact, if \(I_n = (AB)(A\inv B\inv)\text{,}\) then we can multiply both sides on the right by \(BA\) to conclude that \(AB = BA\text{.}\) In other words, \((AB)\inv = A\inv B\inv\) if and only if \(AB=BA\text{.}\)
    🔗
    More generally, the inverse of a product of several invertible matrices is the product of the inverses, in the opposite order; the proof is the same. For instance,
    \begin{gather*} (ABC)\inv = C\inv B\inv A\inv\text{.} \end{gather*}
    🔗
    🔗

    Subsection 3.5.2 Computing the Inverse Matrix

    So far we have defined the inverse matrix without giving any strategy for computing it. We do so now, beginning with the special case of \(2\times 2\) matrices. Then we will give a recipe for the \(n\times n\) case.
    🔗

    Definition 3.5.5.

    The determinant of a \(2\times 2\) matrix is the number
    \begin{align*} \det\begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix} = ad-bc\text{.} \end{align*}
    🔗
    🔗

    Proposition 3.5.6.

    Let \(A = \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\text{.}\)
    1. If \(\det(A) \neq 0\text{,}\) then \(A\) is invertible, and
      \begin{align*} A\inv = \frac 1{\det(A)}\begin{pmatrix} d \amp -b \\ -c \amp a \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    2. If \(\det(A) = 0,\) then \(A\) is not invertible.
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Suppose that \(\det(A)\neq 0\text{.}\) Define \(\displaystyle B = \frac 1{\det(A)}\begin{pmatrix} d \amp -b \\ -c \amp a \end{pmatrix}.\) Then
      \begin{align*} AB = \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\frac 1{\det(A)}\begin{pmatrix} d \amp -b \\ -c \amp a \end{pmatrix} = \frac 1{ad-bc}\begin{pmatrix} ad-bc \amp 0 \\ 0 \amp ad-bc \end{pmatrix} = I_2\text{.} \end{align*}
      The reader can check that \(BA = I_2\text{,}\) so \(A\) is invertible and \(B = A\inv\text{.}\)
      🔗
      🔗
    2. Suppose that \(\det(A) = ad-bc = 0\text{.}\) Let \(T\colon\R^2\to\R^2\) be the matrix transformation \(T(x) = Ax\text{.}\) Then
      \begin{align*} T\begin{pmatrix} -b \\ a \end{pmatrix} \amp= \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\begin{pmatrix} -b \\ a \end{pmatrix} = \begin{pmatrix} -ab+ab \\ -bc+ad \end{pmatrix} = \begin{pmatrix} 0 \\ \det(A) \end{pmatrix} = 0\\ T\begin{pmatrix} d \\ -c \end{pmatrix} \amp= \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\begin{pmatrix} d \\ -c \end{pmatrix} = \begin{pmatrix} ad-bc \\ cd-cd \end{pmatrix} = \begin{pmatrix} \det(A) \\ 0 \end{pmatrix} = 0\text{.} \end{align*}
      If \(A\) is the zero matrix, then it is obviously not invertible. Otherwise, one of \(v= {-b\choose a}\) and \(v = {d\choose -c}\) will be a nonzero vector in the null space of \(A\text{.}\) Suppose that there were a matrix \(B\) such that \(BA=I_2\text{.}\) Then
      \begin{gather*} v = I_2v = BAv = B0 = 0\text{,} \end{gather*}
      which is impossible as \(v\neq 0\text{.}\) Therefore, \(A\) is not invertible.
      🔗
      🔗
    🔗
    🔗
    There is an analogous formula for the inverse of an \(n\times n\) matrix, but it is not as simple, and it is computationally intensive. The interested reader can find it in Subsection 4.2.2.
    🔗

    Example 3.5.7.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 2 \\ 3 \amp 4 \end{pmatrix}\text{.} \end{align*}
    Then \(\det(A) = 1\cdot 4 - 2\cdot 3 = -2.\) By the Proposition 6, the matrix \(A\) is invertible with inverse
    \begin{align*} \begin{pmatrix} 1 \amp 2 \\ 3 \amp 4 \end{pmatrix}\inv = \frac 1{\det(A)}\begin{pmatrix} 4 \amp -2 \\ -3 \amp 1 \end{pmatrix} = -\frac 12\begin{pmatrix} 4 \amp -2 \\ -3 \amp 1 \end{pmatrix}\text{.} \end{align*}
    We check:
    \begin{align*} \begin{pmatrix} 1 \amp 2 \\ 3 \amp 4 \end{pmatrix}\cdot -\frac 12\begin{pmatrix} 4 \amp -2 \\ -3 \amp 1 \end{pmatrix} = -\frac 12\begin{pmatrix} -2 \amp 0 \\ 0 \amp -2 \end{pmatrix} = I_2\text{.} \end{align*}
    🔗
    🔗
    The following theorem gives a procedure for computing \(A\inv\) in general.
    🔗

    Theorem 3.5.8.

    Let \(A\) be an \(n\times n\) matrix, and let \((\,A\mid I_n\,)\) be the matrix obtained by augmenting \(A\) by the identity matrix. If the reduced row echelon form of \((\,A\mid I_n\,)\) has the form \((\,I_n\mid B\,)\text{,}\) then \(A\) is invertible and \(B = A\inv\text{.}\) Otherwise, \(A\) is not invertible.
    🔗
    🔗

    Proof.
    First suppose that the reduced row echelon form of \((\,A\mid I_n\,)\) does not have the form \((\,I_n\mid B\,)\text{.}\) This means that fewer than \(n\) pivots are contained in the first \(n\) columns (the non-augmented part), so \(A\) has fewer than \(n\) pivots. It follows that \(\Nul(A)\neq\{0\}\) (the equation \(Ax=0\) has a free variable), so there exists a nonzero vector \(v\) in \(\Nul(A)\text{.}\) Suppose that there were a matrix \(B\) such that \(BA=I_n\text{.}\) Then
    \begin{gather*} v = I_nv = BAv = B0 = 0\text{,} \end{gather*}
    which is impossible as \(v\neq 0\text{.}\) Therefore, \(A\) is not invertible.
    🔗
    Now suppose that the reduced row echelon form of \((\,A\mid I_n\,)\) has the form \((\,I_n\mid B\,)\text{.}\) In this case, all pivots are contained in the non-augmented part of the matrix, so the augmented part plays no role in the row reduction: the entries of the augmented part do not influence the choice of row operations used. Hence, row reducing \((\,A\mid I_n\,)\) is equivalent to solving the \(n\) systems of linear equations \(Ax_1 = e_1,\,Ax_2=e_2,\,\ldots,Ax_n=e_n\text{,}\) where \(e_1,e_2,\ldots,e_n\) are the standard coordinate vectors:
    \begin{align*} Ax_1 \amp= \o{e_1}: \qquad \hmat{1 0 4 \o1 \mhg{0} \mhg{0;} 0 1 2 \o0 \mhg{1} \mhg{0;} 0 -3 -4 \o0 \mhg{0} \mhg{1}}\\ Ax_2 \amp= \o{e_2}: \qquad \hmat{1 0 4 \mhg{1} \o0 \mhg{0;} 0 1 2 \mhg{0} \o1 \mhg{0;} 0 -3 -4 \mhg{0} \o0 \mhg{1}}\\ Ax_3 \amp= \o{e_3}: \qquad \hmat{1 0 4 \mhg{1} \mhg{0} \o0; 0 1 2 \mhg{0} \mhg{1} \o0; 0 -3 -4 \mhg{0} \mhg{0} \o1}\text{.} \end{align*}
    The columns \(x_1,x_2,\ldots,x_n\) of the matrix \(B\) in the row reduced form are the solutions to these equations:
    \begin{align*} \def\gg{\color{green!70!black}} A\mhp{\begin{pmatrix}} 1 \\ 0 \\ 0 \end{pmatrix} \amp= e_1: \qquad \hmat{1 0 0 \mhp{1} \mhg{-6} \mhg{-2;} 0 1 0 \mhp{0} \mhg{-2} \mhg{-1;} 0 0 1 \mhp{0} \mhg{3/2} \mhg{1/2}}\\ A\mh{\begin{pmatrix}} -6 \\ -2 \\ 3/2 \end{pmatrix} \amp= e_2: \qquad \hmat{1 0 0 \mhg{1} \mh{-6} \mhg{-2;} 0 1 0 \mhg{0} \mh{-2} \mhg{-1;} 0 0 1 \mhg{0} \mh{3/2} \mhg{1/2}}\\ A\gg\begin{pmatrix} -2 \\ -1 \\ 1/2 \end{pmatrix} \amp= e_3: \qquad \hmat{1 0 0 \mhg{1} \mhg{-6} \gg-2; 0 1 0 \mhg{0} \mhg{-2} \gg-1; 0 0 1 \mhg{0} \mhg{3/2} \gg1/2}\text{.} \end{align*}
    By Fact 12 of Section 3.3, the product \(Be_i\) is just the \(i\)th column \(x_i\) of \(B\text{,}\) so
    \begin{gather*} e_i = Ax_i = ABe_i \end{gather*}
    for all \(i\text{.}\) By the same fact, the \(i\)th column of \(AB\) is \(e_i\text{,}\) which means that \(AB\) is the identity matrix. Thus \(B\) is the inverse of \(A\text{.}\)
    🔗
    🔗

    Example 3.5.9 An invertible matrix.

    Find the inverse of the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 4 \\ 0 \amp 1 \amp 2 \\ 0 \amp -3 \amp -4 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We augment by the identity and row reduce: \def\r{\color{red}} \def\rowop#1#2{% \hbox to 2cm{\hss$\xrightarrow{#1}$}\,% \hbox to 4cm{#2\hss}% } \leavevmode \hbox to 4.2cm{$\hmat{1 0 4 1 0 0; 0 1 2 0 1 0; 0 -3 -4 0 0 1}$\hss}% \rowop{R_3 = R_3 + 3R_2}{% $\hmat{1 0 4 1 0 0; 0 1 2 0 1 0; 0 \r0 \r2 0 \r3 1}$} \\[2mm] \leavevmode\hbox to 4.2cm{}\rowop{% \tiny\begin{aligned}R_1\amp=R_1-2R_3\\[-5pt]R_2\amp=R_2-R_3\\[-3pt]\end{aligned}}{% $\hmat{1 0 \r0 1 \r-6 \r-2; 0 1 \r0 0 \r-2 \r-1; 0 0 2 0 3 1}$}\\[2mm] \leavevmode\hbox to 4.2cm{}\rowop{R_3 = R_3\div 2}{% $\hmat{1 0 0 1 -6 -2; 0 1 0 0 -2 -1; 0 0 \r1 0 \r3/2 \r1/2}$.} By the Theorem 8, the inverse matrix is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 4 \\ 0 \amp 1 \amp 2 \\ 0 \amp -3 \amp -4 \end{pmatrix}\inv = \begin{pmatrix} 1 \amp -6 \amp -2 \\ 0 \amp -2 \amp -1 \\ 0 \amp 3/2 \amp 1/2 \end{pmatrix}\text{.} \end{align*}
    We check:
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 4 \\ 0 \amp 1 \amp 2 \\ 0 \amp -3 \amp -4 \end{pmatrix}\begin{pmatrix} 1 \amp -6 \amp -2 \\ 0 \amp -2 \amp -1 \\ 0 \amp 3/2 \amp 1/2 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗

    Example 3.5.10 A non-invertible matrix.

    Is the following matrix invertible?
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 4 \\ 0 \amp 1 \amp 2 \\ 0 \amp -3 \amp -6 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We augment by the identity and row reduce: \def\r{\color{red}} \def\rowop#1#2{% \hbox to 2cm{\hss$\xrightarrow{#1}$}\,% \hbox to 4cm{#2\hss}% } \leavevmode \hbox to 4.2cm{$\hmat{1 0 4 1 0 0; 0 1 2 0 1 0; 0 -3 -6 0 0 1}$\hss}% \rowop{R_3 = R_3 + 3R_2}{% $\hmat{1 0 4 1 0 0; 0 1 2 0 1 0; 0 \r0 \r0 0 3 1}$.} At this point we can stop, because it is clear that the reduced row echelon form will not have \(I_3\) in the non-augmented part: it will have a row of zeros. By the Theorem 8, the matrix is not invertible.

    Subsection 3.5.3 Solving Linear Systems using Inverses

    In this subsection, we learn to solve \(Ax=b\) by “dividing by \(A\text{.}\)”
    🔗

    Theorem 3.5.11.

    Let \(A\) be an invertible \(n\times n\) matrix, and let \(b\) be a vector in \(\R^n.\) Then the matrix equation \(Ax=b\) has exactly one solution:
    \begin{gather*} x = A\inv b\text{.} \end{gather*}
    🔗
    🔗

    Proof.
    We calculate:
    \begin{align*} Ax = b \quad\implies\amp\quad A\inv(Ax) = A\inv b\\ \quad\implies\amp\quad (A\inv A)x = A\inv b\\ \quad\implies\amp\quad I_n x = A\inv b\\ \quad\implies\amp\quad x = A\inv b\text{.} \end{align*}
    Here we used associativity of matrix multiplication, and the fact that \(I_n x = x\) for any vector \(b\text{.}\)
    🔗
    🔗

    Example 3.5.12 Solving a \(2\times 2\) system using inverses.

    Solve the matrix equation
    \begin{align*} \begin{pmatrix} 1 \amp 3 \\ -1 \amp 2 \end{pmatrix}x = \begin{pmatrix} 1 \\ 1 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    By the Theorem 11, the only solution of our linear system is
    \begin{align*} x = \begin{pmatrix} 1 \amp 3 \\ -1 \amp 2 \end{pmatrix}\inv\kern-1pt\begin{pmatrix} 1 \\ 1 \end{pmatrix} = \frac 15\begin{pmatrix} 2 \amp -3 \\ 1 \amp 1 \end{pmatrix}\begin{pmatrix} 1 \\ 1 \end{pmatrix} = \frac 15\begin{pmatrix} -1 \\ 2 \end{pmatrix}\text{.} \end{align*}
    Here we used
    \begin{align*} \det\begin{pmatrix} 1 \amp 3 \\ -1 \amp 2 \end{pmatrix} = 1\cdot 2 - (-1)\cdot 3 = 5\text{.} \end{align*}
    🔗
    🔗
    🔗

    Example 3.5.13 Solving a \(3\times 3\) system using inverses.

    Solve the system of equations
    \begin{align*} \left\{\begin{alignedat}{4} 2x_1 \amp {}+{} \amp 3x_2 \amp {}+{} \amp 2x_3 \amp {}={} \amp 1 \amp {} \\ x_1 \amp {} \amp {} \amp {} \amp 3x_3 \amp {}={} \amp 1 \amp {} \\ 2x_1 \amp {}+{} \amp 2x_2 \amp {}+{} \amp 3x_3 \amp {}={} \amp 1. \amp {} \end{alignedat}\right\text{.} \end{align*}
    🔗

    Solution.

    First we write our system as a matrix equation \(Ax = b\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 2 \amp 3 \amp 2 \\ 1 \amp 0 \amp 3 \\ 2 \amp 2 \amp 3 \end{pmatrix} \sptxt{and} b = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\text{.} \end{align*}

    \begin{align*} \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = \begin{pmatrix} 2 \amp 3 \amp 2 \\ 1 \amp 0 \amp 3 \\ 2 \amp 2 \amp 3 \end{pmatrix}\inv\kern-1pt\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} -6 \amp -5 \amp 9 \\ 3 \amp 2 \amp -4 \\ 2 \amp 2 \amp -3 \end{pmatrix}\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} -2 \\ 1 \\ 1 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗
    The advantage of solving a linear system using inverses is that it becomes much faster to solve the matrix equation \(Ax=b\) for other, or even unknown, values of \(b\text{.}\) For instance, in the above example, the solution of the system of equations

    Subsection 3.5.4 Invertible linear transformations

    As with matrix multiplication, it is helpful to understand matrix inversion as an operation on linear transformations. Recall that the identity transformation on \(\R^n\) is denoted \(\Id_{\R^n}\text{.}\)
    🔗

    Definition 3.5.14.

    A transformation \(T\colon\R^n\to\R^n\) is invertible if there exists a transformation \(U\colon\R^n\to\R^n\) such that \(T\circ U = \Id_{\R^n}\) and \(U\circ T = \Id_{\R^n}\text{.}\) In this case, the transformation \(U\) is called the inverse of \(T\text{,}\) and we write \(U = T\inv\text{.}\)
    🔗
    🔗
    The inverse \(U\) of \(T\) “undoes” whatever \(T\) did. We have
    \begin{gather*} T\circ U(x) = x \sptxt{and} U\circ T(x) = x \end{gather*}
    for all vectors \(x\text{.}\) This means that if you apply \(T\) to \(x\text{,}\) then you apply \(U\text{,}\) you get the vector \(x\) back, and likewise in the other order.
    🔗

    Example 3.5.15 Functions of one variable.

    Define \(f\colon\R\to\R\) by \(f(x) = 2x\text{.}\) This is an invertible transformation, with inverse \(g(x) = x/2\text{.}\) Indeed,
    \begin{gather*} f\circ g(x) = f(g(x)) = f\biggl(\frac x2\biggr) = 2\biggl(\frac x2\biggr) = x \end{gather*}
    and
    \begin{gather*} g\circ f(x) = g(f(x)) = g(2x) = \frac{2x}2 = x\text{.} \end{gather*}
    In other words, dividing by \(2\) undoes the transformation that multiplies by \(2\text{.}\)
    🔗
    Define \(f\colon\R\to\R\) by \(f(x) = x^3\text{.}\) This is an invertible transformation, with inverse \(g(x) = \sqrt[3]x\text{.}\) Indeed,
    \begin{gather*} f\circ g(x) = f(g(x)) = f(\sqrt[3]x) = \bigl(\sqrt[3]x\bigr)^3 = x \end{gather*}
    and
    \begin{gather*} g\circ f(x) = g(f(x)) = g(x^3) = \sqrt[3]{x^3} = x\text{.} \end{gather*}
    In other words, taking the cube root undoes the transformation that takes a number to its cube.
    🔗
    Define \(f\colon\R\to\R\) by \(f(x) = x^2\text{.}\) This is not an invertible function. Indeed, we have \(f(2) = 2 = f(-2)\text{,}\) so there is no way to undo \(f\text{:}\) the inverse transformation would not know if it should send \(2\) to \(2\) or \(-2\text{.}\) More formally, if \(g\colon\R\to\R\) satisfies \(g(f(x)) = x\text{,}\) then
    \begin{gather*} 2 = g(f(2)) = g(2) \sptxt{and} -2 = g(f(-2)) = g(2)\text{,} \end{gather*}
    which is impossible: \(g(2)\) is a number, so it cannot be equal to \(2\) and \(-2\) at the same time.
    🔗
    Define \(f\colon\R\to\R\) by \(f(x) = e^x\text{.}\) This is not an invertible function. Indeed, if there were a function \(g\colon\R\to\R\) such that \(f\circ g = \Id_\R\text{,}\) then we would have
    \begin{gather*} -1 = f\circ g(-1) = f(g(-1)) = e^{g(-1)}\text{.} \end{gather*}
    But \(e^x\) is a positive number for every \(x\text{,}\) so this is impossible.
    🔗
    🔗

    Example 3.5.16 Dilation.

    Let \(T\colon\R^2\to\R^2\) be dilation by a factor of \(3/2\text{:}\) that is, \(T(x) = 3/2x\text{.}\) Is \(T\) invertible? If so, what is \(T\inv\text{?}\)

    Example 3.5.24 Projection.

    Let \(T\colon\R^3\to\R^3\) be the projection onto the \(xy\)-plane, introduced in Example 5 of Section 3.1. Is \(T\) invertible?
    🔗

    Solution.

    The transformation \(T\) is not invertible. Every vector on the \(z\)-axis projects onto the zero vector, so there is no way to undo what \(T\) did: the inverse transformation would not know which vector on the \(z\)-axis it should send the zero vector to. More formally, suppose there were a transformation \(U\colon\R^3\to\R^3\) such that \(U\circ T = \Id_{\R^3}\text{.}\) Then
    \begin{gather*} 0 = U\circ T(0) = U(T(0)) = U(0) \end{gather*}
    and
    \begin{gather*} \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = U\circ T\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = U\left(T\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\right) = U(0)\text{.} \end{gather*}
    But \(U(0)\) is as single vector in \(\R^3\text{,}\) so it cannot be equal to \(0\) and to \((0, 0, 1)\) at the same time.
    🔗
    🔗
    🔗

    Proposition 3.5.26.

    1. A transformation \(T\colon\R^n\to\R^n\) is invertible if and only if it is both one-to-one and onto.
      🔗
      🔗
    2. If \(T\) is already known to be invertible, then \(U\colon\R^n\to\R^n\) is the inverse of \(T\) provided that either \(T\circ U = \Id_{\R^n}\) or \(U\circ T = \Id_{\R^n}\text{:}\) it is only necessary to verify one.
      🔗
      🔗
    🔗
    🔗

    Proof.
    To say that \(T\) is one-to-one and onto means that \(T(x)=b\) has exactly one solution for every \(b\) in \(\R^n\text{.}\)
    🔗
    Suppose that \(T\) is invertible. Then \(T(x)=b\) always has the unique solution \(x = T\inv(b)\text{:}\) indeed, applying \(T\inv\) to both sides of \(T(x)=b\) gives
    \begin{gather*} x = T\inv(T(x)) = T\inv(b)\text{,} \end{gather*}
    and applying \(T\) to both sides of \(x = T\inv(b)\) gives
    \begin{gather*} T(x) = T(T\inv(b)) = b\text{.} \end{gather*}
    🔗
    Conversely, suppose that \(T\) is one-to-one and onto. Let \(b\) be a vector in \(\R^n\text{,}\) and let \(x = U(b)\) be the unique solution of \(T(x)=b\text{.}\) Then \(U\) defines a transformation from \(\R^n\) to \(\R^n\text{.}\) For any \(x\) in \(\R^n\text{,}\) we have \(U(T(x)) = x\text{,}\) because \(x\) is the unique solution of the equation \(T(x) = b\) for \(b = T(x)\text{.}\) For any \(b\) in \(\R^n\text{,}\) we have \(T(U(b)) = b\text{,}\) because \(x = U(b)\) is the unique solution of \(T(x)=b\text{.}\) Therefore, \(U\) is the inverse of \(T\text{,}\) and \(T\) is invertible.
    🔗
    Suppose now that \(T\) is an invertible transformation, and that \(U\) is another transformation such that \(T\circ U = \Id_{\R^n}\text{.}\) We must show that \(U = T\inv\text{,}\) i.e., that \(U\circ T = \Id_{\R^n}\text{.}\) We compose both sides of the equality \(T\circ U = \Id_{\R^n}\) on the left by \(T\inv\) and on the right by \(T\) to obtain
    \begin{gather*} T\inv\circ T\circ U\circ T = T\inv\circ\Id_{\R^n}\circ T\text{.} \end{gather*}
    We have \(T\inv\circ T = \Id_{\R^n}\) and \(\Id_{\R^n}\circ U = U\text{,}\) so the left side of the above equation is \(U\circ T\text{.}\) Likewise, \(\Id_{\R^n}\circ T = T\) and \(T\inv\circ T = \Id_{\R^n}\text{,}\) so our equality simplifies to \(U\circ T = \Id_{\R^n}\text{,}\) as desired.
    🔗
    If instead we had assumed only that \(U\circ T = \Id_{\R^n}\text{,}\) then the proof that \(T\circ U = \Id_{\R^n}\) proceeds similarly.
    🔗
    🔗

    Remark 3.5.27.

    It makes sense in the above Definition 14 to define the inverse of a transformation \(T\colon\R^n\to\R^m\text{,}\) for \(m\neq n\text{,}\) to be a transformation \(U\colon\R^m\to\R^n\) such that \(T\circ U = \Id_{\R^m}\) and \(U\circ T = \Id_{\R^n}\text{.}\) In fact, there exist invertible transformations \(T\colon\R^n\to\R^m\) for any \(m\) and \(n\text{,}\) but they are not linear, or even continuous.
    🔗
    If \(T\) is a linear transformation, then it can only be invertible when \(m = n\text{,}\) i.e., when its domain is equal to its codomain. Indeed, if \(T\colon\R^n\to\R^m\) is one-to-one, then \(n\leq m\) by Note 14 of Section 3.2, and if \(T\) is onto, then \(m\leq n\) by Note 26 of Section 3.2. Therefore, when discussing invertibility we restrict ourselves to the case \(m=n\text{.}\)

    Remark 3.5.28.

    Find an invertible (non-linear) transformation \(T\colon\R^2\to\R\text{.}\)
    🔗
    🔗
    As you might expect, the matrix for the inverse of a linear transformation is the inverse of the matrix for the transformation, as the following theorem asserts.
    🔗

    Theorem 3.5.29.

    Let \(T\colon\R^n\to\R^n\) be a linear transformation with standard matrix \(A\text{.}\) Then \(T\) is invertible if and only if \(A\) is invertible, in which case \(T\inv\) is linear with standard matrix \(A\inv\text{.}\)
    🔗
    🔗

    Proof.
    Suppose that \(T\) is invertible. Let \(U\colon\R^n\to\R^n\) be the inverse of \(T\text{.}\) We claim that \(U\) is linear. We need to check the Definition 1 of Section 3.3. Let \(u,v\) be vectors in \(\R^n\text{.}\) Then
    \begin{gather*} u + v = T(U(u)) + T(U(v)) = T(U(u) + U(v)) \end{gather*}
    by linearity of \(T\text{.}\) Applying \(U\) to both sides gives
    \begin{gather*} U(u + v) = U\bigl(T(U(u) + U(v))\bigr) = U(u) + U(v)\text{.} \end{gather*}
    Let \(c\) be a scalar. Then
    \begin{gather*} cu = cT(U(u)) = T(cU(u)) \end{gather*}
    by linearity of \(T\text{.}\) Applying \(U\) to both sides gives
    \begin{gather*} U(cu) = U\bigl(T(cU(u))\bigr) = cU(u)\text{.} \end{gather*}
    Since \(U\) satisfies the Definition 1 of Section 3.3, it is a linear transformation.
    🔗
    Now that we know that \(U\) is linear, we know that it has a standard matrix \(B\text{.}\) By the Theorem 25 of Section 3.4, the matrix for \(T\circ U\) is \(AB\text{.}\) But \(T\circ U\) is the identity transformation \(\Id_{\R^n},\) and the standard matrix for \(\Id_{\R^n}\) is \(I_n\text{,}\) so \(AB = I_n\text{.}\) One shows similarly that \(BA = I_n\text{.}\) Hence \(A\) is invertible and \(B = A\inv\text{.}\)
    🔗
    Conversely, suppose that \(A\) is invertible. Let \(B = A\inv\text{,}\) and define \(U\colon\R^n\to\R^n\) by \(U(x) = Bx\text{.}\) By the Theorem 25 of Section 3.4, the matrix for \(T\circ U\) is \(AB = I_n\text{,}\) and the matrix for \(U\circ T\) is \(BA = I_n\text{.}\) Therefore,
    \begin{gather*} T\circ U(x) = ABx = I_nx = x \sptxt{and} U\circ T(x) = BAx = I_nx = x\text{,} \end{gather*}
    which shows that \(T\) is invertible with inverse transformation \(U\text{.}\)

    Example 3.5.30 Dilation.

    Let \(T\colon\R^2\to\R^2\) be dilation by a factor of \(3/2\text{:}\) that is, \(T(x) = 3/2x\text{.}\) Is \(T\) invertible? If so, what is \(T\inv\text{?}\)
    🔗

    Solution.

    In Example 9 of Section 3.1 we showed that the matrix for \(T\) is
    \begin{align*} A = \begin{pmatrix} 3/2 \amp 0 \\ 0 \amp 3/2 \end{pmatrix}\text{.} \end{align*}
    The determinant of \(A\) is \(9/4\neq 0\text{,}\) so \(A\) is invertible with inverse
    \begin{align*} A\inv = \frac 1{9/4}\begin{pmatrix} 3/2 \amp 0 \\ 0 \amp 3/2 \end{pmatrix} = \begin{pmatrix} 2/3 \amp 0 \\ 0 \amp 2/3 \end{pmatrix}\text{.} \end{align*}
    By the Theorem 29, \(T\) is invertible, and its inverse is the matrix transformation for \(A\inv\text{:}\)
    \begin{align*} T\inv(x) = \begin{pmatrix} 2/3 \amp 0 \\ 0 \amp 2/3 \end{pmatrix}x\text{.} \end{align*}
    We recognize this as a dilation by a factor of \(2/3\text{.}\)

    Example 3.5.31 Rotation.

    Let \(T\colon\R^2\to\R^2\) be counterclockwise rotation by \(45^\circ\text{.}\) Is \(T\) invertible? If so, what is \(T\inv\text{?}\)
    🔗

    Solution.

    In Example 18 of Section 3.3, we showed that the standard matrix for the counterclockwise rotation of the plane by an angle of \(\theta\) is
    \begin{align*} \begin{pmatrix} \cos\theta \amp -\sin\theta \\ \sin\theta \amp \cos\theta \end{pmatrix}\text{.} \end{align*}
    Therefore, the standard matrix \(A\) for \(T\) is
    \begin{align*} A = \frac 1{\sqrt 2}\begin{pmatrix} 1 \amp -1 \\ 1 \amp 1 \end{pmatrix}\text{,} \end{align*}
    where we have used the trigonometric identities
    \begin{gather*} \cos(45^\circ) = \frac 1{\sqrt2} \qquad \sin(45^\circ) = \frac 1{\sqrt2}\text{.} \end{gather*}
    The determinant of \(A\) is
    \begin{gather*} \det(A) = \frac 1{\sqrt2}\cdot\frac 1{\sqrt2} - \frac 1{\sqrt2}\frac{-1}{\sqrt2} = \frac 12 + \frac 12 = 1\text{,} \end{gather*}
    so the inverse is
    \begin{align*} A\inv = \frac 1{\sqrt2}\begin{pmatrix} 1 \amp 1 \\ -1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    By the Theorem 29, \(T\) is invertible, and its inverse is the matrix transformation for \(A\inv\text{:}\)
    \begin{align*} T\inv(x) = \frac 1{\sqrt2}\begin{pmatrix} 1 \amp 1 \\ -1 \amp 1 \end{pmatrix}x\text{.} \end{align*}
    We recognize this as a clockwise rotation by \(45^\circ\text{,}\) using the trigonometric identities
    \begin{gather*} \cos(-45^\circ) = \frac 1{\sqrt2} \qquad \sin(-45^\circ) = -\frac 1{\sqrt2}\text{.} \end{gather*}

    Example 3.5.32 Reflection.

    Let \(T\colon\R^2\to\R^2\) be the reflection over the \(y\)-axis. Is \(T\) invertible? If so, what is \(T\inv\text{?}\)
    🔗

    Solution.

    In Example 7 of Section 3.1 we showed that the matrix for \(T\) is
    \begin{align*} A = \begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    This matrix has determinant \(-1\text{,}\) so it is invertible, with inverse
    \begin{align*} A\inv = -\begin{pmatrix} 1 \amp 0 \\ 0 \amp -1 \end{pmatrix} = \begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix} = A\text{.} \end{align*}
    By the Theorem 29, \(T\) is invertible, and it is equal to its own inverse: \(T\inv = T\text{.}\) This is another way of saying that a reflection “undoes” itself.
