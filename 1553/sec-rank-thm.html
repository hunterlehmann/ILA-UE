    Section 2.8 The Rank Theorem

    Objectives

    1. Learn to understand and use the rank theorem.
      🔗
      🔗
    2. Picture: the rank theorem.
      🔗
      🔗
    3. Theorem: rank theorem.
      🔗
      🔗
    4. Vocabulary words: rank, nullity.
      🔗
      🔗
    🔗
    In this section we present the rank theorem, which is the culmination of all of the work we have done so far.
    🔗
    The reader may have observed a relationship between the column space and the null space of a matrix. In Example 16 of Section 2.6, the column space and the null space of a \(3\times 2\) matrix are both lines, in \(\R^2\) and \(\R^3\text{,}\) respectively:
    🔗
    
    🔗
    In Example 13 of Section 2.4, the null space of the \(2\times 3\) matrix \(\bigl(\begin{smallmatrix}1&-1&2\\-2&2&-4\end{smallmatrix}\bigr)\) is a plane in \(\R^3\text{,}\) and the column space the line in \(\R^2\) spanned by \({1\choose-2}\text{:}\)
    🔗
    
    🔗
    In Interactive 21 of Section 2.4, the null space of a \(3\times 3\) matrix is a line in \(\R^3\text{,}\) and the column space is a plane in \(\R^3\text{:}\)
    🔗
    
    🔗
    In all examples, the dimension of the column space plus the dimension of the null space is equal to the number of columns of the matrix. This is the content of the rank theorem.
    🔗

    Definition 2.8.1.

    The rank of a matrix \(A\text{,}\) written \(\rank(A)\text{,}\) is the dimension of the column space \(\Col(A)\text{.}\)
    🔗
    The nullity of a matrix \(A\text{,}\) written \(\nullity(A)\text{,}\) is the dimension of the null space \(\Nul(A)\text{.}\)
    🔗
    🔗
    The rank of a matrix \(A\) gives us important information about the solutions to \(Ax=b\text{.}\) Recall from Spans and Consistency that \(Ax=b\) is consistent exactly when \(b\) is in the span of the columns of \(A\text{,}\) in other words when \(b\) is in the column space of \(A\text{.}\) Thus, \(\rank(A)\) is the dimension of the set of \(b\) with the property that \(Ax=b\) is consistent.
    🔗
    We know that the rank of \(A\) is equal to the number of pivot columns (see Theorem 10 of Section 2.7), and the nullity of \(A\) is equal to the number of free variables (see Theorem 17 of Section 2.7), which is the number of columns without pivots. To summarize:
    \begin{align*} \rank(A) = \dim\Col(A) \amp= \text{the number of columns with pivots}\\ \nullity(A) = \dim\Nul(A) \amp= \text{the number of free variables}\\ \amp= \text{the number of columns without pivots} \end{align*}
    Clearly
    \begin{gather*} \text{\#(columns with pivots)} + \text{\#(columns without pivots)} = \text{\#(columns)}\text{,} \end{gather*}
    so we have proved the following theorem.
    🔗

    Theorem 2.8.2 Rank Theorem.

    If \(A\) is a matrix with \(n\) columns, then
    \begin{gather*} \rank(A) + \nullity(A) = n\text{.} \end{gather*}
    🔗
    🔗
    In other words, for any consistent system of linear equations,
    \begin{gather*} \text{(dim of column span)} + \text{(dim of solution set)} = \text{(number of variables)}\text{.} \end{gather*}
    🔗
    The rank theorem theorem is really the culmination of this chapter, as it gives a strong relationship between the null space of a matrix (the solution set of \(Ax=0\)) with the column space (the set of vectors \(b\) making \(Ax=b\) consistent), our two primary objects of interest. The more freedom we have in choosing \(x\) the less freedom we have in choosing \(b\) and vice versa.
    🔗

    Example 2.8.3 Rank and nullity.

    Here is a concrete example of the rank theorem and the interplay between the degrees of freedom we have in choosing \(x\) and \(b\) in a matrix equation \(Ax=b\text{.}\)
    🔗
    Consider the matrices
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \quad \text{and} \quad B = \begin{pmatrix} 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    If we multiply a vector \((x,y,z)\) in \(\R^3\) by \(A\) and \(B\) we obtain the vectors \(Ax = (x,y,0)\) and \(Bx = (0,0,z)\text{.}\) So we can think of multiplication by \(A\) as giving the latitude and longitude of a point in \(\R^3\) and we can think of multiplication by \(B\) as giving the height of a point in \(\R^3\text{.}\) The rank of \(A\) is 2 and the nullity is 1. Similarly, the rank of \(B\) is 1 and the nullity is 2.
    🔗
    These facts have natural interpretations. For the matrix \(A\text{:}\) the set of all latitudes and longitudes in \(\R^3\) is a plane, and the set of points with the same latitude and longitude in \(\R^3\) is a line; and for the matrix \(B\text{:}\) the set of all heights in \(\R^3\) is a line, and the set of points at a given height in \(\R^3\) is a plane. As the rank theorem tells us, we “trade off” having more choices for \(x\) for having more choices for \(b\text{,}\) and vice versa.
    🔗
    🔗
    The rank theorem is a prime example of how we use the theory of linear algebra to say something qualitative about a system of equations without ever solving it. This is, in essence, the power of the subject.
    🔗

    🔗
    A basis for \(\Col(A)\) is given by the pivot columns:
    \begin{gather*} \left\{\begin{pmatrix} 1 \\ -2 \\ 2 \end{pmatrix},\;\begin{pmatrix} 2 \\ -3 \\ 4 \end{pmatrix}\right\}\text{,} \end{gather*}

    Exercises Exercises

    1.

      There is a \(3 \times 2\) matrix \(A\) so that the column space of \(A\) is a line and the null space of \(A\) is a line.
      🔗

    • True.

    • False.

    Solution.
    True: for example, \(A = \begin{pmatrix}1 \amp 0 \\ 1 \amp 0 \\ 1 \amp 0\end{pmatrix}\text{.}\) This has one column with a pivot (so \(\Col(A)\) is a line) and one column without a pivot (so \(\Nul(A)\) is a line).
    🔗
    🔗
    🔗

    2.

      There is a \(2 \times 3\) matrix \(A\) so that the column space of \(A\) is a line and the null space of \(A\) is a line.
      🔗

    • True.

    • False.

    Solution.
    False: If \(\Col(A)\) and \(\Nul(A)\) are both lines, then the sum of their dimensions is \(2\text{,}\) but this is impossible by the Rank Theorem since
    \begin{gather*} \dim(\Col \ A) + \dim(\Nul \ A) = \ (\textup{number of columns of }A) = 3\text{.} \end{gather*}
    🔗
    🔗
    🔗

    3.

      If \(A\) is a \(10 \times 11\) matrix and its null space is a line, then every vector in \({\bf R}^{10}\) is a linear combination of the columns of \(A\text{.}\)
      🔗

    • True.

    • False.

    Solution.
    True. First we recall that since \(A\) has \(10\) rows, the column space of \(A\) is a subspace of \({\bf R}^{10}\text{.}\) By the Rank Theorem and the fact that the null space is a line, we get
    \begin{gather*} \dim(\Col \ A) + \dim(\Nul \ A) = 11, \qquad \dim(\Col \ A) + 1 = 11, \qquad \dim(\Col \ A) = 10\text{.} \end{gather*}
    Therefore, \(\Col(A)\) is a \(10\)-dimensional subspace of \({\bf R}^{10}\text{,}\) which is just another way of saying \(\Col(A) = {\bf R}^{10}\text{.}\)
    🔗
    🔗
    🔗

    4.

    Suppose \(A\) is a \(66 \times 77\) matrix. Which of the following statements are true? Select all that apply.
    🔗

    (a)

    The homogeneous equation \(Ax=0\) must have infinitely many solutions.
    🔗
    Solution.
    True: \(A\) is \(66 \times 77\text{,}\) so \(A\) has at most \(66\) pivots. Since \(A\) has \(77\) columns, this means at least \(11\) columns in \(A\) will not have pivots, therefore the equation \(Ax=0\) has at least \(11\) free variables. This is just another way of rephrasing the consequences of the Rank Theorem, which expresses this succinctly in part (c).
    🔗
    🔗
    🔗

    (b)

    The column space of \(A\) is a subspace \({\bf R}^{66}\text{.}\)
    🔗
    Solution.
    True, since \(A\) has \(66\) rows.
    🔗
    🔗
    🔗

    (c)

    \(\dim(\Nul(A)) \geq 11\text{.}\)
    🔗
    Solution.
    True. By the Rank Theorem,
    \begin{gather*} \dim(\Col \ A) + \dim(\Nul \ A) = 77\text{,} \end{gather*}
    but since \(\Col \ A\) is a subspace of \({\bf R}^{66}\) we know \(\dim(\Col(A)) \leq 66\text{,}\) therefore \(\dim(\Nul \ A) \geq 11\text{.}\)
    🔗
    🔗
    🔗
    🔗

    5.

    Is there a \(3 \times 3\) matrix \(A\) with the property that \(\textup{Nul}(A) = \textup{Col}(A)\text{?}\) If so, write one.
    🔗
    Solution.
    No: if \(\textup{Nul}(A) = \textup{Col}(A)\text{,}\) then by the Rank Theorem,
    \begin{gather*} 3 = \dim(\textup{Nul} \ A) + \dim(\textup{Col} \ A) = 2 \dim(\textup{Nul} \ A)\text{.} \end{gather*}
    This would mean \(\dim(\textup{Nul} \ A) = 3/2\text{.}\)
    🔗
    🔗
    🔗

    6.

    Is there a \(2 \times 2\) matrix \(A\) with the property that \(\textup{Nul}(A) = \textup{Col}(A)\text{?}\) If so, write one.
    🔗
    Solution.
    Yes: unlike in the \(3 \times 3\) case, the Rank Theorem does not rule out the possibility that \(\textup{Nul}(A) = \textup{Col}(A)\text{.}\) However, it may take some time and trial and error to write such an \(A\text{.}\) One example is \(A = \begin{pmatrix}0 \amp 1 \\ 0 \amp 0\end{pmatrix}\text{.}\) Both its range and null space are the span of \(\begin{pmatrix}1 \\ 0\end{pmatrix}\text{.}\)
    🔗
    🔗
    🔗

    7.

    Suppose that \(A\) is a \(6 \times 2\) matrix and that the column space of \(A\) is \(2\)-dimensional. Is it possible for \(\begin{pmatrix}1 \\ 0\end{pmatrix}\) and \(\begin{pmatrix}1 \\ 1\end{pmatrix}\) to be solutions to \(Ax = b\) for some \(b\) in \({\bf R}^6\text{?}\) Justify your answer.
    🔗
    Solution.
    No, it is not possible. Here \(A\) is \(6 \times 2\) with a \(2\)-dimensional column space, so both of its columns are pivot columns. In other words, its columns are linearly independent. Therefore, \(Ax = 0\) has exactly one solution, so any consistent system \(Ax = b\) must have exactly one solution.
    🔗
    🔗
    🔗

    8.

    Suppose that \(A\) is a \(5 \times 7\) matrix and the column space of \(A\) is a line in \({\bf R}^5\text{.}\) Describe the set of solutions to \(Ax = 0\text{.}\)
    🔗
    Solution.
    We are told that \(\dim(\Col \ A) = 1\text{.}\) By the Rank Theorem:
    \begin{gather*} \dim(\Col \ A) + \dim(\Nul \ A) = 7, \qquad 1 + \dim(\Nul \ A) = 7, \qquad \dim(\Nul \ A) = 6\text{.} \end{gather*}
    Also, the null space of \(A\) lives in \({\bf R}^7\) since \(A\) has \(7\) columns. Therefore, the set of solutions to \(Ax = 0\) is \(6\)-dimensional subspace of \({\bf R}^7\text{.}\)
    🔗
    🔗
    🔗

    9.

    Suppose that \(A\) is a \(5 \times 7\) matrix and the column space of \(A\) is \({\bf R}^5\text{.}\) Describe the set of solutions to \(Ax = 0\text{.}\)
    🔗
    Solution.
    We are told that \(\dim(\Col \ A) = 5\text{.}\) By the Rank Theorem:
    \begin{gather*} \dim(\Col \ A) + \dim(\Nul \ A) = 7, \qquad 5 + \dim(\Nul \ A) = 7, \qquad \dim(\Nul \ A) = 2\text{.} \end{gather*}
    Also, the null space of \(A\) lives in \({\bf R}^7\) since \(A\) has \(7\) columns. Therefore, the set of solutions to \(Ax = 0\) is a plane in \({\bf R}^7\text{.}\)
    🔗
    🔗
    🔗

    10.

    Suppose that \(A\) is a \(5 \times 7\) matrix and the null space of \(A\) is a plane. Is the matrix equation \(Ax = (1, 2, 3, 4, 5)\) consistent? Justify your answer.
    🔗
    Solution.
    Yes. The Rank Theorem gives us
    \begin{gather*} \dim(\Col \ A) + \dim(\Nul \ A) = 7, \qquad \dim(\Col \ A) + 2 = 7, \qquad \dim(\Col \ A) = 5\text{.} \end{gather*}
    In other words, the column space of \(A\) is all of \({\bf R}^5\text{,}\) therefore \(Ax = b\) is consistent for every \(b\) in \({\bf R}^5\text{.}\)
    🔗
    🔗
    🔗

    11.

    Fill in the blanks: If \(A\) is a \(5 \times 6\) matrix and whose columns span a plane, then the null space of \(A\) is a \underline{\qquad \qquad}-dimensional subspace of \(\R^{\fbox{\phantom{\tiny 2}}}\text{.}\)
    🔗
    Solution.
    \(\Nul A\) is a subspace of \({\bf R}^6\text{,}\) and \(\dim(\Col \ A)+ \dim(\Nul \ A)=6\) so \(2+\dim(\Nul A)=6\text{.}\) Thus \(\Nul \ A\) is a 4-dimensional subspace of \({\bf R}^6\text{.}\)
    🔗
    🔗
    🔗

    12.

    Write a matrix \(A\) whose null space is \(3\)-dimensional and whose column space is \(4\)-dimensional.
    🔗
    Solution.
    By the Rank Theorem, the sum of the dimensions of the null and column spaces is equal to the number of columns of \(A\text{,}\) so \(A\) must have \(7\) columns. Moreover, exactly \(4\) columns must be pivot columns so that \(\rank(A)=4\text{.}\)
    🔗
    One example is
    \begin{align*} A = \begin{pmatrix}1 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 0 \amp 0 \amp 0\end{pmatrix}\text{.} \end{align*}
