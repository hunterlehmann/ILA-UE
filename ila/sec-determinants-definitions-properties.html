    Section 4.1 Determinants: Definition

    Objectives

    1. Learn the definition of the determinant.
      🔗
      🔗
    2. Learn some ways to eyeball a matrix with zero determinant, and how to compute determinants of upper- and lower-triangular matrices.
      🔗
      🔗
    3. Learn the basic properties of the determinant, and how to apply them.
      🔗
      🔗
    4. Recipe: compute the determinant using row and column operations.
      🔗
      🔗
    5. Theorems: existence theorem, invertibility property, multiplicativity property, transpose property.
      🔗
      🔗
    6. Vocabulary words: diagonal, upper-triangular, lower-triangular, transpose.
      🔗
      🔗
    7. Essential vocabulary word: determinant.
      🔗
      🔗
    🔗
    In this section, we define the determinant, and we present one way to compute it. Then we discuss some of the many wonderful properties the determinant enjoys.
    🔗

    Subsection 4.1.1 The Definition of the Determinant

    The determinant of a square matrix \(A\) is a real number \(\det(A)\text{.}\) It is defined via its behavior with respect to row operations; this means we can use row reduction to compute it. We will give a recursive formula for the determinant in Section 4.2. We will also show in Subsection 4.1.2 that the determinant is related to invertibility, and in Section 4.3 that it is related to volumes.
    🔗

    Definition 4.1.1.

    The determinant is a function
    \begin{gather*} \det\colon \bigl\{\text{square matrices}\bigr\}\To\R \end{gather*}
    satisfying the following properties:
    1. Doing a row replacement on \(A\) does not change \(\det(A)\text{.}\)
      🔗
      🔗
    2. Scaling a row of \(A\) by a scalar \(c\) multiplies the determinant by \(c\text{.}\)
      🔗
      🔗
    3. Swapping two rows of a matrix multiplies the determinant by \(-1\text{.}\)
      🔗
      🔗
    4. The determinant of the identity matrix \(I_n\) is equal to \(1\text{.}\)
      🔗
      🔗
    🔗
    🔗
    In other words, to every square matrix \(A\) we assign a number \(\det(A)\) in a way that satisfies the above properties.
    🔗
    In each of the first three cases, doing a row operation on a matrix scales the determinant by a nonzero number. (Multiplying a row by zero is not a row operation.) Therefore, doing row operations on a square matrix \(A\) does not change whether or not the determinant is zero.
    🔗
    The main motivation behind using these particular defining properties is geometric: see Section 4.3. Another motivation for this definition is that it tells us how to compute the determinant: we row reduce and keep track of the changes.
    🔗

    Example 4.1.2.

    Let us compute \(\det\smallmat2114.\) First we row reduce, then we compute the determinant in the opposite order:
    \begin{align*} \amp\begin{pmatrix} 2 \amp 1 \\ 1 \amp 4 \end{pmatrix} \amp\strut\det\amp=7\\ \;\xrightarrow{\hbox to 1.7cm{\hss\tiny$R_1\longleftrightarrow R_2$\hss}}\;\amp \begin{pmatrix} 1 \amp 4 \\ 2 \amp 1 \end{pmatrix} \amp \strut\det \amp= -7\\ \;\xrightarrow{\hbox to 1.7cm{\hss\tiny$R_2 = R_2 - 2R_1$\hss}}\;\amp \begin{pmatrix} 1 \amp 4 \\ 0 \amp -7 \end{pmatrix} \amp \strut\det \amp= -7\\ \;\xrightarrow{\hbox to 1.7cm{\hss\tiny$R_2 = R_2 \div -7$\hss}}\;\amp \begin{pmatrix} 1 \amp 4 \\ 0 \amp 1 \end{pmatrix} \amp \strut\det \amp= 1\\ \;\xrightarrow{\hbox to 1.7cm{\hss\tiny$R_1 = R_1 - 4R_2$\hss}}\;\amp \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix} \amp \strut\det \amp= 1 \end{align*}
    The reduced row echelon form of the matrix is the identity matrix \(I_2\text{,}\) so its determinant is \(1\text{.}\) The second-last step in the row reduction was a row replacement, so the second-final matrix also has determinant \(1\text{.}\) The previous step in the row reduction was a row scaling by \(-1/7\text{;}\) since (the determinant of the second matrix times \(-1/7\)) is \(1\text{,}\) the determinant of the second matrix must be \(-7\text{.}\) The first step in the row reduction was a row swap, so the determinant of the first matrix is negative the determinant of the second. Thus, the determinant of the original matrix is \(7\text{.}\)
    🔗
    Note that our answer agrees with definition of the determinant.
    🔗
    🔗

    Example 4.1.3.

    Compute \(\det\begin{pmatrix} 1 \amp 0 \\ 0 \amp 3 \end{pmatrix}.\)
    🔗

    Solution.

    Let \(A=\begin{pmatrix} 1 \amp 0 \\ 0 \amp 3 \end{pmatrix}\text{.}\) Since \(A\) is obtained from \(I_2\) by multiplying the second row by the constant \(3\text{,}\) we have
    \begin{gather*} \det(A)=3\det(I_2)=3\cdot 1=3\text{.} \end{gather*}
    🔗
    Note that our answer agrees with definition of the determinant.
    🔗
    🔗
    🔗

    Example 4.1.4.

    Compute \(\det\begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \\ 5 \amp 1 \amp 0 \end{pmatrix}.\)
    🔗

    Solution.

    First we row reduce, then we compute the determinant in the opposite order:
    \begin{align*} \amp\begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \\ 5 \amp 1 \amp 0 \end{pmatrix} \amp\strut\det\amp=-1\\ \;\xrightarrow{\hbox to 1.7cm{\hss\tiny$R_2\longleftrightarrow R_3$\hss}}\;\amp \begin{pmatrix} 1 \amp 0 \amp 0 \\ 5 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \amp \strut\det \amp= 1\\ \;\xrightarrow{\hbox to 1.7cm{\hss\tiny$R_2 = R_2 - 5R_1$\hss}}\;\amp \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \amp \strut\det \amp= 1 \end{align*}
    The reduced row echelon form is \(I_3\text{,}\) which has determinant \(1\text{.}\) Working backwards from \(I_3\) and using the four Definition 1, we see that the second matrix also has determinant \(1\) (it differs from \(I_3\) by a row replacement), and the first matrix has determinant \(-1\) (it differs from the second by a row swap).
    🔗
    🔗
    🔗
    Here is the general method for computing determinants using row reduction.
    🔗

    Recipe 4.1.5 Computing determinants by row reducing.

    Let \(A\) be a square matrix. Suppose that you do some number of row operations on \(A\) to obtain a matrix \(B\) in row echelon form. Then
    \begin{gather*} \det(A) = (-1)^r\cdot \frac{\text{(product of the diagonal entries of $B$)}} {\text{(product of scaling factors used)}}\text{,} \end{gather*}
    where \(r\) is the number of row swaps performed.
    🔗
    🔗
    In other words, the determinant of \(A\) is the product of diagonal entries of the row echelon form \(B\text{,}\) times a factor of \(\pm1\) coming from the number of row swaps you made, divided by the product of the scaling factors used in the row reduction.
    🔗

    Remark 4.1.6.

    This is an efficient way of computing the determinant of a large matrix, either by hand or by computer. The computational complexity of row reduction is \(O(n^3)\text{;}\) by contrast, the cofactor expansion algorithm we will learn in Section 4.2 has complexity \(O(n!)\approx O(n^n\sqrt n)\text{,}\) which is much larger. (Cofactor expansion has other uses.)
    🔗
    🔗

    Compute \(\det\begin{pmatrix} 1 \amp 2 \amp 3 \\ 2 \amp -1 \amp 1 \\ 3 \amp 0 \amp 1 \end{pmatrix}.\)
    🔗

    Solution.

    We row reduce the matrix, keeping track of the number of row swaps and of the scaling factors used. \begin{minipage}{10cm} % needed for pdf version \def\rowop#1#2#3#4{% \hbox to 4.5cm{\hss$\xrightarrow[#2]{#1}$\;}% \hbox to 2.7cm{#3\hss}% \hbox to 3cm{\hskip3mm\begin{minipage}{10cm}#4\end{minipage}\hss}% } \leavevmode\rlap{\hbox{$\begin{pmatrix} 1 \amp 2 \amp 3 \\ 2 \amp -1 \amp 1 \\ 3 \amp 0 \amp 1 \end{pmatrix}$}}% \rowop{R_2=R_2-2R_1}{R_3=R_3-3R_1}{$\begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp -5 \amp -5 \\ 0 \amp -6 \amp -8 \end{pmatrix}$}{}\\ \rowop{R_2=R_2\div-5}{}{$\begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 1 \amp 1 \\ 0 \amp -6 \amp -8 \end{pmatrix}$}{scaling factors${}=-\frac 15$}\\ \rowop{R_3=R_3+6R_2}{}{$\begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp -2 \end{pmatrix}$}{} \end{minipage} We did not make any row swaps, and we scaled once by a factor of \(-1/5\text{,}\) so the Recipe 5 says that

    🔗
    🔗

    Example 4.1.9 The determinant of a \(2\times 2\) matrix.

    Let us use the Recipe 5 to compute the determinant of a general \(2\times 2\) matrix \(A = \smallmat abcd\text{.}\)
    • If \(a = 0\text{,}\) then
      \begin{align*} \det\begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix} = \det\begin{pmatrix} 0 \amp b \\ c \amp d \end{pmatrix} = -\det\begin{pmatrix} c \amp d \\ 0 \amp b \end{pmatrix} = -bc\text{.} \end{align*}
      🔗
      🔗
    • If \(a\neq 0\text{,}\) then
      \begin{align*} \det\begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix} \amp= a\cdot\det\begin{pmatrix} 1 \amp b/a \\ c \amp d \end{pmatrix} = a\cdot\det\begin{pmatrix} 1 \amp b/a \\ 0 \amp d-c\cdot \amp b/a \end{pmatrix}\\ \amp= a\cdot 1\cdot(d-bc/a) = ad-bc\text{.} \end{align*}
      🔗
      🔗
    In either case, we recover the Definition 5 of Section 3.5:
    \begin{align*} \det\begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix} = ad-bc\text{.} \end{align*}
    🔗
    🔗

    Proposition 4.1.11.

    Let \(A\) be an \(n\times n\) matrix.
    1. If \(A\) has a zero row or column, then \(\det(A) = 0.\)
      🔗
      🔗
    2. If \(A\) is upper-triangular or lower-triangular, then \(\det(A)\) is the product of its diagonal entries.
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Suppose that \(A\) has a zero row. Let \(B\) be the matrix obtained by negating the zero row. Then \(\det(A) = -\det(B)\) by the second Definition 1. But \(A = B\text{,}\) so \(\det(A) = \det(B)\text{:}\)
      \begin{align*} \begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 0 \amp 0 \\ 7 \amp 8 \amp 9 \end{pmatrix} \;\xrightarrow{R_2 = -R_2}\; \begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 0 \amp 0 \\ 7 \amp 8 \amp 9 \end{pmatrix}\text{.} \end{align*}
      Putting these together yields \(\det(A) = -\det(A)\text{,}\) so \(\det(A)=0\text{.}\)
      🔗
      Now suppose that \(A\) has a zero column. Then \(A\) is not invertible by the Theorem 1 of Section 3.6, so its reduced row echelon form has a zero row. Since row operations do not change whether the determinant is zero, we conclude \(\det(A)=0\text{.}\)
      🔗
      🔗
    2. First suppose that \(A\) is upper-triangular, and that one of the diagonal entries is zero, say \(a_{ii}=0\text{.}\) We can perform row operations to clear the entries above the nonzero diagonal entries:
      \begin{align*} \begin{pmatrix} a_{11} \amp \star \amp \star \amp \star \\ 0 \amp a_{22} \amp \star \amp \star \\ 0 \amp 0 \amp 0 \amp \star \\ 0 \amp 0 \amp 0 \amp a_{44} \end{pmatrix} \;\xrightarrow{\phantom{MMM}}\; \begin{pmatrix} a_{11} \amp 0 \amp \star \amp 0 \\ 0 \amp a_{22} \amp \star \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp a_{44} \end{pmatrix} \end{align*}
      In the resulting matrix, the \(i\)th row is zero, so \(\det(A) = 0\) by the first part.
      🔗
      Still assuming that \(A\) is upper-triangular, now suppose that all of the diagonal entries of \(A\) are nonzero. Then \(A\) can be transformed to the identity matrix by scaling the diagonal entries and then doing row replacements:
      \begin{align*} \amp\begin{pmatrix} a \amp \star \amp \star \\ 0 \amp b \amp \star \\ 0 \amp 0 \amp c \end{pmatrix} \;\xrightarrow{% \begin{minipage}{1.8cm}% \tiny\centering scale by\\$a\inv,b\inv,c\inv$% \end{minipage}}\; \begin{pmatrix} 1 \amp \star \amp \star \\ 0 \amp 1 \amp \star \\ 0 \amp 0 \amp 1 \end{pmatrix} \;\xrightarrow{% \begin{minipage}{1.6cm}% \tiny\centering row\\replacements% \end{minipage}}\; \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \amp \hbox to 2.1cm{\hss$\det=abc$\hss} \;\xleftarrow{\hbox to 1.8cm{\hss}}\; \hbox to 2.1cm{\hss$\det=1$\hss} \;\xleftarrow{\hbox to 1.6cm{\hss}}\; \hbox to 1.8cm{\hss$\det=1$} \end{align*}
      Since \(\det(I_n) = 1\) and we scaled by the reciprocals of the diagonal entries, this implies \(\det(A)\) is the product of the diagonal entries.
      🔗
      The same argument works for lower triangular matrices, except that the the row replacements go down instead of up.
      🔗
      🔗
    🔗
    🔗

    Example 4.1.12.

    Compute the determinants of these matrices:
    \begin{align*} \begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 4 \amp 5 \\ 0 \amp 0 \amp 6 \end{pmatrix} \qquad \begin{pmatrix} -20 \amp 0 \amp 0 \\ \pi \amp 0 \amp 0 \\ 100 \amp 3 \amp -7 \end{pmatrix} \qquad \begin{pmatrix} 17 \amp -3 \amp 4 \\ 0 \amp 0 \amp 0 \\ 11/2 \amp 1 \amp e \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    The first matrix is upper-triangular, the second is lower-triangular, and the third has a zero row:
    \begin{align*} \det\begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 4 \amp 5 \\ 0 \amp 0 \amp 6 \end{pmatrix} \amp= 1 \cdot 4 \cdot 6 = 24\\ \det\begin{pmatrix} -20 \amp 0 \amp 0 \\ \pi \amp 0 \amp 0 \\ 100 \amp 3 \amp -7 \end{pmatrix} \amp= -20 \cdot 0 \cdot -7 = 0\\ \det\begin{pmatrix} 17 \amp -3 \amp 4 \\ 0 \amp 0 \amp 0 \\ 11/2 \amp 1 \amp e \end{pmatrix} \amp= 0\text{.} \end{align*}
    🔗
    🔗
    🔗
    A matrix can always be transformed into row echelon form by a series of row operations, and a matrix in row echelon form is upper-triangular. Therefore, we have completely justified the Recipe 5 for computing the determinant.
    🔗
    The determinant is characterized by its Definition 1, since we can compute the determinant of any matrix using row reduction, as in the above Recipe 5. However, we have not yet proved the existence of a function satisfying the defining properties! Row reducing will compute the determinant if it exists, but we cannot use row reduction to prove existence, because we do not yet know that you compute the same number by row reducing in two different ways.

    There exists one and only one function from the set of square matrices to the real numbers, that satisfies the four Definition 1.

    Subsection 4.1.2 Magical Properties of the Determinant

    In this subsection, we will discuss a number of the amazing properties enjoyed by the determinant: the Proposition 15, the Proposition 18, and the Proposition 25.
    🔗

    Proposition 4.1.15 Invertibility Property.

    A square matrix is invertible if and only if \(\det(A)\neq 0\text{.}\)
    🔗
    🔗

    Proof.
    If \(A\) is invertible, then it has a pivot in every row and column by the Theorem 1 of Section 3.6, so its reduced row echelon form is the identity matrix. Since row operations do not change whether the determinant is zero, and since \(\det(I_n) = 1\text{,}\) this implies \(\det(A)\neq 0.\) Conversely, if \(A\) is not invertible, then it is row equivalent to a matrix with a zero row. Again, row operations do not change whether the determinant is nonzero, so in this case \(\det(A) = 0.\)
    🔗
    🔗
    By the invertibility property, a matrix that does not satisfy any of the properties of the Theorem 1 of Section 3.6 has zero determinant.
    🔗

    Corollary 4.1.16.

    Let \(A\) be a square matrix. If the rows or columns of \(A\) are linearly dependent, then \(\det(A)=0\text{.}\)
    🔗
    🔗

    Proof.
    If the columns of \(A\) are linearly dependent, then \(A\) is not invertible by condition 4 of the Theorem 1 of Section 3.6. Suppose now that the rows of \(A\) are linearly dependent. If \(r_1,r_2,\ldots,r_n\) are the rows of \(A\text{,}\) then one of the rows is in the span of the others, so we have an equation like
    \begin{gather*} r_2 = 3r_1 - r_3 + 2r_4\text{.} \end{gather*}
    If we perform the following row operations on \(A\text{:}\)
    \begin{gather*} R_2 = R_2 - 3R_1;\quad R_2 = R_2 + R_3;\quad R_2 = R_2 - 2R_4 \end{gather*}
    then the second row of the resulting matrix is zero. Hence \(A\) is not invertible in this case either.
    🔗
    Alternatively, if the rows of \(A\) are linearly dependent, then one can combine condition 4 of the Theorem 1 of Section 3.6 and the Proposition 25 below to conclude that \(\det(A)=0\text{.}\)
    🔗
    🔗
    In particular, if two rows/columns of \(A\) are multiples of each other, then \(\det(A)=0.\) We also recover the fact that a matrix with a row or column of zeros has determinant zero.
    🔗

    Example 4.1.17.

    The following matrices all have zero determinant:
    \begin{align*} \begin{pmatrix} 0 \amp 2 \amp -1 \\ 0 \amp 5 \amp 10 \\ 0 \amp -7 \amp 3 \end{pmatrix},\quad \begin{pmatrix} 5 \amp -15 \amp 11 \\ 3 \amp -9 \amp 2 \\ 2 \amp -6 \amp 16 \end{pmatrix},\quad \begin{pmatrix} 3 \amp 1 \amp 2 \amp 4 \\ 0 \amp 0 \amp 0 \amp 0 \\ 4 \amp 2 \amp 5 \amp 12 \\ -1 \amp 3 \amp 4 \amp 8 \end{pmatrix},\quad \begin{pmatrix} \pi \amp e \amp 11 \\ 3\pi \amp 3e \amp 33 \\ 12 \amp -7 \amp 2 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    The proofs of the Proposition 18 and the Proposition 25 below, as well as the Theorem 3 of Section 4.2 and the Theorem 6 of Section 4.3, use the following strategy: define another function \(d\colon\{\text{$n\times n$ matrices}\} \to \R\text{,}\) and prove that \(d\) satisfies the same four defining properties as the determinant. By the Theorem 13, the function \(d\) is equal to the determinant. This is an advantage of defining a function via its properties: in order to prove it is equal to another function, one only has to check the defining properties.
    🔗

    Proposition 4.1.18 Multiplicativity Property.

    If \(A\) and \(B\) are \(n\times n\) matrices, then
    \begin{gather*} \det(AB) = \det(A)\det(B)\text{.} \end{gather*}
    🔗
    🔗

    Proof.
    In this proof, we need to use the notion of an elementary matrix. This is a matrix obtained by doing one row operation to the identity matrix. There are three kinds of elementary matrices: those arising from row replacement, row scaling, and row swaps:
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \xrightarrow{\parbox{2cm}{\tiny\centering$R_2 = R_2 - 2R_1$}}\amp \begin{pmatrix} 1 \amp 0 \amp 0 \\ -2 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \xrightarrow{\parbox{2cm}{\tiny\centering$R_1 = 3R_1$}}\amp \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \xrightarrow{\parbox{2cm}{\tiny\centering$R_1 \longleftrightarrow R_2$}}\amp \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    The important property of elementary matrices is the following claim.
    🔗
    Claim: If \(E\) is the elementary matrix for a row operation, then \(EA\) is the matrix obtained by performing the same row operation on \(A\text{.}\)
    🔗
    In other words, left-multiplication by an elementary matrix applies a row operation. For example,
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ -2 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} a_{11} \amp a_{12} \amp a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix} \amp= \left(\begin{array}{lll} a_{11} \amp a_{12} \amp a_{13} \\ a_{21}-2a_{11} \amp a_{22}-2a_{12} \amp a_{23}-2a_{13} \\ a_{31} \amp a_{32} \amp a_{33} \end{array}\right)\\ \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} a_{11} \amp a_{12} \amp a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix} \amp= \begin{pmatrix} 3a_{11} \amp 3a_{12} \amp 3a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix}\\ \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} a_{11} \amp a_{12} \amp a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix} \amp= \begin{pmatrix} a_{21} \amp a_{22} \amp a_{23} \\ a_{11} \amp a_{12} \amp a_{13} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix}\text{.} \end{align*}
    The proof of the Claim is by direct calculation; we leave it to the reader to generalize the above equalities to \(n\times n\) matrices.
    🔗
    As a consequence of the Claim and the four Definition 1, we have the following observation. Let \(C\) be any square matrix.
    1. If \(E\) is the elementary matrix for a row replacement, then \(\det(EC) = \det(C).\) In other words, left-multiplication by \(E\) does not change the determinant.
      🔗
      🔗
    2. If \(E\) is the elementary matrix for a row scale by a factor of \(c\text{,}\) then \(\det(EC) = c\det(C).\) In other words, left-multiplication by \(E\) scales the determinant by a factor of \(c\text{.}\)
      🔗
      🔗
    3. If \(E\) is the elementary matrix for a row swap, then \(\det(EC) = -\det(C).\) In other words, left-multiplication by \(E\) negates the determinant.
      🔗
      🔗
    🔗
    Now we turn to the proof of the multiplicativity property. Suppose to begin that \(B\) is not invertible. Then \(AB\) is also not invertible: otherwise, \((AB)\inv AB = I_n\) implies \(B\inv = (AB)\inv A.\) By the Proposition 15, both sides of the equation \(\det(AB) = \det(A)\det(B)\) are zero.
    🔗
    Now assume that \(B\) is invertible, so \(\det(B)\neq 0\text{.}\) Define a function
    \begin{gather*} d\colon\bigl\{\text{$n\times n$ matrices}\bigr\} \To \R \sptxt{by} d(C) = \frac{\det(CB)}{\det(B)}\text{.} \end{gather*}
    We claim that \(d\) satisfies the four defining properties of the determinant.
    1. Let \(C'\) be the matrix obtained by doing a row replacement on \(C\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Since left-multiplication by \(E\) does not change the determinant, we have \(\det(ECB) = \det(CB)\text{,}\) so
      \begin{gather*} d(C') = \frac{\det(C'B)}{\det(B)} = \frac{\det(ECB)}{\det(B)} = \frac{\det(CB)}{\det(B)} = d(C)\text{.} \end{gather*}
      🔗
      🔗
    2. Let \(C'\) be the matrix obtained by scaling a row of \(C\) by a factor of \(c\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Since left-multiplication by \(E\) scales the determinant by a factor of \(c\text{,}\) we have \(\det(ECB) = c\det(CB)\text{,}\) so
      \begin{gather*} d(C') = \frac{\det(C'B)}{\det(B)} = \frac{\det(ECB)}{\det(B)} = \frac{c\det(CB)}{\det(B)} = c\cdot d(C)\text{.} \end{gather*}
      🔗
      🔗
    3. Let \(C'\) be the matrix obtained by swapping two rows of \(C\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Since left-multiplication by \(E\) negates the determinant, we have \(\det(ECB) = -\det(CB)\text{,}\) so
      \begin{gather*} d(C') = \frac{\det(C'B)}{\det(B)} = \frac{\det(ECB)}{\det(B)} = \frac{-\det(CB)}{\det(B)} = -d(C)\text{.} \end{gather*}
      🔗
      🔗
    4. We have
      \begin{gather*} d(I_n) = \frac{\det(I_nB)}{\det(B)} = \frac{\det(B)}{\det(B)} = 1\text{.} \end{gather*}
      🔗
      🔗
    🔗
    Since \(d\) satisfies the four defining properties of the determinant, it is equal to the determinant by the Theorem 13. In other words, for all matrices \(A\text{,}\) we have
    \begin{gather*} \det(A) = d(A) = \frac{\det(AB)}{\det(B)}\text{.} \end{gather*}
    Multiplying through by \(\det(B)\) gives \(\det(A)\det(B)=\det(AB).\)
    🔗
    🔗
    Recall that taking a power of a square matrix \(A\) means taking products of \(A\) with itself:
    \begin{gather*} A^2 = AA \qquad A^3 = AAA \qquad \text{etc.} \end{gather*}
    If \(A\) is invertible, then we define
    \begin{gather*} A^{-2} = A\inv A\inv \qquad A^{-3} = A\inv A\inv A\inv \qquad \text{etc.} \end{gather*}
    For completeness, we set \(A^0 = I_n\) if \(A\neq 0\text{.}\)

    Corollary 4.1.19.

    If \(A\) is a square matrix, then
    \begin{gather*} \det(A^n) = \det(A)^n \end{gather*}
    for all \(n\geq 1\text{.}\) If \(A\) is invertible, then the equation holds for all \(n\leq 0\) as well; in particular,
    \begin{gather*} \det(A\inv) = \frac 1{\det(A)}\text{.} \end{gather*}
    🔗
    🔗

    Proof.
    Using the Proposition 18, we compute
    \begin{gather*} \det(A^2) = \det(AA) = \det(A)\det(A) = \det(A)^2 \end{gather*}
    and
    \begin{gather*} \det(A^3) = \det(AAA) = \det(A)\det(AA) = \det(A)\det(A)\det(A) = \det(A)^3\text{;} \end{gather*}
    the pattern is clear.
    🔗
    We have
    \begin{gather*} 1 = \det(I_n) = \det(A A\inv) = \det(A)\det(A\inv) \end{gather*}
    by the Proposition 18 and the fourth Definition 1, which shows that \(\det(A\inv) = \det(A)\inv\text{.}\) Thus
    \begin{gather*} \det(A^{-2}) = \det(A\inv A\inv) = \det(A\inv)\det(A\inv) = \det(A\inv)^2 = \det(A)^{-2}\text{,} \end{gather*}
    and so on.

    Corollary 4.1.21.

    Let \(A_1,A_2,\ldots,A_k\) be \(n\times n\) matrices. Then the product \(A_1A_2\cdots A_k\) is invertible if and only if each \(A_i\) is invertible.
    🔗
    🔗

    Proof.
    The determinant of the product is the product of the determinants by the Proposition 18:
    \begin{gather*} \det(A_1A_2\cdots A_k) = \det(A_1)\det(A_2)\cdots\det(A_k)\text{.} \end{gather*}
    By the Proposition 15, this is nonzero if and only if \(A_1A_2\cdots A_k\) is invertible. On the other hand, \(\det(A_1)\det(A_2)\cdots\det(A_k)\) is nonzero if and only if each \(\det(A_i)\neq0\text{,}\) which means each \(A_i\) is invertible.

    Definition 4.1.23.

    The transpose of an \(m\times n\) matrix \(A\) is the \(n\times m\) matrix \(A^T\) whose rows are the columns of \(A\text{.}\) In other words, the \(ij\) entry of \(A^T\) is \(a_{ji}\text{.}\)

    Fact 4.1.24.

    Let \(A\) be an \(m\times n\) matrix, and let \(B\) be an \(n\times p\) matrix. Then
    \begin{gather*} (AB)^T = B^TA^T\text{.} \end{gather*}
    🔗
    🔗

    Proof.
    First suppose that \(A\) is a row vector an \(B\) is a column vector, i.e., \(m = p = 1\text{.}\) Then
    \begin{align*} AB \amp= \begin{pmatrix} a_1 \amp a_2 \amp \cdots \amp a_n \end{pmatrix}\begin{pmatrix} b_1 \\ b_2 \\ \vdots \\ b_n \end{pmatrix} = a_1b_1 + a_2b_2 + \cdots + a_nb_n\\ \amp= \begin{pmatrix} b_1 \amp b_2 \amp \cdots \amp b_n \end{pmatrix}\begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_n \end{pmatrix} = B^TA^T\text{.} \end{align*}
    🔗
    Now we use the row-column rule for matrix multiplication. Let \(r_1,r_2,\ldots,r_m\) be the rows of \(A\text{,}\) and let \(c_1,c_2,\ldots,c_p\) be the columns of \(B\text{,}\) so
    \begin{align*} AB = \left(\begin{array}{c} \matrow{r_1} \\ \matrow{r_2} \\ \vdots \\ \matrow{r_m} \end{array}\right) \begin{pmatrix} | \amp | \amp | \\ c_1 \amp c_2 \amp \cdots \amp c_p \\ | \amp | \amp | \end{pmatrix} = \begin{pmatrix} r_1c_1 \amp r_1c_2 \amp \cdots \amp r_1c_p \\ r_2c_1 \amp r_2c_2 \amp \cdots \amp r_2c_p \\ \vdots \amp \vdots \amp \vdots \\ r_mc_1 \amp r_mc_2 \amp \cdots \amp r_mc_p \end{pmatrix}\text{.} \end{align*}
    By the case we handled above, we have \(r_ic_j = c_j^Tr_i^T\text{.}\) Then
    \begin{align*} (AB)^T \amp= \begin{pmatrix} r_1c_1 \amp r_2c_1 \amp \cdots \amp r_mc_1 \\ r_1c_2 \amp r_2c_2 \amp \cdots \amp r_mc_2 \\ \vdots \amp \vdots \amp \vdots \\ r_1c_p \amp r_2c_p \amp \cdots \amp r_mc_p \end{pmatrix}\\ \amp= \begin{pmatrix} c_1^Tr_1^T \amp c_1^Tr_2^T \amp \cdots \amp c_1^Tr_m^T \\ c_2^Tr_1^T \amp c_2^Tr_2^T \amp \cdots \amp c_2^Tr_m^T \\ \vdots \amp \vdots \amp \vdots \\ c_p^Tr_1^T \amp c_p^Tr_2^T \amp \cdots \amp c_p^Tr_m^T \end{pmatrix}\\ \amp= \left(\begin{array}{c} \matrow{c_1^T} \\ \matrow{c_2^T} \\ \vdots \\ \matrow{c_p^T} \end{array}\right) \begin{pmatrix} | \amp | \amp | \\ r_1^T \amp r_2^T \amp \cdots \amp r_m^T \\ | \amp | \amp | \end{pmatrix} = B^TA^T\text{.} \end{align*}
    🔗
    🔗

    Proposition 4.1.25 Transpose Property.

    For any square matrix \(A\text{,}\) we have
    \begin{gather*} \det(A) = \det(A^T)\text{.} \end{gather*}
    🔗
    🔗

    Proof.
    We follow the same strategy as in the proof of the Proposition 18: namely, we define
    \begin{gather*} d(A) = \det(A^T)\text{,} \end{gather*}
    and we show that \(d\) satisfies the four defining properties of the determinant. Again we use elementary matrices, also introduced in the proof of the Proposition 18.
    1. Let \(C'\) be the matrix obtained by doing a row replacement on \(C\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) The elementary matrix for a row replacement is either upper-triangular or lower-triangular, with ones on the diagonal:
      \begin{align*} R_1 = R_1 + 3R_3:\; \begin{pmatrix} 1 \amp 0 \amp 3 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \qquad R_3 = R_3 + 3R_1:\; \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 3 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
      It follows that \(E^T\) is also either upper-triangular or lower-triangular, with ones on the diagonal, so \(\det(E^T) = 1\) by Proposition 11. By the Fact 24 and the Proposition 18,
      \begin{align*} d(C') \amp= \det((C')^T) = \det((EC)^T) = \det(C^TE^T)\\ \amp= \det(C^T)\det(E^T) = \det(C^T) = d(C)\text{.} \end{align*}
      🔗
      🔗
    2. Let \(C'\) be the matrix obtained by scaling a row of \(C\) by a factor of \(c\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Then \(E\) is a diagonal matrix:
      \begin{align*} R_2 = cR_2:\;\begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp c \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
      Thus \(\det(E^T) = c\text{.}\) By the Fact 24 and the Proposition 18,
      \begin{align*} d(C') \amp= \det((C')^T) = \det((EC)^T) = \det(C^TE^T)\\ \amp= \det(C^T)\det(E^T) = c\det(C^T) = c\cdot d(C)\text{.} \end{align*}
      🔗
      🔗
    3. Let \(C'\) be the matrix obtained by swapping two rows of \(C\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) The \(E\) is equal to its own transpose:
      \begin{align*} R_1\longleftrightarrow R_2:\; \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} = \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}^T\text{.} \end{align*}
      Since \(E\) (hence \(E^T\)) is obtained by performing one row swap on the identity matrix, we have \(\det(E^T) = -1\text{.}\) By the Fact 24 and the Proposition 18,
      \begin{align*} d(C') \amp= \det((C')^T) = \det((EC)^T) = \det(C^TE^T)\\ \amp= \det(C^T)\det(E^T) = -\det(C^T) = - d(C)\text{.} \end{align*}
      🔗
      🔗
    4. Since \(I_n^T = I_n,\) we have
      \begin{gather*} d(I_n) = \det(I_n^T) = det(I_n) = 1\text{.} \end{gather*}
      🔗
      🔗
    🔗
    Since \(d\) satisfies the four defining properties of the determinant, it is equal to the determinant by the Theorem 13. In other words, for all matrices \(A\text{,}\) we have
    \begin{gather*} \det(A) = d(A) = \det(A^T)\text{.} \end{gather*}
    🔗
    🔗
    The Proposition 25 is very useful. For concreteness, we note that \(\det(A)=\det(A^T)\) means, for instance, that
    \begin{align*} \det\begin{pmatrix} 1 \amp 2 \amp 3 \\ 4 \amp 5 \amp 6 \\ 7 \amp 8 \amp 9 \end{pmatrix} = \det\begin{pmatrix} 1 \amp 4 \amp 7 \\ 2 \amp 5 \amp 8 \\ 3 \amp 6 \amp 9 \end{pmatrix}\text{.} \end{align*}
    This implies that the determinant has the curious feature that it also behaves well with respect to column operations. Indeed, a column operation on \(A\) is the same as a row operation on \(A^T\text{,}\) and \(\det(A) = \det(A^T)\text{.}\)
    🔗

    Corollary 4.1.26.

    The determinant satisfies the following properties with respect to column operations:
    1. Doing a column replacement on \(A\) does not change \(\det(A)\text{.}\)
      🔗
      🔗
    2. Scaling a column of \(A\) by a scalar \(c\) multiplies the determinant by \(c\text{.}\)
      🔗
      🔗
    3. Swapping two columns of a matrix multiplies the determinant by \(-1\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The previous corollary makes it easier to compute the determinant: one is allowed to do row and column operations when simplifying the matrix. (Of course, one still has to keep track of how the row and column operations change the determinant.)
    🔗

    Multilinearity.

    The following observation is useful for theoretical purposes.
    🔗
    We can think of \(\det\) as a function of the rows of a matrix:
    \begin{gather*} \det(v_1,v_2,\ldots,v_n) = \det\begin{pmatrix} \matrow{v_1} \\ \matrow{v_2} \\ \vdots \\ \matrow{v_n} \end{pmatrix}\text{.} \end{gather*}
    🔗

    Proposition 4.1.28 Multilinearity Property.

    Let \(i\) be a whole number between \(1\) and \(n\text{,}\) and fix \(n-1\) vectors \(v_1,v_2,\ldots,v_{i-1},v_{i+1},\ldots,v_n\) in \(\R^n\text{.}\) Then the transformation \(T\colon\R^n\to\R\) defined by
    \begin{gather*} T(x) = \det(v_1,v_2,\ldots,v_{i-1},x,v_{i+1},\ldots,v_n) \end{gather*}
    is linear.
    🔗
    🔗

    Proof.
    First assume that \(i=1\text{,}\) so
    \begin{gather*} T(x) = \det(x,v_2,\ldots,v_n)\text{.} \end{gather*}
    We have to show that \(T\) satisfies the Definition 1 of Section 3.3.
    • By the first Definition 1, scaling any row of a matrix by a number \(c\) scales the determinant by a factor of \(c\text{.}\) This implies that \(T\) satisfies the second property, i.e., that
      \begin{gather*} T(cx) = \det(cx,v_2,\ldots,v_n) = c\det(x,v_2,\ldots,v_n) = cT(x)\text{.} \end{gather*}
      🔗
      🔗
    • We claim that \(T(v+w) = T(v) + T(w)\text{.}\) If \(w\) is in \(\Span\{v,v_2,\ldots,v_n\}\text{,}\) then
      \begin{gather*} w = cv + c_2v_2 + \cdots + c_nv_n \end{gather*}
      for some scalars \(c,c_2,\ldots,c_n\text{.}\) Let \(A\) be the matrix with rows \(v+w,v_2,\ldots,v_n\text{,}\) so \(T(v+w) = \det(A).\) By performing the row operations
      \begin{gather*} R_1 = R_1 - c_2R_2;\quad R_1 = R_1 - c_3R_3;\quad\ldots\quad R_1 = R_1 - c_nR_n\text{,} \end{gather*}
      the first row of the matrix \(A\) becomes
      \begin{gather*} v+w-(c_2v_2+\cdots+c_nv_n) = v + cv = (1+c)v\text{.} \end{gather*}
      Therefore,
      \begin{align*} T(v+w) = \det(A) \amp= \det((1+c)v,v_2,\ldots,v_n)\\ \amp= (1+c)\det(v,v_2,\ldots,v_n)\\ \amp= T(v) + cT(v) = T(v) + T(cv)\text{.} \end{align*}
      Doing the opposite row operations
      \begin{gather*} R_1 = R_1 + c_2R_2;\quad R_1 = R_1 + c_3R_3;\quad\ldots\quad R_1 = R_1 + c_nR_n \end{gather*}
      to the matrix with rows \(cv,v_2,\ldots,v_n\) shows that
      \begin{align*} T(cv) \amp= \det(cv,v_2,\ldots,v_n)\\ \amp= \det(cv+c_2v_2+\cdots+c_nv_n,v_2,\ldots,v_n)\\ \amp= \det(w,v_2,\ldots,v_n) = T(w)\text{,} \end{align*}
      which finishes the proof of the first property in this case.
      🔗
      Now suppose that \(w\) is not in \(\Span\{v,v_2,\ldots,v_n\}\text{.}\) This implies that \(\{v,v_2,\ldots,v_n\}\) is linearly dependent (otherwise it would form a basis for \(\R^n\)), so \(T(v)\) = 0. If \(v\) is not in \(\Span\{v_2,\ldots,v_n\}\text{,}\) then \(\{v_2,\ldots,v_n\}\) is linearly dependent by the Theorem 14 of Section 2.5, so \(T(x) = 0\) for all \(x\text{,}\) as the matrix with rows \(x,v_2,\ldots,v_n\) is not invertible. Hence we may assume \(v\) is in \(\Span\{v_2,\ldots,v_n\}\text{.}\) By the above argument with the roles of \(v\) and \(w\) reversed, we have \(T(v+w) = T(v)+T(w).\)
      🔗
      🔗
    🔗
    For \(i\neq 1\text{,}\) we note that
    \begin{align*} T(x) \amp= \det(v_1,v_2,\ldots,v_{i-1},x,v_{i+1},\ldots,v_n)\\ \amp= -\det(x,v_2,\ldots,v_{i-1},v_1,v_{i+1},\ldots,v_n)\text{.} \end{align*}
    By the previously handled case, we know that \(-T\) is linear:
    \begin{gather*} -T(cx) = -cT(x) \qquad -T(v+w) = -T(v) - T(w)\text{.} \end{gather*}
    Multiplying both sides by \(-1\text{,}\) we see that \(T\) is linear.
    🔗
    🔗
    For example, we have
    \begin{gather*} \det\begin{pmatrix} \matrow{\makebox[\widthof{$av+bw$}]{$v_1$}} \\ \matrow{av+bw} \\ \matrow{\makebox[\widthof{$av+bw$}]{$v_3$}} \end{pmatrix} = a\det\begin{pmatrix} \matrow{v_1} \\ \matrow{\makebox[\widthof{$v_1$}]{$v$}} \\ \matrow{v_3} \end{pmatrix} + b\det\begin{pmatrix} \matrow{v_1} \\ \matrow{\makebox[\widthof{$v_1$}]{$w$}} \\ \matrow{v_3} \end{pmatrix} \end{gather*}
    By the Proposition 25, the determinant is also multilinear in the columns of a matrix:
    \begin{align*} \det\begin{pmatrix} | \amp | \amp | \\ v_1 \amp av+bw \amp v_3 \\ | \amp | \amp | \end{pmatrix} = a\det\begin{pmatrix} | \amp | \amp | \\ v_1 \amp v \amp v_3 \\ | \amp | \amp | \end{pmatrix} + b\det\begin{pmatrix} | \amp | \amp | \\ v_1 \amp w \amp v_3 \\ | \amp | \amp | \end{pmatrix}\text{.} \end{align*}
    🔗

    Remark 4.1.29 Alternative defining properties.

    In more theoretical treatments of the topic, where row reduction plays a secondary role, the defining properties of the determinant are often taken to be:
    1. The determinant \(\det(A)\) is multilinear in the rows of \(A\text{.}\)
      🔗
      🔗
    2. If \(A\) has two identical rows, then \(\det(A) = 0\text{.}\)
      🔗
      🔗
    3. The determinant of the identity matrix is equal to one.
      🔗
      🔗
    We have already shown that our four Definition 1 imply these three. Conversely, we will prove that these three alternative properties imply our four, so that both sets of properties are equivalent.
    🔗
    Defining property \(2\) is just the second Definition 1 of Section 3.3. Suppose that the rows of \(A\) are \(v_1,v_2,\ldots,v_n\text{.}\) If we perform the row replacement \(R_i = R_i + cR_j\) on \(A\text{,}\) then the rows of our new matrix are \(v_1,v_2,\ldots,v_{i-1},v_i+cv_j,v_{i+1},\ldots,v_n\text{,}\) so by linearity in the \(i\)th row,
    \begin{align*} \det(\amp v_1,v_2,\ldots,v_{i-1},v_i+cv_j,v_{i+1},\ldots,v_n)\\ \amp= \det(v_1,v_2,\ldots,v_{i-1},v_i,v_{i+1},\ldots,v_n) + c\det(v_1,v_2,\ldots,v_{i-1},v_j,v_{i+1},\ldots,v_n)\\ \amp= \det(v_1,v_2,\ldots,v_{i-1},v_i,v_{i+1},\ldots,v_n) = \det(A)\text{,} \end{align*}
    where \(\det(v_1,v_2,\ldots,v_{i-1},v_j,v_{i+1},\ldots,v_n)=0\) because \(v_j\) is repeated. Thus, the alternative defining properties imply our first two defining properties. For the third, suppose that we want to swap row \(i\) with row \(j\text{.}\) Using the second alternative defining property and multilinearity in the \(i\)th and \(j\)th rows, we have
    \begin{align*} 0 \amp= \det(v_1,\ldots,v_i+v_j,\ldots,v_i+v_j,\ldots,v_n)\\ \amp= \det(v_1,\ldots,v_i,\ldots,v_i+v_j,\ldots,v_n) + \det(v_1,\ldots,v_j,\ldots,v_i+v_j,\ldots,v_n)\\ \amp= \det(v_1,\ldots,v_i,\ldots,v_i,\ldots,v_n) + \det(v_1,\ldots,v_i,\ldots,v_j,\ldots,v_n)\\ \amp\qquad+\det(v_1,\ldots,v_j,\ldots,v_i,\ldots,v_n) + \det(v_1,\ldots,v_j,\ldots,v_j,\ldots,v_n)\\ \amp= \det(v_1,\ldots,v_i,\ldots,v_j,\ldots,v_n) + \det(v_1,\ldots,v_j,\ldots,v_i,\ldots,v_n)\text{,} \end{align*}
    as desired.
    🔗

    This is the basic idea behind cofactor expansions in Section 4.2.

    Insight 4.1.31 Summary: Magical Properties of the Determinant.

    1. There is one and only one function \(\det\colon\{n\times n\text{ matrices}\}\to\R\) satisfying the four Definition 1.
      🔗
      🔗
    2. The determinant of an upper-triangular or lower-triangular matrix is the product of the diagonal entries.
      🔗
      🔗
    3. A square matrix is invertible if and only if \(\det(A)\neq 0\text{;}\) in this case,
      \begin{gather*} \det(A\inv) = \frac 1{\det(A)}\text{.} \end{gather*}
      🔗
      🔗
    4. If \(A\) and \(B\) are \(n\times n\) matrices, then
      \begin{gather*} \det(AB) = \det(A)\det(B)\text{.} \end{gather*}
      🔗
      🔗
    5. For any square matrix \(A\text{,}\) we have
      \begin{gather*} \det(A^T) = \det(A)\text{.} \end{gather*}
      🔗
      🔗
    6. The determinant can be computed by performing row and/or column operations.

    8.

    Suppose \(T\) is a linear transformation with the property that \(T \circ T = T\text{.}\) What are the possibilities for the determinant of the standard matrix for \(T\text{?}\)
    🔗
    Solution.
    Let \(A\) be the standard matrix for \(T\text{,}\) so \(T(x) = Ax\text{.}\) Note
    \begin{gather*} T(x) = (T \circ T)(x) = T(T(x)) = T(Ax)=A(Ax) = A^2 x\text{,} \end{gather*}
    so \(A = A^2\text{.}\) Using this and the multiplicative property of determinants, we get
    \begin{gather*} \det(A) = \det(A^2) = \det(A) \det(A) = (\det \ A)^2\text{.} \end{gather*}
    For \(x = \det(A)\text{,}\) the above says \(x = x^2\text{,}\) so \(0 = x^2-x = x(x-1)\text{.}\) Therefore \(x=0\) or \(x=1\text{,}\) so \(\det(A)\) is \(0\) or \(1\text{.}\)
    🔗
    Both \(0\) and \(1\) are possible for the determinant of \(A\text{.}\) For example, the transformations \(T(x) = \begin{pmatrix}0 \amp 0 \\ 0 \amp 0\end{pmatrix}x\) and \(T(x) = \begin{pmatrix}1 \amp 0 \\ 0 \amp 1\end{pmatrix}x\) both satisfy \(T \circ T = T\text{.}\)

    9.

    Suppose \(T\) is a linear transformation with the property that \(T \circ T\) is the identity transformation. What is the determinant of the standard matrix for \(T\text{?}\)
    🔗
    Solution.
    Let \(A\) be the standard matrix for \(T\text{.}\) The same argument as the previous exercise shows that the standard matrix for \(T \circ T\) is \(A^2\text{.}\) But we were told \(T \circ T\) is the identity transformation, so we also know that its standard matrix is \(I\text{,}\) therefore \(I = A^2\text{.}\) Now:
    \begin{gather*} \det(I) = \det(A^2) \ \implies \ 1 = \det(A)\det(A) \ \implies \ 1 = (\det \ A)^2 \ \implies \ \det(A) = \pm 1\text{.} \end{gather*}
    Both values for \(\det(A)\) are possible in practice. For example, the matrices \(\begin{pmatrix}1 \amp 0 \\ 0 \amp 1\end{pmatrix}\) and \(\begin{pmatrix}1 \amp 0 \\ 0 \amp -1\end{pmatrix}\) have determinants \(1\) and \(-1\) respectively, and both satisfy \(A^2 = I\text{.}\)

    11.

    Suppose \(A\) is an invertible \(2 \times 2\) matrix and \(\det(A) = 2\text{.}\) Find \(\det( (3A)^{-1} )\text{.}\)
    🔗
    Solution.
    By properties of the determinant, \(\det( (3A)^{-1} ) = \dfrac{1}{\det(3A)}\text{.}\) Since \(3A\) is obtained from \(A\) by multiplying \textit{each row} of \(A\) by \(3\text{,}\) we need to multiply the determinant by \(3\) twice.
    \begin{gather*} \det(3A) = 3^2 \det(A) = 9 (2) = 18\text{.} \end{gather*}
    Therefore,
    \begin{gather*} \det((3A)^{-1}) = \dfrac{1}{18}\text{.} \end{gather*}

    12.

    A problem from section 2.2, revisited: Find all values of \(c\) and \(d\) so that \(\textup{Span}\left\{\begin{pmatrix}1 \\ c\end{pmatrix}, \begin{pmatrix}d \\ 2\end{pmatrix}\right\}\) is not \({\bf R}^2\text{.}\)
    🔗
    Solution.
    Two vectors in \({\bf R}^2\) will fail to span \({\bf R}^2\) precisely when they are linearly dependent, so we solve:
    \begin{align*} \det\begin{pmatrix}1 \amp d \\ c \amp 2\end{pmatrix} = 0, \qquad 2 - cd = 0, \qquad cd = 2\text{.} \end{align*}
    Therefore, \(d = 2/c\) where \(c\) is any nonzero number (the fact that \(cd=2\) means neither \(c\) or \(d\) can be zero).

    13.

    Is there a \(2 \times 2\) matrix (whose entries are real numbers) with the property that \(A^2 = -I\text{?}\) If so, give an example. If not, justify why there is no such matrix.
    🔗
    Solution.
    Yes. Take \(A\) to be the matrix for rotation by \(90^\circ\) counterclockwise. Then \(A^2\) is rotation by \(2 \cdot 90 ^\circ = 180^\circ\text{,}\) which is the same as scalar multiplication by \(-1\text{.}\) In other words, \(A^2 = -I\text{.}\) We can verify this algebraically:
    \begin{align*} \begin{pmatrix}0 \amp -1 \\ 1 \amp 0\end{pmatrix} \begin{pmatrix}0 \amp -1 \\ 1 \amp 0\end{pmatrix} = \begin{pmatrix}-1 \amp 0 \\ 0 \amp -1\end{pmatrix}\text{.} \end{align*}

    14.

    Is there a \(3 \times 3\) matrix (whose entries are real numbers) with the property that \(A^2 = -I\text{?}\) If so, give an example. If not, justify why there is no such matrix.
    🔗
    Solution.
    No. If \(A^2 = -I\) then
    \begin{align*} \det(A^2) = \det(-I) = \det\begin{pmatrix}-1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp -1\end{pmatrix} = -1\text{.} \end{align*}
    But this would mean
    \begin{gather*} \det(A^2) = -1, \quad (\det A)^2 = -1, \qquad \det(A) = \pm i\text{.} \end{gather*}
    This is impossible, since the determinant of every real matrix is real.
    🔗
    It is natural to ask: why doesn’t the above argument also show that we can never have \(A^2 = -I\) in the \(2 \times 2\) case? Note that the \(2 \times 2\) matrix \(-I\) has determinant equal to \(1\) (not \(-1\)) since
    \begin{align*} \det\begin{pmatrix}-1 \amp 0 \\ 0 \amp -1\end{pmatrix} = (-1)^2 = 1\text{,} \end{align*}
    so we do not obtain an impossible equality for \(\det(A)\) in the \(2 \times 2\) case, and in fact we can found an actual example of a \(2 \times 2\) matrix \(A\) so that \(A^2 = -I\text{.}\)

    15.

    Suppose \(A\) is a square matrix and that \(A^k\) is invertible for some \(k\text{.}\) Must it be true that \(A\) is invertible? Justify your answer.
    🔗
    Solution.
    Yes, \(A\) must be invertible. We use the fact that a square matrix is invertible if and only if its determinant is nonzero. Since \(A^k\) is invertible for some \(k\text{,}\) this means \(\det(A^k) \neq 0\text{.}\) From the properties of determinants we know \(\det(A^k) = (\det \ A)^k\text{,}\) so the previous sentence means \((\det A)^k \neq 0\text{,}\) thus \(\det(A) \neq 0\text{.}\) Therefore, \(A\) is invertible.
