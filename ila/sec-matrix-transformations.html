    Section 3.1 Matrix Transformations

    Objectives

    1. Learn to view a matrix geometrically as a function.
      🔗
      🔗
    2. Learn examples of matrix transformations: reflection, dilation, rotation, shear, projection.
      🔗
      🔗
    3. Understand the vocabulary surrounding transformations: domain, codomain, range.
      🔗
      🔗
    4. Understand the domain, codomain, and range of a matrix transformation.
      🔗
      🔗
    5. Pictures: common matrix transformations.
      🔗
      🔗
    6. Vocabulary words: transformation / function, domain, codomain, range, identity transformation, matrix transformation.
      🔗
      🔗
    🔗
    In this section we learn to understand matrices geometrically as functions, or transformations. We briefly discuss transformations in general, then specialize to matrix transformations, which are transformations that come from matrices.
    🔗

    Subsection 3.1.1 Matrices as Functions

    Informally, a function is a rule that accepts inputs and produces outputs. For instance, \(f(x) = x^2\) is a function that accepts one number \(x\) as its input, and outputs the square of that number: \(f(2) = 4\text{.}\) In this subsection, we interpret matrices as functions.
    🔗
    Let \(A\) be a matrix with \(m\) rows and \(n\) columns. Consider the matrix equation \(b=Ax\) (we write it this way instead of \(Ax=b\) to remind the reader of the notation \(y=f(x)\)). If we vary \(x\text{,}\) then \(b\) will also vary; in this way, we think of \(A\) as a function with independent variable \(x\) and dependent variable \(b\text{.}\)
    • The independent variable (the input) is \(x\text{,}\) which is a vector in \(\R^n\text{.}\)
      🔗
      🔗
    • The dependent variable (the output) is \(b\text{,}\) which is a vector in \(\R^m\text{.}\)
      🔗
      🔗
    The set of all possible output vectors are the vectors \(b\) such that \(Ax=b\) has some solution; this is the same as the column space of \(A\) by Note .

    Example 3.1.5 Projection onto the \(xy\)-plane.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    Describe the function \(b=Ax\) geometrically.
    🔗

    Solution.

    In the equation \(Ax=b\text{,}\) the input vector \(x\) and the output vector \(b\) are both in \(\R^3\text{.}\) First we multiply \(A\) by a vector to see what it does:
    \begin{align*} A\begin{pmatrix} x \\ y \\ z \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix} = \begin{pmatrix} x \\ y \\ 0 \end{pmatrix}\text{.} \end{align*}
    Multiplication by \(A\) simply sets the \(z\)-coordinate equal to zero: it projects vertically onto the \(xy\)-plane.

    Subsection 3.1.2 Transformations

    At this point it is convenient to fix our ideas and terminology regarding functions, which we will call transformations in this book. This allows us to systematize our discussion of matrices as functions.
    🔗

    Definition 3.1.17.

    A transformation from \(\R^n\) to \(\R^m\) is a rule \(T\) that assigns to each vector \(x\) in \(\R^n\) a vector \(T(x)\) in \(\R^m\text{.}\)
    • \(\R^n\) is called the domain of \(T\text{.}\)
      🔗
      🔗
    • \(\R^m\) is called the codomain of \(T\text{.}\)
      🔗
      🔗
    • For \(x\) in \(\R^n\text{,}\) the vector \(T(x)\) in \(\R^m\) is the image of \(x\) under \(T\text{.}\)
      🔗
      🔗
    • The set of all images \(\{T(x)\mid x\text{ in }\R^n\}\) is the range of \(T\text{.}\)
      🔗
      🔗
    The notation \(T\colon\R^n\To\R^m\) means “\(T\) is a transformation from \(\R^n\) to \(\R^m\text{.}\)”
    🔗

    Example 3.1.18 A Function of one variable.

    Most of the functions you may have seen previously have domain and codomain equal to \(\R = \R^1\text{.}\) For example,
    \begin{gather*} \sin\colon\R\To\R \qquad \sin(x) = \left(\,\parbox{5cm}{ the length of the opposite edge over the hypotenuse of a right triangle with angle $x$ in radians}\,\right)\text{.} \end{gather*}
    Notice that we have defined \(\sin\) by a rule: a function is defined by specifying what the output of the function is for any possible input.

    You may be used to thinking of such functions in terms of their graphs: \usetikzlibrary{datavisualization.formats.functions} \begin{tikzpicture} \datavisualization[school book axes, all axes={ticks=none}, visualize as smooth line/.list={sin}, sin={style=seq1}] data[format=function, set=sin] { var x : interval[-2:2] ; func y = sin(\value x r); }; \point[minimum size=1.5mm, "$x$" below] at (1,0); \point[minimum size=1.5mm, "${(x,\sin x)}$" {label distance=1.2mm, above}] at (1,{sin(1 r)}); \end{tikzpicture} In this case, the horizontal axis is the domain, and the vertical axis is the codomain. For this reason, we will rarely graph a transformation.
    🔗
    Note that the range of \(\sin\) is the interval \([-1,1]\text{:}\) this is the set of all possible outputs of the \(\sin\) function.

    Example 3.1.19 Functions of several variables.

    Here is an example of a function from \(\R^2\) to \(\R^3\text{:}\)
    \begin{gather*} f\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x+y \\ \cos(y) \\ y-x^2 \end{pmatrix}\text{.} \end{gather*}
    The inputs of \(f\) each have two entries, and the outputs have three entries. In this case, we have defined \(f\) by a formula, so we evaluate \(f\) by substituting values for the variables:
    \begin{gather*} f\begin{pmatrix} 2 \\ 3 \end{pmatrix} = \begin{pmatrix} 2+3 \\ \cos(3) \\ 3-2^2 \end{pmatrix} = \begin{pmatrix} 5 \\ \cos(3) \\ -1 \end{pmatrix}\text{.} \end{gather*}
    🔗
    Here is an example of a function from \(\R^3\) to \(\R^3\text{:}\)
    \begin{gather*} f(v) = \left(\,\parbox{5.5cm}{the counterclockwise rotation of $v$ by an angle of $42^\circ$ about the $z$-axis}\,\right)\text{.} \end{gather*}
    In other words, \(f\) takes a vector with three entries, then rotates it; hence the ouput of \(f\) also has three entries. In this case, we have defined \(f\) by a geometric rule.
    🔗
    🔗

    Definition 3.1.20.

    The identity transformation \(\Id_{\R^n}\colon\R^n\to\R^n\) is the transformation defined by the rule
    \begin{gather*} \Id_{\R^n}(x) = x \qquad\text{for all $x$ in $\R^n$}\text{.} \end{gather*}
    🔗
    🔗
    In other words, the identity transformation does not move its input vector: the output is the same as the input. Its domain and codomain are both \(\R^n\text{,}\) and its range is \(\R^n\) as well, since every vector in \(\R^n\) is the output of itself.

    Subsection 3.1.3 Matrix Transformations

    Now we specialize the general notions and vocabulary from Subsection 3.1.2 to the functions defined by matrices that we considered in the first Subsection 3.1.1.
    🔗

    Definition 3.1.22.

    Let \(A\) be an \(m\times n\) matrix. The matrix transformation associated to \(A\) is the transformation
    \begin{gather*} T\colon \R^n\To\R^m \sptxt{defined by} T(x) = Ax\text{.} \end{gather*}
    This is the transformation that takes a vector \(x\) in \(\R^n\) to the vector \(Ax\) in \(\R^m\text{.}\)
    🔗
    🔗
    If \(A\) has \(n\) columns, then it only makes sense to multiply \(A\) by vectors with \(n\) entries. This is why the domain of \(T(x)=Ax\) is \(\R^n\text{.}\) If \(A\) has \(n\) rows, then \(Ax\) has \(m\) entries for any vector \(x\) in \(\R^n\text{;}\) this is why the codomain of \(T(x)=Ax\) is \(\R^m\text{.}\)
    🔗
    The definition of a matrix transformation \(T\) tells us how to evaluate \(T\) on any given vector: we multiply the input vector by a matrix. For instance, let
    \begin{align*} A = \begin{pmatrix} 1 \amp 2 \amp 3 \\ 4 \amp 5 \amp 6 \end{pmatrix} \end{align*}
    and let \(T(x)=Ax\) be the associated matrix transformation. Then
    \begin{align*} T\begin{pmatrix} -1 \\ -2 \\ -3 \end{pmatrix} = A\begin{pmatrix} -1 \\ -2 \\ -3 \end{pmatrix} = \begin{pmatrix} 1 \amp 2 \amp 3 \\ 4 \amp 5 \amp 6 \end{pmatrix}\begin{pmatrix} -1 \\ -2 \\ -3 \end{pmatrix} = \begin{pmatrix} -14 \\ -32 \end{pmatrix}\text{.} \end{align*}
    🔗
    Suppose that \(A\) has columns \(v_1,v_2,\ldots,v_n\text{.}\) If we multiply \(A\) by a general vector \(x\text{,}\) we get
    \begin{align*} Ax = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_n \\ | \amp | \amp | \end{pmatrix}\begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{pmatrix} = x_1v_1 + x_2v_2 + \cdots + x_nv_n\text{.} \end{align*}
    This is just a general linear combination of \(v_1,v_2,\ldots,v_n\text{.}\) Therefore, the outputs of \(T(x) = Ax\) are exactly the linear combinations of the columns of \(A\text{:}\) the range of \(T\) is the column space of \(A\text{.}\) See Note .
    🔗

    Insight 3.1.23.

    Let \(A\) be an \(m\times n\) matrix, and let \(T(x)=Ax\) be the associated matrix transformation.
    • The domain of \(T\) is \(\R^n\text{,}\) where \(n\) is the number of columns of \(A\text{.}\)
      🔗
      🔗
    • The codomain of \(T\) is \(\R^m\text{,}\) where \(m\) is the number of rows of \(A\text{.}\)
      🔗
      🔗
    • The range of \(T\) is the column space of \(A\text{.}\)
      🔗
      🔗
    🔗

    Example 3.1.28 Projection onto the \(xy\)-plane: reprise.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{,} \end{align*}
    and let \(T(x) = Ax\text{.}\) What are the domain, the codomain, and the range of \(T\text{?}\)
    🔗

    Solution.

    Geometrically, the transformation \(T\) projects a vector directly “down” onto the \(xy\)-plane in \(\R^3\text{.}\)
    🔗
    
    🔗
    The inputs and outputs have three entries, so the domain and codomain are both \(\R^3\text{.}\) The possible outputs all lie on the \(xy\)-plane, and every point on the \(xy\)-plane is an output of \(T\) (with itself as the input), so the range of \(T\) is the \(xy\)-plane.
    🔗
    Be careful not to confuse the codomain with the range here. The range is a plane, but it is a plane in \(\R^3\), so the codomain is still \(\R^3\text{.}\) The outputs of \(T\) all have three entries; the last entry is simply always zero.
    🔗
    🔗
    🔗
    In the case of an \(n\times n\) square matrix, the domain and codomain of \(T(x) = Ax\) are both \(\R^n\text{.}\) In this situation, one can regard \(T\) as operating on \(\R^n\text{:}\) it moves the vectors around in the same space.
    🔗

    Example 3.1.29 Matrix transformations of \(\R^2\).

    In the first Subsection 3.1.1 we discussed the transformations defined by several \(2\times 2\) matrices, namely:
    \begin{align*} \text{Reflection:} \amp\qquad A=\begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Dilation:} \amp\qquad A=\begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}\\ \text{Identity:} \amp\qquad A=\begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Rotation:} \amp\qquad A=\begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}\\ \text{Shear:} \amp\qquad A=\begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    In each case, the associated matrix transformation \(T(x)=Ax\) has domain and codomain equal to \(\R^2\text{.}\) The range is also \(\R^2\text{,}\) as can be seen geometrically (what is the input for a given output?), or using the fact that the columns of \(A\) are not collinear (so they form a basis for \(\R^2\)).
    🔗
    🔗

    Example 3.1.30 Questions about a [matrix] transformation.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \\ 1 \amp 1 \end{pmatrix}\text{,} \end{align*}
    and let \(T(x)=Ax\text{,}\) so \(T\colon\R^2\to\R^3\) is a matrix transformation.
    1. Evaluate \(T(u)\) for \(u=\begin{pmatrix} 3 \\ 4 \end{pmatrix}\text{.}\)
      🔗
      🔗
    2. Let
      \begin{gather*} b = \begin{pmatrix} 7 \\ 5 \\ 7 \end{pmatrix}\text{.} \end{gather*}
      Find a vector \(v\) in \(\R^2\) such that \(T(v)=b\text{.}\) Is there more than one?
      🔗
      🔗
    3. Does there exist a vector \(w\) in \(\R^3\) such that there is more than one \(v\) in \(\R^2\) with \(T(v)=w\text{?}\)
      🔗
      🔗
    4. Find a vector \(w\) in \(\R^3\) which is not in the range of \(T\text{.}\)
      🔗
      🔗
    🔗
    Note: all of the above questions are intrinsic to the transformation \(T\text{:}\) they make sense to ask whether or not \(T\) is a matrix transformation. See the next Example 31. As \(T\) is in fact a matrix transformation, all of these questions will translate into questions about the corresponding matrix \(A\text{.}\)
    🔗

    Solution.

    1. We evaluate \(T(u)\) by substituting the definition of \(T\) in terms of matrix multiplication:
      \begin{align*} T\begin{pmatrix} 3 \\ 4 \end{pmatrix} = \begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \\ 1 \amp 1 \end{pmatrix}\begin{pmatrix} 3 \\ 4 \end{pmatrix} = \begin{pmatrix} 7 \\ 4 \\ 7 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    2. We want to find a vector \(v\) such that \(b = T(v) = Av\text{.}\) In other words, we want to solve the matrix equation \(Av = b\text{.}\) We form an augmented matrix and row reduce:
      \begin{align*} \begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \\ 1 \amp 1 \end{pmatrix} v = \begin{pmatrix} 7 \\ 5 \\ 7 \end{pmatrix} \;\xrightarrow{\parbox{\widthof{\small augmented}} {\small\centering augmented matrix}}\; \left(\begin{array}{rr|r} 1 \amp 1 \amp 7 \\ 0 \amp 1 \amp 5 \\ 1 \amp 1 \amp 7 \end{array}\right) \;\xrightarrow{\parbox{\widthof{\small reduce}} {\small\centering row reduce}}\; \left(\begin{array}{rr|r} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 5 \\ 0 \amp 0 \amp 0 \end{array}\right)\text{.} \end{align*}
      This gives \(x=2\) and \(y=5\text{,}\) so that there is a unique vector
      \begin{gather*} v = \begin{pmatrix} 2 \\ 5 \end{pmatrix} \end{gather*}
      such that \(T(v) = b\text{.}\)
      🔗
      🔗
    3. Translation: is there any vector \(w\) in \(\R^3\) such that the solution set of \(Av=w\) has more than one vector in it? The solution set of \(Ax=w\text{,}\) if non-empty, is a translate of the solution set of \(Av=b\) above, which has one vector in it. See Note . It follows that the solution set of \(Av=w\) can have at most one vector.
      🔗
      🔗
    4. Translation: find a vector \(w\) such that the matrix equation \(Av=w\) is not consistent. Notice that if we take
      \begin{gather*} w = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}\text{,} \end{gather*}
      then the matrix equation \(Av=w\) translates into the system of equations
      \begin{align*} \left\{\begin{alignedat}{3} x \amp {}+{} \amp y \amp {}={} \amp 1 \amp {} \\ {} \amp {} \amp y \amp {}={} \amp 2 \amp {} \\ x \amp {}+{} \amp y \amp {}={} \amp 3, \amp {} \end{alignedat}\right\text{.} \end{align*}
      which is clearly inconsistent.
      🔗
      🔗
    🔗
    🔗
    🔗

    1. Evaluate \(T(u)\) for \(u=\begin{pmatrix} 1 \\ \pi \end{pmatrix}\text{.}\)
      🔗
      🔗
    2. Let

      🔗

In this case, these questions do not translate into questions about a matrix; they have to be answered in some other way.

    Solution.

    1. We evaluate \(T(u)\) using the defining formula:
      \begin{gather*} T\begin{pmatrix} 1 \\ \pi \end{pmatrix} = \begin{pmatrix} \ln(1) \\ \cos(\pi) \\ \ln(1) \end{pmatrix} = \begin{pmatrix} 0 \\ -1 \\ 0 \end{pmatrix}\text{.} \end{gather*}
      🔗
      🔗
    2. We have
      \begin{gather*} T\begin{pmatrix} e^7 \\ 2\pi \\ n \\ e^7 \end{pmatrix} = \begin{pmatrix} \ln(e^7) \\ \cos(2\pi \\ n) \\ \ln(e^7) \end{pmatrix} = \begin{pmatrix} 7 \\ 1 \\ 7 \end{pmatrix} \end{gather*}
      for any whole number \(n\text{.}\) Hence there are infinitely many such vectors.
      🔗
      🔗
    3. The vector \(b\) from the previous part is an example of such a vector.
      🔗
      🔗
    4. Since \(\cos(y)\) is always between \(-1\) and \(1\text{,}\) the vector
      \begin{gather*} w = \begin{pmatrix} 0 \\ 2 \\ 0 \end{pmatrix} \end{gather*}
      is not in the range of \(T\text{.}\)

    Exercises 3.1.4 Exercises

    1.

      If \(A\) is a matrix and \(T\) is the associated matrix transformation, then the statement that \(Ax = b\) is consistent is equivalent to the statement that \(b\) is in the range of \(T\text{.}\)
      🔗

    • True.

    • False.

    Solution.
    True. This follows directly from the definition of range and the fact that \(T\) is the transformation \(T(x) = Ax\text{:}\)
    🔗
    The matrix equation \(Ax = b\) is consistent \(\iff\) \(T(x) = b\) is consistent \(\iff\) \(b\) is in the range of \(T\text{.}\)
    🔗
    🔗
    🔗

    2.

    There is a matrix \(A\) so that the domain of the associated matrix transformation \(T\) is a line in \({\bf R}^3\text{.}\)
    🔗
    Solution.
    False: the domain of \(T\) is (all of) \({\bf R}^n\text{,}\) where \(n\) is the number of columns of \(A\text{.}\) If \(A\) has one column, then the domain of \(T\) is \({\bf R}\text{.}\) If \(A\) has three columns, then the domain of \(T\) is \({\bf R}^3\text{.}\) The domain of \(T\) can never be a line in \({\bf R}^3\text{.}\)

    Exercises 3.1.5 Exercises

    1.

    It is possible for the matrix transformation associated to a \(5 \times 6\) matrix to be both one-to-one and onto.
    🔗
    Solution.
    False. A matrix cannot have more pivots than rows or columns, so the matrix has a max of \(5\) pivots. This means it is possible for the matrix to have a pivot in every row, so the corresponding transformation might be onto. However, the matrix will have at least one pivot without a column, so the corresponding transformation \(T\) cannot be one-to-one.
    🔗

    2.

    The transformation \(T: {\bf R}^3 \to {\bf R}^3\) given by projection onto the \(yz\)-plane is onto.
    🔗
    Solution.
    False. Recall that in order for the transformation to be onto, its range must be all of \({\bf R}^3\text{.}\) However, the range of \(T\) is the \(yz\)-plane. In other words, the range is \(\Span\left\{\begin{pmatrix}0 \\ 1 \\ 0\end{pmatrix}, \begin{pmatrix}0 \\ 0 \\ 1\end{pmatrix}\right\}\text{,}\) which is only a \(2\)-dimensional subspace of \({\bf R}^3\text{,}\) not all of \({\bf R}^3\text{.}\)
    🔗
    🔗
    🔗

    3.

    The transformation \(T: {\bf R}^2 \to {\bf R}^2\) given by rotation by \(\pi/5\) radians clockwise is onto.
    🔗
    Solution.
    True. Let \(y\) be \textit{any} vector in \({\bf R}^2\text{.}\) Then for the vector \(x\) obtained by rotating \(y\) by \(\pi/5\) radians \textit{counterclockwise}, we get \(T(x) = y\text{.}\) This shows that every vector in \({\bf R}^2\) is in the range of \(T\text{.}\) In other words, range\((T) = {\bf R}^2\text{,}\) so \(T\) is onto.
    🔗
    🔗
    🔗

    4.

    If a matrix \(A\) has more rows than columns, then the matrix transformation \(T\) given by \(T(x)=Ax\) is not onto.
    🔗
    Solution.
    True. Since \(A\) cannot have more pivots than columns, and since there are more rows than columns, we conclude \(A\) cannot have a pivot in every row.
