    Section 3.3 Linear Transformations

    Objectives

    1. Learn how to verify that a transformation is linear, or prove that a transformation is not linear.
      🔗
      🔗
    2. Understand the relationship between linear transformations and matrix transformations.
      🔗
      🔗
    3. Recipe: compute the matrix of a linear transformation.
      🔗
      🔗
    4. Theorem: linear transformations and matrix transformations.
      🔗
      🔗
    5. Notation: the standard coordinate vectors \(e_1,e_2,\ldots\text{.}\)
      🔗
      🔗
    6. Vocabulary words: linear transformation, standard matrix, identity matrix.
      🔗
      🔗
    🔗
    In Section 3.1, we studied the geometry of matrices by regarding them as functions, i.e., by considering the associated matrix transformations. We defined some vocabulary (domain, codomain, range), and asked a number of natural questions about a transformation. For a matrix transformation, these translate into questions about matrices, which we have many tools to answer.
    🔗
    In this section, we make a change in perspective. Suppose that we are given a transformation that we would like to study. If we can prove that our transformation is a matrix transformation, then we can use linear algebra to study it. This raises two important questions:
    1. How can we tell if a transformation is a matrix transformation?
      🔗
      🔗
    2. If our transformation is a matrix transformation, how do we find its matrix?
      🔗
      🔗
    For example, we saw in Example 13 of Section 3.1 that the matrix transformation
    \begin{align*} T\colon\R^2\To\R^2 \qquad T(x) = \begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}x \end{align*}
    is a counterclockwise rotation of the plane by \(90^\circ\text{.}\) However, we could have defined \(T\) in this way:
    \begin{gather*} T\colon\R^2\To\R^2 \qquad T(x) = \text{the counterclockwise rotation of $x$ by $90^\circ$}\text{.} \end{gather*}
    Given this definition, it is not at all obvious that \(T\) is a matrix transformation, or what matrix it is associated to.
    🔗

    Subsection 3.3.1 Linear Transformations: Definition

    In this section, we introduce the class of transformations that come from matrices.
    🔗

    Definition 3.3.1.

    A linear transformation is a transformation \(T\colon\R^n\to\R^m\) satisfying
    \begin{align*} T(u + v) \amp= T(u) + T(v)\\ T(cu) \amp= cT(u) \end{align*}
    for all vectors \(u,v\) in \(\R^n\) and all scalars \(c\text{.}\)
    🔗
    🔗
    Let \(T\colon\R^n\to\R^m\) be a matrix transformation: \(T(x)=Ax\) for an \(m\times n\) matrix \(A\text{.}\) By Proposition 4 of Section 2.3, we have
    \begin{align*} T(u + v) = A(u + v) \amp= Au + Av = T(u) + T(v)\\ T(cu) = A(cu) \amp= cAu = cT(u) \end{align*}
    for all vectors \(u,v\) in \(\R^n\) and all scalars \(c\text{.}\) Since a matrix transformation satisfies the two defining properties, it is a linear transformation
    🔗
    We will see in the next Subsection 3.3.3 that the opposite is true: every linear transformation is a matrix transformation; we just haven’t computed its matrix yet.
    🔗

    Fact 3.3.2 Facts about linear transformations.

    Let \(T\colon\R^n\to\R^m\) be a linear transformation. Then:
    1. \(T(0)=0\text{.}\)
      🔗
      🔗
    2. For any vectors \(v_1,v_2,\ldots,v_k\) in \(\R^n\) and scalars \(c_1,c_2,\ldots,c_k\text{,}\) we have
      \begin{gather*} T\bigl( c_1v_1 + c_2v_2 + \cdots + c_kv_k \bigr) = c_1 T(v_1) + c_2 T(v_2) + \cdots + c_k T(v_k)\text{.} \end{gather*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    1. Since \(0 = -0\text{,}\) we have
      \begin{gather*} T(0) = T(-0) = -T(0) \end{gather*}
      by the second Definition 1. The only vector \(w\) such that \(w=-w\) is the zero vector.
      🔗
      🔗
    2. Let us suppose for simplicity that \(k=2\text{.}\) Then
      \begin{align*} T(c_1v_1 + c_2v_2) \amp= T(c_1v_1) + T(c_2v_2) \amp \text{first property}\\ \amp= c_1T(v_1) + c_2T(v_2) \amp \text{second property.} \end{align*}
      🔗
      🔗
    🔗
    🔗
    In engineering, the second fact is called the superposition principle; it should remind you of the distributive property. For example, \(T(cu + dv) = cT(u) + dT(v)\) for any vectors \(u,v\) and any scalars \(c,d\text{.}\) To restate the first fact:
    🔗

    Insight 3.3.3.

    A linear transformation necessarily takes the zero vector to the zero vector.
    🔗
    🔗

    Example 3.3.4 A non-linear transformation.

    Define \(T\colon\R\to\R\) by \(T(x) = x+1\text{.}\) Is \(T\) a linear transformation?
    🔗

    Solution.

    We have \(T(0) = 0 + 1 = 1\text{.}\) Since any linear transformation necessarily takes zero to zero by the above Insight 3, we conclude that \(T\) is not linear (even though its graph is a line).
    🔗
    Note: in this case, it was not necessary to check explicitly that \(T\) does not satisfy both Definition 1: since \(T(0)=0\) is a consequence of these properties, at least one of them must not be satisfied. (In fact, this \(T\) satisfies neither.)
    🔗
    🔗
    🔗

    Example 3.3.5 Verifying linearity: dilation.

    Define \(T\colon\R^2\to\R^2\) by \(T(x)=1.5x\text{.}\) Verify that \(T\) is linear.
    🔗

    Solution.

    We have to check the Definition 1 for all vectors \(u,v\) and all scalars \(c\text{.}\) In other words, we have to treat \(u,v,\) and \(c\) as unknowns. The only thing we are allowed to use is the definition of \(T\text{.}\)
    \begin{align*} T(u + v) \amp= 1.5(u + v) = 1.5u + 1.5v = T(u) + T(v)\\ T(cu) \amp= 1.5(cu) = c(1.5u) = cT(u)\text{.} \end{align*}
    Since \(T\) satisfies both defining properties, \(T\) is linear.
    🔗
    Note: we know from Example 9 of Section 3.1 that \(T\) is a matrix transformation: in fact,
    \begin{align*} T(x) = \begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}x\text{.} \end{align*}
    Since a matrix transformation is a linear transformation, this is another proof that \(T\) is linear.
    🔗
    🔗
    🔗

    Example 3.3.6 Verifying linearity: rotation.

    Define \(T\colon\R^2\to\R^2\) by
    \begin{gather*} T(x) = \text{ the vector $x$ rotated counterclockwise by the angle $\theta$}\text{.} \end{gather*}
    Verify that \(T\) is linear.
    🔗

    Solution.

    Since \(T\) is defined geometrically, we give a geometric argument. For the first property, \(T(u) + T(v)\) is the sum of the vectors obtained by rotating \(u\) and \(v\) by \(\theta\text{.}\) On the other side of the equation, \(T(u+v)\) is the vector obtained by rotating the sum of the vectors \(u\) and \(v\text{.}\) But it does not matter whether we sum or rotate first, as the following picture shows. \usetikzlibrary{angles}
    🔗
    
    🔗
    For the second property, \(cT(u)\) is the vector obtained by rotating \(u\) by the angle \(\theta\text{,}\) then changing its length by a factor of \(c\) (reversing direction of \(c<0\text{.}\) On the other hand, \(T(cu)\) first changes the length of \(c\text{,}\) then rotates. But it does not matter in which order we do these two operations. \usetikzlibrary{angles}
    🔗
    
    🔗
    This verifies that \(T\) is a linear transformation. We will find its matrix in the next Subsection 3.3.3. Note however that it is not at all obvious that \(T\) can be expressed as multiplication by a matrix.
    🔗
    🔗
    🔗

    Example 3.3.7 A transformation defined by a formula.

    Define \(T\colon\R^2\to\R^3\) by the formula
    \begin{gather*} T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 3x-y \\ y \\ x \end{pmatrix}\text{.} \end{gather*}
    Verify that \(T\) is linear.
    🔗

    Solution.

    We have to check the Definition 1 for all vectors \(u,v\) and all scalars \(c\text{.}\) In other words, we have to treat \(u,v,\) and \(c\) as unknowns; the only thing we are allowed to use is the definition of \(T\text{.}\) Since \(T\) is defined in terms of the coordinates of \(u,v\text{,}\) we need to give those names as well; say \(u={x_1\choose y_1}\) and \(v={x_2\choose y_2}\text{.}\) For the first property, we have
    \begin{align*} T\left(\begin{pmatrix} x_1 \\ y_1 \end{pmatrix} + \begin{pmatrix} x_2 \\ y_2 \end{pmatrix}\right) \amp= T\begin{pmatrix} x_1+x_2 \\ y_1+y_2 \end{pmatrix} = \begin{pmatrix} 3(x_1+x_2)-(y_1+y_2) \\ y_1+y_2 \\ x_1+x_2 \end{pmatrix}\\ \amp= \begin{pmatrix} (3x_1-y_1)+(3x_2-y_2) \\ y_1+y_2 \\ x_1+x_2 \end{pmatrix}\\ \amp= \begin{pmatrix} 3x_1-y_1 \\ y_1 \\ x_1 \end{pmatrix} + \begin{pmatrix} 3x_2-y_2 \\ y_2 \\ x_2 \end{pmatrix} = T\begin{pmatrix} x_1 \\ y_1 \end{pmatrix} + T\begin{pmatrix} x_2 \\ y_2 \end{pmatrix}\text{.} \end{align*}
    For the second property,
    \begin{align*} T\left(c\begin{pmatrix} x_1 \\ y_1 \end{pmatrix}\right) \amp= T\begin{pmatrix} cx_1 \\ cy_1 \end{pmatrix} = \begin{pmatrix} 3(cx_1)-(cy_1) \\ cy_1 \\ cx_1 \end{pmatrix}\\ \amp= \begin{pmatrix} c(3x_1-y_1) \\ cy_1 \\ cx_1 \end{pmatrix} = c\begin{pmatrix} 3x_1-y_1 \\ y_1 \\ x_1 \end{pmatrix} = cT\begin{pmatrix} x_1 \\ y_1 \end{pmatrix}\text{.} \end{align*}
    Since \(T\) satisfies the Definition 1, \(T\) is a linear transformation.
    🔗
    Note: we will see in Example 19 below that
    \begin{align*} T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 3 \amp -1 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix}\text{.} \end{align*}
    Hence \(T\) is in fact a matrix transformation.
    🔗
    🔗
    🔗
    One can show that, if a transformation is defined by formulas in the coordinates as in the above example, then the transformation is linear if and only if each coordinate is a linear expression in the variables with no constant term.
    🔗

    Example 3.3.8 A translation.

    Define \(T\colon\R^3\to\R^3\) by
    \begin{gather*} T(x) = x + \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}\text{.} \end{gather*}
    This kind of transformation is called a translation. As in a previous Example 4, this \(T\) is not linear, because \(T(0)\) is not the zero vector.
    🔗
    🔗

    Example 3.3.9 More non-linear transformations.

    Verify that the following transformations from \(\R^2\) to \(\R^2\) are not linear:
    \begin{gather*} T_1\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} |x| \\ y \end{pmatrix} \qquad T_2\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} xy \\ y \end{pmatrix} \qquad T_3\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 2x+1 \\ x-2y \end{pmatrix}\text{.} \end{gather*}
    🔗

    Solution.

    In order to verify that a transformation \(T\) is not linear, we have to show that \(T\) does not satisfy at least one of the two Definition 1. For the first, the negation of the statement “\(T(u+v)=T(u)+T(v)\) for all vectors \(u,v\)” is “there exists at least one pair of vectors \(u,v\) such that \(T(u+v)\neq T(u)+T(v)\text{.}\)” In other words, it suffices to find one example of a pair of vectors \(u,v\) such that \(T(u+v)\neq T(u)+T(v)\text{.}\) Likewise, for the second, the negation of the statement “\(T(cu) = cT(u)\) for all vectors \(u\) and all scalars \(c\)” is “there exists some vector \(u\) and some scalar \(c\) such that \(T(cu)\neq cT(u)\text{.}\)” In other words, it suffices to find one vector \(u\) and one scalar \(c\) such that \(T(cu)\neq cT(u)\text{.}\)
    🔗
    For the first transformation, we note that
    \begin{gather*} T_1\left(-\begin{pmatrix} 1 \\ 0 \end{pmatrix}\right) = T_1\begin{pmatrix} -1 \\ 0 \end{pmatrix} = \begin{pmatrix} |-1| \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix} \end{gather*}
    but that
    \begin{gather*} -T_1\begin{pmatrix} 1 \\ 0 \end{pmatrix} = -\begin{pmatrix} |1| \\ 0 \end{pmatrix} = -\begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} -1 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    Therefore, this transformation does not satisfy the second property.
    🔗
    For the second transformation, we note that
    \begin{gather*} T_2\left(2\begin{pmatrix} 1 \\ 1 \end{pmatrix}\right) = T_2\begin{pmatrix} 2 \\ 2 \end{pmatrix} = \begin{pmatrix} 2\cdot \\ 2 \\ 2 \end{pmatrix} = \begin{pmatrix} 4 \\ 2 \end{pmatrix} \end{gather*}
    but that
    \begin{gather*} 2T_2\begin{pmatrix} 1 \\ 1 \end{pmatrix} = 2\begin{pmatrix} 1\cdot \\ 1 \\ 1 \end{pmatrix} = 2\begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 2 \\ 2 \end{pmatrix}\text{.} \end{gather*}
    Therefore, this transformation does not satisfy the second property.
    🔗
    For the third transformation, we observe that
    \begin{gather*} T_3\begin{pmatrix} 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 2(0)+1 \\ 0-2(0) \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}\neq\begin{pmatrix} 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    Since \(T_3\) does not take the zero vector to the zero vector, it cannot be linear.
    🔗
    🔗
    🔗
    When deciding whether a transformation \(T\) is linear, generally the first thing to do is to check whether \(T(0)=0\text{;}\) if not, \(T\) is automatically not linear. Note however that the non-linear transformations \(T_1\) and \(T_2\) of the above example do take the zero vector to the zero vector.
    🔗

    Remark 3.3.10.

    Find an example of a transformation that satisfies the first Definition 1 but not the second.

    Subsection 3.3.2 The Standard Coordinate Vectors

    In the next subsection, we will present the relationship between linear transformations and matrix transformations. Before doing so, we need the following important notation.
    🔗

    Insight 3.3.11 Standard coordinate vectors.

    The standard coordinate vectors in \(\R^n\) are the \(n\) vectors
    \begin{gather*} e_1=\begin{pmatrix} 1 \\ 0 \\ \vdots \\ 0 \\ 0 \end{pmatrix},\quad e_2=\begin{pmatrix} 0 \\ 1 \\ \vdots \\ 0 \\ 0 \end{pmatrix},\quad\ldots,\quad e_{n-1}=\begin{pmatrix} 0 \\ 0 \\ \vdots \\ 1 \\ 0 \end{pmatrix},\quad e_n=\begin{pmatrix} 0 \\ 0 \\ \vdots \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    The \(i\)th entry of \(e_i\) is equal to 1, and the other entries are zero.
    🔗
    From now on, for the rest of the book, we will use the symbols \(\mh{e_1,e_2,\ldots}\) to denote the standard coordinate vectors.
    🔗
    🔗
    There is an ambiguity in this notation: one has to know from context that \(e_1\) is meant to have \(n\) entries. That is, the vectors
    \begin{gather*} \begin{pmatrix} 1 \\ 0 \end{pmatrix} \quad\text{ and }\quad \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \end{gather*}
    may both be denoted \(e_1\text{,}\) depending on whether we are discussing vectors in \(\R^2\) or in \(\R^3\text{.}\)
    🔗
    The standard coordinate vectors in \(\R^2\) and \(\R^3\) are pictured below.
    🔗
    
    🔗
    These are the vectors of length 1 that point in the positive directions of each of the axes.
    🔗

    Fact 3.3.12 Multiplying a matrix by the standard coordinate vectors.

    If \(A\) is an \(m\times n\) matrix with columns \(v_1,v_2,\ldots,v_m\text{,}\) then \(\mh{Ae_i} = v_i\) for each \(i=1,2,\ldots,n\text{:}\)
    \begin{align*} \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_n \\ | \amp | \amp | \end{pmatrix}e_i = v_i\text{.} \end{align*}
    In other words, multiplying a matrix by \(e_i\) simply selects its \(i\)th column.
    🔗
    🔗
    For example,
    \begin{align*} \def\A{\begin{pmatrix} 1 \amp 2 \amp 3 \\ 4 \amp 5 \amp 6 \\ 7 \amp 8 \amp 9 \end{pmatrix}} \A\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \\ 4 \\ 7 \end{pmatrix} \quad \A\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 2 \\ 5 \\ 8 \end{pmatrix} \quad \A\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 3 \\ 6 \\ 9 \end{pmatrix}\text{.} \end{align*}
    🔗

    Definition 3.3.13.

    The \(n\times n\) identity matrix is the matrix \(I_n\) whose columns are the \(n\) standard coordinate vectors in \(\R^n\text{:}\)
    \begin{align*} I_n = \begin{pmatrix} 1 \amp 0 \amp \cdots \amp 0 \amp 0 \\ 0 \amp 1 \amp \cdots \amp 0 \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp 1 \amp 0 \\ 0 \amp 0 \amp \cdots \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    We will see in Example 22 below that the identity matrix is the matrix of the identity transformation.

    Subsection 3.3.3 The Matrix of a Linear Transformation

    Now we can prove that every linear transformation is a matrix transformation, and we will show how to compute the matrix.
    🔗

    Theorem 3.3.14 The matrix of a linear transformation.

    Let \(T\colon\R^n\to\R^m\) be a linear transformation. Let \(A\) be the \(m\times n\) matrix
    \begin{align*} A = \begin{pmatrix} | \amp | \amp | \\ T(e_1) \amp T(e_2) \amp \cdots \amp T(e_n) \\ | \amp | \amp | \end{pmatrix}\text{.} \end{align*}
    Then \(T\) is the matrix transformation associated with \(A\text{:}\) that is, \(T(x) = Ax\text{.}\)
    🔗
    🔗

    Proof.
    We suppose for simplicity that \(T\) is a transformation from \(\R^3\) to \(\R^2\text{.}\) Let \(A\) be the matrix given in the statement of the theorem. Then
    \begin{align*} T\begin{pmatrix} x \\ y \\ z \end{pmatrix} \amp;= T\left( x\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} + y\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} + z\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} \right)\\ \amp= T\bigl( xe_1 + ye_2 + ze_3 \bigr)\\ \amp= xT(e_1) + yT(e_2) + zT(e_3)\\ \amp= \begin{pmatrix} | \amp | \amp | \\ T(e_1) \amp T(e_2) \amp T(e_3) \\ | \amp | \amp | \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix}\\ \amp= A\begin{pmatrix} x \\ y \\ z \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    The matrix \(A\) in the above theorem is called the standard matrix for \(T\text{.}\) The columns of \(A\) are the vectors obtained by evaluating \(T\) on the \(n\) standard coordinate vectors in \(\R^n\text{.}\) To summarize part of the theorem:

    Insight 3.3.15.

    Matrix transformations are the same as linear transformations.
    🔗
    🔗

    Example 3.3.17 The matrix of a dilation.

    Define \(T\colon\R^2\to\R^2\) by \(T(x)=1.5x\text{.}\) Find the standard matrix \(A\) for \(T\text{.}\)
    🔗

    Solution.

    The columns of \(A\) are obtained by evaluating \(T\) on the standard coordinate vectors \(e_1,e_2\text{.}\)
    \begin{align*} \left.\begin{aligned} T(e_1) \amp= 1.5e_1 = \begin{pmatrix} 1.5 \\ 0 \end{pmatrix} \\ T(e_2) \amp= 1.5e_2 = \begin{pmatrix} 0 \\ 1.5 \end{pmatrix} \end{aligned}\right\} \implies A = \begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}\text{.} \end{align*}
    This is the matrix we started with in Example 9 of Section 3.1.

    Example 3.3.18 The matrix of a rotation.

    Define \(T\colon\R^2\to\R^2\) by
    \begin{gather*} T(x) = \text{ the vector $x$ rotated counterclockwise by the angle $\theta$}\text{.} \end{gather*}
    Find the standard matrix for \(T\text{.}\)
    🔗

    Solution.

    The columns of \(A\) are obtained by evaluating \(T\) on the standard coordinate vectors \(e_1,e_2\text{.}\) In order to compute the entries of \(T(e_1)\) and \(T(e_2)\text{,}\) we have to do some trigonometry. \usetikzlibrary{math}

    Example 3.3.19 A transformation defined by a formula.

    Define \(T\colon\R^2\to\R^3\) by the formula
    \begin{gather*} T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 3x-y \\ y \\ x \end{pmatrix}\text{.} \end{gather*}

    Example 3.3.22 The standard matrix of the identity transformation.

    Verify that the identity transformation \(\Id_{\R^n}\colon\R^n\to\R^n\) is linear, and compute its standard matrix.
    🔗

    Solution.

    We verify the two Definition 1 of linear transformations. Let \(u,v\) be vectors in \(\R^n\text{.}\) Then
    \begin{gather*} \Id_{\R^n}(u+v) = u+v = \Id_{\R^n}(u) + \Id_{\R^n}(v)\text{.} \end{gather*}
    If \(c\) is a scalar, then
    \begin{gather*} \Id_{\R^n}(cu) = cu = c\Id_{\R^n}(u)\text{.} \end{gather*}
    Since \(\Id_{\R^n}\) satisfies the two defining properties, it is a linear transformation.
    🔗
    Now that we know that \(\Id_{\R^n}\) is linear, it makes sense to compute its standard matrix. For each standard coordinate vector \(e_i\text{,}\) we have \(\Id_{R^n}(e_i) = e_i\text{.}\) In other words, the columns of the standard matrix of \(\Id_{\R^n}\) are the standard coordinate vectors, so the standard matrix is the identity matrix
    \begin{align*} I_n = \begin{pmatrix} 1 \amp 0 \amp \cdots \amp 0 \amp 0 \\ 0 \amp 1 \amp \cdots \amp 0 \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp 1 \amp 0 \\ 0 \amp 0 \amp \cdots \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗
    We computed in Example 22 that the matrix of the identity transform is the identity matrix: for every \(x\) in \(\R^n\text{,}\)
    \begin{gather*} x = \Id_{\R^n}(x) = I_nx\text{.} \end{gather*}
    Therefore, \(I_nx=x\) for all vectors \(x\text{:}\) the product of the identity matrix and a vector is the same vector.

    Suppose \(T: {\bf R}^2 \to {\bf R}^3\) is a linear transformation satisfying
    \begin{gather*} T\begin{pmatrix}1 \\ 1\end{pmatrix} = \begin{pmatrix}3 \\ 3 \\ 1\end{pmatrix} \quad \textup{ and } \quad T \begin{pmatrix}2 \\ 1\end{pmatrix} = \begin{pmatrix}3 \\ 1 \\ 1\end{pmatrix}\text{.} \end{gather*}
    What is \(T \begin{pmatrix}1 \\ 0\end{pmatrix}\text{?}\)
    🔗
    Solution.
    First we write \(\begin{pmatrix}1 \\ 0\end{pmatrix}\) as a linear combination of \(u = \begin{pmatrix}1 \\ 1\end{pmatrix}\) and \(v = \begin{pmatrix}2 \\ 1\end{pmatrix}\text{.}\)
    \begin{gather*} x_1 u + x_2 v = \begin{pmatrix}1 \\ 0\end{pmatrix}, \qquad x_1 \begin{pmatrix}1 \\ 1\end{pmatrix} + x_2 \begin{pmatrix}2 \\ 1\end{pmatrix} = \begin{pmatrix}1 \\ 0\end{pmatrix}\text{.} \end{gather*}

    \begin{gather*} -u + v= \begin{pmatrix}1 \\ 0\end{pmatrix}\text{.} \end{gather*}

    \begin{gather*} T\begin{pmatrix}1 \\ 0\end{pmatrix} = T(-u+v) = T(-u)+T(v) = -T(u)+T(v) = -\begin{pmatrix}3 \\ 3 \\ 1\end{pmatrix} + \begin{pmatrix}3 \\ 1 \\ 1\end{pmatrix} = \begin{pmatrix}0 \\ -2 \\ 0\end{pmatrix}\text{.} \end{gather*}

    3.

    Suppose \(T: {\bf R}^2 \to {\bf R}^2\) is a linear transformation satisfying
    \begin{gather*} T\begin{pmatrix}3 \\ -1\end{pmatrix} = \begin{pmatrix}1 \\ 1\end{pmatrix} \quad \textup{ and } \quad T \begin{pmatrix}1 \\ 2\end{pmatrix} = \begin{pmatrix}4 \\ 4\end{pmatrix}\text{.} \end{gather*}
    Find the standard matrix \(A\) for \(T\text{,}\) and use it to find \(T\begin{pmatrix}11 \\ 1\end{pmatrix}\text{.}\)
    🔗
    Solution.
    We know that \(A = \begin{pmatrix}T\begin{pmatrix}1 \amp \\ \amp 0\end{pmatrix} \amp T\begin{pmatrix}0 \amp \\ \amp 1\end{pmatrix}\end{pmatrix}\text{,}\) and we use linearity of \(T\) to find both columns of \(A\text{.}\) Let \(u = \begin{pmatrix}3 \\ -1\end{pmatrix}\) and \(v = \begin{pmatrix}1 \\ 2\end{pmatrix}\text{.}\) Work using the basics of chapter 1 gives us
    \begin{gather*} \begin{pmatrix}1 \\ 0\end{pmatrix} = \dfrac{2}{7} u + \dfrac{1}{7} v \quad \textup{ and } \quad \begin{pmatrix}0 \\ 1\end{pmatrix} = \dfrac{-1}{7} u + \dfrac{3}{7} v\text{.} \end{gather*}

    \begin{gather*} T \begin{pmatrix}1 \\ 0\end{pmatrix} = T\left(\dfrac{2}{7}u + \dfrac{1}{7} v\right) = \dfrac{2}{7} T(u) + \dfrac{1}{7} T(v) = \dfrac{2}{7} \begin{pmatrix}1 \\ 1\end{pmatrix} + \dfrac{1}{7} \begin{pmatrix}4 \\ 4\end{pmatrix} = \begin{pmatrix}6/7 \\ 6/7\end{pmatrix} \end{gather*}
    and
    \begin{gather*} T \begin{pmatrix}0 \\ 1\end{pmatrix} = T\left(\dfrac{-1}{7}u + \dfrac{3}{7} v\right) = \dfrac{-1}{7} T(u) + \dfrac{3}{7} T(v) = \dfrac{-1}{7} \begin{pmatrix}1 \\ 1\end{pmatrix} + \dfrac{3}{7} \begin{pmatrix}4 \\ 4\end{pmatrix} = \begin{pmatrix}11/7 \\ 11/7.\end{pmatrix} \end{gather*}

    \begin{align*} T\begin{pmatrix}11 \\ 1\end{pmatrix} = A \begin{pmatrix}11 \\ 1\end{pmatrix} = \begin{pmatrix}6/7 \amp 11/7 \\ 6/7 \amp 11/7\end{pmatrix} \begin{pmatrix}11 \\ 1\end{pmatrix} = \begin{pmatrix}11 \\ 11\end{pmatrix}\text{.} \end{align*}

    🔗
    Solution.

    🔗
    🔗
    🔗

    🔗
    Solution.
    Yes, \(T\) is one-to-one because \(A\) has a pivot in every column.

    🔗
    Solution.
    We examine what happens to \(e_1\) and \(e_2\text{.}\)
    🔗
    \(e_1\text{:}\) The reflection sends \(\begin{pmatrix}1 \\ 0\end{pmatrix}\) to \(\begin{pmatrix}0 \\ 1\end{pmatrix}\text{,}\) then rotating cc by \(45^\circ\) gives \(T(e_1) = \begin{pmatrix}\frac{-1}{\sqrt{2}} \\ \frac{1}{\sqrt{2}}\end{pmatrix}\text{.}\)
    🔗

    🔗

    \begin{align*} A = \begin{pmatrix}T(e_1) \amp T(e_2)\end{pmatrix} = \begin{pmatrix}\frac{-1}{\sqrt{2}} \amp \frac{1}{\sqrt{2}} \\ \frac{1}{\sqrt{2}} \amp \frac{1}{\sqrt{2}}\end{pmatrix}\text{.} \end{align*}
