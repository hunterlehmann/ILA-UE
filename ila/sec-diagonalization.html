    Section 5.4 Diagonalization

    Objectives

    1. Learn two main criteria for a matrix to be diagonalizable.
      🔗
      🔗
    2. Develop a library of examples of matrices that are and are not diagonalizable.
      🔗
      🔗
    3. Understand what diagonalizability and multiplicity have to say about similarity.
      🔗
      🔗
    4. Recipes: diagonalize a matrix, quickly compute powers of a matrix by diagonalization.
      🔗
      🔗
    5. Pictures: the geometry of diagonal matrices, why a shear is not diagonalizable.
      🔗
      🔗
    6. Theorem: the diagonalization theorem (two variants).
      🔗
      🔗
    7. Vocabulary words: diagonalizable, algebraic multiplicity, geometric multiplicity.
      🔗
      🔗
    🔗
    Diagonal matrices are the easiest kind of matrices to understand: they just scale the coordinate directions by their diagonal entries. In Section 5.3, we saw that similar matrices behave in the same way, with respect to different coordinate systems. Therefore, if a matrix is similar to a diagonal matrix, it is also relatively easy to understand. This section is devoted to the question: “When is a matrix similar to a diagonal matrix?”
    🔗

    Subsection 5.4.1 Diagonalizability

    Before answering the above question, first we give it a name.
    🔗

    Definition 5.4.1.

    An \(n\times n\) matrix \(A\) is diagonalizable if it is similar to a diagonal matrix: that is, if there exists an invertible \(n\times n\) matrix \(C\) and a diagonal matrix \(D\) such that
    \begin{gather*} A = CDC\inv\text{.} \end{gather*}
    🔗
    🔗

    Example 5.4.2.

    Any diagonal matrix is \(D\) is diagonalizable because it is similar to itself. For instance,
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} = I_3\begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}I_3\inv\text{.} \end{align*}
    🔗
    🔗

    Example 5.4.3.

    Most of the examples in Section 5.3 involve diagonalizable matrices:
    \begin{align*} \def\idb{\quad\parbox{\widthof{because it equals}}{is diagonalizable\\because it equals}\quad} \begin{pmatrix} -12 \amp 15 \\ -10 \amp 13 \end{pmatrix} \amp\idb \begin{pmatrix} -2 \amp 3 \\ 1 \amp -1 \end{pmatrix} \begin{pmatrix} 3 \amp 0 \\ 0 \amp -2 \end{pmatrix} \begin{pmatrix} -2 \amp 3 \\ 1 \amp -1 \end{pmatrix}\inv\\ \begin{pmatrix} 1/2 \amp 3/2 \\ 3/2 \amp 1/2 \end{pmatrix} \amp\idb \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix} \begin{pmatrix} 2 \amp 0 \\ 0 \amp -1 \end{pmatrix} \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix}\inv\\ \frac 15\begin{pmatrix} -8 \amp -9 \\ 6 \amp 13 \end{pmatrix} \amp\idb \frac 12\begin{pmatrix} -1 \amp -3 \\ 2 \amp 1 \end{pmatrix} \begin{pmatrix} 2 \amp 0 \\ 0 \amp -1 \end{pmatrix} \left(\frac 12\begin{pmatrix} -1 \amp -3 \\ 2 \amp 1 \end{pmatrix}\right)\inv\\ \begin{pmatrix} -1 \amp 0 \amp 0 \\ -1 \amp 0 \amp 2 \\ -1 \amp 1 \amp 1 \end{pmatrix} \amp\idb \begin{pmatrix} -1 \amp 1 \amp 0 \\ 1 \amp 1 \amp 1 \\ -1 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} -1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix} \begin{pmatrix} -1 \amp 1 \amp 0 \\ 1 \amp 1 \amp 1 \\ -1 \amp 0 \amp 1 \end{pmatrix}\inv\text{.} \end{align*}
    🔗
    🔗

    Example 5.4.4.

    If a matrix \(A\) is diagonalizable, and if \(B\) is similar to \(A\text{,}\) then \(B\) is diagonalizable as well by Proposition 5 of Section 5.3.
    🔗
    🔗

    Powers of diagonalizable matrices.

    Multiplying diagonal matrices together just multiplies their diagonal entries:
    \begin{align*} \begin{pmatrix} x_1 \amp 0 \amp 0 \\ 0 \amp x_2 \amp 0 \\ 0 \amp 0 \amp x_3 \end{pmatrix}\begin{pmatrix} y_1 \amp 0 \amp 0 \\ 0 \amp y_2 \amp 0 \\ 0 \amp 0 \amp y_3 \end{pmatrix} = \begin{pmatrix} x_1y_1 \amp 0 \amp 0 \\ 0 \amp x_2y_2 \amp 0 \\ 0 \amp 0 \amp x_3y_3 \end{pmatrix}\text{.} \end{align*}
    Therefore, it is easy to take powers of a diagonal matrix:
    \begin{align*} \begin{pmatrix} x \amp 0 \amp 0 \\ 0 \amp y \amp 0 \\ 0 \amp 0 \amp z \end{pmatrix}^n = \begin{pmatrix} x^n \amp 0 \amp 0 \\ 0 \amp y^n \amp 0 \\ 0 \amp 0 \amp z^n \end{pmatrix}\text{.} \end{align*}
    By Fact 7 of Section 5.3, if \(A = CDC\inv\) then \(A^n = CD^nC\inv\text{,}\) so it is also easy to take powers of diagonalizable matrices. This will be very important in applications to difference equations in Section 5.6.
    🔗

    Recipe 5.4.5 Compute powers of a diagonalizable matrix.

    If \(A = CDC\inv\text{,}\) where \(D\) is a diagonal matrix, then \(A^n = CD^nC\inv\text{:}\)
    \begin{align*} A = C\begin{pmatrix} x \amp 0 \amp 0 \\ 0 \amp y \amp 0 \\ 0 \amp 0 \amp z \end{pmatrix}C\inv \quad\implies\quad A^n = C\begin{pmatrix} x^n \amp 0 \amp 0 \\ 0 \amp y^n \amp 0 \\ 0 \amp 0 \amp z^n \end{pmatrix}C\inv\text{.} \end{align*}
    🔗
    🔗

    Example 5.4.6.

    Let
    \begin{align*} A = \begin{pmatrix} 1/2 \amp 3/2 \\ 3/2 \amp 1/2 \end{pmatrix} = \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix} \begin{pmatrix} 2 \amp 0 \\ 0 \amp -1 \end{pmatrix} \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix}\inv\text{.} \end{align*}
    Find a formula for \(A^n\) in which the entries are functions of \(n\text{,}\) where \(n\) is any positive whole number.
    🔗
    Solution.
    We have
    \begin{align*} A^n \amp= \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix} \begin{pmatrix} 2 \amp 0 \\ 0 \amp -1 \end{pmatrix}^n \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix}\inv\\ \amp= \begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix} \begin{pmatrix} 2^n \amp 0 \\ 0 \amp (-1)^n \end{pmatrix} \frac 1{-2}\begin{pmatrix} -1 \amp -1 \\ -1 \amp 1 \end{pmatrix}\\ \amp= \begin{pmatrix} 2^n \amp (-1)^n \\ 2^n \amp (-1)^{n+1} \end{pmatrix}\frac 12\begin{pmatrix} 1 \amp 1 \\ 1 \amp -1 \end{pmatrix}\\ \amp= \frac 12\begin{pmatrix} 2^n+(-1)^n \amp 2^n+(-1)^{n+1} \\ 2^n+(-1)^{n+1} \amp 2^n+(-1)^{n} \end{pmatrix}\text{,} \end{align*}
    where we used \((-1)^{n+2}=(-1)^2(-1)^n = (-1)^n\text{.}\)
    🔗
    🔗
    🔗
    🔗
    A fundamental question about a matrix is whether or not it is diagonalizable. The following is the primary criterion for diagonalizability. It shows that diagonalizability is an eigenvalue problem.
    🔗

    Theorem 5.4.7.

    An \(n\times n\) matrix \(A\) is diagonalizable if and only if \(A\) has \(n\) linearly independent eigenvectors.
    🔗
    In this case, \(A = CDC\inv\) for
    \begin{align*} C = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_n \\ | \amp | \amp | \end{pmatrix} \qquad D = \begin{pmatrix} \lambda_1 \amp 0 \amp \cdots \amp 0 \\ 0 \amp \lambda_2 \amp \cdots \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp \lambda_n \end{pmatrix}\text{,} \end{align*}
    where \(v_1,v_2,\ldots,v_n\) are linearly independent eigenvectors, and \(\lambda_1,\lambda_2,\ldots,\lambda_n\) are the corresponding eigenvalues, in the same order.
    🔗
    🔗

    Proof.
    First suppose that \(A\) has \(n\) linearly independent eigenvectors \(v_1,v_2,\ldots,v_n\text{,}\) with eigenvalues \(\lambda_1,\lambda_2,\ldots,\lambda_n\text{.}\) Define \(C\) as above, so \(C\) is invertible by the Theorem 31 of Section 5.1. Let \(D = C\inv A C\text{,}\) so \(A = CDC\inv\text{.}\) Multiplying by standard coordinate vectors picks out the columns of \(C\text{:}\) we have \(Ce_i = v_i\text{,}\) so \(e_i = C\inv v_i\text{.}\) We multiply by the standard coordinate vectors to find the columns of \(D\text{:}\)
    \begin{gather*} De_i = C\inv A Ce_i = C\inv Av_i = C\inv\lambda_i v_i = \lambda_iC\inv v_i = \lambda_ie_i\text{.} \end{gather*}
    Therefore, the columns of \(D\) are multiples of the standard coordinate vectors:
    \begin{align*} D = \begin{pmatrix} \lambda_1 \amp 0 \amp \cdots \amp 0 \amp 0 \\ 0 \amp \lambda_2 \amp \cdots \amp 0 \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp \lambda_{n-1} \amp 0 \\ 0 \amp 0 \amp \cdots \amp 0 \amp \lambda_n \end{pmatrix}\text{.} \end{align*}
    🔗
    Now suppose that \(A = CDC\inv\text{,}\) where \(C\) has columns \(v_1,v_2,\ldots,v_n\text{,}\) and \(D\) is diagonal with diagonal entries \(\lambda_1,\lambda_2,\ldots,\lambda_n\text{.}\) Since \(C\) is invertible, its columns are linearly independent. We have to show that \(v_i\) is an eigenvector of \(A\) with eigenvalue \(\lambda_i\text{.}\) We know that the standard coordinate vector \(e_i\) is an eigenvector of \(D\) with eigenvalue \(\lambda_i\text{,}\) so:
    \begin{gather*} Av_i = CDC\inv v_i = CDe_i = C\lambda_ie_i = \lambda_iCe_i = \lambda_i v_i\text{.} \end{gather*}
    🔗
    🔗
    By Fact 19 of Section 5.1, if an \(n\times n\) matrix \(A\) has \(n\) distinct eigenvalues \(\lambda_1,\lambda_2,\ldots,\lambda_n\text{,}\) then a choice of corresponding eigenvectors \(v_1,v_2,\ldots,v_n\) is automatically linearly independent.
    🔗

    Insight 5.4.8.

    An \(n\times n\) matrix with \(n\) distinct eigenvalues is diagonalizable.
    🔗
    🔗

    Example 5.4.9 Easy Example.

    Apply the Theorem 7 to the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    This diagonal matrix is in particular upper-triangular, so its eigenvalues are the diagonal entries \(1,2,3\text{.}\) The standard coordinate vectors are eigenvalues of a diagonal matrix:
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} = 1\cdot\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \qquad \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} = 2\cdot\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} \end{align*}
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = 3\cdot\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{align*}
    Therefore, the diagonalization theorem says that \(A=CDC\inv\text{,}\) where the columns of \(C\) are the standard coordinate vectors, and the \(D\) is the diagonal matrix with entries \(1,2,3\text{:}\)
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\inv\text{.} \end{align*}
    This just tells us that \(A\) is similar to itself.
    🔗
    Actually, the diagonalization theorem is not completely trivial even for diagonal matrices. If we put our eigenvalues in the order \(3,2,1\text{,}\) then the corresponding eigenvectors are \(e_3,e_2,e_1\text{,}\) so we also have that \(A = C'D'(C')\inv\text{,}\) where \(C'\) is the matrix with columns \(e_3,e_2,e_1\text{,}\) and \(D'\) is the diagonal matrix with entries \(3,2,1\text{:}\)
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} = \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix} \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix}\inv\text{.} \end{align*}
    In particular, the matrices
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} \sptxt{and} \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
    are similar to each other.
    🔗
    🔗
    🔗
    🔗

    Note 5.4.10 Non-Uniqueness of Diagonalization.

    We saw in the above example that changing the order of the eigenvalues and eigenvectors produces a different diagonalization of the same matrix. There are generally many different ways to diagonalize a matrix, corresponding to different orderings of the eigenvalues of that matrix. The important thing is that the eigenvalues and eigenvectors have to be listed in the same order.
    \begin{align*} A \amp= \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp v_3 \\ | \amp | \amp | \end{pmatrix} \begin{pmatrix} \lambda_1 \amp 0 \amp 0 \\ 0 \amp \lambda_2 \amp 0 \\ 0 \amp 0 \amp \lambda_3 \end{pmatrix} \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp v_3 \\ | \amp | \amp | \end{pmatrix}\inv\\ \amp= \begin{pmatrix} | \amp | \amp | \\ v_3 \amp v_2 \amp v_1 \\ | \amp | \amp | \end{pmatrix} \begin{pmatrix} \lambda_3 \amp 0 \amp 0 \\ 0 \amp \lambda_2 \amp 0 \\ 0 \amp 0 \amp \lambda_1 \end{pmatrix} \begin{pmatrix} | \amp | \amp | \\ v_3 \amp v_2 \amp v_1 \\ | \amp | \amp | \end{pmatrix}\inv\text{.} \end{align*}
    🔗
    There are other ways of finding different diagonalizations of the same matrix. For instance, you can scale one of the eigenvectors by a constant \(c\text{:}\)
    \begin{align*} A \amp= \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp v_3 \\ | \amp | \amp | \end{pmatrix} \begin{pmatrix} \lambda_1 \amp 0 \amp 0 \\ 0 \amp \lambda_2 \amp 0 \\ 0 \amp 0 \amp \lambda_3 \end{pmatrix} \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp v_3 \\ | \amp | \amp | \end{pmatrix}\inv\\ \amp= \begin{pmatrix} | \amp | \amp | \\ cv_1 \amp v_2 \amp v_3 \\ | \amp | \amp | \end{pmatrix} \begin{pmatrix} \lambda_1 \amp 0 \amp 0 \\ 0 \amp \lambda_2 \amp 0 \\ 0 \amp 0 \amp \lambda_3 \end{pmatrix} \begin{pmatrix} | \amp | \amp | \\ cv_1 \amp v_2 \amp v_3 \\ | \amp | \amp | \end{pmatrix}\inv\text{,} \end{align*}
    you can find a different basis entirely for an eigenspace of dimension at least \(2\text{,}\) etc.
    🔗
    🔗

    Example 5.4.11 A diagonalizable \(2\times 2\) matrix.

    Diagonalize the matrix
    \begin{align*} A = \begin{pmatrix} 1/2 \amp 3/2 \\ 3/2 \amp 1/2 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We need to find the eigenvalues and eigenvectors of \(A\text{.}\) First we compute the characteristic polynomial:
    \begin{gather*} f(\lambda) = \lambda^2-\Tr(A)\lambda + \det(A) = \lambda^2-\lambda-2 = (\lambda+1)(\lambda-2)\text{.} \end{gather*}
    Therefore, the eigenvalues are \(-1\) and \(2\text{.}\) We need to compute eigenvectors for each eigenvalue. We start with \(\lambda_1 = -1\text{:}\)
    \begin{align*} (A + 1I_2)v = 0 \iff \begin{pmatrix} 3/2 \amp 3/2 \\ 3/2 \amp 3/2 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form is \(x = -y\text{,}\) so \(v_1 = {-1\choose 1}\) is an eigenvector with eigenvalue \(\lambda_1\text{.}\) Now we find an eigenvector with eigenvalue \(\lambda_2 = 2\text{:}\)
    \begin{align*} (A-2I_2)v = 0 \iff \begin{pmatrix} -3/2 \amp 3/2 \\ 3/2 \amp -3/2 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form is \(x = y\text{,}\) so \(v_2 = {1\choose 1}\) is an eigenvector with eigenvalue \(2\text{.}\)
    🔗
    The eigenvectors \(v_1,v_2\) are linearly independent, so the Theorem 7 says that
    \begin{align*} A = CDC\inv \sptxt{for} C = \begin{pmatrix} -1 \amp 1 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} -1 \amp 0 \\ 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    Alternatively, if we choose \(2\) as our first eigenvalue, then
    \begin{align*} A = C'D'(C')\inv \sptxt{for} C' = \begin{pmatrix} 1 \amp -1 \\ 1 \amp 1 \end{pmatrix} \qquad D' = \begin{pmatrix} 2 \amp 0 \\ 0 \amp -1 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗

    Example 5.4.13 A diagonalizable \(2\times 2\) matrix with a zero eigenvector.

    Diagonalize the matrix
    \begin{align*} A = \begin{pmatrix} 2/3 \amp -4/3 \\ -2/3 \amp 4/3 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We need to find the eigenvalues and eigenvectors of \(A\text{.}\) First we compute the characteristic polynomial:
    \begin{gather*} f(\lambda) = \lambda^2-\Tr(A)\lambda + \det(A) = \lambda^2 -2\lambda = \lambda(\lambda-2)\text{.} \end{gather*}
    Therefore, the eigenvalues are \(0\) and \(2\text{.}\) We need to compute eigenvectors for each eigenvalue. We start with \(\lambda_1 = 0\text{:}\)
    \begin{align*} (A - 0I_2)v = 0 \iff \begin{pmatrix} 2/3 \amp -4/3 \\ -2/3 \amp 4/3 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -2 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form is \(x = 2y\text{,}\) so \(v_1 = {2\choose 1}\) is an eigenvector with eigenvalue \(\lambda_1\text{.}\) Now we find an eigenvector with eigenvalue \(\lambda_2 = 2\text{:}\)
    \begin{align*} (A-2I_2)v = 0 \iff \begin{pmatrix} -4/3 \amp -4/3 \\ -2/3 \amp -2/3 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form is \(x = -y\text{,}\) so \(v_2 = {1\choose-1}\) is an eigenvector with eigenvalue \(2\text{.}\)
    🔗
    The eigenvectors \(v_1,v_2\) are linearly independent, so the Theorem 7 says that
    \begin{align*} A = CDC\inv \sptxt{for} C = \begin{pmatrix} 2 \amp 1 \\ 1 \amp -1 \end{pmatrix} \qquad D = \begin{pmatrix} 0 \amp 0 \\ 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    Alternatively, if we choose \(2\) as our first eigenvalue, then
    \begin{align*} A = C'D'(C')\inv \sptxt{for} C' = \begin{pmatrix} 1 \amp 2 \\ -1 \amp 1 \end{pmatrix} \qquad D' = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗
    In the above example, the (non-invertible) matrix \(A = \frac 13\smallmat{2}{-4}{-2}{4}\) is similar to the diagonal matrix \(D = \smallmat0002.\) Since \(A\) is not invertible, zero is an eigenvalue by the invertible matrix theorem, so one of the diagonal entries of \(D\) is necessarily zero. Also see Example 19 below.
    🔗

    Example 5.4.14 A diagonalizable \(3\times 3\) matrix.

    Diagonalize the matrix
    \begin{align*} A = \begin{pmatrix} 4 \amp -3 \amp 0 \\ 2 \amp -1 \amp 0 \\ 1 \amp -1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We need to find the eigenvalues and eigenvectors of \(A\text{.}\) First we compute the characteristic polynomial by expanding cofactors along the third column:
    \begin{align*} f(\lambda) \amp= \det(A-\lambda I_3) = (1-\lambda)\det\left(\begin{pmatrix} 4 \amp -3 \\ 2 \amp -1 \end{pmatrix} - \lambda I_2\right)\\ \amp= (1-\lambda)(\lambda^2 - 3\lambda + 2) = -(\lambda-1)^2(\lambda-2)\text{.} \end{align*}
    Therefore, the eigenvalues are \(1\) and \(2\text{.}\) We need to compute eigenvectors for each eigenvalue. We start with \(\lambda_1 = 1\text{:}\)
    \begin{align*} (A-I_3)v = 0 \iff \begin{pmatrix} 3 \amp -3 \amp 0 \\ 2 \amp -2 \amp 0 \\ 1 \amp -1 \amp 0 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric vector form is
    \begin{align*} \left\{\begin{alignedat}{2} x \amp {}={} \amp y \amp {} \\ y \amp {}={} \amp y \amp {} \\ z \amp {}={} \amp z \amp {} \end{alignedat}\right. \implies \begin{pmatrix} x \\ y \\ z \end{pmatrix} = y\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + z\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{align*}
    Hence a basis for the \(1\)-eigenspace is
    \begin{gather*} \cB_1 = \bigl\{ v_1,v_2 \bigr\} \sptxt{where} v_1 = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}, \quad v_2 = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    Now we compute the eigenspace for \(\lambda_2 = 2\text{:}\)
    \begin{align*} (A-2I_3)v = 0 \iff \begin{pmatrix} 2 \amp -3 \amp 0 \\ 2 \amp -3 \amp 0 \\ 1 \amp -1 \amp -1 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 0 \amp -3 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 0 \end{pmatrix}v = 0 \end{align*}
    The parametric form is \(x = 3z, y = 2z\text{,}\) so an eigenvector with eigenvalue \(2\) is
    \begin{gather*} v_3 = \begin{pmatrix} 3 \\ 2 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    🔗
    The eigenvectors \(v_1,v_2,v_3\) are linearly independent: \(v_1,v_2\) form a basis for the \(1\)-eigenspace, and \(v_3\) is not contained in the \(1\)-eigenspace because its eigenvalue is \(2\text{.}\) Therefore, the Theorem 7 says that
    \begin{align*} A = CDC\inv \sptxt{for} C = \begin{pmatrix} 1 \amp 0 \amp 3 \\ 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗
    Here is the procedure we used in the above examples.
    🔗

    Recipe 5.4.16 Diagonalization.

    Let \(A\) be an \(n\times n\) matrix. To diagonalize \(A\text{:}\)
    1. Find the eigenvalues of \(A\) using the characteristic polynomial.
      🔗
      🔗
    2. For each eigenvalue \(\lambda\) of \(A\text{,}\) compute a basis \(\cB_\lambda\) for the \(\lambda\)-eigenspace.
      🔗
      🔗
    3. If there are fewer than \(n\) total vectors in all of the eigenspace bases \(B_\lambda\text{,}\) then the matrix is not diagonalizable.
      🔗
      🔗
    4. Otherwise, the \(n\) vectors \(v_1,v_2,\ldots,v_n\) in the eigenspace bases are linearly independent, and \(A = CDC\inv\) for
      \begin{align*} C = \begin{pmatrix} | \amp | \amp | \\ v_1 \amp v_2 \amp \cdots \amp v_n \\ | \amp | \amp | \end{pmatrix} \sptxt{and} D = \begin{pmatrix} \lambda_1 \amp 0 \amp \cdots \amp 0 \\ 0 \amp \lambda_2 \amp \cdots \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp \lambda_n \end{pmatrix}\text{,} \end{align*}
      where \(\lambda_i\) is the eigenvalue for \(v_i\text{.}\)
      🔗
      🔗
    🔗
    🔗
    We will justify the linear independence assertion in part 4 in the proof of Theorem 46 below.

    Example 5.4.17 A shear is not diagonalizable.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix}\text{,} \end{align*}
    so \(T(x) = Ax\) is a shear. The characteristic polynomial of \(A\) is \(f(\lambda) = (\lambda-1)^2\text{,}\) so the only eigenvalue of \(A\) is \(1\text{.}\) We compute the \(1\)-eigenspace:
    \begin{align*} (A - I_2)v = 0 \iff \begin{pmatrix} 0 \amp 1 \\ 0 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = 0 \iff y = 0\text{.} \end{align*}
    In other words, the \(1\)-eigenspace is exactly the \(x\)-axis, so all of the eigenvectors of \(A\) lie on the \(x\)-axis. It follows that \(A\) does not admit two linearly independent eigenvectors, so by the Theorem 7, it is not diagonalizable.

    🔗

    This is an example of an orthogonal projection. We will see in Section 6.3 that \(T\) is a linear transformation; let \(A\) be the matrix for \(T\text{.}\) Any vector on \(L\) is not moved by \(T\) because it is the closest point on \(L\) to itself: hence it is an eigenvector of \(A\) with eigenvalue \(1\text{.}\) Let \(L^\perp\) be the line perpendicular to \(L\) and passing through the origin. Any vector \(x\) on \(L^\perp\) is closest to the zero vector on \(L\text{,}\) so a (nonzero) such vector is an eigenvector of \(A\) with eigenvalue \(0\text{.}\) (See Example 9 of Section 5.1 for a special case.)     Example 5.4.21 A non-diagonalizable \(3\times 3\) matrix.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    The characteristic polynomial of \(A\) is \(f(\lambda) = -(\lambda-1)^2(\lambda-2)\text{,}\) so the eigenvalues of \(A\) are \(1\) and \(2\text{.}\) We compute the \(1\)-eigenspace:
    \begin{align*} (A - I_3)v = 0 \iff \begin{pmatrix} 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix} = 0 \iff y = z = 0\text{.} \end{align*}
    In other words, the \(1\)-eigenspace is the \(x\)-axis. Similarly,
    \begin{align*} (A - 2I_3)v = 0 \iff \begin{pmatrix} -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix} = 0 \iff x = y = 0\text{,} \end{align*}
    so the \(2\)-eigenspace is the \(z\)-axis. In particular, all eigenvectors of \(A\) lie on the \(xz\)-plane, so there do not exist three linearly independent eigenvectors of \(A\text{.}\) By the Theorem 7, the matrix \(A\) is not diagonalizable.
    🔗
    Notice that \(A\) contains a \(2\times 2\) block on its diagonal that looks like a shear:
    \begin{align*} A = \begin{pmatrix} \amp 1 \amp \amp 1 \amp 0 \\ \amp 0 \amp \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
    This makes one suspect that such a matrix is not diagonalizable.

    Example 5.4.23 A rotation matrix.

    Let
    \begin{align*} A = \begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
    so \(T(x) = Ax\) is the linear transformation that rotates counterclockwise by \(90^\circ\text{.}\) We saw in Example 17 of Section 5.1 that \(A\) does not have any eigenvectors at all. It follows that \(A\) is not diagonalizable.
    🔗
    The characteristic polynomial of \(A\) is \(f(\lambda) = \lambda^2+1\text{,}\) which of course does not have any real roots. If we allow complex numbers, however, then \(f\) has two roots, namely, \(\pm i\text{,}\) where \(i = \sqrt{-1}\text{.}\) Hence the matrix is diagonalizable if we allow ourselves to use complex numbers. We will treat this topic in detail in Section 5.5.

    Remark 5.4.26 Non-diagonalizable \(2\times 2\) matrices with an eigenvalue.

    As in the above Example 17, one can check that the matrix
    \begin{align*} A_\lambda = \begin{pmatrix} \lambda \amp 1 \\ 0 \amp \lambda \end{pmatrix} \end{align*}
    is not diagonalizable for any number \(\lambda\text{.}\) We claim that any non-diagonalizable \(2\times 2\) matrix \(B\) with a real eigenvalue \(\lambda\) is similar to \(A_\lambda\text{.}\) Therefore, up to similarity, these are the only such examples.
    🔗
    To prove this, let \(B\) be such a matrix. Let \(v_1\) be an eigenvector with eigenvalue \(\lambda\text{,}\) and let \(v_2\) be any vector in \(\R^2\) that is not collinear with \(v_1\text{,}\) so that \(\{v_1,v_2\}\) forms a basis for \(\R^2\text{.}\) Let \(C\) be the matrix with columns \(v_1,v_2\text{,}\) and consider \(A = C\inv BC\text{.}\) We have \(Ce_1=v_1\) and \(Ce_2=v_2\text{,}\) so \(C\inv v_1=e_1\) and \(C\inv v_2=e_2\text{.}\) We can compute the first column of \(A\) as follows:
    \begin{gather*} Ae_1 = C\inv BC e_1 = C\inv Bv_1 = C\inv\lambda v_1 = \lambda C\inv v_1 = \lambda e_1\text{.} \end{gather*}
    Therefore, \(A\) has the form
    \begin{align*} A = \begin{pmatrix} \lambda \amp b \\ 0 \amp d \end{pmatrix}\text{.} \end{align*}
    Since \(A\) is similar to \(B\text{,}\) it also has only one eigenvalue \(\lambda\text{;}\) since \(A\) is upper-triangular, this implies \(d=\lambda\text{,}\) so
    \begin{align*} A = \begin{pmatrix} \lambda \amp b \\ 0 \amp \lambda \end{pmatrix}\text{.} \end{align*}
    As \(B\) is not diagonalizable, we know \(A\) is not diagonal (\(B\) is similar to \(A\)), so \(b\neq 0\text{.}\) Now we observe that
    \begin{align*} \begin{pmatrix} 1/b \amp 0 \\ 0 \amp 1 \end{pmatrix}\begin{pmatrix} \lambda \amp b \\ 0 \amp \lambda \end{pmatrix}\begin{pmatrix} 1/b \amp 0 \\ 0 \amp 1 \end{pmatrix}\inv = \begin{pmatrix} \lambda/b \amp 1 \\ 0 \amp \lambda \end{pmatrix}\begin{pmatrix} b \amp 0 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} \lambda \amp 1 \\ 0 \amp \lambda \end{pmatrix} = A_\lambda\text{.} \end{align*}
    We have shown that \(B\) is similar to \(A\text{,}\) which is similar to \(A_\lambda\text{,}\) so \(B\) is similar to \(A_\lambda\) by the transitivity property of similar matrices.
    🔗
    🔗
    🔗

    Subsection 5.4.2 The Geometry of Diagonalizable Matrices

    A diagonal matrix is easy to understand geometrically, as it just scales the coordinate axes:
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} = 1\cdot\begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \qquad \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} = 2\cdot\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} \end{align*}
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix}\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = 3\cdot\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{align*}
    Therefore, we know from Section 5.3 that a diagonalizable matrix simply scales the “axes” with respect to a different coordinate system. Indeed, if \(v_1,v_2,\ldots,v_n\) are linearly independent eigenvectors of an \(n\times n\) matrix \(A\text{,}\) then \(A\) scales the \(v_i\)-direction by the eigenvalue \(\lambda_i\text{.}\)
    🔗
    In the following examples, we visualize the action of a diagonalizable matrix \(A\) in terms of its dynamics. In other words, we start with a collection of vectors (drawn as points), and we see where they move when we multiply them by \(A\) repeatedly.
    🔗

    Example 5.4.27 Eigenvalues \(|\lambda_1| > 1,\,|\lambda_2|\lt1\).

    Describe how the matrix
    \begin{align*} A = \frac 1{10}\begin{pmatrix} 11 \amp 6 \\ 9 \amp 14 \end{pmatrix} \end{align*}
    acts on the plane.
    🔗

    Solution.

    First we diagonalize \(A\text{.}\) The characteristic polynomial is
    \begin{gather*} f(\lambda) = \lambda^2 - \Tr(A)\lambda + \det(A) = \lambda^2 - \frac 52\lambda + 1 = (\lambda - 2)\left(\lambda - \frac 12\right)\text{.} \end{gather*}
    We compute the \(2\)-eigenspace:
    \begin{align*} (A-2I_3)v = 0 \iff \frac 1{10}\begin{pmatrix} -9 \amp 6 \\ 9 \amp -6 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -2/3 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form of this equation is \(x = 2/3y\text{,}\) so one eigenvector is \(v_1 = {2/3\choose 1}\text{.}\) For the \(1/2\)-eigenspace, we have:
    \begin{align*} \left(A-\frac 12I_3\right)v = 0 \iff \frac 1{10}\begin{pmatrix} 6 \amp 6 \\ 9 \amp 9 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form of this equation is \(x = -y\text{,}\) so an eigenvector is \(v_2 = {-1\choose 1}\text{.}\) It follows that \(A = CDC\inv\text{,}\) where
    \begin{align*} C = \begin{pmatrix} 2/3 \amp -1 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 1/2 \end{pmatrix}\text{.} \end{align*}
    🔗
    The diagonal matrix \(D\) scales the \(x\)-coordinate by \(2\) and the \(y\)-coordinate by \(1/2\text{.}\) Therefore, it moves vectors closer to the \(x\)-axis and farther from the \(y\)-axis. In fact, since \((2x)(y/2) = xy\text{,}\) multiplication by \(D\) does not move a point off of a hyperbola \(xy = C\text{.}\)
    🔗
    The matrix \(A\) does the same thing, in the \(v_1,v_2\)-coordinate system: multiplying a vector by \(A\) scales the \(v_1\)-coordinate by \(2\) and the \(v_2\)-coordinate by \(1/2\text{.}\) Therefore, \(A\) moves vectors closer to the \(2\)-eigenspace and farther from the \(1/2\)-eigenspace.
    🔗
    🔗
    🔗

    Example 5.4.29 Eigenvalues \(|\lambda_1| > 1,\,|\lambda_2| > 1\).

    Describe how the matrix
    \begin{align*} A = \frac 1{5}\begin{pmatrix} 13 \amp -2 \\ -3 \amp 12 \end{pmatrix} \end{align*}
    acts on the plane.
    🔗

    Solution.

    First we diagonalize \(A\text{.}\) The characteristic polynomial is
    \begin{gather*} f(\lambda) = \lambda^2 - \Tr(A)\lambda + \det(A) = \lambda^2 - 5\lambda + 6 = (\lambda - 2)(\lambda - 3)\text{.} \end{gather*}
    Next we compute the \(2\)-eigenspace:
    \begin{align*} (A-2I_3)v = 0 \iff \frac 15\begin{pmatrix} 3 \amp -2 \\ -3 \amp 2 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -2/3 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form of this equation is \(x = 2/3y\text{,}\) so one eigenvector is \(v_1 = {2/3\choose 1}\text{.}\) For the \(3\)-eigenspace, we have:
    \begin{align*} (A-3I_3)v = 0 \iff \frac 15\begin{pmatrix} -2 \amp -2 \\ -3 \amp -3 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form of this equation is \(x = -y\text{,}\) so an eigenvector is \(v_2 = {-1\choose 1}\text{.}\) It follows that \(A = CDC\inv\text{,}\) where
    \begin{align*} C = \begin{pmatrix} 2/3 \amp -1 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 3 \end{pmatrix}\text{.} \end{align*}
    🔗
    The diagonal matrix \(D\) scales the \(x\)-coordinate by \(2\) and the \(y\)-coordinate by \(3\text{.}\) Therefore, it moves vectors farther from both the \(x\)-axis and the \(y\)-axis, but faster in the \(y\)-direction than the \(x\)-direction.
    🔗
    The matrix \(A\) does the same thing, in the \(v_1,v_2\)-coordinate system: multiplying a vector by \(A\) scales the \(v_1\)-coordinate by \(2\) and the \(v_2\)-coordinate by \(3\text{.}\) Therefore, \(A\) moves vectors farther from the \(2\)-eigenspace and the \(3\)-eigenspace, but faster in the \(v_2\)-direction than the \(v_1\)-direction.
    🔗
    🔗
    🔗

    Example 5.4.31 Eigenvalues \(|\lambda_1| \lt 1,\,|\lambda_2| \lt 1\).

    Describe how the matrix
    \begin{align*} A' = \frac 1{30}\begin{pmatrix} 12 \amp 2 \\ 3 \amp 13 \end{pmatrix} \end{align*}
    acts on the plane.
    🔗

    Solution.

    This is the inverse of the matrix \(A\) from Example 29. In that example, we found \(A = CDC\inv\) for
    \begin{align*} C = \begin{pmatrix} 2/3 \amp -1 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 3 \end{pmatrix}\text{.} \end{align*}
    Therefore, remembering that taking inverses reverses the order of multiplication, we have
    \begin{align*} A' = A\inv = (CDC\inv)\inv = (C\inv)\inv D\inv C\inv = C\begin{pmatrix} 1/2 \amp 0 \\ 0 \amp 1/3 \end{pmatrix}C\inv\text{.} \end{align*}
    The diagonal matrix \(D\inv\) does the opposite of what \(D\) does: it scales the \(x\)-coordinate by \(1/2\) and the \(y\)-coordinate by \(1/3\text{.}\) Therefore, it moves vectors closer to both coordinate axes, but faster in the \(y\)-direction. The matrix \(A'\) does the same thing, but with respect to the \(v_1,v_2\)-coordinate system.

    Example 5.4.33 Eigenvalues \(|\lambda_1| = 1,\,|\lambda_2|\lt1\).

    Describe how the matrix
    \begin{align*} A = \frac 16\begin{pmatrix} 5 \amp -1 \\ -2 \amp 4 \end{pmatrix} \end{align*}
    acts on the plane.
    🔗

    Solution.

    First we diagonalize \(A\text{.}\) The characteristic polynomial is
    \begin{gather*} f(\lambda) = \lambda^2 - \Tr(A)\lambda + \det(A) = \lambda^2 - \frac 32\lambda + \frac 12 = (\lambda - 1)\left(\lambda - \frac 12\right)\text{.} \end{gather*}
    Next we compute the \(1\)-eigenspace:
    \begin{align*} (A-I_3)v = 0 \iff \frac 16\begin{pmatrix} -1 \amp -1 \\ -2 \amp -2 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form of this equation is \(x = -y\text{,}\) so one eigenvector is \(v_1 = {-1\choose 1}\text{.}\) For the \(1/2\)-eigenspace, we have:
    \begin{align*} \left(A-\frac 12I_3\right)v = 0 \iff \frac 16\begin{pmatrix} 2 \amp -1 \\ -2 \amp 1 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -1/2 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
    The parametric form of this equation is \(x = 1/2y\text{,}\) so an eigenvector is \(v_2 = {1/2\choose 1}\text{.}\) It follows that \(A = CDC\inv\text{,}\) where
    \begin{align*} C = \begin{pmatrix} -1 \amp 1/2 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1/2 \end{pmatrix}\text{.} \end{align*}
    🔗
    The diagonal matrix \(D\) scales the \(y\)-coordinate by \(1/2\) and does not move the \(x\)-coordinate. Therefore, it simply moves vectors closer to the \(x\)-axis along vertical lines. The matrix \(A\) does the same thing, in the \(v_1,v_2\)-coordinate system: multiplying a vector by \(A\) scales the \(v_2\)-coordinate by \(1/2\) and does not change the \(v_1\)-coordinate. Therefore, \(A\) “sucks vectors into the \(1\)-eigenspace” along lines parallel to \(v_2\text{.}\)
    🔗
    🔗
    🔗

    Interactive 5.4.35 A diagonalizable \(3\times 3\) matrix.

    The diagonal matrix
    \begin{align*} D = \begin{pmatrix} 1/2 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3/2 \end{pmatrix} \end{align*}
    scales the \(x\)-coordinate by \(1/2\text{,}\) the \(y\)-coordinate by \(2\text{,}\) and the \(z\)-coordinate by \(3/2\text{.}\) Looking straight down at the \(xy\)-plane, the points follow parabolic paths taking them away from the \(x\)-axis and toward the \(y\)-axis. The \(z\)-coordinate is scaled by \(3/2\text{,}\) so points fly away from the \(xy\)-plane in that direction.
    🔗
    If \(A = CDC\inv\) for some invertible matrix \(C\text{,}\) then \(A\) does the same thing as \(D\text{,}\) but with respect to the coordinate system defined by the columns of \(C\text{.}\)

    Subsection 5.4.3 Algebraic and Geometric Multiplicity

    In this subsection, we give a variant of the Theorem 7 that provides another criterion for diagonalizability. It is stated in the language of multiplicities of eigenvalues.
    🔗
    In algebra, we define the multiplicity of a root \(\lambda_0\) of a polynomial \(f(\lambda)\) to be the number of factors of \(\lambda-\lambda_0\) that divide \(f(\lambda).\) For instance, in the polynomial
    \begin{gather*} f(\lambda) = -\lambda^3 + 4\lambda^2 - 5\lambda + 2 = -(\lambda-1)^2(\lambda-2)\text{,} \end{gather*}
    the root \(\lambda_0=2\) has multiplicity \(1\text{,}\) and the root \(\lambda_0=1\) has multiplicity \(2\text{.}\)
    🔗

    Definition 5.4.37.

    Let \(A\) be an \(n\times n\) matrix, and let \(\lambda\) be an eigenvalue of \(A\text{.}\)
    1. The algebraic multiplicity of \(\lambda\) is its multiplicity as a root of the characteristic polynomial of \(A\text{.}\)
      🔗
      🔗
    2. The geometric multiplicity of \(\lambda\) is the dimension of the \(\lambda\)-eigenspace.
      🔗
      🔗
    🔗
    🔗
    Since the \(\lambda\)-eigenspace of \(A\) is \(\Nul(A-\lambda I_n)\text{,}\) its dimension is the number of free variables in the system of equations \((A - \lambda I_n)x=0\text{,}\) i.e., the number of columns without pivots in the matrix \(A-\lambda I_n\text{.}\)
    🔗

    Example 5.4.38.

    The shear matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix} \end{align*}
    has only one eigenvalue \(\lambda=1\text{.}\) The characteristic polynomial of \(A\) is \(f(\lambda) = (\lambda-1)^2\text{,}\) so \(1\) has algebraic multiplicity \(2\text{,}\) as it is a double root of \(f\text{.}\) On the other hand, we showed in Example 17 that the \(1\)-eigenspace of \(A\) is the \(x\)-axis, so the geometric multiplicity of \(1\) is equal to \(1\text{.}\) This matrix is not diagonalizable.
    🔗
    The identity matrix
    \begin{align*} I_2 = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix} \end{align*}
    also has characteristic polynomial \((\lambda-1)^2\text{,}\) so the eigenvalue \(1\) has algebraic multiplicity \(2\text{.}\) Since every nonzero vector in \(\R^2\) is an eigenvector of \(I_2\) with eigenvalue \(1\text{,}\) the \(1\)-eigenspace is all of \(\R^2\text{,}\) so the geometric multiplicity is \(2\) as well. This matrix is diagonal.
    🔗
    🔗

    Example 5.4.41.

    Continuing with Example 14, let
    \begin{align*} A = \begin{pmatrix} 4 \amp -3 \amp 0 \\ 2 \amp -1 \amp 0 \\ 1 \amp -1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    The characteristic polynomial is \(f(\lambda) = -(\lambda-1)^2(\lambda-2)\text{,}\) so that \(1\) and \(2\) are the eigenvalues, with algebraic multiplicities \(2\) and \(1\text{,}\) respectively. We computed that the \(1\)-eigenspace is a plane and the \(2\)-eigenspace is a line, so that \(1\) and \(2\) also have geometric multiplicities \(2\) and \(1\text{,}\) respectively. This matrix is diagonalizable.
    🔗
    In Example 21, we saw that the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix} \end{align*}
    also has characteristic polynomial \(f(\lambda) = -(\lambda-1)^2(\lambda-2)\text{,}\) so that \(1\) and \(2\) are the eigenvalues, with algebraic multiplicities \(2\) and \(1\text{,}\) respectively. In this case, however, both eigenspaces are lines, so that both eigenvalues have geometric multiplicity \(1\text{.}\) This matrix is not diagonalizable.
    🔗
    🔗
    We saw in the above examples that the algebraic and geometric multiplicities need not coincide. However, they do satisfy the following fundamental inequality, the proof of which is beyond the scope of this text.
    🔗

    Theorem 5.4.44 Algebraic and Geometric Multiplicity.

    Let \(A\) be a square matrix and let \(\lambda\) be an eigenvalue of \(A\text{.}\) Then
    \begin{gather*} 1 \leq \text{(the geometric multiplicity of $\lambda$)} \leq \text{(the algebraic multiplicity of $\lambda$)}\text{.} \end{gather*}
    🔗
    🔗
    In particular, if the algebraic multiplicity of \(\lambda\) is equal to \(1\text{,}\) then so is the geometric multiplicity.
    🔗

    Insight 5.4.45.

    If \(A\) has an eigenvalue \(\lambda\) with algebraic multiplicity \(1\text{,}\) then the \(\lambda\)-eigenspace is a line.
    🔗
    🔗
    We can use the Theorem 44 to give another criterion for diagonalizability (in addition to the Theorem 7).
    🔗

    Theorem 5.4.46 Diagonalization Theorem, Variant.

    Let \(A\) be an \(n\times n\) matrix. The following are equivalent:
    1. \(A\) is diagonalizable.
      🔗
      🔗
    2. The sum of the geometric multiplicities of the eigenvalues of \(A\) is equal to \(n\text{.}\)
      🔗
      🔗
    3. The sum of the algebraic multiplicities of the eigenvalues of \(A\) is equal to \(n\text{,}\) and for each eigenvalue, the geometric multiplicity equals the algebraic multiplicity.
      🔗
      🔗
    🔗
    🔗

    Proof.
    We will show \(1\implies 2\implies 3\implies 1\text{.}\) First suppose that \(A\) is diagonalizable. Then \(A\) has \(n\) linearly independent eigenvectors \(v_1,v_2,\ldots,v_n\text{.}\) This implies that the sum of the geometric multiplicities is at least \(n\text{:}\) for instance, if \(v_1,v_2,v_3\) have the same eigenvalue \(\lambda\text{,}\) then the geometric multiplicity of \(\lambda\) is at least \(3\) (as the \(\lambda\)-eigenspace contains three linearly independent vectors), and so on. But the sum of the algebraic multiplicities is greater than or equal to the sum of the geometric multiplicities by the Theorem 44, and the sum of the algebraic multiplicities is at most \(n\) because the characteristic polynomial has degree \(n\text{.}\) Therefore, the sum of the geometric multiplicities equals \(n\text{.}\)
    🔗
    Now suppose that the sum of the geometric multiplicities equals \(n\text{.}\) As above, this forces the sum of the algebraic multiplicities to equal \(n\) as well. As the algebraic multiplicities are all greater than or equal to the geometric multiplicities in any case, this implies that they are in fact equal.
    🔗
    Finally, suppose that the third condition is satisfied. Then the sum of the geometric multiplicities equals \(n\text{.}\) Suppose that the distinct eigenvectors are \(\lambda_1,\lambda_2,\ldots,\lambda_k\text{,}\) and that \(\cB_i\) is a basis for the \(\lambda_i\)-eigenspace, which we call \(V_i\text{.}\) We claim that the collection \(\cB = \{v_1,v_2,\ldots,v_n\}\) of all vectors in all of the eigenspace bases \(\cB_i\) is linearly independent. Consider the vector equation
    \begin{gather*} 0 = c_1v_1 + c_2v_2 + \cdots + c_nv_n\text{.} \end{gather*}
    Grouping the eigenvectors with the same eigenvalues, this sum has the form
    \begin{gather*} 0 = \text{(something in $V_1$)} + \text{(something in $V_2$)} + \cdots + \text{(something in $V_k$)}\text{.} \end{gather*}
    Since eigenvectors with distinct eigenvalues are linearly independent, each “something in \(V_i\)” is equal to zero. But this implies that all coefficients \(c_1,c_2,\ldots,c_n\) are equal to zero, since the vectors in each \(\cB_i\) are linearly independent. Therefore, \(A\) has \(n\) linearly independent eigenvectors, so it is diagonalizable.
    🔗
    🔗
    The first part of the third statement simply says that the characteristic polynomial of \(A\) factors completely into linear polynomials over the real numbers: in other words, there are no complex (non-real) roots. The second part of the third statement says in particular that for any diagonalizable matrix, the algebraic and geometric multiplicities coincide.
    🔗

    Insight 5.4.47.

    Let \(A\) be a square matrix and let \(\lambda\) be an eigenvalue of \(A\text{.}\) If the algebraic multiplicity of \(\lambda\) does not equal the geometric multiplicity, then \(A\) is not diagonalizable.
    🔗
    🔗
    The examples at the beginning of this subsection illustrate the theorem. Here we give some general consequences for diagonalizability of \(2\times 2\) and \(3\times 3\) matrices.
    🔗

    Example 5.4.48 Diagonalizability of \(2\times 2\) Matrices.

    Let \(A\) be a \(2\times 2\) matrix. There are four cases:
    1. \(A\) has two different eigenvalues. In this case, each eigenvalue has algebraic and geometric multiplicity equal to one. This implies \(A\) is diagonalizable. For example:
      \begin{align*} A = \begin{pmatrix} 1 \amp 7 \\ 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    2. \(A\) has one eigenvalue \(\lambda\) of algebraic and geometric multiplicity \(2\text{.}\) To say that the geometric multiplicity is \(2\) means that \(\Nul(A-\lambda I_2) = \R^2\text{,}\) i.e., that every vector in \(\R^2\) is in the null space of \(A-\lambda I_2\text{.}\) This implies that \(A-\lambda I_2\) is the zero matrix, so that \(A\) is the diagonal matrix \(\lambda I_2\text{.}\) In particular, \(A\) is diagonalizable. For example:
      \begin{align*} A = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    3. \(A\) has one eigenvalue \(\lambda\) of algebraic multiplicity \(2\) and geometric multiplicity \(1\text{.}\) In this case, \(A\) is not diagonalizable, by part 3 of the Theorem 46. For example, a shear:
      \begin{align*} A = \begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    4. \(A\) has no eigenvalues. This happens when the characteristic polynomial has no real roots. In particular, \(A\) is not diagonalizable. For example, a rotation:
      \begin{align*} A = \begin{pmatrix} 1 \amp -1 \\ 1 \amp 1 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    🔗
    🔗

    Example 5.4.49 Diagonalizability of \(3\times 3\) Matrices.

    Let \(A\) be a \(3\times 3\) matrix. We can analyze the diagonalizability of \(A\) on a case-by-case basis, as in Example 48.
    1. \(A\) has three different eigenvalues. In this case, each eigenvalue has algebraic and geometric multiplicity equal to one. This implies \(A\) is diagonalizable. For example:
      \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 4 \\ 0 \amp 2 \amp 3 \\ 0 \amp 0 \amp -1 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    2. \(A\) has two distinct eigenvalues \(\lambda_1,\lambda_2\text{.}\) In this case, one has algebraic multiplicity one and the other has algebraic multiplicity two; after reordering, we can assume \(\lambda_1\) has multiplicity \(1\) and \(\lambda_2\) has multiplicity \(2\text{.}\) This implies that \(\lambda_1\) has geometric multiplicity \(1\text{,}\) so \(A\) is diagonalizable if and only if the \(\lambda_2\)-eigenspace is a plane. For example:
      \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 4 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
      On the other hand, if the geometric multiplicity of \(\lambda_2\) is \(1\text{,}\) then \(A\) is not diagonalizable. For example:
      \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 4 \\ 0 \amp 2 \amp 1 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗
    3. \(A\) has only one eigenvalue \(\lambda\text{.}\) If the algebraic multiplicity of \(\lambda\) is \(1\text{,}\) then \(A\) is not diagonalizable. This happens when the characteristic polynomial has two complex (non-real) roots. For example:
      \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 0 \\ 1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
      Otherwise, the algebraic multiplicity of \(\lambda\) is equal to \(3\text{.}\) In this case, if the geometric multiplicity is \(1\text{:}\)
      \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
      or \(2\text{:}\)
      \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
      then \(A\) is not diagonalizable. If the geometric multiplicity is \(3\text{,}\) then \(\Nul(A-\lambda I_3) = \R^3\text{,}\) so that \(A-\lambda I_3\) is the zero matrix, and hence \(A = \lambda I_3\text{.}\) Therefore, in this case \(A\) is necessarily diagonal, as in:
      \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
      🔗
      🔗

    Similarity and multiplicity.

    Recall from Theorem 18 of Section 5.3 that similar matrices have the same eigenvalues. It turns out that both notions of multiplicity of an eigenvalue are preserved under similarity.
    🔗

    Theorem 5.4.50.

    Let \(A\) and \(B\) be similar \(n\times n\) matrices, and let \(\lambda\) be an eigenvalue of \(A\) and \(B\text{.}\) Then:
    1. The algebraic multiplicity of \(\lambda\) is the same for \(A\) and \(B\text{.}\)
      🔗
      🔗
    2. The geometric multiplicity of \(\lambda\) is the same for \(A\) and \(B\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    Since \(A\) and \(B\) have the same characteristic polynomial, the multiplicity of \(\lambda\) as a root of the characteristic polynomial is the same for both matrices, which proves the first statement. For the second, suppose that \(A = CBC\inv\) for an invertible matrix \(C\text{.}\) By Theorem 20 of Section 5.3, the matrix \(C\) takes eigenvectors of \(B\) to eigenvectors of \(A\text{,}\) both with eigenvalue \(\lambda\text{.}\)
    🔗
    Let \(\{v_1,v_2,\ldots,v_k\}\) be a basis of the \(\lambda\)-eigenspace of \(B\text{.}\) We claim that \(\{Cv_1,Cv_2,\ldots,Cv_k\}\) is linearly independent. Suppose that
    \begin{gather*} c_1Cv_1 + c_2Cv_2 + \cdots + c_kCv_k = 0\text{.} \end{gather*}
    Regrouping, this means
    \begin{gather*} C\bigl(c_1v_1 + c_2v_2 + \cdots + c_kv_k\bigr) = 0\text{.} \end{gather*}
    By the Theorem 31 of Section 5.1, the null space of \(C\) is trivial, so this implies
    \begin{gather*} c_1v_1 + c_2v_2 + \cdots + c_kv_k = 0\text{.} \end{gather*}
    Since \(v_1,v_2,\ldots,v_k\) are linearly independent, we get \(c_1=c_2=\cdots=c_k=0\text{,}\) as desired.
    🔗
    By the previous paragraph, the dimension of the \(\lambda\)-eigenspace of \(A\) is greater than or equal to the dimension of the \(\lambda\)-eigenspace of \(B\text{.}\) By symmetry (\(B\) is similar to \(A\) as well), the dimensions are equal, so the geometric multiplicities coincide.
    🔗
    🔗
    For instance, the four matrices in Example 48 are not similar to each other, because the algebraic and/or geometric multiplicities of the eigenvalues do not match up. Or, combined with the above Theorem 46, we see that a diagonalizable matrix cannot be similar to a non-diagonalizable one, because the algebraic and geometric multiplicities of such matrices cannot both coincide.
    🔗

    Example 5.4.51.

    Continuing with Example 14, let
    \begin{align*} A = \begin{pmatrix} 4 \amp -3 \amp 0 \\ 2 \amp -1 \amp 0 \\ 1 \amp -1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    This is a diagonalizable matrix that is similar to
    \begin{align*} D = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix} \sptxt{using the matrix} C = \begin{pmatrix} 1 \amp 0 \amp 3 \\ 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    The \(1\)-eigenspace of \(D\) is the \(xy\)-plane, and the \(2\)-eigenspace is the \(z\)-axis. The matrix \(C\) takes the \(xy\)-plane to the \(1\)-eigenspace of \(A\text{,}\) which is again a plane, and the \(z\)-axis to the \(2\)-eigenspace of \(A\text{,}\) which is again a line. This shows that the geometric multiplicities of \(A\) and \(D\) coincide.
    🔗
    🔗
    The converse of the Theorem 50 is false: there exist matrices whose eigenvectors have the same algebraic and geometric multiplicities, but which are not similar. See the Example 53 below. However, for \(2\times 2\) and \(3\times 3\) matrices whose characteristic polynomial has no complex (non-real) roots, the converse of the Theorem 50 is true. (We will handle the case of complex roots in Section 5.5.)
    🔗

    Example 5.4.53 Matrices that look similar but are not.

    Show that the matrices
    \begin{align*} A = \begin{pmatrix} 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \sptxt{and} B = \begin{pmatrix} 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \end{align*}
    have the same eigenvalues with the same algebraic and geometric multiplicities, but are not similar.
    🔗
    Solution.
    These matrices are upper-triangular. They both have characteristic polynomial \(f(\lambda) = \lambda^4\text{,}\) so they both have one eigenvalue \(0\) with algebraic multiplicity \(4\text{.}\) The \(0\)-eigenspace is the null space, which has dimension \(2\) in each case because \(A\) and \(B\) have two columns without pivots. Hence \(0\) has geometric multiplicity \(2\) in each case.
    🔗
    To show that \(A\) and \(B\) are not similar, we note that
    \begin{align*} A^2 = \begin{pmatrix} 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix} \sptxt{and} B^2 = \begin{pmatrix} 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix}\text{,} \end{align*}
    as the reader can verify. If \(A = CBC\inv\) then by Recipe 5, we have
    \begin{gather*} A^2 = CB^2C\inv = C0C\inv = 0\text{,} \end{gather*}
    which is not the case.
    🔗
    🔗
    🔗
    On the other hand, suppose that \(A\) and \(B\) are diagonalizable matrices with the same characteristic polynomial. Since the geometric multiplicities of the eigenvalues coincide with the algebraic multiplicities, which are the same for \(A\) and \(B\text{,}\) we conclude that there exist \(n\) linearly independent eigenvectors of each matrix, all of which have the same eigenvalues. This shows that \(A\) and \(B\) are both similar to the same diagonal matrix. Using the transitivity property of similar matrices, this shows:
    🔗

    Insight 5.4.54.

    Diagonalizable matrices are similar if and only if they have the same characteristic polynomial, or equivalently, the same eigenvalues with the same algebraic multiplicities.
    🔗
    🔗

    Example 5.4.55.

    Show that the matrices
    \begin{align*} A = \begin{pmatrix} 1 \amp 7 \amp 2 \\ 0 \amp -1 \amp 3 \\ 0 \amp 0 \amp 4 \end{pmatrix} \sptxt{and} B = \begin{pmatrix} 1 \amp 0 \amp 0 \\ -2 \amp 4 \amp 0 \\ -5 \amp -4 \amp -1 \end{pmatrix} \end{align*}
    are similar.
    🔗
    Solution.
    Both matrices have the three distinct eigenvalues \(1,-1,4\text{.}\) Hence they are both diagonalizable, and are similar to the diagonal matrix
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 4 \end{pmatrix}\text{.} \end{align*}
    By the transitivity property of similar matrices, this implies that \(A\) and \(B\) are similar to each other.
    🔗
    🔗
    🔗

    Example 5.4.56 Diagonal matrices with the same entries are similar.

    Any two diagonal matrices with the same diagonal entries (possibly in a different order) are similar to each other. Indeed, such matrices have the same characteristic polynomial. We saw this phenomenon in Example 9, where we noted that
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 3 \end{pmatrix} = \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix} \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \end{pmatrix}\inv\text{.} \end{align*}

    Exercises 5.4.4 Exercises

    1.

      If \(A\) is a \(3 \times 3\) matrix with eigenvalues \(0\text{,}\) \(1\text{,}\) and \(2\text{,}\) then \(A\) is diagonalizable.
      🔗

    • True.

    • False.

    Solution.
    True: any \(3 \times 3\) matrix with \(3\) real eigenvalues is automatically diagonalizable. One way to see this is that each of the \(3\) eigenvalues must have a nonzero eigenvector in their eigenspace, and eigenvectors corresponding to different eigenvalues are linearly independent, therefore we obtain \(3\) linearly independent eigenvectors. In other words, we obtain a basis for \({\bf R}^{3}\) consisting of eigenvectors of \(A\text{,}\) which is equivalent to the property that \(A\) is diagonalizable.
    🔗
    🔗
    🔗

    2.

      If \(\lambda\) is an eigenvalue of a matrix \(A\text{,}\) it is possible that the \(\lambda\)-eigenspace is \(0\)-dimensional.
      🔗

    • True.

    • False.

    Solution.
    False. It is a fundamental fact that the geometric multiplicity of any eigenvalue \(\lambda\) is at least \(1\text{.}\) By definition of eigenvalue, the equation \(Ax = \lambda x\) must have a non-trivial solution, therefore \((A-\lambda I)x = 0\) has a non-trivial solution, which means that \(\Nul(A-\lambda I)\) is at least \(1\)-dimensional.

    🔗
    🔗

    3.

      All diagonalizable matrices are invertible.
      🔗

    • True.

    • False.

    Solution.
    False: for example, zero matrix is diagonalizable (in fact, diagonal!) but is not invertible.

    🔗
    🔗

      All invertible matrices are diagonalizable.
      🔗

    • False.

However, the only eigenvalue of \(A\) is \(\lambda = 1\text{,}\) and we can compute that the \(1\)-eigenspace is only \(1\)-dimensional, so \(A\) is not diagonalizable.

    7.

    Find \(\begin{pmatrix}2 \amp 6 \\ 0 \amp -1\end{pmatrix}^{100}\text{.}\)
    🔗
    Solution.
    \(A\) is \(2 \times 2\) with \(2\) different eigenvalues \(\lambda = 2\) and \(\lambda = -1\text{,}\) so \(A\) is diagonalizable.
    \begin{align*} \left(\begin{array}{r|r}A-2I \amp 0\end{array}\right) = \left(\begin{array}{rr|r}0 \amp 6 \amp 0 \\ 0 \amp -3 \amp 0\end{array}\right) \xrightarrow[]{RREF} \left(\begin{array}{rr|r}0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0\end{array}\right), \quad 2\textup{-eigenspace} = \Span \left\{\begin{pmatrix}1 \\ 0\end{pmatrix} \right\}\text{.} \end{align*}
    \begin{align*} \left(\begin{array}{r|r}A+I \amp 0\end{array}\right) = \left(\begin{array}{rr|r}3 \amp 6 \amp 0 \\ 0 \amp 0 \amp 0\end{array}\right) \xrightarrow[]{RREF} \left(\begin{array}{rr|r}1 \amp 2 \amp 0 \\ 0 \amp 0 \amp 0\end{array}\right), \quad (-1)\textup{-eigenspace} = \Span \left\{\begin{pmatrix}-2 \\ 1\end{pmatrix} \right\}\text{.} \end{align*}
    Therefore, \(A = CDC^{-1}\) where \(C = \begin{pmatrix}1 \amp -2 \\ 0 \amp 1\end{pmatrix}\) and \(D = \begin{pmatrix}2 \amp 0 \\ 0 \amp -1\end{pmatrix}\text{.}\) Using the repeated cancellations of \(C\) with \(C^{-1}\) when expanding \(A^{100}\text{,}\) we get
    \begin{align*} A^{100} \amp = (C D C^{-1})^{100} = C D^{100} C^{-1}\\ \amp = C \begin{pmatrix}2^{100} \amp 0\\ 0 \amp (-1)^{100}\end{pmatrix} C^{-1}\\ \amp = \begin{pmatrix}1 \amp -2\\ 0 \amp 1\end{pmatrix} \begin{pmatrix}2^{100} \amp 0\\ 0 \amp 1\end{pmatrix} \begin{pmatrix}1 \amp 2\\ 0 \amp 1\end{pmatrix}\\ \amp = \begin{pmatrix}1 \amp -2\\ 0 \amp 1\end{pmatrix} \begin{pmatrix}2^{100} \amp 2^{101}\\ 0 \amp 1\end{pmatrix}\\ \amp = \begin{pmatrix}2^{100} \amp 2^{101}-2\\ 0 \amp 1\end{pmatrix}\text{.} \end{align*}

    14.

    (a)

    Suppose \(A\) is a diagonalizable \(n \times n\) matrix, and suppose \(B\) is an \(n \times n\) matrix with the same eigenvalues of \(A\) and the same corresponding eigenspaces for each eigenvalue. Is it necessarily true that \(A=B\text{?}\)
    🔗
    Solution.
    Yes. Since \(A\) is diagonalizable, we can write \(A = PDP^{-1}\text{,}\) where the columns of \(P\) are a basis of \({\bf R}^n\) consisting of eigenvectors of \(A\) and where \(D\) is the diagonal matrix with the corresponding eigenvalues. Since \(B\) has the same eigenvalues of \(A\) and the same corresponding eigenspaces, we also have \(B = PDP^{-1}\text{,}\) so \(A = B = PDP^{-1}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Answer part (a) in the case that \(A\) is an \(n \times n\) matrix which is \textit{not} diagonalizable.
    🔗
    Solution.
    No. For example, consider \(A= \begin{pmatrix}0 \amp 1 \\ 0 \amp 0\end{pmatrix}\) and \(B = \begin{pmatrix}0 \amp 2 \\ 0 \amp 0\end{pmatrix}\text{.}\) Each matrix has only one eigenvalue \(\lambda = 0\) with algebraic multiplicity \(2\text{,}\) and the \(0\)-eigenspace for each matrix is the span of \(\begin{pmatrix}1 \\ 0\end{pmatrix}\text{,}\) yet \(A \neq B\text{.}\)

    We show that \(A=B\text{.}\) By the Diagonalization Theorem, \(A = PDP^{-1}\text{,}\) where \(D\) is any diagonal matrix of eigenvalues of \(A\) (with their geometric multiplicities) and \(P\) is \textit{any} matrix whose column vectors form bases for the corresponding eigenspaces.

    🔗
