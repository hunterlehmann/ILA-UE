Fact 6.2.16 Facts about Orthogonal Complements.

Let \(W\) be a subspace of \(\R^n\text{.}\) Then:
  1. \(W^\perp\) is also a subspace of \(\R^n.\)
    🔗
    🔗
  2. \(\displaystyle (W^\perp)^\perp = W.\)
    🔗
    🔗
  3. \(\displaystyle \dim(W) + \dim(W^\perp) = n.\)
    🔗
    🔗
🔗
🔗

Proof.
For the first assertion, we verify the three defining properties of subspaces.
  1. The zero vector is in \(W^\perp\) because the zero vector is orthogonal to every vector in \(\R^n\text{.}\)
    🔗
    🔗
  2. Let \(u,v\) be in \(W^\perp\text{,}\) so \(u\cdot x = 0\) and \(v\cdot x = 0\) for every vector \(x\) in \(W\text{.}\) We must verify that \((u+v)\cdot x = 0\) for every \(x\) in \(W\text{.}\) Indeed, we have
    \begin{gather*} (u+v)\cdot x = u\cdot x + v\cdot x = 0 + 0 = 0\text{.} \end{gather*}
    🔗
    🔗
  3. Let \(u\) be in \(W^\perp\text{,}\) so \(u\cdot x = 0\) for every \(x\) in \(W\text{,}\) and let \(c\) be a scalar. We must verify that \((cu)\cdot x = 0\) for every \(x\) in \(W\text{.}\) Indeed, we have
    \begin{gather*} (cu)\cdot x = c(u\cdot x) = c0 = 0\text{.} \end{gather*}
    🔗
    🔗
🔗
Next we prove the third assertion. Let \(v_1,v_2,\ldots,v_m\) be a basis for \(W\text{,}\) so \(m = \dim(W)\text{,}\) and let \(v_{m+1},v_{m+2},\ldots,v_k\) be a basis for \(W^\perp\text{,}\) so \(k-m = \dim(W^\perp)\text{.}\) We need to show \(k=n\text{.}\) First we claim that \(\{v_1,v_2,\ldots,v_m,v_{m+1},v_{m+2},\ldots,v_k\}\) is linearly independent. Suppose that \(c_1v_1 + c_2v_2 + \cdots + c_kv_k = 0\text{.}\) Let \(w = c_1v_1 + c_2v_2 + \cdots + c_mv_m\) and \(w' = c_{m+1}v_{m+1} + c_{m+2}v_{m+2} + \cdots + c_kv_k\text{,}\) so \(w\) is in \(W\text{,}\) \(w'\) is in \(W'\text{,}\) and \(w + w' = 0\text{.}\) Then \(w = -w'\) is in both \(W\) and \(W^\perp\text{,}\) which implies \(w\) is perpendicular to itself. In particular, \(w\cdot w = 0\text{,}\) so \(w = 0\text{,}\) and hence \(w' = 0\text{.}\) Therefore, all coefficients \(c_i\) are equal to zero, because \(\{v_1,v_2,\ldots,v_m\}\) and \(\{v_{m+1},v_{m+2},\ldots,v_k\}\) are linearly independent.
🔗
It follows from the previous paragraph that \(k \leq n\text{.}\) Suppose that \(k \lt n\text{.}\) Then the matrix
\begin{gather*} A = \begin{pmatrix} \matrow{v_1^T} \\ \matrow{v_2^T} \\ \vdots \\ \matrow{v_k^T} \end{pmatrix} \end{gather*}
has more columns than rows (it is “wide”), so its null space is nonzero by Note 14 of Section 3.2. Let \(x\) be a nonzero vector in \(\Nul(A)\text{.}\) Then
\begin{gather*} 0 = Ax = \begin{pmatrix} v_1^Tx \\ v_2^Tx \\ \vdots \\ v_k^Tx \end{pmatrix} = \begin{pmatrix} v_1\cdot x \\ v_2\cdot x \\ \vdots \\ v_k\cdot x \end{pmatrix} \end{gather*}
by the Definition 9 of Section 2.3. Since \(v_1\cdot x = v_2\cdot x = \cdots = v_m\cdot x = 0\text{,}\) it follows from Proposition 10 that \(x\) is in \(W^\perp\text{,}\) and similarly, \(x\) is in \((W^\perp)^\perp\text{.}\) As above, this implies \(x\) is orthogonal to itself, which contradicts our assumption that \(x\) is nonzero. Therefore, \(k = n\text{,}\) as desired.
🔗
Finally, we prove the second assertion. Clearly \(W\) is contained in \((W^\perp)^\perp\text{:}\) this says that everything in \(W\) is perpendicular to the set of all vectors perpendicular to everything in \(W\text{.}\) Let \(m=\dim(W).\) By 3, we have \(\dim(W^\perp) = n-m\text{,}\) so \(\dim((W^\perp)^\perp) = n - (n-m) = m\text{.}\) The only \(m\)-dimensional subspace of \((W^\perp)^\perp\) is all of \((W^\perp)^\perp\text{,}\) so \((W^\perp)^\perp = W.\)
