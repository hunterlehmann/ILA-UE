Recipe 5.4.5 Compute powers of a diagonalizable matrix.

If \(A = CDC\inv\text{,}\) where \(D\) is a diagonal matrix, then \(A^n = CD^nC\inv\text{:}\)
\begin{align*} A = C\begin{pmatrix} x \amp 0 \amp 0 \\ 0 \amp y \amp 0 \\ 0 \amp 0 \amp z \end{pmatrix}C\inv \quad\implies\quad A^n = C\begin{pmatrix} x^n \amp 0 \amp 0 \\ 0 \amp y^n \amp 0 \\ 0 \amp 0 \amp z^n \end{pmatrix}C\inv\text{.} \end{align*}
