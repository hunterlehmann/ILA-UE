Proposition 4.1.11.

Let \(A\) be an \(n\times n\) matrix.
  1. If \(A\) has a zero row or column, then \(\det(A) = 0.\)
    🔗
    🔗
  2. If \(A\) is upper-triangular or lower-triangular, then \(\det(A)\) is the product of its diagonal entries.
    🔗
    🔗
🔗
🔗

Proof.
  1. Suppose that \(A\) has a zero row. Let \(B\) be the matrix obtained by negating the zero row. Then \(\det(A) = -\det(B)\) by the second Definition 1. But \(A = B\text{,}\) so \(\det(A) = \det(B)\text{:}\)
    \begin{align*} \begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 0 \amp 0 \\ 7 \amp 8 \amp 9 \end{pmatrix} \;\xrightarrow{R_2 = -R_2}\; \begin{pmatrix} 1 \amp 2 \amp 3 \\ 0 \amp 0 \amp 0 \\ 7 \amp 8 \amp 9 \end{pmatrix}\text{.} \end{align*}
    Putting these together yields \(\det(A) = -\det(A)\text{,}\) so \(\det(A)=0\text{.}\)
    🔗
    Now suppose that \(A\) has a zero column. Then \(A\) is not invertible by the Theorem 1 of Section 3.6, so its reduced row echelon form has a zero row. Since row operations do not change whether the determinant is zero, we conclude \(\det(A)=0\text{.}\)
    🔗
    🔗
  2. First suppose that \(A\) is upper-triangular, and that one of the diagonal entries is zero, say \(a_{ii}=0\text{.}\) We can perform row operations to clear the entries above the nonzero diagonal entries:
    \begin{align*} \begin{pmatrix} a_{11} \amp \star \amp \star \amp \star \\ 0 \amp a_{22} \amp \star \amp \star \\ 0 \amp 0 \amp 0 \amp \star \\ 0 \amp 0 \amp 0 \amp a_{44} \end{pmatrix} \;\xrightarrow{\phantom{MMM}}\; \begin{pmatrix} a_{11} \amp 0 \amp \star \amp 0 \\ 0 \amp a_{22} \amp \star \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp a_{44} \end{pmatrix} \end{align*}
    In the resulting matrix, the \(i\)th row is zero, so \(\det(A) = 0\) by the first part.
    🔗
    Still assuming that \(A\) is upper-triangular, now suppose that all of the diagonal entries of \(A\) are nonzero. Then \(A\) can be transformed to the identity matrix by scaling the diagonal entries and then doing row replacements:
    \begin{align*} \amp\begin{pmatrix} a \amp \star \amp \star \\ 0 \amp b \amp \star \\ 0 \amp 0 \amp c \end{pmatrix} \;\xrightarrow{% \begin{minipage}{1.8cm}% \tiny\centering scale by\\$a\inv,b\inv,c\inv$% \end{minipage}}\; \begin{pmatrix} 1 \amp \star \amp \star \\ 0 \amp 1 \amp \star \\ 0 \amp 0 \amp 1 \end{pmatrix} \;\xrightarrow{% \begin{minipage}{1.6cm}% \tiny\centering row\\replacements% \end{minipage}}\; \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \amp \hbox to 2.1cm{\hss$\det=abc$\hss} \;\xleftarrow{\hbox to 1.8cm{\hss}}\; \hbox to 2.1cm{\hss$\det=1$\hss} \;\xleftarrow{\hbox to 1.6cm{\hss}}\; \hbox to 1.8cm{\hss$\det=1$} \end{align*}
    Since \(\det(I_n) = 1\) and we scaled by the reciprocals of the diagonal entries, this implies \(\det(A)\) is the product of the diagonal entries.
    🔗
    The same argument works for lower triangular matrices, except that the the row replacements go down instead of up.
