Interactive 5.3.16 Similar \(3\times 3\) matrices.

Consider the matrices
\begin{align*} A = \begin{pmatrix} -1 \amp 0 \amp 0 \\ -1 \amp 0 \amp 2 \\ -1 \amp 1 \amp 1 \end{pmatrix} \qquad B = \begin{pmatrix} -1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix} \qquad C = \begin{pmatrix} -1 \amp 1 \amp 0 \\ 1 \amp 1 \amp 1 \\ -1 \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
Then \(A = CBC\inv\text{,}\) as one can verify. Let \(v_1,v_2,v_3\) be the columns of \(C\text{,}\) and let \(\cB = \{v_1,v_2,v_3\}\text{,}\) a basis of \(\R^3\text{.}\) Then \(A\) does the same thing as \(B\text{,}\) except \(A\) uses the \(\cB\)-coordinate system. In other words:
  • \(B\) scales the \(e_1,e_2\)-plane by \(-1\) and the \(e_3\)-direction by \(2\text{.}\)
    🔗
    🔗
  • \(A\) scales the \(v_1,v_2\)-plane by \(-1\) and the \(v_3\)-direction by \(2\text{.}\)
