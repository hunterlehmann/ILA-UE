Theorem 6.4.8.

Let \(W\) be a subspace of \(\R^n\text{,}\) and let \(\{u_1,u_2,\ldots,u_m\}\) be an orthogonal basis for \(W\text{.}\) Then for any vector \(x\) in \(\R^n\text{,}\) the orthogonal projection of \(x\) onto \(W\) is given by the formula
\begin{gather*} x_W = \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \cdots + \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m\text{.} \end{gather*}
🔗
🔗

Proof.
Let
\begin{gather*} y = \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \cdots + \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m\text{.} \end{gather*}
This vector is contained in \(W\) because it is a linear combination of \(u_1,u_2,\ldots,u_m\text{.}\) Hence we just need to show that \(x - y\) is in \(W^\perp\text{,}\) i.e., that \(u_i\cdot (x-y) = 0\) for each \(i=1,2,\ldots,m\text{.}\) For \(u_1\text{,}\) we have
\begin{align*} u_1\cdot(x-y) \amp= u_1\cdot\left( x - \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 - \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 - \cdots - \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m \right)\\ \amp= u_1\cdot x - \frac{x\cdot u_1}{u_1\cdot u_1}(u_1\cdot u_1) - 0 - \cdots - 0\\ \amp= 0\text{.} \end{align*}
A similar calculation shows that \(u_i\cdot(x-y) = 0\) for each \(i\text{,}\) so \(x-y\) is in \(W^\perp\text{,}\) as desired.
