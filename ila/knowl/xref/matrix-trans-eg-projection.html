Example 3.1.5 Projection onto the \(xy\)-plane.

Let
\begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
Describe the function \(b=Ax\) geometrically.
🔗

Solution.

In the equation \(Ax=b\text{,}\) the input vector \(x\) and the output vector \(b\) are both in \(\R^3\text{.}\) First we multiply \(A\) by a vector to see what it does:
\begin{align*} A\begin{pmatrix} x \\ y \\ z \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix} = \begin{pmatrix} x \\ y \\ 0 \end{pmatrix}\text{.} \end{align*}
Multiplication by \(A\) simply sets the \(z\)-coordinate equal to zero: it projects vertically onto the \(xy\)-plane.
