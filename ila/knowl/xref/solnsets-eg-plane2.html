Example 2.4.13 The solution set is a plane.

What is the solution set of \(Ax=b\text{,}\) where
\begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix} \sptxt{and} b = \begin{pmatrix} 1 \\ -2 \end{pmatrix}? \end{align*}
(Compare Example 9.)
🔗

Solution.

We row reduce the associated augmented matrix:
\begin{align*} \left(\begin{array}{rrr|r} 1 \amp -1 \amp 2 \amp 1 \\ -2 \amp 2 \amp -4 \amp -2 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \begin{pmatrix} 1 \amp -1 \amp 2 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
This corresponds to the single equation \(x_1 - x_2 + 2x_3 = 1\text{.}\) We can write the parametric form as follows:
\begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp x_2 - 2x_3 + 1 \amp {} \\ x_2 \amp {}={} \amp x_2 \. + 0 \amp {} \\ x_3 \amp {}={} \amp x_3 + 0 \amp . \end{alignedat}\right. \end{align*}
We turn the above system into a vector equation:
\begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = x_2\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + x_3\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix} + \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
This vector equation is called the parametric vector form of the solution set. Since \(x_2\) and \(x_3\) are allowed to be anything, this says that the solution set is the set of all linear combinations of \(\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\) and \(\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\text{,}\) translated by the vector \(p = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.}\) This is a plane which contains \(p\) and is parallel to \(\Span\left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\right\}\text{:}\) it is a translate of a plane. We write the solution set as
\begin{gather*} \Span\left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\right\} + \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
