Example 5.4.21 A non-diagonalizable \(3\times 3\) matrix.

Let
\begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
The characteristic polynomial of \(A\) is \(f(\lambda) = -(\lambda-1)^2(\lambda-2)\text{,}\) so the eigenvalues of \(A\) are \(1\) and \(2\text{.}\) We compute the \(1\)-eigenspace:
\begin{align*} (A - I_3)v = 0 \iff \begin{pmatrix} 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix} = 0 \iff y = z = 0\text{.} \end{align*}
In other words, the \(1\)-eigenspace is the \(x\)-axis. Similarly,
\begin{align*} (A - 2I_3)v = 0 \iff \begin{pmatrix} -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \\ z \end{pmatrix} = 0 \iff x = y = 0\text{,} \end{align*}
so the \(2\)-eigenspace is the \(z\)-axis. In particular, all eigenvectors of \(A\) lie on the \(xz\)-plane, so there do not exist three linearly independent eigenvectors of \(A\text{.}\) By the Theorem 7, the matrix \(A\) is not diagonalizable.
🔗
Notice that \(A\) contains a \(2\times 2\) block on its diagonal that looks like a shear:
\begin{align*} A = \begin{pmatrix} \amp 1 \amp \amp 1 \amp 0 \\ \amp 0 \amp \amp 1 \amp 0 \\ 0 \amp 0 \amp 2 \end{pmatrix}\text{.} \end{align*}
This makes one suspect that such a matrix is not diagonalizable.
