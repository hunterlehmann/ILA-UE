Example 6.3.4 Orthogonal decomposition with respect to the \(xy\)-plane.

Let \(W\) be the \(xy\)-plane in \(\R^3\text{,}\) so \(W^\perp\) is the \(z\)-axis. It is easy to compute the orthogonal decomposition of a vector with respect to this \(W\text{:}\)
\begin{align*} x \amp= \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} \implies x_W = \begin{pmatrix} 1 \\ 2 \\ 0 \end{pmatrix} \quad x_{W^\perp} = \begin{pmatrix} 0 \\ 0 \\ 3 \end{pmatrix}\\ x \amp= \begin{pmatrix} a \\ b \\ c \end{pmatrix} \implies x_W = \begin{pmatrix} a \\ b \\ 0 \end{pmatrix} \quad x_{W^\perp} = \begin{pmatrix} 0 \\ 0 \\ c \end{pmatrix}\text{.} \end{align*}
We see that the orthogonal decomposition in this case expresses a vector in terms of a “horizontal” component (in the \(xy\)-plane) and a “vertical” component (on the \(z\)-axis).
