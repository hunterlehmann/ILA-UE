Theorem 2.5.14 Increasing Span Criterion.

A set of vectors \(\{v_1,v_2,\ldots,v_k\}\) is linearly independent if and only if, for every \(j\text{,}\) the vector \(v_j\) is not in \(\Span\{v_1,v_2,\ldots,v_{j-1}\}\text{.}\)
🔗
🔗

Proof.
It is equivalent to show that \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent if and only if \(v_j\) is in \(\Span\{v_1,v_2,\ldots,v_{j-1}\}\) for some \(j\text{.}\) The “if” implication is an immediate consequence of Theorem 12. Suppose then that \(\{v_1,v_2,\ldots,v_k\}\) is linearly dependent. This means that some \(v_j\) is in the span of the others. Choose the largest such \(j\text{.}\) We claim that this \(v_j\) is in \(\Span\{v_1,v_2,\ldots,v_{j-1}\}\text{.}\) If not, then
\begin{gather*} v_j = x_1v_1 + x_2v_2 + \cdots + x_{j-1}v_{j-1} + x_{j+1}v_{j+1} + \cdots + x_kv_k \end{gather*}
with not all of \(x_{j+1},\ldots,x_k\) equal to zero. Suppose for simplicity that \(x_k\neq 0\text{.}\) Then we can rearrange:
\begin{gather*} v_k = -\frac 1{x_k}\bigl( x_1v_1 + x_2v_2 + \cdots + x_{j-1}v_{j-1} - v_j + x_{j+1}v_{j+1} + \cdots + x_{p-1}v_{p-1} \bigr)\text{.} \end{gather*}
This says that \(v_k\) is in the span of \(\{v_1,v_2,\ldots,v_{p-1}\}\text{,}\) which contradicts our assumption that \(v_j\) is the last vector in the span of the others.
