Note 3.2.14 Wide matrices do not have one-to-one transformations.

If \(T\colon\R^n\to\R^m\) is a one-to-one matrix transformation, what can we say about the relative sizes of \(n\) and \(m\text{?}\)
🔗
The matrix associated to \(T\) has \(n\) columns and \(m\) rows. Each row and each column can only contain one pivot, so in order for \(A\) to have a pivot in every column, it must have at least as many rows as columns: \(n\leq m\text{.}\)
🔗
This says that, for instance, \(\R^3\) is “too big” to admit a one-to-one linear transformation into \(\R^2\text{.}\)
🔗
Note that there exist tall matrices that are not one-to-one: for example,
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{align*}
does not have a pivot in every column.
