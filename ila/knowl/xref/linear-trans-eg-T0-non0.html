Example 3.3.4 A non-linear transformation.

Define \(T\colon\R\to\R\) by \(T(x) = x+1\text{.}\) Is \(T\) a linear transformation?
🔗

Solution.

We have \(T(0) = 0 + 1 = 1\text{.}\) Since any linear transformation necessarily takes zero to zero by the above Insight 3, we conclude that \(T\) is not linear (even though its graph is a line).
🔗
Note: in this case, it was not necessary to check explicitly that \(T\) does not satisfy both Definition 1: since \(T(0)=0\) is a consequence of these properties, at least one of them must not be satisfied. (In fact, this \(T\) satisfies neither.)
