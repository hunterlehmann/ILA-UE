Example 3.2.6 A matrix transformation that is one-to-one.

Let \(A\) be the matrix
\begin{align*} A = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
and define \(T\colon\R^2\to\R^3\) by \(T(x) = Ax\text{.}\) Is \(T\) one-to-one?
🔗

Solution.

The reduced row echelon form of \(A\) is
\begin{align*} \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
Hence \(A\) has a pivot in every column, so \(T\) is one-to-one.
