Example 2.4.11 The solution set is a line.

What is the solution set of \(Ax=b\text{,}\) where
\begin{align*} A = \begin{pmatrix} 1 \amp -3 \\ 2 \amp -6 \end{pmatrix} \sptxt{and} b = \begin{pmatrix} -3 \\ -6 \end{pmatrix}? \end{align*}
(Compare to Example 7, where we solved the corresponding homogeneous equation.)
🔗

Solution.

We row reduce the associated augmented matrix:
\begin{align*} \left(\begin{array}{rr|r} 1 \amp -3 \amp -3 \\ 2 \amp -6 \amp -6 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \left(\begin{array}{rr|r} 1 \amp -3 \amp -3 \\ 0 \amp 0 \amp 0 \end{array}\right)\text{.} \end{align*}
This corresponds to the single equation \(x_1 - 3x_2 = -3\text{.}\) We can write the parametric form as follows:
\begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp 3x_2 - 3 \amp {} \\ x_2 \amp {}={} \amp x_2 + 0 \amp . \end{alignedat}\right. \end{align*}
We turn the above system into a vector equation:
\begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = x_2\begin{pmatrix} 3 \\ 1 \end{pmatrix} + \begin{pmatrix} -3 \\ 0 \end{pmatrix}\text{.} \end{gather*}
This vector equation is called the parametric vector form of the solution set. We write the solution set as
\begin{gather*} \Span\left\{\begin{pmatrix} 3 \\ 1 \end{pmatrix}\right\} + \begin{pmatrix} -3 \\ 0 \end{pmatrix}\text{.} \end{gather*}
