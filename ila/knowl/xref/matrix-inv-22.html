Proposition 3.5.6.

Let \(A = \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\text{.}\)
  1. If \(\det(A) \neq 0\text{,}\) then \(A\) is invertible, and
    \begin{align*} A\inv = \frac 1{\det(A)}\begin{pmatrix} d \amp -b \\ -c \amp a \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
  2. If \(\det(A) = 0,\) then \(A\) is not invertible.
    🔗
    🔗
🔗
🔗

Proof.
  1. Suppose that \(\det(A)\neq 0\text{.}\) Define \(\displaystyle B = \frac 1{\det(A)}\begin{pmatrix} d \amp -b \\ -c \amp a \end{pmatrix}.\) Then
    \begin{align*} AB = \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\frac 1{\det(A)}\begin{pmatrix} d \amp -b \\ -c \amp a \end{pmatrix} = \frac 1{ad-bc}\begin{pmatrix} ad-bc \amp 0 \\ 0 \amp ad-bc \end{pmatrix} = I_2\text{.} \end{align*}
    The reader can check that \(BA = I_2\text{,}\) so \(A\) is invertible and \(B = A\inv\text{.}\)
    🔗
    🔗
  2. Suppose that \(\det(A) = ad-bc = 0\text{.}\) Let \(T\colon\R^2\to\R^2\) be the matrix transformation \(T(x) = Ax\text{.}\) Then
    \begin{align*} T\begin{pmatrix} -b \\ a \end{pmatrix} \amp= \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\begin{pmatrix} -b \\ a \end{pmatrix} = \begin{pmatrix} -ab+ab \\ -bc+ad \end{pmatrix} = \begin{pmatrix} 0 \\ \det(A) \end{pmatrix} = 0\\ T\begin{pmatrix} d \\ -c \end{pmatrix} \amp= \begin{pmatrix} a \amp b \\ c \amp d \end{pmatrix}\begin{pmatrix} d \\ -c \end{pmatrix} = \begin{pmatrix} ad-bc \\ cd-cd \end{pmatrix} = \begin{pmatrix} \det(A) \\ 0 \end{pmatrix} = 0\text{.} \end{align*}
    If \(A\) is the zero matrix, then it is obviously not invertible. Otherwise, one of \(v= {-b\choose a}\) and \(v = {d\choose -c}\) will be a nonzero vector in the null space of \(A\text{.}\) Suppose that there were a matrix \(B\) such that \(BA=I_2\text{.}\) Then
    \begin{gather*} v = I_2v = BAv = B0 = 0\text{,} \end{gather*}
    which is impossible as \(v\neq 0\text{.}\) Therefore, \(A\) is not invertible.
