Recipe 6.3.22 Compute an orthogonal decomposition.

Let \(W\) be a subspace of \(\R^m\text{.}\) Here is a method to compute the orthogonal decomposition of a vector \(x\) with respect to \(W\text{:}\)
  1. Rewrite \(W\) as the column space of a matrix \(A\text{.}\) In other words, find a a spanning set for \(W\text{,}\) and let \(A\) be the matrix with those columns.
    🔗
    🔗
  2. Compute the matrix \(A^TA\) and the vector \(A^Tx\text{.}\)
    🔗
    🔗
  3. Form the augmented matrix for the matrix equation \(A^TAc = A^Tx\) in the unknown vector \(c\text{,}\) and row reduce.
    🔗
    🔗
  4. This equation is always consistent; choose one solution \(c\text{.}\) Then
    \begin{gather*} x_W = Ac \qquad x_{W^\perp} = x - x_W\text{.} \end{gather*}

    🔗
