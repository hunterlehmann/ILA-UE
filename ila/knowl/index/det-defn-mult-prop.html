Proposition 4.1.18 Multiplicativity Property.

If \(A\) and \(B\) are \(n\times n\) matrices, then
\begin{gather*} \det(AB) = \det(A)\det(B)\text{.} \end{gather*}
🔗
🔗

Proof.
In this proof, we need to use the notion of an elementary matrix. This is a matrix obtained by doing one row operation to the identity matrix. There are three kinds of elementary matrices: those arising from row replacement, row scaling, and row swaps:
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \xrightarrow{\parbox{2cm}{\tiny\centering$R_2 = R_2 - 2R_1$}}\amp \begin{pmatrix} 1 \amp 0 \amp 0 \\ -2 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \xrightarrow{\parbox{2cm}{\tiny\centering$R_1 = 3R_1$}}\amp \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix}\\ \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \xrightarrow{\parbox{2cm}{\tiny\centering$R_1 \longleftrightarrow R_2$}}\amp \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \end{align*}
The important property of elementary matrices is the following claim.
🔗
Claim: If \(E\) is the elementary matrix for a row operation, then \(EA\) is the matrix obtained by performing the same row operation on \(A\text{.}\)
🔗
In other words, left-multiplication by an elementary matrix applies a row operation. For example,
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ -2 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} a_{11} \amp a_{12} \amp a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix} \amp= \left(\begin{array}{lll} a_{11} \amp a_{12} \amp a_{13} \\ a_{21}-2a_{11} \amp a_{22}-2a_{12} \amp a_{23}-2a_{13} \\ a_{31} \amp a_{32} \amp a_{33} \end{array}\right)\\ \begin{pmatrix} 3 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} a_{11} \amp a_{12} \amp a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix} \amp= \begin{pmatrix} 3a_{11} \amp 3a_{12} \amp 3a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix}\\ \begin{pmatrix} 0 \amp 1 \amp 0 \\ 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{pmatrix} \begin{pmatrix} a_{11} \amp a_{12} \amp a_{13} \\ a_{21} \amp a_{22} \amp a_{23} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix} \amp= \begin{pmatrix} a_{21} \amp a_{22} \amp a_{23} \\ a_{11} \amp a_{12} \amp a_{13} \\ a_{31} \amp a_{32} \amp a_{33} \end{pmatrix}\text{.} \end{align*}
The proof of the Claim is by direct calculation; we leave it to the reader to generalize the above equalities to \(n\times n\) matrices.
🔗
As a consequence of the Claim and the four Definition 1, we have the following observation. Let \(C\) be any square matrix.
  1. If \(E\) is the elementary matrix for a row replacement, then \(\det(EC) = \det(C).\) In other words, left-multiplication by \(E\) does not change the determinant.
    🔗
    🔗
  2. If \(E\) is the elementary matrix for a row scale by a factor of \(c\text{,}\) then \(\det(EC) = c\det(C).\) In other words, left-multiplication by \(E\) scales the determinant by a factor of \(c\text{.}\)
    🔗
    🔗
  3. If \(E\) is the elementary matrix for a row swap, then \(\det(EC) = -\det(C).\) In other words, left-multiplication by \(E\) negates the determinant.
    🔗
    🔗
🔗
Now we turn to the proof of the multiplicativity property. Suppose to begin that \(B\) is not invertible. Then \(AB\) is also not invertible: otherwise, \((AB)\inv AB = I_n\) implies \(B\inv = (AB)\inv A.\) By the Proposition 15, both sides of the equation \(\det(AB) = \det(A)\det(B)\) are zero.
🔗
Now assume that \(B\) is invertible, so \(\det(B)\neq 0\text{.}\) Define a function
\begin{gather*} d\colon\bigl\{\text{$n\times n$ matrices}\bigr\} \To \R \sptxt{by} d(C) = \frac{\det(CB)}{\det(B)}\text{.} \end{gather*}
We claim that \(d\) satisfies the four defining properties of the determinant.
  1. Let \(C'\) be the matrix obtained by doing a row replacement on \(C\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Since left-multiplication by \(E\) does not change the determinant, we have \(\det(ECB) = \det(CB)\text{,}\) so
    \begin{gather*} d(C') = \frac{\det(C'B)}{\det(B)} = \frac{\det(ECB)}{\det(B)} = \frac{\det(CB)}{\det(B)} = d(C)\text{.} \end{gather*}
    🔗
    🔗
  2. Let \(C'\) be the matrix obtained by scaling a row of \(C\) by a factor of \(c\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Since left-multiplication by \(E\) scales the determinant by a factor of \(c\text{,}\) we have \(\det(ECB) = c\det(CB)\text{,}\) so
    \begin{gather*} d(C') = \frac{\det(C'B)}{\det(B)} = \frac{\det(ECB)}{\det(B)} = \frac{c\det(CB)}{\det(B)} = c\cdot d(C)\text{.} \end{gather*}
    🔗
    🔗
  3. Let \(C'\) be the matrix obtained by swapping two rows of \(C\text{,}\) and let \(E\) be the elementary matrix for this row replacement, so \(C' = EC\text{.}\) Since left-multiplication by \(E\) negates the determinant, we have \(\det(ECB) = -\det(CB)\text{,}\) so
    \begin{gather*} d(C') = \frac{\det(C'B)}{\det(B)} = \frac{\det(ECB)}{\det(B)} = \frac{-\det(CB)}{\det(B)} = -d(C)\text{.} \end{gather*}
    🔗
    🔗
  4. We have
    \begin{gather*} d(I_n) = \frac{\det(I_nB)}{\det(B)} = \frac{\det(B)}{\det(B)} = 1\text{.} \end{gather*}
    🔗
    🔗
🔗
Since \(d\) satisfies the four defining properties of the determinant, it is equal to the determinant by the Theorem 13. In other words, for all matrices \(A\text{,}\) we have
\begin{gather*} \det(A) = d(A) = \frac{\det(AB)}{\det(B)}\text{.} \end{gather*}
Multiplying through by \(\det(B)\) gives \(\det(A)\det(B)=\det(AB).\)
