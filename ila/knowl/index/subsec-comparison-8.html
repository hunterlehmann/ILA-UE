Note 3.2.36 One-to-one is the same as onto for square matrices.

We observed in Example 34 that a square matrix has a pivot in every row if and only if it has a pivot in every column. Therefore, a matrix transformation \(T\) from \(\R^n\) to itself is one-to-one if and only if it is onto: in this case, the two notions are equivalent.
🔗
Conversely, by Note 14 and Note 26, if a matrix transformation \(T\colon\R^m\to\R^n\) is both one-to-one and onto, then \(m=n\text{.}\)
