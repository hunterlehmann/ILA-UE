Example 3.2.17 Functions of one variable.

The function \(\sin\colon\R\to\R\) is not onto. Indeed, taking \(b=2\text{,}\) the equation \(\sin(x)=2\) has no solution. The range of \(\sin\) is the closed interval \([-1,1]\text{,}\) which is smaller than the codomain \(\R\text{.}\)
🔗
The function \(\exp\colon\R\to\R\) defined by \(\exp(x) = e^x\) is not onto. Indeed, taking \(b=-1\text{,}\) the equation \(\exp(x) = e^x = -1\) has no solution. The range of \(\exp\) is the set \((0,\infty)\) of all positive real numbers.
🔗
The function \(f\colon\R\to\R\) defined by \(f(x)=x^3\) is onto. Indeed, the equation \(f(x) = x^3 = b\) always has the solution \(x = \sqrt[3]b\text{.}\)
🔗
The function \(f\colon\R\to\R\) defined by \(f(x)=x^3-x\) is onto. Indeed, the solutions of the equation \(f(x) = x^3 - x = b\) are the roots of the polynomial \(x^3 - x - b\text{;}\) as this is a cubic polynomial, it has at least one real root.
