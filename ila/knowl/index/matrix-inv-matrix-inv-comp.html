Theorem 3.5.29.

Let \(T\colon\R^n\to\R^n\) be a linear transformation with standard matrix \(A\text{.}\) Then \(T\) is invertible if and only if \(A\) is invertible, in which case \(T\inv\) is linear with standard matrix \(A\inv\text{.}\)
🔗
🔗

Proof.
Suppose that \(T\) is invertible. Let \(U\colon\R^n\to\R^n\) be the inverse of \(T\text{.}\) We claim that \(U\) is linear. We need to check the Definition 1 of Section 3.3. Let \(u,v\) be vectors in \(\R^n\text{.}\) Then
\begin{gather*} u + v = T(U(u)) + T(U(v)) = T(U(u) + U(v)) \end{gather*}
by linearity of \(T\text{.}\) Applying \(U\) to both sides gives
\begin{gather*} U(u + v) = U\bigl(T(U(u) + U(v))\bigr) = U(u) + U(v)\text{.} \end{gather*}
Let \(c\) be a scalar. Then
\begin{gather*} cu = cT(U(u)) = T(cU(u)) \end{gather*}
by linearity of \(T\text{.}\) Applying \(U\) to both sides gives
\begin{gather*} U(cu) = U\bigl(T(cU(u))\bigr) = cU(u)\text{.} \end{gather*}
Since \(U\) satisfies the Definition 1 of Section 3.3, it is a linear transformation.
🔗
Now that we know that \(U\) is linear, we know that it has a standard matrix \(B\text{.}\) By the Theorem 25 of Section 3.4, the matrix for \(T\circ U\) is \(AB\text{.}\) But \(T\circ U\) is the identity transformation \(\Id_{\R^n},\) and the standard matrix for \(\Id_{\R^n}\) is \(I_n\text{,}\) so \(AB = I_n\text{.}\) One shows similarly that \(BA = I_n\text{.}\) Hence \(A\) is invertible and \(B = A\inv\text{.}\)
🔗
Conversely, suppose that \(A\) is invertible. Let \(B = A\inv\text{,}\) and define \(U\colon\R^n\to\R^n\) by \(U(x) = Bx\text{.}\) By the Theorem 25 of Section 3.4, the matrix for \(T\circ U\) is \(AB = I_n\text{,}\) and the matrix for \(U\circ T\) is \(BA = I_n\text{.}\) Therefore,
\begin{gather*} T\circ U(x) = ABx = I_nx = x \sptxt{and} U\circ T(x) = BAx = I_nx = x\text{,} \end{gather*}
which shows that \(T\) is invertible with inverse transformation \(U\text{.}\)
