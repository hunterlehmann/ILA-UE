Theorem 2.3.16.

Let \(A\) be an \(m\times n\) (non-augmented) matrix. The following are equivalent:
  1. \(Ax=b\) has a solution for all \(b\) in \(\R^m\text{.}\)
    🔗
    🔗
  2. The span of the columns of \(A\) is all of \(\R^m\text{.}\)
    🔗
    🔗
  3. \(A\) has a pivot position in every row.
    🔗
    🔗
🔗
🔗

Proof.
The equivalence of 1 and 2 is established by Spans and Consistency as applied to every \(b\) in \(\R^m\text{.}\)
🔗
Now we show that 1 and 3 are equivalent. (Since we know 1 and 2 are equivalent, this implies 2 and 3 are equivalent as well.) If \(A\) has a pivot in every row, then its reduced row echelon form looks like this:
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp \star \amp 0 \amp \star \\ 0 \amp 1 \amp \star \amp 0 \amp \star \\ 0 \amp 0 \amp 0 \amp 1 \amp \star \end{pmatrix}\text{,} \end{align*}
and therefore \(\left(\begin{array}{r|r} A \amp b \end{array}\right)\) reduces to this:
\begin{align*} \left(\begin{array}{ccccc|c} 1 \amp 0 \amp \star \amp 0 \amp \star \amp \star \\ 0 \amp 1 \amp \star \amp 0 \amp \star \amp \star \\ 0 \amp 0 \amp 0 \amp 1 \amp \star \amp \star \end{array}\right)\text{.} \end{align*}
There is no \(b\) that makes it inconsistent, so there is always a solution. Conversely, if \(A\) does not have a pivot in each row, then its reduced row echelon form looks like this:
\begin{align*} \begin{pmatrix} 1 \amp 0 \amp \star \amp 0 \amp \star \\ 0 \amp 1 \amp \star \amp 0 \amp \star \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{pmatrix}\text{,} \end{align*}
which can give rise to an inconsistent system after augmenting with \(b\text{:}\)
\begin{align*} \left(\begin{array}{rrrrr|r} 1 \amp 0 \amp \star \amp 0 \amp \star \amp 0 \\ 0 \amp 1 \amp \star \amp 0 \amp \star \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 16 \end{array}\right)\text{.} \end{align*}
