Example 3.5.32 Reflection.

Let \(T\colon\R^2\to\R^2\) be the reflection over the \(y\)-axis. Is \(T\) invertible? If so, what is \(T\inv\text{?}\)
🔗

Solution.

In Example 7 of Section 3.1 we showed that the matrix for \(T\) is
\begin{align*} A = \begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
This matrix has determinant \(-1\text{,}\) so it is invertible, with inverse
\begin{align*} A\inv = -\begin{pmatrix} 1 \amp 0 \\ 0 \amp -1 \end{pmatrix} = \begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix} = A\text{.} \end{align*}
By the Theorem 29, \(T\) is invertible, and it is equal to its own inverse: \(T\inv = T\text{.}\) This is another way of saying that a reflection “undoes” itself.
