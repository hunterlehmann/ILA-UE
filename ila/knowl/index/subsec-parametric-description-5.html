Example 1.24 Lines.

Consider the linear equation \(x+y=1\) of Example 15. In this context, we call \(x+y=1\) an implicit equation of the line. We can write the same line in parametric form as follows:
\begin{gather*} (x, y) = (t,\, 1-t) \sptxt{for any} t \in \R. \end{gather*}
This means that every point on the line has the form \((t,\, 1-t)\) for some real number \(t\text{.}\) In this case, we call \(t\) a parameter, as it parameterizes the points on the line.

Now consider the system of two linear equations
\begin{align*} \left\{\begin{alignedat}{4} \mhp{x} \amp {}+{} \amp \mhp{y} \amp {}+{} \amp \mhp{z} \amp {}={} \amp \mhp{1} \amp {} \\ \mhg{x} \amp {}{} \amp {} \amp {}-{} \amp \mhg{z} \amp {}={} \amp \mhg{0} \amp {} \end{alignedat}\right. \end{align*}
of Example 21. These collectively form the implicit equations for a line in \(\R^3\text{.}\) (At least two equations are needed to define a line in space.) This line also has a parametric form with one parameter \(t\text{:}\)
\begin{gather*} (x,\, y,\, z) = (t,\, 1-2t,\, t). \end{gather*}
🔗
Note that in each case, the parameter \(t\) allows us to use \(\R\) to label the points on the line. However, neither line is the same as the number line \(\R\text{:}\) indeed, every point on the first line has two coordinates, like the point \((0,1)\text{,}\) and every point on the second line has three coordinates, like \((0,1,0)\text{.}\)
