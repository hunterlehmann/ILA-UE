Theorem 6.3.14.

Let \(A\) be an \(m \times n\) matrix, let \(W = \Col(A)\text{,}\) and let \(x\) be a vector in \(\R^m\text{.}\) Then the matrix equation
\begin{gather*} A^TAc=A^Tx \end{gather*}
in the unknown vector \(c\) is consistent, and \(x_W\) is equal to \(Ac\) for any solution \(c\text{.}\)
🔗
🔗

Proof.
Let \(x = x_W + x_{W^\perp}\) be the orthogonal decomposition with respect to \(W\text{.}\) By definition \(x_W\) lies in \(W=\Col(A)\) and so there is a vector \(c\) in \(\R^n\) with \(Ac = x_W\text{.}\) Choose any such vector \(c\text{.}\) We know that \(x-x_W=x-Ac\) lies in \(W^\perp\text{,}\) which is equal to \(\Nul(A^T)\) by Note . We thus have
\begin{gather*} 0=A^T(x-Ac) = A^Tx-A^TAc \end{gather*}
and so
\begin{gather*} A^TAc = A^Tx\text{.} \end{gather*}
This exactly means that \(A^TAc = A^Tx\) is consistent. If \(c\) is any solution to \(A^TAc=A^Tx\) then by reversing the above logic, we conclude that \(x_W = Ac\text{.}\)
