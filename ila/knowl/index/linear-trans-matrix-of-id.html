Example 3.3.22 The standard matrix of the identity transformation.

Verify that the identity transformation \(\Id_{\R^n}\colon\R^n\to\R^n\) is linear, and compute its standard matrix.
🔗

Solution.

We verify the two Definition 1 of linear transformations. Let \(u,v\) be vectors in \(\R^n\text{.}\) Then
\begin{gather*} \Id_{\R^n}(u+v) = u+v = \Id_{\R^n}(u) + \Id_{\R^n}(v)\text{.} \end{gather*}
If \(c\) is a scalar, then
\begin{gather*} \Id_{\R^n}(cu) = cu = c\Id_{\R^n}(u)\text{.} \end{gather*}
Since \(\Id_{\R^n}\) satisfies the two defining properties, it is a linear transformation.
🔗
Now that we know that \(\Id_{\R^n}\) is linear, it makes sense to compute its standard matrix. For each standard coordinate vector \(e_i\text{,}\) we have \(\Id_{R^n}(e_i) = e_i\text{.}\) In other words, the columns of the standard matrix of \(\Id_{\R^n}\) are the standard coordinate vectors, so the standard matrix is the identity matrix
\begin{align*} I_n = \begin{pmatrix} 1 \amp 0 \amp \cdots \amp 0 \amp 0 \\ 0 \amp 1 \amp \cdots \amp 0 \amp 0 \\ \vdots \amp \vdots \amp \ddots \amp \vdots \amp \vdots \\ 0 \amp 0 \amp \cdots \amp 1 \amp 0 \\ 0 \amp 0 \amp \cdots \amp 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
