Example 5.1.27 Reflection.

Let \(T\colon\R^2\to\R^2\) be the linear transformation that reflects over the line \(L\) defined by \(y=-x\text{,}\) and let \(A\) be the matrix for \(T\text{.}\) Find all eigenspaces of \(A\text{.}\)
🔗

Solution.

We showed in Example 7 that all eigenvectors with eigenvalue \(1\) lie on \(L\text{,}\) and all eigenvectors with eigenvalue \(-1\) lie on the line \(L^\perp\) that is perpendicular to \(L\text{.}\) Hence, \(L\) is the \(1\)-eigenspace, and \(L^\perp\) is the \(-1\)-eigenspace.
🔗
None of this required any computations, but we can verify our conclusions using algebra. First we compute the matrix \(A\text{:}\)
\begin{align*} T\begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ -1 \end{pmatrix} \qquad T\begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} -1 \\ 0 \end{pmatrix} \quad\implies\quad A = \begin{pmatrix} 0 \amp -1 \\ -1 \amp 0 \end{pmatrix}\text{.} \end{align*}
Computing the \(1\)-eigenspace means solving the matrix equation \((A-I_2)v=0\text{.}\) We have
\begin{align*} A-I_2 = \begin{pmatrix} 0 \amp -1 \\ -1 \amp 0 \end{pmatrix} - \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} -1 \amp -1 \\ -1 \amp -1 \end{pmatrix} \quad\xrightarrow{\text{RREF}}\quad\begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
The parametric form of the solution set is \(x = -y\text{,}\) or equivalently, \(y = -x\text{,}\) which is exactly the equation for \(L\text{.}\) Computing the \(-1\)-eigenspace means solving the matrix equation \((A+I_2)v=0\text{;}\) we have
\begin{align*} A+I_2 = \begin{pmatrix} 0 \amp -1 \\ -1 \amp 0 \end{pmatrix} + \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix} = \begin{pmatrix} 1 \amp -1 \\ -1 \amp 1 \end{pmatrix} \quad\xrightarrow{\text{RREF}}\quad\begin{pmatrix} 1 \amp -1 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
The parametric form of the solution set is \(x = y\text{,}\) or equivalently, \(y = x\text{,}\) which is exactly the equation for \(L^\perp\text{.}\)
