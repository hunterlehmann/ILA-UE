Example 5.4.29 Eigenvalues \(|\lambda_1| > 1,\,|\lambda_2| > 1\).

Describe how the matrix
\begin{align*} A = \frac 1{5}\begin{pmatrix} 13 \amp -2 \\ -3 \amp 12 \end{pmatrix} \end{align*}
acts on the plane.
🔗

Solution.

First we diagonalize \(A\text{.}\) The characteristic polynomial is
\begin{gather*} f(\lambda) = \lambda^2 - \Tr(A)\lambda + \det(A) = \lambda^2 - 5\lambda + 6 = (\lambda - 2)(\lambda - 3)\text{.} \end{gather*}
Next we compute the \(2\)-eigenspace:
\begin{align*} (A-2I_3)v = 0 \iff \frac 15\begin{pmatrix} 3 \amp -2 \\ -3 \amp 2 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp -2/3 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
The parametric form of this equation is \(x = 2/3y\text{,}\) so one eigenvector is \(v_1 = {2/3\choose 1}\text{.}\) For the \(3\)-eigenspace, we have:
\begin{align*} (A-3I_3)v = 0 \iff \frac 15\begin{pmatrix} -2 \amp -2 \\ -3 \amp -3 \end{pmatrix}v = 0 \;\xrightarrow{\text{RREF}}\; \begin{pmatrix} 1 \amp 1 \\ 0 \amp 0 \end{pmatrix}v = 0\text{.} \end{align*}
The parametric form of this equation is \(x = -y\text{,}\) so an eigenvector is \(v_2 = {-1\choose 1}\text{.}\) It follows that \(A = CDC\inv\text{,}\) where
\begin{align*} C = \begin{pmatrix} 2/3 \amp -1 \\ 1 \amp 1 \end{pmatrix} \qquad D = \begin{pmatrix} 2 \amp 0 \\ 0 \amp 3 \end{pmatrix}\text{.} \end{align*}
🔗
The diagonal matrix \(D\) scales the \(x\)-coordinate by \(2\) and the \(y\)-coordinate by \(3\text{.}\) Therefore, it moves vectors farther from both the \(x\)-axis and the \(y\)-axis, but faster in the \(y\)-direction than the \(x\)-direction.
🔗
The matrix \(A\) does the same thing, in the \(v_1,v_2\)-coordinate system: multiplying a vector by \(A\) scales the \(v_1\)-coordinate by \(2\) and the \(v_2\)-coordinate by \(3\text{.}\) Therefore, \(A\) moves vectors farther from the \(2\)-eigenspace and the \(3\)-eigenspace, but faster in the \(v_2\)-direction than the \(v_1\)-direction.
🔗
