Fact 5.1.30.

Let \(A\) be an \(n\times n\) matrix.
  1. The number \(0\) is an eigenvalue of \(A\) if and only if \(A\) is not invertible.
    🔗
    🔗
  2. In this case, the \(0\)-eigenspace of \(A\) is \(\Nul(A)\text{.}\)
    🔗
    🔗
🔗
🔗

Proof.
We know that \(0\) is an eigenvalue of \(A\) if and only if \(\Nul(A - 0I_n) = \Nul(A)\) is nonzero, which is equivalent to the noninvertibility of \(A\) by the Theorem 1 of Section 3.6. In this case, the \(0\)-eigenspace is by definition \(\Nul(A-0I_n) = \Nul(A)\text{.}\)
