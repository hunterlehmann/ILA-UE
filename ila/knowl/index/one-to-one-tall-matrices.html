Note 3.2.26 Tall matrices do not have onto transformations.

If \(T\colon\R^n\to\R^m\) is an onto matrix transformation, what can we say about the relative sizes of \(n\) and \(m\text{?}\)
🔗
The matrix associated to \(T\) has \(n\) columns and \(m\) rows. Each row and each column can only contain one pivot, so in order for \(A\) to have a pivot in every row, it must have at least as many columns as rows: \(m\leq n\text{.}\)
🔗
This says that, for instance, \(\R^2\) is “too small” to admit an onto linear transformation to \(\R^3\text{.}\)
🔗
Note that there exist wide matrices that are not onto: for example,
\begin{align*} \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix} \end{align*}
does not have a pivot in every row.
