Insight 3.4.22 Matrix multiplication caveats.

  • Matrix multiplication is not commutative: \(AB\) is not usually equal to \(BA\text{,}\) even when both products are defined and have the same size. See Example 23.
    🔗
    🔗
  • Matrix multiplication does not satisfy the cancellation law: \(AB=AC\) does not imply \(B=C\text{,}\) even when \(A\neq 0\text{.}\) For example,
    \begin{align*} \begin{pmatrix} 1 \amp 0 \\ 0 \amp 0 \end{pmatrix}\begin{pmatrix} 1 \amp 2 \\ 3 \amp 4 \end{pmatrix} = \begin{pmatrix} 1 \amp 2 \\ 0 \amp 0 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 0 \end{pmatrix}\begin{pmatrix} 1 \amp 2 \\ 5 \amp 6 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
  • It is possible for \(AB=0\text{,}\) even when \(A\neq 0\) and \(B\neq 0\text{.}\) For example,
    \begin{align*} \begin{pmatrix} 1 \amp 0 \\ 1 \amp 0 \end{pmatrix}\begin{pmatrix} 0 \amp 0 \\ 1 \amp 1 \end{pmatrix} = \begin{pmatrix} 0 \amp 0 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
