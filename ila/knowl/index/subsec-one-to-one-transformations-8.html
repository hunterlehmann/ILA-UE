Example 3.2.3 Functions of one variable.

The function \(\sin\colon\R\to\R\) is not one-to-one. Indeed, \(\sin(0) = \sin(\pi) = 0\text{,}\) so the inputs \(0\) and \(\pi\) have the same output \(0\text{.}\) In fact, the equation \(\sin(x) = 0\) has infinitely many solutions \(\ldots,-2\pi,-\pi,0,\pi,2\pi,\ldots\text{.}\)
🔗
The function \(\exp\colon\R\to\R\) defined by \(\exp(x) = e^x\) is one-to-one. Indeed, if \(T(x) = T(y)\text{,}\) then \(e^x = e^y\text{,}\) so \(\ln(e^x) = \ln(e^y)\text{,}\) and hence \(x = y\text{.}\) The equation \(T(x) = C\) has one solution \(x = \ln(C)\) if \(C > 0\text{,}\) and it has zero solutions if \(C\leq 0\text{.}\)
🔗
The function \(f\colon\R\to\R\) defined by \(f(x)=x^3\) is one-to-one. Indeed, if \(f(x) = f(y)\) then \(x^3 = y^3\text{;}\) taking cube roots gives \(x = y\text{.}\) In other words, the only solution of \(f(x) = C\) is \(x=\sqrt[3]C\text{.}\)
🔗
The function \(f\colon\R\to\R\) defined by \(f(x)=x^3-x\) is not one-to-one. Indeed, \(f(0) = f(1) = f(-1) = 0\text{,}\) so the inputs \(0,1,-1\) all have the same output \(0\text{.}\) The solutions of the equation \(x^3 - x = 0\) are exactly the roots of \(f(x) = x(x-1)(x+1)\text{,}\) and this equation has three roots.
🔗
The function \(f\colon\R\to\R\) defined by \(f(x)=x^2\) is not one-to-one. Indeed, \(f(1) = 1 = f(-1)\text{,}\) so the inputs \(1\) and \(-1\) have the same outputs. The function \(g\colon\R\to\R\) defined by \(g(x)=|x|\) is not one-to-one for the same reason.
