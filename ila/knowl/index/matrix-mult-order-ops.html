Example 3.4.24 Order of Operations.

Let \(T\colon\R^n\to\R^m\) and \(U\colon\R^p\to\R^n\) be linear transformations, and let \(A\) and \(B\) be their standard matrices, respectively. Recall that \(T\circ U(x)\) is the vector obtained by first applying \(U\) to \(x\text{,}\) and then \(T\text{.}\)
🔗
On the matrix side, the standard matrix of \(T\circ U\) is the product \(AB\text{,}\) so \(T\circ U(x) = (AB)x\text{.}\) By associativity of matrix multiplication, we have \((AB)x = A(Bx)\text{,}\) so the product \((AB)x\) can be computed by first multiplying \(x\) by \(B\text{,}\) then multipyling the product by \(A\text{.}\)
🔗
Therefore, matrix multiplication happens in the same order as composition of transformations. In other words, both matrices and transformations are written in the order opposite from the order in which they act. But matrix multiplication and composition of transformations are written in the same order as each other: the matrix for \(T\circ U\) is \(AB\text{.}\)
