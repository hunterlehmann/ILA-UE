Theorem 5.6.10 Perron–Frobenius Theorem.

Let \(A\) be a positive stochastic matrix. Then \(A\) admits a unique steady state vector \(w\text{,}\) which spans the \(1\)-eigenspace.
🔗
Moreover, for any vector \(v_0\) with entries summing to some number \(c\text{,}\) the iterates
\begin{gather*} v_1 = Av_0,\; v_2 = Av_1,\; \ldots,\; v_t = Av_{t-1},\; \ldots \end{gather*}
approach \(cw\) as \(t\) gets large.
