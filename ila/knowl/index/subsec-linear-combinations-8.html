Example 2.21 Linear Combinations of a Single Vector.

A linear combination of a single vector \(v = {1\choose 2}\) is just a scalar multiple of \(v\text{.}\) So some examples include
\begin{gather*} v=\begin{pmatrix} 1 \\ 2 \end{pmatrix},\quad \frac 32v=\begin{pmatrix} 3/2 \\ 3 \end{pmatrix},\quad -\frac12v = \begin{pmatrix} -1/2 \\ -1 \end{pmatrix},\quad\ldots \end{gather*}
The set of all linear combinations is the line through \(v\). (Unless \(v=0\text{,}\) in which case any scalar multiple of \(v\) is again \(0\text{.}\))
