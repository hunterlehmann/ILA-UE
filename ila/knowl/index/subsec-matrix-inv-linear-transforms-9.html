Example 3.5.24 Projection.

Let \(T\colon\R^3\to\R^3\) be the projection onto the \(xy\)-plane, introduced in Example 5 of Section 3.1. Is \(T\) invertible?
🔗

Solution.

The transformation \(T\) is not invertible. Every vector on the \(z\)-axis projects onto the zero vector, so there is no way to undo what \(T\) did: the inverse transformation would not know which vector on the \(z\)-axis it should send the zero vector to. More formally, suppose there were a transformation \(U\colon\R^3\to\R^3\) such that \(U\circ T = \Id_{\R^3}\text{.}\) Then
\begin{gather*} 0 = U\circ T(0) = U(T(0)) = U(0) \end{gather*}
and
\begin{gather*} \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = U\circ T\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = U\left(T\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\right) = U(0)\text{.} \end{gather*}
But \(U(0)\) is as single vector in \(\R^3\text{,}\) so it cannot be equal to \(0\) and to \((0, 0, 1)\) at the same time.
