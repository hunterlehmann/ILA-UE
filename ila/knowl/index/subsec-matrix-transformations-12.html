Example 3.1.29 Matrix transformations of \(\R^2\).

In the first Subsection 3.1.1 we discussed the transformations defined by several \(2\times 2\) matrices, namely:
\begin{align*} \text{Reflection:} \amp\qquad A=\begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Dilation:} \amp\qquad A=\begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}\\ \text{Identity:} \amp\qquad A=\begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Rotation:} \amp\qquad A=\begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}\\ \text{Shear:} \amp\qquad A=\begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
In each case, the associated matrix transformation \(T(x)=Ax\) has domain and codomain equal to \(\R^2\text{.}\) The range is also \(\R^2\text{,}\) as can be seen geometrically (what is the input for a given output?), or using the fact that the columns of \(A\) are not collinear (so they form a basis for \(\R^2\)).
