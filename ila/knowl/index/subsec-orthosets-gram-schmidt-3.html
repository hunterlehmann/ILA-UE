Theorem 6.4.21 The Gram–Schmidt Process.

Let \(v_1,v_2,\ldots,v_m\) be a basis for a subspace \(W\) of \(\R^n\text{.}\) Define:
\begin{align*} 1.\quad u_1 \amp= v_1 \phantom{\dfrac{u_1}{u_1}}\\ 2.\quad u_2 \amp= \hbox to 3.4cm{$(v_2)_{\Span\{u_1\}^\perp}$} = v_2 - \frac{v_2\cdot u_1}{u_1\cdot u_1}\,u_1\\ 3.\quad u_3 \amp= \hbox to 3.4cm{$(v_3)_{\Span\{u_1,u_2\}^\perp}$} = v_3 - \frac{v_3\cdot u_1}{u_1\cdot u_1}\,u_1 - \frac{v_3\cdot u_2}{u_2\cdot u_2}\,u_2\\ \vdots\quad\amp\\ m.\quad u_m \amp= \hbox to 3.4cm{$(v_m)_{\Span\{u_1,u_2,\ldots,u_{m-1}\}^\perp}$} = v_m - \sum_{i=1}^{m-1}\frac{v_m\cdot u_i}{u_i\cdot u_i}\,u_i\text{.} \end{align*}
Then \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal basis for the same subspace \(W\text{.}\)
🔗
🔗

Proof.
First we claim that each \(u_i\) is in \(W\text{,}\) and in fact that \(u_i\) is in \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\) Clearly \(u_1 = v_1\) is in \(\Span\{v_1\}\text{.}\) Then \(u_2\) is a linear combination of \(u_1\) and \(v_2\text{,}\) which are both in \(\Span\{v_1,v_2\}\text{,}\) so \(u_2\) is in \(\Span\{v_1,v_2\}\) as well. Similarly, \(u_3\) is a linear combination of \(u_1,\,u_2,\) and \(v_3\text{,}\) which are all in \(\Span\{v_1,v_2,v_3\}\text{,}\) so \(u_3\) is in \(\Span\{v_1,v_2,v_3\}\text{.}\) Continuing in this way, we see that each \(u_i\) is in \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\)
🔗
Now we claim that \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal set. Let \(1\leq i \lt j \leq m\text{.}\) Then \(u_j = (v_j)_{\Span\{u_1,u_2,\ldots,u_{j-1}\}^\perp}\text{,}\) so by definition \(u_j\) is orthogonal to every vector in \(\Span\{u_1,u_2,\ldots,u_{j-1}\}\text{.}\) In particular, \(u_j\) is orthogonal to \(u_i\text{.}\)
🔗
We still have to prove that each \(u_i\) is nonzero. Clearly \(u_1=v_1\neq 0\text{.}\) Suppose that \(u_i=0\text{.}\) Then \((v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}^\perp}=0\text{,}\) which means that \(v_i\) is in \(\Span\{u_1,u_2,\ldots,u_{i-1}\}.\) But each \(u_1,u_2,\ldots,u_{i-1}\) is in \(\Span\{v_1,v_2,\ldots,v_{i-1}\}\) by the first paragraph, so \(v_i\) is in \(\Span\{v_1,v_2,\ldots,v_{i-1}\}.\) This contradicts the Theorem 14 of Section 2.5; therefore, \(u_i\) must be nonzero.
🔗
The previous two paragraphs justify the use of the Theorem 8 in the equalities
\begin{gather*} (v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}^\perp} = v_i - (v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}} = v_i - \sum_{j=1}^{i-1}\frac{v_i\cdot u_j}{u_j\cdot u_j}\,u_j \end{gather*}
in the statement of the theorem.
🔗
Since \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal set, it is linearly independent. Thus it is a set of \(m\) linearly independent vectors in \(W\text{,}\) so it is a basis for \(W\) by the Theorem 19 of Section 2.7. Similarly, for every \(i\text{,}\) we saw that the set \(\{u_1,u_2,\ldots,u_i\}\) is contained in the \(i\)-dimensional subspace \(\Span\{v_1,v_2,\ldots,v_i\}\text{,}\) so \(\{u_1,u_2,\ldots,u_i\}\) is an orthogonal basis for \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\)
