    Section 2.4 Solution Sets

    Objectives

    1. Understand the relationship between the solution set of \(Ax=0\) and the solution set of \(Ax=b\text{.}\)
      🔗
      🔗
    2. Understand the difference between the solution set and the column span.
      🔗
      🔗
    3. Recipes: parametric vector form, write the solution set of a homogeneous system as a span.
      🔗
      🔗
    4. Pictures: solution set of a homogeneous system, solution set of an inhomogeneous system, the relationship between the two.
      🔗
      🔗
    5. Vocabulary words: homogeneous/inhomogeneous, trivial solution.
      🔗
      🔗
    🔗
    In this section we will study the geometry of the solution set of any matrix equation \(Ax=b\text{.}\)
    🔗

    Subsection 2.4.1 Homogeneous Systems

    The equation \(Ax=b\) is easier to solve when \(b=0\text{,}\) so we start with this case.
    🔗

    Definition 2.4.1.

    A system of linear equations of the form \(Ax=0\) is called homogeneous.
    🔗
    A system of linear equations of the form \(Ax=b\) for \(b\neq 0\) is called inhomogeneous.
    🔗
    🔗
    A homogeneous system is just a system of linear equations where all constants on the right side of the equals sign are zero.
    🔗
    A homogeneous system always has the solution \(x=0\text{.}\) This is called the trivial solution. Any nonzero solution is called nontrivial.
    🔗
    🔗

    Example 2.4.2.

    The equation \(Ax=0\) has a nontrivial solution \(\iff\) there is a free variable \(\iff\) \(A\) has a column without a pivot position.
    🔗
    🔗

    Example 2.4.3 No nontrivial solutions.

    What is the solution set of \(Ax=0\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 1 \amp 3 \amp 4 \\ 2 \amp -1 \amp 2 \\ 1 \amp 0 \amp 1 \end{pmatrix}? \end{align*}
    🔗

    Solution.

    We form an augmented matrix and row reduce:
    \begin{align*} \left(\begin{array}{rrr|r} 1 \amp 3 \amp 4 \amp 0 \\ 2 \amp -1 \amp 2 \amp 0 \\ 1 \amp 0 \amp 1 \amp 0 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \left(\begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \end{array}\right)\text{.} \end{align*}
    The only solution is the trivial solution \(x=0\text{.}\)
    🔗
    🔗
    🔗

    Example 2.4.4.

    When we row reduce the augmented matrix for a homogeneous system of linear equations, the last column will be zero throughout the row reduction process. We saw this in the last Example 3:
    \begin{align*} \left(\begin{array}{rrr|r} 1 \amp 3 \amp 4 \amp 0 \\ 2 \amp -1 \amp 2 \amp 0 \\ 1 \amp 0 \amp 1 \amp 0 \end{array}\right) \end{align*}
    So it is not really necessary to write augmented matrices when solving homogeneous systems.
    🔗
    🔗
    When the homogeneous equation \(Ax=0\) does have nontrivial solutions, it turns out that the solution set can be conveniently expressed as a span.
    🔗

    Example 2.4.5 Parametric Vector Form (homogeneous case).

    Consider the following matrix in reduced row echelon form:
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp -8 \amp -7 \\ 0 \amp 1 \amp 4 \amp 3 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    The matrix equation \(Ax=0\) corresponds to the system of equations
    \begin{align*} \left\{\begin{alignedat}{5} x_1 \amp {} \amp {} \amp {} \amp 8x_3 \amp {}-{} \amp 7x_4 \amp {}={} \amp 0 \amp {} \\ {} \amp {} \amp x_2 \amp {}+{} \amp 4x_3 \amp {}+{} \amp 3x_4 \amp {}={} \amp 0 \amp . \end{alignedat}\right. \end{align*}
    We can write the parametric form as follows:
    \begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp 8x_3 + 7x_4 \amp {} \\ x_2 \amp {}={} \amp -4x_3 - 3x_4 \amp {} \\ x_3 \amp {}={} \amp x_3 \amp {} \\ x_4 \amp {}={} \amp x_4 \amp . \end{alignedat}\right. \end{align*}
    We wrote the redundant equations \(x_3=x_3\) and \(x_4=x_4\) in order to turn the above system into a vector equation:
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{pmatrix} = x_3\begin{pmatrix} 8 \\ -4 \\ 1 \\ 0 \end{pmatrix} + x_4\begin{pmatrix} 7 \\ -3 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    This vector equation is called the parametric vector form of the solution set. Since \(x_3\) and \(x_4\) are allowed to be anything, this says that the solution set is the set of all linear combinations of \(\begin{pmatrix} 8 \\ -4 \\ 1 \\ 0 \end{pmatrix}\) and \(\begin{pmatrix} 7 \\ -3 \\ 0 \\ 1 \end{pmatrix}\text{.}\) In other words, the solution set is
    \begin{gather*} \Span\left\{\begin{pmatrix} 8 \\ -4 \\ 1 \\ 0 \end{pmatrix},\;\begin{pmatrix} 7 \\ -3 \\ 0 \\ 1 \end{pmatrix}\right\}\text{.} \end{gather*}
    🔗
    🔗
    Here is the general procedure.
    🔗

    Recipe 2.4.6 Parametric vector form (homogeneous case).

    Let \(A\) be an \(m\times n\) matrix. Suppose that the free variables in the homogeneous equation \(Ax=0\) are, for example, \(x_3\text{,}\) \(x_6\text{,}\) and \(x_8\text{.}\)
    1. Find the reduced row echelon form of \(A\text{.}\)
      🔗
      🔗
    2. Write the parametric form of the solution set, including the redundant equations \(x_3=x_3\text{,}\) \(x_6=x_6\text{,}\) \(x_8=x_8\text{.}\) Put equations for all of the \(x_i\) in order.
      🔗
      🔗
    3. Make a single vector equation from these equations by making the coefficients of \(x_3,x_6,\) and \(x_8\) into vectors \(v_3,v_6,\) and \(v_8\text{,}\) respectively.
      🔗
      🔗
    The solutions to \(Ax=0\) will then be expressed in the form
    \begin{gather*} x = x_3v_3 + x_6v_6 + x_8v_8 \end{gather*}
    for some vectors \(v_3,v_6,v_8\) in \(\R^n\text{,}\) and any scalars \(x_3,x_6,x_8\text{.}\) This is called the parametric vector form of the solution.
    🔗
    In this case, the solution set can be written as \(\Span\{v_3,\,v_6,\,v_8\}.\)
    🔗
    🔗
    We emphasize the following fact in particular.
    🔗
    The set of solutions to a homogeneous equation \(Ax=0\) is a span.
    🔗
    🔗

    Example 2.4.7 The solution set is a line.

    Compute the parametric vector form of the solution set of \(Ax=0\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 1 \amp -3 \\ 2 \amp -6 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We row reduce (without augmenting, as suggested in the above Example 4):
    \begin{align*} \begin{pmatrix} 1 \amp -3 \\ 2 \amp -6 \end{pmatrix} \quad\xrightarrow{\text{RREF}}\quad \begin{pmatrix} 1 \amp -3 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    This corresponds to the single equation \(x_1 - 3x_2=0\text{.}\) We write the parametric form including the redundant equation \(x_2=x_2\text{:}\)
    \begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp 3x_2 \amp {} \\ x_2 \amp {}={} \amp x_2 \amp . \end{alignedat}\right. \end{align*}
    We turn these into a single vector equation:
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = x_2\begin{pmatrix} 3 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    This is the parametric vector form of the solution set. Since \(x_2\) is allowed to be anything, this says that the solution set is the set of all scalar multiples of \({3\choose 1}\text{,}\) otherwise known as
    \begin{gather*} \Span\left\{\begin{pmatrix} 3 \\ 1 \end{pmatrix}\right\}\text{.} \end{gather*}
    We know how to draw the picture of a span of a vector: it is a line. Therefore, this is a picture of the the solution set:
    🔗
    
    🔗
    🔗
    🔗
    Since there were two variables in the above Example 7, the solution set is a subset of \(\R^2\text{.}\) Since one of the variables was free, the solution set is a line:

    🔗

    Example 2.4.9 The solution set is a plane.

    Compute the parametric vector form of the solution set of \(Ax=0\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\text{.} \end{align*}
    🔗

    Solution.

    We row reduce (without augmenting, as suggested in the above Example 4):
    \begin{align*} \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix} \quad\xrightarrow{\text{RREF}}\quad \begin{pmatrix} 1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    This corresponds to the single equation \(x_1 - x_2 + 2x_3 = 0\text{.}\) We write the parametric form including the redundant equations \(x_2=x_2\) and \(x_3=x_3\text{:}\)
    \begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp x_2 - 2x_3 \amp {} \\ x_2 \amp {}={} \amp x_2 \amp {} \\ x_3 \amp {}={} \amp x_3 \amp . \end{alignedat}\right. \end{align*}
    We turn these into a single vector equation:
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = x_2\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + x_3\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    This is the parametric vector form of the solution set. Since \(x_2\) and \(x_3\) are allowed to be anything, this says that the solution set is the set of all linear combinations of \(\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}\) and \(\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\text{.}\) In other words, the solution set is
    \begin{gather*} \Span\left\{\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix},\;\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\right\}\text{.} \end{gather*}
    We know how to draw the span of two noncollinear vectors in \(\R^3\text{:}\) it is a plane. Therefore, this is a picture of the solution set:
    🔗
    
    🔗
    🔗
    🔗
    Since there were three variables in the above Example 9, the solution set is a subset of \(\R^3\text{.}\) Since two of the variables were free, the solution set is a plane.
    🔗
    There is a natural question to ask here: is it possible to write the solution to a homogeneous matrix equation using fewer vectors than the one given in the above recipe? We will see in Example 8 of Section 2.5 that the answer is no: the vectors from the recipe are always linearly independent, which means that there is no way to write the solution with fewer vectors.
    🔗
    Another natural question is: are the solution sets for inhomogeneuous equations also spans? As we will see shortly, they are never spans, but they are closely related to spans.
    🔗
    There is a natural relationship between the number of free variables and the “size” of the solution set, as follows.
    🔗

    Dimension of the solution set.

    The above examples show us the following pattern: when there is one free variable in a consistent matrix equation, the solution set is a line, and when there are two free variables, the solution set is a plane, etc. The number of free variables is called the dimension of the solution set.
    🔗
    🔗
    We will develop a rigorous definition of dimension in Section 2.7, but for now the dimension will simply mean the number of free variables. Compare with Insight 27 of Section 2.5.
    🔗
    Intuitively, the dimension of a solution set is the number of parameters you need to describe a point in the solution set. For a line only one parameter is needed, and for a plane two parameters are needed. This is similar to how the location of a building on Peachtree Street—which is like a line—is determined by one number and how a street corner in Manhattan—which is like a plane—is specified by two numbers.
    🔗
    🔗

    Subsection 2.4.2 Inhomogeneous Systems

    Recall that a matrix equation \(Ax=b\) is called inhomogeneous when \(b\neq0\text{.}\)
    🔗

    Example 2.4.11 The solution set is a line.

    What is the solution set of \(Ax=b\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 1 \amp -3 \\ 2 \amp -6 \end{pmatrix} \sptxt{and} b = \begin{pmatrix} -3 \\ -6 \end{pmatrix}? \end{align*}
    (Compare to Example 7, where we solved the corresponding homogeneous equation.)
    🔗

    Solution.

    We row reduce the associated augmented matrix:
    \begin{align*} \left(\begin{array}{rr|r} 1 \amp -3 \amp -3 \\ 2 \amp -6 \amp -6 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \left(\begin{array}{rr|r} 1 \amp -3 \amp -3 \\ 0 \amp 0 \amp 0 \end{array}\right)\text{.} \end{align*}
    This corresponds to the single equation \(x_1 - 3x_2 = -3\text{.}\) We can write the parametric form as follows:
    \begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp 3x_2 - 3 \amp {} \\ x_2 \amp {}={} \amp x_2 + 0 \amp . \end{alignedat}\right. \end{align*}
    We turn the above system into a vector equation:
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = x_2\begin{pmatrix} 3 \\ 1 \end{pmatrix} + \begin{pmatrix} -3 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    This vector equation is called the parametric vector form of the solution set. We write the solution set as
    \begin{gather*} \Span\left\{\begin{pmatrix} 3 \\ 1 \end{pmatrix}\right\} + \begin{pmatrix} -3 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    Here is a picture of the the solution set:
    🔗
    
    🔗
    🔗
    🔗
    In the above Example 11, the solution set was all vectors of the form
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = x_2\begin{pmatrix} 3 \\ 1 \end{pmatrix} + \begin{pmatrix} -3 \\ 0 \end{pmatrix} \end{gather*}
    where \(x_2\) is any scalar. The vector \(p = {-3\choose 0}\) is also a solution of \(Ax=b\text{:}\) take \(x_2=0\text{.}\) We call \(p\) a particular solution.
    🔗
    In the solution set, \(x_2\) is allowed to be anything, and so the solution set is obtained as follows: we take all scalar multiples of \({3\choose 1}\) and then add the particular solution \(p = {-3\choose 0}\) to each of these scalar multiples. Geometrically, this is accomplished by first drawing the span of \({3\choose 1}\text{,}\) which is a line through the origin (and, not coincidentally, the solution to \(Ax=0\)), and we translate, or push, this line along \(p = {-3\choose 0}\text{.}\) The translated line contains \(p\) and is parallel to \(\Span\{{3\choose 1}\}\text{:}\) it is a translate of a line.
    🔗
    
    🔗

    Example 2.4.13 The solution set is a plane.

    What is the solution set of \(Ax=b\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix} \sptxt{and} b = \begin{pmatrix} 1 \\ -2 \end{pmatrix}? \end{align*}
    (Compare Example 9.)
    🔗

    Solution.

    We row reduce the associated augmented matrix:
    \begin{align*} \left(\begin{array}{rrr|r} 1 \amp -1 \amp 2 \amp 1 \\ -2 \amp 2 \amp -4 \amp -2 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \begin{pmatrix} 1 \amp -1 \amp 2 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    This corresponds to the single equation \(x_1 - x_2 + 2x_3 = 1\text{.}\) We can write the parametric form as follows:
    \begin{align*} \left\{\begin{alignedat}{2} x_1 \amp {}={} \amp x_2 - 2x_3 + 1 \amp {} \\ x_2 \amp {}={} \amp x_2 \. + 0 \amp {} \\ x_3 \amp {}={} \amp x_3 + 0 \amp . \end{alignedat}\right. \end{align*}
    We turn the above system into a vector equation:
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = x_2\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + x_3\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix} + \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    This vector equation is called the parametric vector form of the solution set. Since \(x_2\) and \(x_3\) are allowed to be anything, this says that the solution set is the set of all linear combinations of \(\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\) and \(\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\text{,}\) translated by the vector \(p = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.}\) This is a plane which contains \(p\) and is parallel to \(\Span\left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\right\}\text{:}\) it is a translate of a plane. We write the solution set as
    \begin{gather*} \Span\left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix}\right\} + \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    Here is a picture of the solution set:
    🔗
    
    🔗
    🔗
    🔗
    In the above Example 13, the solution set was all vectors of the form
    \begin{gather*} x = \begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = x_2\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + x_3\begin{pmatrix} -2 \\ 0 \\ 1 \end{pmatrix} + \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    where \(x_2\) and \(x_3\) are any scalars. In this case, a particular solution is \(p = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\text{.}\)
    🔗
    In Example 13 and the Example 11 before it, the parametric vector form of the solution set of \(Ax=b\) was exactly the same as the parametric vector form of the solution set of \(Ax=0\) (from Example 9 and Example 7, respectively), plus a particular solution.
    🔗

    Key Observation.

    If \(Ax=b\) is consistent, the set of solutions to is obtained by taking one particular solution \(p\) of \(Ax=b\text{,}\) and adding all solutions of \(Ax=0\text{.}\)
    🔗
    In particular, if \(Ax=b\) is consistent, the solution set is a translate of a span.
    🔗
    🔗
    The parametric vector form of the solutions of \(Ax=b\) is just the parametric vector form of the solutions of \(Ax=0\text{,}\) plus a particular solution \(p\text{.}\)
    🔗
    It is not hard to see why the Note  is true. If \(p\) is a particular solution, then \(Ap=b\text{,}\) and if \(x\) is a solution to the homogeneous equation \(Ax=0\text{,}\) then
    \begin{gather*} A(x+p) = Ax + Ap = 0 + b = b\text{,} \end{gather*}
    so \(x+p\) is another solution of \(Ax=b\text{.}\) On the other hand, if we start with any solution \(x\) to \(Ax=b\) then \(x-p\) is a solution to \(Ax=0\) since
    \begin{gather*} A(x-p)=Ax-Ap=b-b=0\text{.} \end{gather*}
    🔗

    Remark 2.4.15.

    Row reducing to find the parametric vector form will give you one particular solution \(p\) of \(Ax=b\text{.}\) But the Note  is true for any solution \(p\text{.}\) In other words, if we row reduce in a different way and find a different solution \(p'\) to \(Ax=b\) then the solutions to \(Ax=b\) can be obtained from the solutions to \(Ax=0\) by either adding \(p\) or by adding \(p'\text{.}\)
    🔗
    🔗

    Example 2.4.16 The solution set is a point.

    What is the solution set of \(Ax=b\text{,}\) where
    \begin{align*} A = \begin{pmatrix} 1 \amp 3 \amp 4 \\ 2 \amp -1 \amp 2 \\ 1 \amp 0 \amp 1 \end{pmatrix} \sptxt{and} b = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}? \end{align*}
    🔗

    Solution.

    We form an augmented matrix and row reduce:
    \begin{align*} \left(\begin{array}{rrr|r} 1 \amp 3 \amp 4 \amp 0 \\ 2 \amp -1 \amp 2 \amp 1 \\ 1 \amp 0 \amp 1 \amp 0 \end{array}\right) \quad\xrightarrow{\text{RREF}}\quad \left(\begin{array}{rrr|r} 1 \amp 0 \amp 0 \amp -1 \\ 0 \amp 1 \amp 0 \amp -1 \\ 0 \amp 0 \amp 1 \amp 1 \end{array}\right)\text{.} \end{align*}
    The only solution is \(p=\begin{pmatrix} -1 \\ -1 \\ 1 \end{pmatrix}\text{.}\)
    🔗
    According to the Note , this is supposed to be a translate of a span by \(p\text{.}\) Indeed, we saw in the first Example 3 that the only solution of \(Ax=0\) is the trivial solution, i.e., that the solution set is the one-point set \(\{0\}\text{.}\) The solution set of the inhomogeneous equation \(Ax=b\) is
    \begin{gather*} \{0\} + \begin{pmatrix} -1 \\ -1 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    Note that \(\{0\} = \Span\{0\}\text{,}\) so the homogeneous solution set is a span.
    🔗
    
    🔗
    🔗
    🔗
    See the interactive figures in the next Subsection 2.4.3 for visualizations of the Note .
    🔗

    Dimension of the solution set.

    As in Dimension of the solution set, when there is one free variable in a consistent matrix equation, the solution set is a line—this line does not pass through the origin when the system is inhomogeneous—when there are two free variables, the solution set is a plane (again not through the origin when the system is inhomogeneous), etc.
    🔗
    🔗
    Again compare with Insight 27 of Section 2.5.
    🔗
    🔗

    Subsection 2.4.3 Solution Sets and Column Spans

    To every \(m\times n\) matrix \(A\text{,}\) we have now associated two completely different geometric objects, both described using spans.
    • The solution set: for fixed \(b\text{,}\) this is the set of all \(x\) such that \(Ax=b\text{.}\)
      • This is a span if \(b=0\text{,}\) and it is a translate of a span if \(b\neq 0\) (and \(Ax=b\) is consistent).
        🔗
        🔗
      • It is a subset of \(\R^n\text{.}\)
        🔗
        🔗
      • It is computed by solving a system of equations: usually by row reducing and finding the parametric vector form.
        🔗
        🔗
      🔗
      🔗
    • The span of the columns of \(A\): this is the set of all \(b\) such that \(Ax=b\) is consistent.
      • This is always a span.
        🔗
        🔗
      • It is a subset of \(\R^m\text{.}\)
        🔗
        🔗
      • It is not computed by solving a system of equations: row reduction plays no role.
        🔗
        🔗
      🔗
      🔗
    🔗
    Do not confuse these two geometric constructions! In the first the question is which \(x\)’s work for a given \(b\) and in the second the question is which \(b\)’s work for some \(x\text{.}\)

    Exercises 2.4.4 Exercises

    1.

      If \(A\) is a \(4 \times 6\) matrix with four pivots, then the matrix equation \(Ax = b\) must be consistent for every \(b\) in \({\bf R}^4\text{.}\)
      🔗

    • True.

    • False.

    Solution.
    True. Since \(A\) has \(4\) pivots, it follows that for any vector \(b\) in \({\bf R}^4\text{,}\) the matrix \((A \ | \ b)\) will have a pivot in each of its \(4\) rows, and each pivot will be to the left of the augment bar. Therefore, the system \(Ax = b\) will be consistent.
    🔗
    🔗
    🔗

    2.

    If \(A\) is a \(3 \times 5\) matrix with three pivots, then the set of solutions to \(Ax = 0\) is a plane.
    🔗
    Solution.
    True. Since \(A\) has \(3\) pivots but \(5\) columns, there will be exactly \(2\) columns that do not have a pivot. Therefore, the system \(Ax = 0\) will have exactly two free variables, which means that its solution set is a plane.
    🔗
    🔗
    🔗

    3.

      If \(b\) is a nonzero vector and \(Ax=b\) has infinitely many solutions, then \(Ax=0\) must have infinitely many solutions.
      🔗

    • True.

    • False.

    Solution.
    True. The solution set to \(Ax=b\) is a translate of the solution set to \(Ax=0\text{,}\) hence \(Ax=0\) must also have infinitely many solutions.
    🔗
    🔗
    🔗

    4.

      If \(A\) is a \(3 \times 4\) matrix and the solution set for \(Ax=0\) is a line, then \(A\) has exactly \(2\) pivots.
      🔗

    • True.

    • False.

    Solution.
    False. The solution set to \(Ax=0\) will be a line if and only if \(A\) has exactly \(1\) free variable. Since \(A\) has \(4\) columns, this means \(A\) has exactly \(3\) (not \(2\)) pivots.
    🔗
    🔗
    🔗

    5.

      There is a \(3 \times 2\) matrix \(A\) whose homogeneous solution set \(Ax=0\) is the line \(x_1 + x_2 = 1\text{.}\)
      🔗

    • True.

    • False.

    Solution.
    False. The zero vector \(x_1 = x_2 = 0\) does not satisfy the equation \(x_1 + x_2 = 1\text{.}\)
    🔗
    🔗
    🔗

    6.

    Suppose that the set of solutions to \(Ax = b\) is the plane \(z=1\text{.}\) What is the set of solutions to \(Ax = 0\text{?}\)
    🔗
    Solution.
    From the theory of section 2.4, the solution set to \(Ax = 0\) is the plane through the origin parallel to the plane \(z=1\text{.}\) Therefore, the solution set to \(Ax = 0\) is the \(x_1x_2\)-plane in \({\bf R}^3\) (this is the plane \(z=0\)).
    🔗
    🔗
    🔗

    7.

    Suppose that the set of solutions to \(Ax = 0\) is the plane \(y=x\) in \({\bf R}^2\text{.}\) Is it possible that there is a \(b\) so that the set of solutions to \(Ax = b\) is the line \(x+y=1\text{?}\) Justify your answer.
    🔗
    Solution.
    No. If \(Ax=b\) is consistent, then its solution set must be parallel to the solution set to \(Ax=0\text{,}\) namely the line \(y=x\) which has slope \(1\text{.}\) The line \(x+y=1\) is the line \(y= -x + 1\text{,}\) which has slope \(-1\text{,}\) so it cannot be the solution set to any consistent system \(Ax=b\text{.}\)
    🔗
    🔗
    🔗

    8.

    Suppose that the set of solutions to \(Ax = 0\) is the plane \(x+y = 0\) in \({\bf R}^3\text{.}\) Is it possible that there is a \(b\) so that the set of solutions to \(Ax = b\) is the \(z\)-axis in \({\bf R}^3\text{?}\) Justify your answer.
    🔗
    Solution.
    No. The solution set to \(Ax=0\) is a plane, then the solution set of any consistent equation \(Ax=b\) must be a parallel plane, but the \(z\)-axis is a line.
    🔗
    🔗
    🔗

    9.

    Suppose that the set of solutions to \(Ax = 0\) is the plane \(x + 2y - 3z = 0\) in \({\bf R}^3\) and that the vector \(\begin{pmatrix}1 \\ 3 \\ 5\end{pmatrix}\) is a solution to \(Ax = b\text{.}\)
    🔗

    (a)

    Find one other solution to \(Ax=b\text{.}\)
    🔗
    Solution.
    We can get the solution set to \(Ax=b\) by taking any particular solution to \(Ax = b\) (in this case, \(\begin{pmatrix}1 \\ 3 \\ 5\end{pmatrix}\)) and then adding all homogeneous solutions. The solution set to \(Ax=0\) is the plane \(x+2y-3z=0\text{,}\) and we can find a homogeneous solution by just guessing and checking to find \(x\text{,}\) \(y\text{,}\) and \(z\) that satisfy the equation. One such homogeneous solution is \(\begin{pmatrix}3 \\ 0 \\ 1\end{pmatrix}\text{.}\) Another solution to \(Ax = b\) is
    \begin{gather*} \begin{pmatrix}1 \\ 3 \\ 5\end{pmatrix} + \begin{pmatrix}3 \\ 0 \\ 1\end{pmatrix} = \begin{pmatrix}4 \\ 3 \\ 6\end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    (b)

    Find all solutions to \(Ax=b\text{.}\) Write your answer in parametric vector form.
    🔗
    Solution.
    The homogeneous equation \(x+2y-3z=0\) corresponds to \(\left(\begin{array}{rrr|r}1 \amp 2 \amp -3 \amp 0\end{array}\right)\text{,}\) which gives \(x = -2y + 3z\) where \(y\) and \(z\) are free.
    \begin{gather*} \begin{pmatrix}x \\ y \\ z\end{pmatrix} = \begin{pmatrix}-2y+3z \\ y \\ z\end{pmatrix} = \begin{pmatrix}-2y \\ y \\ 0\end{pmatrix} + \begin{pmatrix}3z \\ 0 \\ z\end{pmatrix} = y \begin{pmatrix}-2 \\ 1 \\ 0\end{pmatrix} + z \begin{pmatrix}3 \\ 0 \\ 1\end{pmatrix}\text{.} \end{gather*}
    The solution set to \(Ax = b\) is the translation of the homogeneous solution set by the particular solution \(\begin{pmatrix}1 \\ 3 \\ 5\end{pmatrix}\text{:}\)
    \begin{gather*} \begin{pmatrix}1 \\ 3 \\ 5\end{pmatrix} + y \begin{pmatrix}-2 \\ 1 \\ 0\end{pmatrix} + z \begin{pmatrix}3 \\ 0 \\ 1\end{pmatrix}, \quad \textup{ where } y, z \textup{ real}\text{.} \end{gather*}
    🔗
    🔗
    🔗
    🔗

    10.

    Is there a \(2 \times 2\) matrix so that the set of solutions to \(Av = \begin{pmatrix}1 \\ 2\end{pmatrix}\) is the line \(y = x + 1\text{?}\) If so, find such an \(A\text{.}\) If not, explain why not.
    🔗
    Solution.
    Yes: we need \(\begin{pmatrix}1 \\ 2\end{pmatrix}\) to be in the span of the columns of \(A\text{,}\) so that \(Av = \begin{pmatrix}1 \\ 2\end{pmatrix}\) is consistent. Also, we need for the line \(y=x\) to be the set of solutions to \(Ax=0\) since that is the line through the origin parallel to \(y=x+1\text{.}\) One way to get \(A\) is to start as if both columns are \(\begin{pmatrix}1 \\ 2\end{pmatrix}\text{,}\) then modify \(A\) until we satisfy the above. One such matrix is
    \begin{align*} A = \begin{pmatrix}-1 \amp 1 \\ -2 \amp 2\end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗

    11.

    Fill in the blanks: If \(A\) is a \(5 \times 3\) matrix with two pivots, then the set of solutions to \(Ax = 0\) is a \underline{\qquad \quad} that lives in \underline{\qquad}.
    🔗
    Solution.
    \(A\) has two pivot columns, so we will get one free variable in the when we solve \(Ax = 0\text{,}\) therefore the solution set will be a line. The solution set lives in \({\bf R}^3\) since \(A\) has three columns.

    12.

    Let
    \begin{align*} A = \begin{pmatrix}1 \amp -2 \amp 1 \\ 0 \amp 1 \amp 2\end{pmatrix}, \qquad b_1 = \begin{pmatrix}1 \\ -1 \\ 0\end{pmatrix}, \qquad b_2 = \begin{pmatrix}2 \\ 3\end{pmatrix}\text{.} \end{align*}
    🔗

    (a)

    Which matrix equation makes sense: \(Ax = b_1\) or \(Ax = b_2\text{?}\)
    🔗
    Solution.
    \(A\) is a \(2 \times 3\) matrix, so any solution \(x\) must be in \({\bf R}^3\) and the target vector must be in \({\bf R}^2\text{.}\) Therefore, \(Ax = b_2\) makes sense but \(Ax = b_1\) does not. One way to check this is to translate the matrix equation into a system of equations to confirm our answer, which we do in part (b).
    🔗
    🔗
    🔗

    (b)

    For the answer you chose in part (a), write the matrix equation as a system of equations.
    🔗
    Solution.
    The linear system corresponding to \(Ax = b_2\) is
    \begin{gather*} x_1 - 2x_2 + x_3 = 2 \end{gather*}
    \begin{gather*} 0x_1 + x_2 + 2x_3 = 3\text{.} \end{gather*}
    🔗
    🔗
    🔗

    (c)

    For the answer you chose in part (a), write the matrix equation as a vector equation.
    🔗
    Solution.
    The corresponding vector equation is
    \begin{gather*} x_1 \begin{pmatrix}1 \\ 0\end{pmatrix} + x_2 \begin{pmatrix}-2 \\ 1\end{pmatrix} + x_3 \begin{pmatrix}1 \\ 2\end{pmatrix} = \begin{pmatrix}2 \\ 3\end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    (d)

    Solve the matrix equation and write your answer in parametric vector form.
    🔗
    Solution.
    We row-reduce \((A \ | \ b_2)\text{:}\)
    \begin{align*} \left(\begin{array}{rrr|r}1 \amp -2 \amp 1 \amp 2 \\ 0 \amp 1 \amp 2 \amp 3\end{array}\right) \xrightarrow[]{R_1 = R_1 + 2R_2} \left(\begin{array}{rrr|r}1 \amp 0 \amp 5 \amp 8 \\ 0 \amp 1 \amp 2 \amp 3\end{array}\right)\text{.} \end{align*}
    This gives us \(x_1 + 5 x_3 = 8\) and \(x_2 + 2x_3 = 3\text{,}\) with \(x_3\) free.
    \begin{gather*} x_1 = 8 - 5x_3, \qquad x_2 = 3 - 2x_3, \qquad x_3 = x_3 \textup{ (free)}\text{.} \end{gather*}
    We finish the problem by putting this into parametric vector form:
    \begin{gather*} \begin{pmatrix}x_1 \\ x_2 \\ x_3\end{pmatrix} = \begin{pmatrix}8-5x_3 \\ 3-2x_3 \\ x_3\end{pmatrix} \ = \ \begin{pmatrix}8 \\ 3 \\ 0\end{pmatrix} + \begin{pmatrix}-5x_3 \\ -2x_3 \\ x_3\end{pmatrix} \ = \ \begin{pmatrix}8 \\ 3 \\ 0\end{pmatrix} + x_3 \begin{pmatrix}-5 \\ -2 \\ 1\end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗
    🔗

    13.

    Consider the system of equations in \(x_1\text{,}\) \(x_2\text{,}\) \(x_3\text{,}\) and \(x_4\) given below.
    \begin{gather*} x_1 - x_2 + 2x_3 - 2x_4 \ = \ -1 \end{gather*}
    \begin{gather*} -x_1 + x_2 -2x_3 + x_4 = \ 2 \end{gather*}
    \begin{gather*} -4x_1 + 4x_2 -8x_3 + 6x_4 \ = \ 6\text{.} \end{gather*}
    Put an augmented matrix into reduced row echelon form to solve the system of equations. Write your answer in parametric vector form.
    🔗
    Solution.
    \begin{align*} \left(\begin{array}{rrrr|r}1 \amp -1 \amp 2 \amp -2 \amp -1\\ -1 \amp 1 \amp -2 \amp 1 \amp 2\\ -4 \amp 4 \amp -8 \amp 6 \amp 6\end{array}\right) \amp \xrightarrow[R_3=R_3+4R_1]{R_2=R_2+R_1} \left(\begin{array}{rrrr|r}1 \amp -1 \amp 2 \amp -2 \amp -1\\ 0 \amp 0 \amp 0 \amp -1 \amp 1\\ 0 \amp 0 \amp 0 \amp -2 \amp 2\end{array}\right) \xrightarrow[R_3= R_3/-2]{R_2= \ -R_2} \left(\begin{array}{rrrr|r}1 \amp -1 \amp 2 \amp -2 \amp -1\\ 0 \amp 0 \amp 0 \amp 1 \amp -1\\ 0 \amp 0 \amp 0 \amp 1 \amp -1\end{array}\right)\\ \\ \amp \xrightarrow[R_1= R_1+2R_2]{R_3=R_3-R_2} \left(\begin{array}{rrrr|r}1 \amp -1 \amp 2 \amp 0 \amp -3\\ 0 \amp 0 \amp 0 \amp 1 \amp -1\\ 0 \amp 0 \amp 0 \amp 0 \amp 0\end{array}\right) \end{align*}
    🔗
    The free variables are \(x_2\) and \(x_3\text{:}\)
    \begin{gather*} x_1= x_2-2x_3-3, \qquad x_2=x_2, \qquad x_3=x_3, \qquad x_4= -1\text{.} \end{gather*}
    🔗
    \begin{gather*} \begin{pmatrix}x_1 \\ x_2 \\ x_3 \\ x_4\end{pmatrix} = \begin{pmatrix}x_2-2x_3-3 \\ x_2 \\ x_3 \\ -1\end{pmatrix} = \begin{pmatrix}x_2 \\ x_2 \\ 0 \\ 0\end{pmatrix} + \begin{pmatrix}-2x_3 \\ 0 \\ x_3 \\ 0\end{pmatrix} + \begin{pmatrix}-3 \\ 0 \\ 0 \\ -1\end{pmatrix} \ = \ \boxed{\begin{pmatrix}-3 \\ 0 \\ 0 \\ -1\end{pmatrix} + x_2 \begin{pmatrix}1 \\ 1 \\ 0 \\ 0\end{pmatrix} + x_3 \begin{pmatrix}-2 \\ 0 \\ 1 \\ 0\end{pmatrix}}\text{.} \end{gather*}
    🔗
    🔗

    14.

    Consider the linear system of equations in \(x_1\text{,}\) \(x_2\text{,}\) \(x_3\text{,}\) and \(x_4\) given below.
    \begin{gather*} -2x_1 - 2x_2 + x_3 - 4x_4 = -8 \end{gather*}
    \begin{gather*} -x_1 - x_2 + x_3 - 2x_4 = -5 \end{gather*}
    \begin{gather*} 4x_1 + 4x_2 - x_3 + 8x_4 = 14\text{.} \end{gather*}
    🔗

    (a)

    Write the set of solutions to the system in parametric vector form.
    🔗
    Solution.
    We put the system into an augmented matrix and row-reduce:
    \begin{align*} \left(\begin{array}{rrrr|r}-2 \amp -2 \amp 1 \amp -4 \amp -8 \\ -1 \amp -1 \amp 1 \amp -2 \amp -5 \\ 4 \amp 4 \amp -1 \amp 8 \amp 14\end{array}\right) \xrightarrow[]{RREF} \left(\begin{array}{rrrr|r}1 \amp 1 \amp 0 \amp 2 \amp 3 \\ 0 \amp 0 \amp 1 \amp 0 \amp -2 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0\end{array}\right)\text{.} \end{align*}
    Therefore, \(x_1 = 3 - x_2 - 2x_4\) and \(x_3 = -2\) while \(x_2\) and \(x_4\) are free:
    \begin{gather*} \begin{pmatrix}x_1 \\ x_2 \\ x_3 \\ x_4\end{pmatrix} = \begin{pmatrix}3-x_2-2x_4 \\ x_2 \\ -2 \\ x_4\end{pmatrix} = \boxed{\begin{pmatrix}3 \\ 0 \\ -2 \\ 0\end{pmatrix} + x_2 \begin{pmatrix}-1 \\ 1 \\ 0 \\ 0\end{pmatrix} + x_4 \begin{pmatrix}-2 \\ 0 \\ 0 \\ 1\end{pmatrix}}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    (b)

    Write two different solutions to the system of equations.
    🔗
    Solution.
    We can obtain a solution to the system by choosing any values we wish for \(x_2\) and \(x_4\text{.}\) For example, if we choose \(x_2 = 0\) and \(x_4 = 0\) we get
    \begin{gather*} \begin{pmatrix}x_1 \\ x_2 \\ x_3 \\ x_4\end{pmatrix} = \begin{pmatrix}3 \\ 0 \\ -2 \\ 0\end{pmatrix}\text{.} \end{gather*}
    If we choose \(x_2 = 1\) and \(x_4 = 0\) we get
    \begin{gather*} \begin{pmatrix}x_1 \\ x_2 \\ x_3 \\ x_4\end{pmatrix} = \begin{pmatrix}2 \\ 1 \\ -2 \\ 0\end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    (c)

    Write two nonzero solutions to the corresponding homogeneous linear system of equations.
    🔗
    Solution.
    The solutions to the corresponding homogeneous system (where \(-8\text{,}\) \(-5\text{,}\) and \(14\) are all replaced by zero) are given by everything in the span of the two vectors \(\begin{pmatrix}-1 \\ 1 \\ 0 \\ 0\end{pmatrix}\) and \(\begin{pmatrix}-2 \\ 0 \\ 0 \\ 1\end{pmatrix}\text{.}\) Therefore, \(\begin{pmatrix}-1 \\ 1 \\ 0 \\ 0\end{pmatrix}\) and \(\begin{pmatrix}-2 \\ 0 \\ 0 \\ 1\end{pmatrix}\) are two solutions to the homogeneous equations.

    15.

    Suppose \(A\) is a \(2 \times 2\) matrix and that for some vector \(b\text{,}\) the set of solutions to \(Ax = b\) is the line \(x_2 = 4-x_1\text{.}\) Write the general solution to the homogeneous equation \(Ax=0\) in parametric vector form.
    🔗
    Solution.
    The solution set for \(Ax = 0\) must include the origin and also must be a translate to the solution set to \(Ax = b\text{.}\) In other words, the solution set for \(Ax = 0\) is the line through the origin that is parallel to \(x_2 = 4-x_1\text{.}\) This is the line \(x_2 = -x_1\text{,}\) so \(x_1 = -x_2\) and \(x_2\) is free.
    \begin{gather*} \begin{pmatrix}x_1 \\ x_2\end{pmatrix} = \begin{pmatrix}-x_2 \\ x_2\end{pmatrix} = x_2 \begin{pmatrix}-1 \\ 1\end{pmatrix}\text{.} \end{gather*}
    Another way to do this problem is to draw the line \(x_2 = 4-x_1\text{,}\) then draw its parallel line through the origin and notice that this line is the span of \(\begin{pmatrix}-1 \\ 1\end{pmatrix}\) (or equivalently the span of \(\begin{pmatrix}1 \\ -1\end{pmatrix}\)).

    (c)

    Were we given enough information to know the exact values of \(x_1\text{,}\) \(x_2\text{,}\) and \(x_3\text{?}\) If your answer is yes, justify why. If your answer is no, give the range of possible values for \(x_1\text{,}\) \(x_2\text{,}\) and \(x_3\text{.}\)
    🔗
    Solution.
    We cannot know the exact values of \(x_1\text{,}\) \(x_2\text{,}\) and \(x_3\) with the information we have only been given. For example, we could have \(x_3=0\text{,}\) \(x_2 = 290\text{,}\) \(x_1=70\text{.}\) Or, we could have \(x_3= 100\text{,}\) \(x_2= 190\text{,}\) \(x_1=170\text{,}\) etc.
    🔗
    Even though \(x_3\) is a free variable in the system of equations, the real-world constraints of the problem make us consider what is actually possible here. Since the variables are counting the number of cars at each intersection, they must all be at least zero. Therefore, we need to have \(x_3 \geq 0\) (whereby \(x_1 = x_3 + 70\)), and since \(x_2 = 290-x_3 \geq 0\) we also need \(x_3 \leq 290\text{.}\)
    🔗
    To summarize: As the values of \(x_3\) range from \(0\) to \(290\text{,}\) the values of \(x_1\) range from \(70\) to \(360\) while the values for \(x_3\) range from \(290\) (when \(x_3=0\)) down to \(0\) (when \(x_3 = 290\)).
