    1.1.4.14.

    Solution.
    While Alice and Bob are alive, the difference between their ages is some constant \(c\) no matter what year we are in:
    \begin{gather*} (\textup{Alice's age}) - (\textup{Bob's age}) = c\text{.} \end{gather*}
    We’re told that alice is 24, so
    \begin{gather*} 24-(\textup{Bob's age now}) = c\text{.} \end{gather*}
    Also, from the information we are given, Bob was 12 when Alice was the same age that Bob is now.
    \begin{gather*} (\textup{Alice's age when Bob was 12}) - 12 = c, \quad \textup{ so} \quad (\textup{Bob's age now})-12 = c\text{.} \end{gather*}
    We have a system of two equations:
    \begin{gather*} 24-(\textup{Bob's age now}) = c \end{gather*}
    \begin{gather*} (\textup{Bob's age now}) - 12 = c\text{.} \end{gather*}
    Subtracting the first equation from the second, we get
    \begin{gather*} -36 + 2(\textup{Bob's age now}) = 0\text{,} \end{gather*}
    therefore Bob is now \(18\) years old and \(c = 6\) (\(c=6\) means Alice is \(6\) years older than Bob, which agrees with the fact that Alice is 24).

    Solution.

    \begin{align*} \left(\begin{array}{rrr|r}2 \amp -3 \amp 1 \amp 6\\ 1 \amp -1 \amp 0 \amp 4\\ 0 \amp 1 \amp -1 \amp 2\end{array}\right) \amp \xrightarrow[]{R_1 \leftrightarrow R_2} \left(\begin{array}{rrr|r}1 \amp -1 \amp 0 \amp 4\\ 2 \amp -3 \amp 1 \amp 6\\ 0 \amp 1 \amp -1 \amp 2\end{array}\right) \xrightarrow[]{R_2 = R_2 - 2 R_1} \left(\begin{array}{rrr|r}1 \amp -1 \amp 0 \amp 4\\ 0 \amp -1 \amp 1 \amp 2\\ 0 \amp 1 \amp -1 \amp 2\end{array}\right)\\ \amp \xrightarrow[\textup{then } R_3 = R_3 - R_2]{R_2 = (-1)*R_2} \left(\begin{array}{rrr|r}1 \amp -1 \amp 0 \amp 4\\ 0 \amp 1 \amp -1 \amp 2\\ 0 \amp 0 \amp 0 \amp 0\end{array}\right) \xrightarrow[]{R_1 = R_1 + R_2} \left(\begin{array}{rrr|r}1 \amp 0 \amp -1 \amp 6\\ 0 \amp 1 \amp -1 \amp 2\\ 0 \amp 0 \amp 0 \amp 0\end{array}\right)\text{.} \end{align*}
    Now that we have found the RREF of the matrix, we see that \((x_1, x_2, x_3)\) is a solution as long as \(x_1 - x_3 = 6\) and \(x_2 - x_3 = 2\text{.}\) To find a solution, we could just pre-set our favorite value for one of the variables and see if we could solve for the others. For example, if we set \(x_1 = 1\text{,}\) then to satisfy \(x_1 - x_3 = 6\) we need \(x_3 = -5\text{,}\) and now the second equation becomes
    \begin{gather*} x_2 - x_3 = 2, \qquad x_2 - (-5) = 2, \qquad x_2 = -3\text{.} \end{gather*}
    Therefore, \((1, -3, -5)\) is a solution.
    🔗
    To get a second solution, we could set \(x_3 = 0\) and solve for \(x_1\) and \(x_2\text{:}\) \(x_1 - x_3 = 6\) gives \(x_1 = 6\text{,}\) and then \(x_2-x_3 = 2\) gives \(x_2 = 2\text{,}\) so \((6, 2, 0)\) is a second solution.
    🔗
    In reality, there are infinitely many solutions to this system of equations. We’ll see in section 1.3 that this consistent system has \(x_3\) as a \emph{free} variable because its column does not have a pivot, which means that we can set \(x_3\) equal to any real number and then solve for \(x_1\) and \(x_2\text{.}\)
    🔗

    2.7.4.15.

    2.7.4.15.a

    Solution.
    A set of polynomials \(\{f_1, \ldots, f_k\}\) in \(W\) is linearly independent if the equation
    \begin{gather*} c_1 f_1 + \cdots + c_k f_k = {\bf 0} \end{gather*}
    has only the trivial solution \(c_1 = \cdots c_k = 0\text{.}\)
    🔗
    In other words, if
    \begin{gather*} c_1 f_1(x) + \cdots + c_k f_k(x) = 0 \end{gather*}
    for every real number \(x\text{,}\) then \(c_1 = \cdots c_k = 0\text{.}\)
    🔗
    🔗

    2.7.4.15.b

    Solution.
    A basis for \(W\) is \(\{f_1, f_2, f_3\}\) where
    \begin{gather*} f_1(x) = 1 + 0x + 0x^2, \qquad f_2(x) = 0 + 1x + 0x^2, \qquad f_3(x) = 0 + 0x + 1x^2\text{.} \end{gather*}
    🔗
    First we show that \(f_1, f_2\text{,}\) and \(f_3\) span \(W\text{.}\) Let \(f\) be any polynomial in \(W\text{.}\) Then for some \(a_0\text{,}\) \(a_1\text{,}\) and \(a_2\) we have
    \begin{gather*} f(x) = a_0 + a_1 x + a_2 x^2\text{,} \end{gather*}
    so \(f= a_0 f_1 + a_1 f_2 + a_2 f_3\) and therefore \(f\) is in \(\textup{Span}\{f_1, f_2, f_3\}\text{.}\)
    🔗
    Also, \(\{f_1, f_2, f_3\}\) is linearly independent: if
    \begin{gather*} {\bf 0} = c_1 f_1 + c_2 f_2 + c_3 f_3\text{,} \end{gather*}
    then for all \(x\) we have
    \begin{gather*} 0 = c_1 + c_2 x + c_3 x^2\text{.} \end{gather*}
    This means that the polynomial \(c_1 + c_2 x + c_3 x^2\) has infinitely many roots, which is only possible if all coefficients are \(0\) (otherwise, it would have a maximum of \(2\) roots).
