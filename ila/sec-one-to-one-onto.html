    Section 3.2 One-to-one and Onto Transformations

    Objectives

    1. Understand the definitions of one-to-one and onto transformations.
      🔗
      🔗
    2. Recipes: verify whether a matrix transformation is one-to-one and/or onto.
      🔗
      🔗
    3. Pictures: examples of matrix transformations that are/are not one-to-one and/or onto.
      🔗
      🔗
    4. Vocabulary words: one-to-one, onto.
      🔗
      🔗
    🔗
    In this section, we discuss two of the most basic questions one can ask about a transformation: whether it is one-to-one and/or onto. For a matrix transformation, we translate these questions into the language of matrices.
    🔗

    Subsection 3.2.1 One-to-one Transformations

    Definition 3.2.1 One-to-one transformations.

    A transformation \(T\colon\R^n\to\R^m\) is one-to-one if, for every vector \(b\) in \(\R^m\text{,}\) the equation \(T(x)=b\) has at most one solution \(x\) in \(\R^n\text{.}\)
    🔗
    🔗

    Remark 3.2.2.

    Another word for one-to-one is injective.
    🔗
    🔗
    Here are some equivalent ways of saying that \(T\) is one-to-one:
    • For every vector \(b\) in \(\R^m\text{,}\) the equation \(T(x) = b\) has zero or one solution \(x\) in \(\R^n\text{.}\)
      🔗
      🔗
    • Different inputs of \(T\) have different outputs.
      🔗
      🔗
    • If \(T(u) = T(v)\) then \(u=v\text{.}\)
      🔗
      🔗
    🔗
    
    🔗
    Here are some equivalent ways of saying that \(T\) is not one-to-one:
    • There exists some vector \(b\) in \(\R^m\) such that the equation \(T(x)=b\) has more than one solution \(x\) in \(\R^n\text{.}\)
      🔗
      🔗
    • There are two different inputs of \(T\) with the same output.
      🔗
      🔗
    • There exist vectors \(u,v\) such that \(u\neq v\) but \(T(u)=T(v)\text{.}\)
      🔗
      🔗
    🔗
    
    🔗

    Example 3.2.3 Functions of one variable.

    The function \(\sin\colon\R\to\R\) is not one-to-one. Indeed, \(\sin(0) = \sin(\pi) = 0\text{,}\) so the inputs \(0\) and \(\pi\) have the same output \(0\text{.}\) In fact, the equation \(\sin(x) = 0\) has infinitely many solutions \(\ldots,-2\pi,-\pi,0,\pi,2\pi,\ldots\text{.}\)
    🔗
    The function \(\exp\colon\R\to\R\) defined by \(\exp(x) = e^x\) is one-to-one. Indeed, if \(T(x) = T(y)\text{,}\) then \(e^x = e^y\text{,}\) so \(\ln(e^x) = \ln(e^y)\text{,}\) and hence \(x = y\text{.}\) The equation \(T(x) = C\) has one solution \(x = \ln(C)\) if \(C > 0\text{,}\) and it has zero solutions if \(C\leq 0\text{.}\)
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^3\) is one-to-one. Indeed, if \(f(x) = f(y)\) then \(x^3 = y^3\text{;}\) taking cube roots gives \(x = y\text{.}\) In other words, the only solution of \(f(x) = C\) is \(x=\sqrt[3]C\text{.}\)
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^3-x\) is not one-to-one. Indeed, \(f(0) = f(1) = f(-1) = 0\text{,}\) so the inputs \(0,1,-1\) all have the same output \(0\text{.}\) The solutions of the equation \(x^3 - x = 0\) are exactly the roots of \(f(x) = x(x-1)(x+1)\text{,}\) and this equation has three roots.
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^2\) is not one-to-one. Indeed, \(f(1) = 1 = f(-1)\text{,}\) so the inputs \(1\) and \(-1\) have the same outputs. The function \(g\colon\R\to\R\) defined by \(g(x)=|x|\) is not one-to-one for the same reason.
    🔗
    🔗

    Theorem 3.2.5 One-to-one matrix transformations.

    Let \(A\) be an \(m\times n\) matrix, and let \(T(x)=Ax\) be the associated matrix transformation. The following statements are equivalent:
    1. \(T\) is one-to-one.
      🔗
      🔗
    2. For every \(b\) in \(\R^m\text{,}\) the equation \(T(x)=b\) has at most one solution.
      🔗
      🔗
    3. For every \(b\) in \(\R^m\text{,}\) the equation \(Ax=b\) has a unique solution or is inconsistent.
      🔗
      🔗
    4. \(Ax=0\) has only the trivial solution.
      🔗
      🔗
    5. The columns of \(A\) are linearly independent.
      🔗
      🔗
    6. \(A\) has a pivot in every column.
      🔗
      🔗
    7. The range of \(T\) has dimension \(n\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    Statements 1, 2, and 3 are translations of each other. The equivalence of 3 and 4 follows from Note : if \(Ax=0\) has only one solution, then \(Ax=b\) has only one solution as well, or it is inconsistent. The equivalence of 4, 5, and 6 is a consequence of Recipe 9 of Section 2.5, and the equivalence of 6 and 7 follows from the fact that the rank of a matrix is equal to the number of columns with pivots.
    🔗
    🔗
    Recall that equivalent means that, for a given matrix, either all of the statements are true simultaneously, or they are all false.
    🔗

    Example 3.2.6 A matrix transformation that is one-to-one.

    Let \(A\) be the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^2\to\R^3\) by \(T(x) = Ax\text{.}\) Is \(T\) one-to-one?
    🔗

    Solution.

    The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    Hence \(A\) has a pivot in every column, so \(T\) is one-to-one.
    🔗
    🔗
    🔗

    Example 3.2.8 A matrix transformation that is not one-to-one.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^3\) by \(T(x) = Ax\text{.}\) Is \(T\) one-to-one? If not, find two different vectors \(u,v\) such that \(T(u)=T(v)\text{.}\)
    🔗

    Solution.

    The matrix \(A\) is already in reduced row echelon form. It does not have a pivot in every column, so \(T\) is not one-to-one. Therefore, we know from the Theorem 5 that \(Ax=0\) has nontrivial solutions. If \(v\) is a nontrivial (i.e., nonzero) solution of \(Av = 0\text{,}\) then \(T(v) = Av = 0 = A0 = T(0)\text{,}\) so \(0\) and \(v\) are different vectors with the same output. For instance,
    \begin{align*} T\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix}\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = 0 = T\begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{align*}
    🔗
    Geometrically, \(T\) is projection onto the \(xy\)-plane. Any two vectors that lie on the same vertical line will have the same projection. For \(b\) on the \(xy\)-plane, the solution set of \(T(x) = b\) is the entire vertical line containing \(b\text{.}\) In particular, \(T(x) = b\) has infinitely many solutions.
    🔗
    🔗
    🔗

    Example 3.2.10 A matrix transformation that is not one-to-one.

    Let \(A\) be the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) Is \(T\) one-to-one? If not, find two different vectors \(u,v\) such that \(T(u)=T(v)\text{.}\)
    🔗

    Solution.

    The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    There is not a pivot in every column, so \(T\) is not one-to-one. Therefore, we know from the Theorem 5 that \(Ax=0\) has nontrivial solutions. If \(v\) is a nontrivial (i.e., nonzero) solution of \(Av = 0\text{,}\) then \(T(v) = Av = 0 = A0 = T(0)\text{,}\) so \(0\) and \(v\) are different vectors with the same output. In order to find a nontrivial solution, we find the parametric form of the solutions of \(Ax=0\) using the reduced matrix above:
    \begin{align*} \left\{\begin{alignedat}{4} x \amp {} \amp {} \amp {} \amp z \amp {}={} \amp 0 \amp {} \\ {} \amp {} \amp y \amp {}+{} \amp z \amp {}={} \amp 0 \amp {} \end{alignedat}\right. \quad\implies\quad \left\{\begin{alignedat}{2} x \amp {}={} \amp z \amp {} \\ y \amp {}={} \amp -z \amp {} \end{alignedat}\right\text{.} \end{align*}
    The free variable is \(z\text{.}\) Taking \(z=1\) gives the nontrivial solution
    \begin{align*} T\begin{pmatrix} 1 \\ -1 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \end{pmatrix}\begin{pmatrix} 1 \\ -1 \\ 1 \end{pmatrix} = 0 = T\begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗

    Example 3.2.12 A matrix transformation that is not one-to-one.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) Is \(T\) one-to-one? If not, find two different vectors \(u,v\) such that \(T(u)=T(v)\text{.}\)
    🔗

    Solution.

    The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    There is not a pivot in every column, so \(T\) is not one-to-one. Therefore, we know from the Theorem 5 that \(Ax=0\) has nontrivial solutions. If \(v\) is a nontrivial (i.e., nonzero) solution of \(Av = 0\text{,}\) then \(T(v) = Av = 0 = A0 = T(0)\text{,}\) so \(0\) and \(v\) are different vectors with the same output. In order to find a nontrivial solution, we find the parametric form of the solutions of \(Ax=0\) using the reduced matrix above:
    \begin{gather*} x - y + 2z = 0 \quad\implies\quad x = y - 2z\text{.} \end{gather*}
    The free variables are \(y\) and \(z\text{.}\) Taking \(y=1\) and \(z=0\) gives the nontrivial solution
    \begin{align*} T\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = 0 = T\begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\text{.} \end{align*}
    🔗
    🔗
    🔗
    The previous three examples can be summarized as follows. Suppose that \(T(x)=Ax\) is a matrix transformation that is not one-to-one. By the Theorem 5, there is a nontrivial solution of \(Ax=0\text{.}\) This means that the null space of \(A\) is not the zero space. All of the vectors in the null space are solutions to \(T(x)=0\text{.}\) If you compute a nonzero vector \(v\) in the null space (by row reducing and finding the parametric form of the solution set of \(Ax=0\text{,}\) for instance), then \(v\) and \(0\) both have the same output: \(T(v) = Av = 0 = T(0).\)
    🔗

    Note 3.2.14 Wide matrices do not have one-to-one transformations.

    If \(T\colon\R^n\to\R^m\) is a one-to-one matrix transformation, what can we say about the relative sizes of \(n\) and \(m\text{?}\)
    🔗
    The matrix associated to \(T\) has \(n\) columns and \(m\) rows. Each row and each column can only contain one pivot, so in order for \(A\) to have a pivot in every column, it must have at least as many rows as columns: \(n\leq m\text{.}\)
    🔗
    This says that, for instance, \(\R^3\) is “too big” to admit a one-to-one linear transformation into \(\R^2\text{.}\)
    🔗
    Note that there exist tall matrices that are not one-to-one: for example,
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{pmatrix} \end{align*}
    does not have a pivot in every column.
    🔗
    🔗
    🔗

    Subsection 3.2.2 Onto Transformations

    Definition 3.2.15 Onto transformations.

    A transformation \(T\colon\R^n\to\R^m\) is onto if, for every vector \(b\) in \(\R^m\text{,}\) the equation \(T(x)=b\) has at least one solution \(x\) in \(\R^n\text{.}\)
    🔗
    🔗

    Remark 3.2.16.

    Another word for onto is surjective.
    🔗
    🔗
    Here are some equivalent ways of saying that \(T\) is onto:
    • The range of \(T\) is equal to the codomain of \(T\text{.}\)
      🔗
      🔗
    • Every vector in the codomain is the output of some input vector.
      🔗
      🔗
    🔗
    
    🔗
    Here are some equivalent ways of saying that \(T\) is not onto:
    • The range of \(T\) is smaller than the codomain of \(T\text{.}\)
      🔗
      🔗
    • There exists a vector \(b\) in \(\R^m\) such that the equation \(T(x)=b\) does not have a solution.
      🔗
      🔗
    • There is a vector in the codomain that is not the output of any input vector.
      🔗
      🔗
    🔗
    
    🔗

    Example 3.2.17 Functions of one variable.

    The function \(\sin\colon\R\to\R\) is not onto. Indeed, taking \(b=2\text{,}\) the equation \(\sin(x)=2\) has no solution. The range of \(\sin\) is the closed interval \([-1,1]\text{,}\) which is smaller than the codomain \(\R\text{.}\)
    🔗
    The function \(\exp\colon\R\to\R\) defined by \(\exp(x) = e^x\) is not onto. Indeed, taking \(b=-1\text{,}\) the equation \(\exp(x) = e^x = -1\) has no solution. The range of \(\exp\) is the set \((0,\infty)\) of all positive real numbers.
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^3\) is onto. Indeed, the equation \(f(x) = x^3 = b\) always has the solution \(x = \sqrt[3]b\text{.}\)
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^3-x\) is onto. Indeed, the solutions of the equation \(f(x) = x^3 - x = b\) are the roots of the polynomial \(x^3 - x - b\text{;}\) as this is a cubic polynomial, it has at least one real root.
    🔗
    🔗

    Example 3.2.18 A real-word transformation: robotics.

    The robot arm transformation of Example 4 is not onto. The robot cannot reach objects that are very far away.
    🔗
    🔗

    Theorem 3.2.19 Onto matrix transformations.

    Let \(A\) be an \(m\times n\) matrix, and let \(T(x)=Ax\) be the associated matrix transformation. The following statements are equivalent:
    1. \(T\) is onto.
      🔗
      🔗
    2. \(T(x)=b\) has at least one solution for every \(b\) in \(\R^m\text{.}\)
      🔗
      🔗
    3. \(Ax=b\) is consistent for every \(b\) in \(\R^m\text{.}\)
      🔗
      🔗
    4. The columns of \(A\) span \(\R^m\text{.}\)
      🔗
      🔗
    5. \(A\) has a pivot in every row.
      🔗
      🔗
    6. The range of \(T\) has dimension \(m\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    Statements 1, 2, and 3 are translations of each other. The equivalence of 3, 4, 5, and 6 follows from Theorem 16 of Section 2.3.
    🔗
    🔗

    Example 3.2.20 A matrix transformation that is onto.

    Let \(A\) be the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) Is \(T\) onto?
    🔗

    Solution.

    The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp 1 \end{pmatrix}\text{.} \end{align*}
    Hence \(A\) has a pivot in every row, so \(T\) is onto.
    🔗
    🔗
    🔗

    Example 3.2.22 A matrix transformation that is not onto.

    Let \(A\) be the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^2\to\R^3\) by \(T(x) = Ax\text{.}\) Is \(T\) onto? If not, find a vector \(b\) in \(\R^3\) such that \(T(x)=b\) has no solution.
    🔗

    Solution.

    The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    Hence \(A\) does not have a pivot in every row, so \(T\) is not onto. In fact, since
    \begin{align*} T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} x \\ y \\ x \end{pmatrix}\text{,} \end{align*}
    we see that for every output vector of \(T\text{,}\) the third entry is equal to the first. Therefore,
    \begin{gather*} b=(1,2,3) \end{gather*}
    is not in the range of \(T\text{.}\)
    🔗
    🔗
    🔗

    Example 3.2.24 A matrix transformation that is not onto.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) Is \(T\) onto? If not, find a vector \(b\) in \(\R^2\) such that \(T(x)=b\) has no solution.
    🔗

    Solution.

    The reduced row echelon form of \(A\) is
    \begin{align*} \begin{pmatrix} 1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 0 \end{pmatrix}\text{.} \end{align*}
    There is not a pivot in every row, so \(T\) is not onto. The range of \(T\) is the column space of \(A\text{,}\) which is equal to
    \begin{gather*} \Span\left\{\begin{pmatrix} 1 \\ -2 \end{pmatrix},\;\begin{pmatrix} -1 \\ 2 \end{pmatrix},\;\begin{pmatrix} 2 \\ -4 \end{pmatrix}\right\} = \Span\left\{\begin{pmatrix} 1 \\ -2 \end{pmatrix}\right\}\text{,} \end{gather*}
    since all three columns of \(A\) are collinear. Therefore, any vector not on the line through \(1\choose-2\) is not in the range of \(T\text{.}\) For instance, if \(b={1\choose 1}\) then \(T(x)=b\) has no solution.
    🔗
    🔗
    🔗
    The previous two examples illustrate the following observation. Suppose that \(T(x)=Ax\) is a matrix transformation that is not onto. This means that \(\text{range}(T) = \Col(A)\) is a subspace of \(\R^m\) of dimension less than \(m\text{:}\) perhaps it is a line in the plane, or a line in \(3\)-space, or a plane in \(3\)-space, etc. Whatever the case, the range of \(T\) is very small compared to the codomain. To find a vector not in the range of \(T\text{,}\) choose a random nonzero vector \(b\) in \(\R^m\text{;}\) you have to be extremely unlucky to choose a vector that is in the range of \(T\text{.}\) Of course, to check whether a given vector \(b\) is in the range of \(T\text{,}\) you have to solve the matrix equation \(Ax=b\) to see whether it is consistent.
    🔗

    Note 3.2.26 Tall matrices do not have onto transformations.

    If \(T\colon\R^n\to\R^m\) is an onto matrix transformation, what can we say about the relative sizes of \(n\) and \(m\text{?}\)
    🔗
    The matrix associated to \(T\) has \(n\) columns and \(m\) rows. Each row and each column can only contain one pivot, so in order for \(A\) to have a pivot in every row, it must have at least as many columns as rows: \(m\leq n\text{.}\)
    🔗
    This says that, for instance, \(\R^2\) is “too small” to admit an onto linear transformation to \(\R^3\text{.}\)
    🔗
    Note that there exist wide matrices that are not onto: for example,
    \begin{align*} \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix} \end{align*}
    does not have a pivot in every row.
    🔗
    🔗

    Subsection 3.2.3 Comparison

    The above expositions of one-to-one and onto transformations were written to mirror each other. However, “one-to-one” and “onto” are complementary notions: neither one implies the other. Below we have provided a chart for comparing the two. In the chart, \(A\) is an \(m\times n\) matrix, and \(T\colon\R^n\to\R^m\) is the matrix transformation \(T(x)=Ax\text{.}\) \parbox{2.5in}{\centering% \textbf{$T$ is one-to-one}\\[3mm] $T(x)=b$ has \emph{at most one solution} for every $b$.\\[3mm] The columns of $A$ are linearly independent.\\[3mm] $A$ has a pivot in every column.\\[3mm] The range of $T$ has dimension $n$. }\qquad\parbox{2.5in}{\centering% \textbf{$T$ is onto}\\[3mm] $T(x)=b$ has \emph{at least one solution} for every $b$.\\[3mm] The columns of $A$ span $\R^m$.\\~\\[3mm] $A$ has a pivot in every row.\\[3mm] The range of $T$ has dimension $m$. }
    🔗

    Example 3.2.27 Functions of one variable.

    The function \(\sin\colon\R\to\R\) is neither one-to-one nor onto.
    🔗
    The function \(\exp\colon\R\to\R\) defined by \(\exp(x) = e^x\) is one-to-one but not onto.
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^3\) is one-to-one and onto.
    🔗
    The function \(f\colon\R\to\R\) defined by \(f(x)=x^3-x\) is onto but not one-to-one.
    🔗
    🔗

    Example 3.2.28 A matrix transformation that is neither one-to-one nor onto.

    Let
    \begin{align*} A = \begin{pmatrix} 1 \amp -1 \amp 2 \\ -2 \amp 2 \amp -4 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) This transformation is neither one-to-one nor onto, as we saw in Example 12 and Example 24.
    🔗
    🔗

    Example 3.2.30 A matrix transformation that is one-to-one but not onto.

    Let \(A\) be the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^2\to\R^3\) by \(T(x) = Ax\text{.}\) This transformation is one-to-one but not onto, as we saw in Example 6 and Example 22.
    🔗
    🔗

    Example 3.2.32 A matrix transformation that is onto but not one-to-one.

    Let \(A\) be the matrix
    \begin{align*} A = \begin{pmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \end{pmatrix}\text{,} \end{align*}
    and define \(T\colon\R^3\to\R^2\) by \(T(x) = Ax\text{.}\) This transformation is onto but not one-to-one, as we saw in Example 20 and Example 20.

    Example 3.2.34 Matrix transformations that are both one-to-one and onto.

    In Subsection 3.1.1, we discussed the transformations defined by several \(2\times 2\) matrices, namely:
    \begin{align*} \text{Reflection:} \amp\qquad A=\begin{pmatrix} -1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Dilation:} \amp\qquad A=\begin{pmatrix} 1.5 \amp 0 \\ 0 \amp 1.5 \end{pmatrix}\\ \text{Identity:} \amp\qquad A=\begin{pmatrix} 1 \amp 0 \\ 0 \amp 1 \end{pmatrix}\\ \text{Rotation:} \amp\qquad A=\begin{pmatrix} 0 \amp -1 \\ 1 \amp 0 \end{pmatrix}\\ \text{Shear:} \amp\qquad A=\begin{pmatrix} 1 \amp 1 \\ 0 \amp 1 \end{pmatrix}\text{.} \end{align*}
    In each case, the associated matrix transformation \(T(x)=Ax\) is both one-to-one and onto. A \(2\times 2\) matrix \(A\) has a pivot in every row if and only if it has a pivot in every column (if and only if it has two pivots), so in this case, the transformation \(T\) is one-to-one if and only if it is onto. One can see geometrically that they are onto (what is the input for a given output?), or that they are one-to-one using the fact that the columns of \(A\) are not collinear.
    🔗
    🔗

    Note 3.2.36 One-to-one is the same as onto for square matrices.

    We observed in Example 34 that a square matrix has a pivot in every row if and only if it has a pivot in every column. Therefore, a matrix transformation \(T\) from \(\R^n\) to itself is one-to-one if and only if it is onto: in this case, the two notions are equivalent.
    🔗
    Conversely, by Note 14 and Note 26, if a matrix transformation \(T\colon\R^m\to\R^n\) is both one-to-one and onto, then \(m=n\text{.}\)
    🔗
    🔗
    Note that in general, a transformation \(T\) is both one-to-one and onto if and only if \(T(x)=b\) has exactly one solution for all \(b\) in \(\R^m\text{.}\)
