    Section 6.4 Orthogonal Sets

    Objectives

    1. Understand which is the best method to use to compute an orthogonal projection in a given situation.
      🔗
      🔗
    2. Recipes: an orthonormal set from an orthogonal set, Projection Formula, \(\cB\)-coordinates when \(\cB\) is an orthogonal set, Gram–Schmidt process.
      🔗
      🔗
    3. Vocabulary words: orthogonal set, orthonormal set.
      🔗
      🔗
    🔗
    In this section, we give a formula for orthogonal projection that is considerably simpler than the one in Section 6.3, in that it does not require row reduction or matrix inversion. However, this formula, called the Projection Formula, only works in the presence of an orthogonal basis. We will also present the Gram–Schmidt process for turning an arbitrary basis into an orthogonal one.
    🔗

    Subsection 6.4.1 Orthogonal Sets and the Projection Formula

    Computations involving projections tend to be much easier in the presence of an orthogonal set of vectors.
    🔗

    Definition 6.4.1.

    A set of nonzero vectors \(\{u_1,u_2,\ldots,u_m\}\) is called orthogonal if \(u_i\cdot u_j = 0\) whenever \(i\neq j\text{.}\) It is orthonormal if it is orthogonal, and in addition \(u_i\cdot u_i = 1\) for all \(i=1,2,\ldots,m\text{.}\)
    🔗
    🔗
    In other words, a set of vectors is orthogonal if different vectors in the set are perpendicular to each other. An orthonormal set is an orthogonal set of unit vectors.
    🔗

    Example 6.4.2.

    The standard coordinate vectors in \(\R^n\) always form an orthonormal set. For instance, in \(\R^3\) we check that
    \begin{gather*} \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\cdot\begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix} = 0 \qquad \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}\cdot\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = 0 \qquad \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}\cdot\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = 0\text{.} \end{gather*}
    Since \(e_i\cdot e_i = 1\) for all \(i=1,2,3\text{,}\) this shows that \(\{e_1,e_2,e_3\}\) is orthonormal.
    🔗
    
    🔗
    🔗

    Example 6.4.3.

    Is this set orthogonal? Is it orthonormal?
    \begin{gather*} \cB = \left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} 1 \\ -2 \\ 1 \end{pmatrix},\;\begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix}\right\} \end{gather*}
    🔗

    Solution.

    We check that
    \begin{gather*} \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\cdot\begin{pmatrix} 1 \\ -2 \\ 1 \end{pmatrix} = 0 \qquad \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\cdot\begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix} = 0 \qquad \begin{pmatrix} 1 \\ -2 \\ 1 \end{pmatrix}\cdot\begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix} = 0\text{.} \end{gather*}
    Therefore, \(\cB\) is orthogonal.
    🔗
    
    🔗
    The set \(\cB\) is not orthonormal because, for instance,
    \begin{gather*} \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} \cdot \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} = 3 \neq 1\text{.} \end{gather*}
    However, we can make it orthonormal by replacing each vector by the unit vector in the direction of each vector:
    \begin{gather*} \left\{\frac 1{\sqrt3}\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\frac 1{\sqrt6}\begin{pmatrix} 1 \\ -2 \\ 1 \end{pmatrix},\; \frac 1{\sqrt2}\begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix}\right\} \end{gather*}
    is orthonormal.
    🔗
    🔗
    🔗
    We saw in the previous example that it is easy to produce an orthonormal set of vectors from an orthogonal one by replacing each vector with the unit vector in the same direction.
    🔗

    Recipe 6.4.4 An orthonormal set from an orthogonal set.

    If \(\{v_1,v_2,\ldots,v_m\}\) is an orthogonal set of vectors, then
    \begin{gather*} \left\{\frac{v_1}{\|v_1\|},\;\frac{v_2}{\|v_2\|},\ldots,\;\frac{v_m}{\|v_m\|}\right\} \end{gather*}
    is an orthonormal set.
    🔗
    🔗

    Example 6.4.5.

    Let \(a,b\) be scalars, and let
    \begin{gather*} u_1 = \begin{pmatrix} a \\ b \end{pmatrix} \qquad u_2 = \begin{pmatrix} -b \\ a \end{pmatrix}\text{.} \end{gather*}
    Is \(\cB = \{u_1,u_2\}\) orthogonal?
    🔗

    Solution.

    We only have to check that
    \begin{gather*} \begin{pmatrix} a \\ b \end{pmatrix}\cdot\begin{pmatrix} -b \\ a \end{pmatrix} = -ab + ab = 0\text{.} \end{gather*}
    Therefore, \(\{u_1,u_2\}\) is orthogonal, unless \(a=b=0\text{.}\)
    🔗
    🔗
    🔗

    Example 6.4.6.

    Is this set orthogonal?
    \begin{gather*} \cB = \left\{\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix},\;\begin{pmatrix} 1 \\ -2 \\ 1 \end{pmatrix},\;\begin{pmatrix} 1 \\ -1 \\ -1 \end{pmatrix}\right\} \end{gather*}
    🔗

    Solution.

    This set is not orthogonal because
    \begin{gather*} \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\cdot\begin{pmatrix} 1 \\ -1 \\ -1 \end{pmatrix} = 1-1-1 = -1 \neq 0\text{.} \end{gather*}
    We will see how to produce an orthogonal set from \(\cB\) in Subsection 6.4.2.
    🔗
    🔗
    🔗
    A nice property enjoyed by orthogonal sets is that they are automatically linearly independent.
    🔗

    Fact 6.4.7.

    An orthogonal set is linearly independent. Therefore, it is a basis for its span.
    🔗
    🔗

    Proof.
    Suppose that \(\{u_1,u_2,\ldots,u_m\}\) is orthogonal. We need to show that the equation
    \begin{gather*} c_1u_1 + c_2u_2 + \cdots + c_mu_m = 0 \end{gather*}
    has only the trivial solution \(c_1=c_2=\cdots=c_m=0\text{.}\) Taking the dot product of both sides of this equation with \(u_1\) gives
    \begin{align*} 0 = u_1\cdot 0 \amp= u_1\cdot\bigl(c_1u_1 + c_2u_2 + \cdots + c_mu_m\bigr)\\ \amp= c_1(u_1\cdot u_1) + c_2(u_1\cdot u_2) + \cdots + c_m(u_1\cdot u_m)\\ \amp= c_1(u_1\cdot u_1) \end{align*}
    because \(u_1\cdot u_i = 0\) for \(i > 1\text{.}\) Since \(u_1\neq 0\) we have \(u_1\cdot u_1\neq 0\text{,}\) so \(c_1 = 0\text{.}\) Similarly, taking the dot product with \(u_i\) shows that each \(c_i = 0\text{,}\) as desired.
    🔗
    🔗
    One advantage of working with orthogonal sets is that it gives a simple formula for the orthogonal projection of a vector.
    🔗

    Theorem 6.4.8.

    Let \(W\) be a subspace of \(\R^n\text{,}\) and let \(\{u_1,u_2,\ldots,u_m\}\) be an orthogonal basis for \(W\text{.}\) Then for any vector \(x\) in \(\R^n\text{,}\) the orthogonal projection of \(x\) onto \(W\) is given by the formula
    \begin{gather*} x_W = \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \cdots + \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m\text{.} \end{gather*}
    🔗
    🔗

    Proof.
    Let
    \begin{gather*} y = \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \cdots + \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m\text{.} \end{gather*}
    This vector is contained in \(W\) because it is a linear combination of \(u_1,u_2,\ldots,u_m\text{.}\) Hence we just need to show that \(x - y\) is in \(W^\perp\text{,}\) i.e., that \(u_i\cdot (x-y) = 0\) for each \(i=1,2,\ldots,m\text{.}\) For \(u_1\text{,}\) we have
    \begin{align*} u_1\cdot(x-y) \amp= u_1\cdot\left( x - \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 - \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 - \cdots - \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m \right)\\ \amp= u_1\cdot x - \frac{x\cdot u_1}{u_1\cdot u_1}(u_1\cdot u_1) - 0 - \cdots - 0\\ \amp= 0\text{.} \end{align*}
    A similar calculation shows that \(u_i\cdot(x-y) = 0\) for each \(i\text{,}\) so \(x-y\) is in \(W^\perp\text{,}\) as desired.
    🔗
    🔗
    If \(\{u_1,u_2,\ldots,u_m\}\) is an orthonormal basis for \(W\text{,}\) then the denominators \(u_i\cdot u_i = 1\) go away, so the projection formula becomes even simpler:
    \begin{gather*} x_W = (x\cdot u_1)\,u_1 + (x\cdot u_2)\,u_2 + \cdots + (x\cdot u_m)\,u_m\text{.} \end{gather*}
    🔗

    Example 6.4.9.

    Suppose that \(L = \Span\{u\}\) is a line. The set \(\{u\}\) is an orthogonal basis for \(L\text{,}\) so the Projection Formula says that for any vector \(x\text{,}\) we have
    \begin{gather*} x_L = \frac{x\cdot u}{u\cdot u}\,u\text{,} \end{gather*}
    as in Example 15 of Section 6.3. See also Example 18 of Section 6.3 and Example 20 of Section 6.3.
    🔗
    🔗
    Suppose that \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal basis for a subspace \(W\text{,}\) and let \(L_i = \Span\{u_i\}\) for each \(i=1,2,\ldots,m\text{.}\) Then we see that for any vector \(x\text{,}\) we have
    \begin{align*} \spalignsysdelims.. \left\{\begin{alignedat}{2} x_W \amp {}={} \amp \dfrac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \dfrac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \cdots, + \dfrac{x\cdot u_m}{u_m\cdot u_m}\,u_m \amp {} \\ {} \amp {}={} \amp \vphantom{\frac{u_1}{u_1}}x_{L_1}\hfil, + x_{L_2}\hfil, + \cdots, + x_{L_m}\hfil \amp . \end{alignedat}\right\text{.} \end{align*}
    In other words, for an orthogonal basis, the projection of \(x\) onto \(W\) is the sum of the projections onto the lines spanned by the basis vectors. In this sense, projection onto a line is the most important example of an orthogonal projection.
    🔗

    Example 6.4.10 Projection onto the \(xy\)-plane.

    Continuing with Example 4 of Section 6.3 and Example 23 of Section 6.3, use the Theorem 8 to compute the orthogonal projection of a vector onto the \(xy\)-plane in \(\R^3\text{.}\)
    🔗

    Solution.

    A basis for the \(xy\)-plane is given by the two standard coordinate vectors
    \begin{gather*} e_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \qquad e_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    The set \(\{e_1,e_2\}\) is orthogonal, so for any vector \(x = (x_1,x_2,x_3)\text{,}\) we have
    \begin{gather*} x_W = \frac{x\cdot e_1}{e_1\cdot e_1}\,e_1 + \frac{x\cdot e_2}{e_2\cdot e_2}\,e_2 = x_1e_1 + x_2e_2 = \begin{pmatrix} x_1 \\ x_2 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    Example 6.4.12 Projection onto a plane in \(\R^3\).

    Let
    \begin{gather*} W = \Span\left\{\begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix},\;\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\right\} \qquad x = \begin{pmatrix} 2 \\ 3 \\ -2 \end{pmatrix}\text{.} \end{gather*}
    Find \(x_W\) and \(x_{W^\perp}\text{.}\)
    🔗

    Solution.

    The vectors
    \begin{gather*} u_1 = \begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix} \qquad u_2 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} \end{gather*}
    are orthogonal, so we can use the Projection Formula:
    \begin{gather*} x_W = \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 = \frac{4}{2}\begin{pmatrix} 1 \\ 0 \\ -1 \end{pmatrix} + \frac{3}{3}\begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 3 \\ 1 \\ -1 \end{pmatrix}\text{.} \end{gather*}
    Then we have
    \begin{gather*} x_{W^\perp} = x - x_W = \begin{pmatrix} -1 \\ 2 \\ -1 \end{pmatrix}\text{.} \end{gather*}
    🔗
    🔗
    🔗

    Example 6.4.14 Projection onto a \(3\)-space in \(\R^4\).

    Let
    \begin{gather*} W = \Span\left\{\begin{pmatrix} 1 \\ 0 \\ -1 \\ 0 \end{pmatrix},\;\begin{pmatrix} 0 \\ 1 \\ 0 \\ -1 \end{pmatrix},\;\begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix}\right\} \qquad x = \begin{pmatrix} 0 \\ 1 \\ 3 \\ 4 \end{pmatrix}\text{.} \end{gather*}
    Compute \(x_W\text{,}\) and find the distance from \(x\) to \(W\text{.}\)
    🔗

    Solution.

    The vectors
    \begin{gather*} u_1 = \begin{pmatrix} 1 \\ 0 \\ -1 \\ 0 \end{pmatrix} \qquad u_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \\ -1 \end{pmatrix} \qquad u_3 = \begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix} \end{gather*}
    are orthogonal, so we can use the Projection Formula:
    \begin{align*} x_W \amp= \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \frac{x\cdot u_3}{u_3\cdot u_3}\,u_3\\ \amp= \frac{-3}{2}\begin{pmatrix} 1 \\ 0 \\ -1 \\ 0 \end{pmatrix} + \frac{-3}{2}\begin{pmatrix} 0 \\ 1 \\ 0 \\ -1 \end{pmatrix} + \frac{8}{4}\begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix} = \frac 12\begin{pmatrix} 1 \\ 1 \\ 7 \\ 7 \end{pmatrix}\\ x_{W^\perp} \amp= x - x_W = \frac 12\begin{pmatrix} -1 \\ 1 \\ -1 \\ 1 \end{pmatrix}\text{.} \end{align*}
    The distance from \(x\) to \(W\) is
    \begin{gather*} \|x_{W^\perp}\| = \frac 12\sqrt{1+1+1+1} = 1\text{.} \end{gather*}
    🔗
    🔗
    🔗
    Now let \(W\) be a subspace of \(\R^n\) with orthogonal basis \(\cB=\{v_1,v_2,\ldots,v_m\}\text{,}\) and let \(x\) be a vector in \(W\text{.}\) Then \(x = x_W\text{,}\) so by the Theorem 8, we have
    \begin{gather*} x = x_W = \frac{x\cdot u_1}{u_1\cdot u_1}\,u_1 + \frac{x\cdot u_2}{u_2\cdot u_2}\,u_2 + \cdots + \frac{x\cdot u_m}{u_m\cdot u_m}\,u_m\text{.} \end{gather*}
    This gives us a way of expressing \(x\) as a linear combination of the basis vectors in \(\cB\text{:}\) we have computed the \(\cB\)-coordinates of \(x\) without row reducing!
    🔗

    Recipe 6.4.15 \(\cB\)-coordinates when \(\cB\) is an orthogonal set.

    Let \(W\) be a subspace of \(\R^n\) with orthogonal basis \(\cB=\{v_1,v_2,\ldots,v_m\}\) and let \(x\) be a vector in \(W\text{.}\) Then
    \begin{gather*} [x]_\cB = \left( \frac{x\cdot u_1}{u_1\cdot u_1},\; \frac{x\cdot u_2}{u_2\cdot u_2},\; \ldots,\; \frac{x\cdot u_m}{u_m\cdot u_m} \right)\text{.} \end{gather*}
    🔗
    🔗
    As with orthogonal projections, if \(\{u_1,u_2,\ldots,u_m\}\) is an orthonormal basis of \(W\text{,}\) then the formula is even simpler:
    \begin{gather*} [x]_\cB = \bigl(x\cdot u_1,\; x\cdot u_2,\; \ldots,\; x\cdot u_m\bigr)\text{.} \end{gather*}
    🔗

    Example 6.4.16 Computing coordinates with respect to an orthogonal basis.

    Find the \(\cB\)-coordinates of \(x\text{,}\) where
    \begin{gather*} \cB = \left\{ \begin{pmatrix} 1 \\ 2 \end{pmatrix},\;\begin{pmatrix} -4 \\ 2 \end{pmatrix} \right\} \qquad x = \begin{pmatrix} 0 \\ 3 \end{pmatrix}\text{.} \end{gather*}
    🔗

    Solution.

    Since
    \begin{gather*} u_1 = \begin{pmatrix} 1 \\ 2 \end{pmatrix} \qquad u_2 = \begin{pmatrix} -4 \\ 2 \end{pmatrix} \end{gather*}
    form an orthogonal basis of \(\R^2\text{,}\) we have
    \begin{gather*} [x]_\cB = \left(\frac{x\cdot u_1}{u_1\cdot u_1},\; \frac{x\cdot u_2}{u_2\cdot u_2} \right) = \left(\frac{3\cdot 2}{1^2+2^2},\; \frac{3\cdot 2}{(-4)^2+2^2} \right) = \left(\frac 65,\;\frac 3{10} \right)\text{.} \end{gather*}
    🔗
    
    🔗
    🔗
    🔗
    The following example shows that the Projection Formula does in fact require an orthogonal basis.
    🔗

    Example 6.4.18 A non-orthogonal basis.

    Consider the basis \(\cB = \{v_1,v_2\}\) of \(\R^2\text{,}\) where
    \begin{gather*} v_1 = \begin{pmatrix} 2 \\ -1/2 \end{pmatrix} \qquad v_2 = \begin{pmatrix} 1 \\ 2 \end{pmatrix}\text{.} \end{gather*}
    This is not orthogonal because \(v_1\cdot v_2 = 2-1 = 1\neq 0\text{.}\) Let \(x = {1\choose 1}\text{.}\) Let us try to compute \(x = x_{\R^2}\) using the Projection Formula with respect to the basis \(\cB\text{:}\)
    \begin{gather*} x_{\R^2} = \mhg{\frac{x\cdot v_1}{v_1\cdot v_1}v_1} + \textcolor{seq-violet}{\frac{x\cdot v_2}{v_2\cdot v_2}v_2} = \mhg{\frac{3/2}{17/4}\begin{pmatrix} 2 \\ -1/2 \end{pmatrix}} + \textcolor{seq-violet}{\frac{3}{5}\begin{pmatrix} 1 \\ 2 \end{pmatrix}} = \begin{pmatrix} 111/85 \\ 87/85 \end{pmatrix} \neq x\text{.} \end{gather*}
    Since \(x = x_{\R^2}\text{,}\) we see that the Projection Formula does not compute the orthogonal projection in this case. Geometrically, the projections of \(x\) onto the lines spanned by \(v_1\) and \(v_2\) do not sum to \(x\text{,}\) as we can see from the picture.
    🔗
    
    🔗
    🔗

    Insight 6.4.20.

    You need an orthogonal basis to use the Projection Formula.
    🔗
    🔗

    Subsection 6.4.2 The Gram–Schmidt Process

    We saw in the previous subsection that orthogonal projections and \(\cB\)-coordinates are much easier to compute in the presence of an orthogonal basis for a subspace. In this subsection, we give a method, called the Gram–Schmidt Process, for computing an orthogonal basis of a subspace.
    🔗

    Theorem 6.4.21 The Gram–Schmidt Process.

    Let \(v_1,v_2,\ldots,v_m\) be a basis for a subspace \(W\) of \(\R^n\text{.}\) Define:
    \begin{align*} 1.\quad u_1 \amp= v_1 \phantom{\dfrac{u_1}{u_1}}\\ 2.\quad u_2 \amp= \hbox to 3.4cm{$(v_2)_{\Span\{u_1\}^\perp}$} = v_2 - \frac{v_2\cdot u_1}{u_1\cdot u_1}\,u_1\\ 3.\quad u_3 \amp= \hbox to 3.4cm{$(v_3)_{\Span\{u_1,u_2\}^\perp}$} = v_3 - \frac{v_3\cdot u_1}{u_1\cdot u_1}\,u_1 - \frac{v_3\cdot u_2}{u_2\cdot u_2}\,u_2\\ \vdots\quad\amp\\ m.\quad u_m \amp= \hbox to 3.4cm{$(v_m)_{\Span\{u_1,u_2,\ldots,u_{m-1}\}^\perp}$} = v_m - \sum_{i=1}^{m-1}\frac{v_m\cdot u_i}{u_i\cdot u_i}\,u_i\text{.} \end{align*}
    Then \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal basis for the same subspace \(W\text{.}\)
    🔗
    🔗

    Proof.
    First we claim that each \(u_i\) is in \(W\text{,}\) and in fact that \(u_i\) is in \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\) Clearly \(u_1 = v_1\) is in \(\Span\{v_1\}\text{.}\) Then \(u_2\) is a linear combination of \(u_1\) and \(v_2\text{,}\) which are both in \(\Span\{v_1,v_2\}\text{,}\) so \(u_2\) is in \(\Span\{v_1,v_2\}\) as well. Similarly, \(u_3\) is a linear combination of \(u_1,\,u_2,\) and \(v_3\text{,}\) which are all in \(\Span\{v_1,v_2,v_3\}\text{,}\) so \(u_3\) is in \(\Span\{v_1,v_2,v_3\}\text{.}\) Continuing in this way, we see that each \(u_i\) is in \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\)
    🔗
    Now we claim that \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal set. Let \(1\leq i \lt j \leq m\text{.}\) Then \(u_j = (v_j)_{\Span\{u_1,u_2,\ldots,u_{j-1}\}^\perp}\text{,}\) so by definition \(u_j\) is orthogonal to every vector in \(\Span\{u_1,u_2,\ldots,u_{j-1}\}\text{.}\) In particular, \(u_j\) is orthogonal to \(u_i\text{.}\)
    🔗
    We still have to prove that each \(u_i\) is nonzero. Clearly \(u_1=v_1\neq 0\text{.}\) Suppose that \(u_i=0\text{.}\) Then \((v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}^\perp}=0\text{,}\) which means that \(v_i\) is in \(\Span\{u_1,u_2,\ldots,u_{i-1}\}.\) But each \(u_1,u_2,\ldots,u_{i-1}\) is in \(\Span\{v_1,v_2,\ldots,v_{i-1}\}\) by the first paragraph, so \(v_i\) is in \(\Span\{v_1,v_2,\ldots,v_{i-1}\}.\) This contradicts the Theorem 14 of Section 2.5; therefore, \(u_i\) must be nonzero.
    🔗
    The previous two paragraphs justify the use of the Theorem 8 in the equalities
    \begin{gather*} (v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}^\perp} = v_i - (v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}} = v_i - \sum_{j=1}^{i-1}\frac{v_i\cdot u_j}{u_j\cdot u_j}\,u_j \end{gather*}
    in the statement of the theorem.
    🔗
    Since \(\{u_1,u_2,\ldots,u_m\}\) is an orthogonal set, it is linearly independent. Thus it is a set of \(m\) linearly independent vectors in \(W\text{,}\) so it is a basis for \(W\) by the Theorem 19 of Section 2.7. Similarly, for every \(i\text{,}\) we saw that the set \(\{u_1,u_2,\ldots,u_i\}\) is contained in the \(i\)-dimensional subspace \(\Span\{v_1,v_2,\ldots,v_i\}\text{,}\) so \(\{u_1,u_2,\ldots,u_i\}\) is an orthogonal basis for \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\)
    🔗
    🔗

    Example 6.4.22 Two vectors.

    Find an orthogonal basis \(\{u_1,u_2\}\) for \(W = \Span\{v_1,v_2\}\text{,}\) where
    \begin{gather*} v_1 = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} \qquad v_2 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    🔗

    Solution.

    We run Gram–Schmidt: first take \(u_1 = v_1\text{,}\) then
    \begin{gather*} u_2 = v_2 - \frac{v_2\cdot u_1}{u_1\cdot u_1}\,u_1 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} - \frac{2}{2}\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    Then \(\{u_1,u_2\}\) is an orthogonal basis for \(W\text{:}\) indeed, it is clear that \(u_1\cdot u_2 = 0.\)
    🔗
    Geometrically, we are simply replacing \(v_2\) with the part of \(v_2\) that is perpendicular to the line \(L_1 = \Span\{v_1\}\text{:}\)
    🔗
    
    🔗
    🔗
    🔗

    Example 6.4.23 Three vectors.

    Find an orthogonal basis \(\{u_1,u_2,u_3\}\) for \(W = \Span\{v_1,v_2,v_3\} = \R^3\text{,}\) where
    \begin{gather*} v_1 = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} \qquad v_2 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} \qquad v_3 = \begin{pmatrix} 3 \\ 1 \\ 1 \end{pmatrix}\text{.} \end{gather*}
    🔗

    Solution.

    We run Gram–Schmidt:
    \begin{align*} 1.\quad u_1 \amp= v_1 = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}\\ 2.\quad u_2 \amp= v_2 - \frac{v_2\cdot u_1}{u_1\cdot u_1}\,u_1 = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} - \frac{2}{2}\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}\\ 3.\quad u_3 \amp= v_3 - \frac{v_3\cdot u_1}{u_1\cdot u_1}\,u_1 - \frac{v_3\cdot u_2}{u_2\cdot u_2}\,u_2 \phantom{\begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}}\\ \amp\qquad= \begin{pmatrix} 3 \\ 1 \\ 1 \end{pmatrix} - \frac{4}{2}\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} - \frac{1}{1}\begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 \\ -1 \\ 0 \end{pmatrix}\text{.} \end{align*}
    Then \(\{u_1,u_2,u_3\}\) is an orthogonal basis for \(W\text{:}\) indeed, we have
    \begin{gather*} u_1\cdot u_2 = 0 \qquad u_1\cdot u_3 = 0 \qquad u_2\cdot u_3 = 0\text{.} \end{gather*}
    🔗
    Geometrically, once we have \(u_1\) and \(u_2\text{,}\) we replace \(v_3\) by the part that is orthogonal to \(W_2 = \Span\{u_1,u_2\} = \Span\{v_1,v_2\}\text{:}\)
    🔗
    
    🔗
    🔗
    🔗

    Example 6.4.24 Three vectors in \(\R^4\).

    Find an orthogonal basis \(\{u_1,u_2,u_3\}\) for \(W = \Span\{v_1,v_2,v_3\}\text{,}\) where
    \begin{gather*} v_1 = \begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix} \qquad v_2 = \begin{pmatrix} -1 \\ 4 \\ 4 \\ -1 \end{pmatrix} \qquad v_3 = \begin{pmatrix} 4 \\ -2 \\ -2 \\ 0 \end{pmatrix}\text{.} \end{gather*}
    🔗

    Solution.

    We run Gram–Schmidt:
    \begin{align*} 1.\quad u_1 \amp= v_1 = \begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix}\\ 2.\quad u_2 \amp= v_2 - \frac{v_2\cdot u_1}{u_1\cdot u_1}\,u_1 = \begin{pmatrix} -1 \\ 4 \\ 4 \\ -1 \end{pmatrix} - \frac{6}{4}\begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} -5/2 \\ 5/2 \\ 5/2 \\ -5/2 \end{pmatrix}\\ 3.\quad u_3 \amp= v_3 - \frac{v_3\cdot u_1}{u_1\cdot u_1}\,u_1 - \frac{v_3\cdot u_2}{u_2\cdot u_2}\,u_2\\ \amp\qquad= \begin{pmatrix} 4 \\ -2 \\ -2 \\ 0 \end{pmatrix} - \frac{0}{24}\begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \end{pmatrix} - \frac{-20}{25}\begin{pmatrix} -5/2 \\ 5/2 \\ 5/2 \\ -5/2 \end{pmatrix} = \begin{pmatrix} 2 \\ 0 \\ 0 \\ -2 \end{pmatrix}\text{.} \end{align*}
    Then \(\{u_1,u_2,u_3\}\) is an orthogonal basis for \(W\text{.}\)
    🔗
    🔗
    🔗
    We saw in the proof of the Gram–Schmidt Process that for every \(i\) between \(1\) and \(m\text{,}\) the set \(\{u_1,u_2,\ldots,u_i\}\) is a an orthogonal basis for \(\Span\{v_1,v_2,\ldots,v_i\}\text{.}\)
    🔗
    If we had started with a spanning set \(\{v_1,v_2,\ldots,v_m\}\) which is linearly dependent, then for some \(i\text{,}\) the vector \(v_i\) is in \(\Span\{v_1,v_2,\ldots,v_{i-1}\}\) by the Theorem 14 of Section 2.5. Hence
    \begin{gather*} 0 = (v_i)_{\Span\{v_1,v_2,\ldots,v_{i-1}\}^\perp} = (v_i)_{\Span\{u_1,u_2,\ldots,u_{i-1}\}^\perp} = u_i\text{.} \end{gather*}
    🔗

    Insight 6.4.25.

    You can use the Gram–Schmidt Process to produce an orthogonal basis from any spanning set: if some \(u_i = 0\text{,}\) just throw away \(u_i\) and \(v_i\text{,}\) and continue.
    🔗
    🔗
    🔗

    Subsection 6.4.3 Two Methods to Compute the Projection

    We have now presented two methods for computing the orthogonal projection of a vector: Theorem 14 of Section 6.3 involves row reduction, and the Theorem 8 requires an orthogonal basis. Here are some guidelines for which to use in a given situation.
    1. If you already have an orthogonal basis, it is almost always easier to use the Theorem 8. This often happens in the sciences.
      🔗
      🔗
    2. If you are going to have to compute the projections of many vectors onto the same subspace, it is worth your time to run Gram–Schmidt to produce an orthogonal basis, so that you can use the Theorem 8.
      🔗
      🔗
    3. If you only have to project one or a few vectors onto a subspace, it is faster to use the Theorem 14 of Section 6.3. This is the method we will follow in Section 6.5.
      🔗
      🔗
